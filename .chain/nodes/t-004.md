# 任务 · 补分析模式建链通道

## 缺口（2026-10-04 实测确认）

- `create_node_impl` / `link_nodes_impl` 对非 dev 工作区一律拒绝（WORKSPACE_MODE_MISMATCH）——**3.2.0 的 MCP 在分析模式无法建节点、无法建边**；
- GUI 人治写通道已于 ADR 0015 删除——此前分析链由人建（旧节点全无 origin，属 legacy）；
- 结果：指南宣称"分析模式的链由 AI 按协议维护"，但 AI 没有写入工具；本工作区本次以**设计稿 §11 bootstrap 通道**建链（origin: bootstrap）。

- 契约增量 + golden 覆盖分析模式建链路径；指南同步。
