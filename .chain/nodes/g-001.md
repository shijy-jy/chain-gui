# 目标 · 完善记忆层

**一句话定位**：把 Engram 的记忆层从"规则容器"打磨成完整的"像大脑一样二次加工"的记忆系统——编码、巩固、存储组织、提取、遗忘、元记忆六环闭环，且每环有可证伪的实验依据。

## 目标原则

- 记忆的可靠性来自**结构约束**（不变量）而非数据量；
- 写路径唯一、痕迹完整——治理权在 AI，**验证权在痕迹**；
- 所有机制沿既有纪律推进：ADR / 契约 golden / 指南版本 / CHANGELOG 四件套。

## 边界原则

- 不优化"正确性"（语义质量由事实校验与人治外部完成），只优化"可及性"与"组织"；
- 不建模 LLM 本身（查询流是外部环境，非自治声明）；
- 权重在校准前只作序数分。

## 当前状态（2026-10-04）

- 第一阶段（源输入建立节点 S1–S4）已落地：3.2.0 部署投入使用，见 d-001 及其任务链；
- 已知缺口：分析模式建链无 MCP 通道（t-004，进行中）；
- 记忆层两个已知缺陷（强度 clamp 归零、墙钟恒空）仍待立项。
