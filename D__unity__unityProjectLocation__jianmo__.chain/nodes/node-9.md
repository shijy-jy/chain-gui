## 技术要点

- **塔身用 bmesh 按轮廓生成**，而不是拼接基础体：`(z, 半径)` 轮廓表 → 内外两层环 → 桥接 + 首尾环面封口 → `recalc_face_normals` 统一法线。这样收分曲线完全可控，装饰带能按同一函数求半径。
- **锐边标记**：Blender 4.1+ 移除了 `mesh.use_auto_smooth`，按角度自动平滑改由几何节点资源实现。正确做法是遍历边、按面夹角设 `edge.smooth`——**锐边属性本身就生效**。
- **入口拱门**：方形切割体 + 拱形柱体分两次布尔。**多壳体合并成一次布尔会失败**（见试错记录）。
- **剖面**：复制塔身后用半空间盒布尔差集，再摆到主塔右侧。

## 试错记录

- 🔑 **矩阵乘法顺序 bug（本次最贵的一课）**

  ```python
  # ❌ 错误：先旋转后平移
  place = Matrix.Translation((0, 6.25, 75)) @ Matrix.Rotation(angle, 4, 'Z')
  ```

  `(T @ R) @ v` 是**先旋转、后平移**。槽的局部几何在原点附近（径向偏移为 0），绕 Z 轴旋转一个在轴上的点 = 没旋转，最后才被平移到固定的 +Y 位置——**6 个槽全叠在同一处**。

  表症极具迷惑性：布尔**每次都报 `{'FINISHED'}`**、面数稳定增长（694→790），但只有一处出现几何，且重复布尔在重合几何上让面数虚涨到 1048。

  正确写法是先平移出去、再绕轴旋转：`Matrix.Rotation(angle,4,'Z') @ Matrix.Translation((0, MID_R, CROWN_Z))`。

- ❌ **多壳体合并成一次布尔 → 返回空集**，塔身被整个清空（686 面 → 0 面）。诊断显示单壳体法线正常（有符号体积 +48.52、0 条非流形边）。改为**逐个壳体分别布尔**后稳定。教训：**做破坏性布尔前先备份对象**，之后我才养成这个习惯。
- ❌ **手写合并 bmesh 时用错了索引**：用 `bm_tmp` 的顶点索引去索引 `bm_all` 的顶点列表，6 个壳体全部塌到同一组顶点（合并体积只有 48.52 = 单个槽）。
- ⚠️ **射线验收脚本自己写错了**：切割槽按 +Y 起算角度，射线却从 +X 发射，6 条全部打在柱墩上。**校验工具本身也要被校验**——否则会得出"开口没开"的错误结论。
- ⚠️ **手动摆相机取景反复裁切**：自己算距离/朝向容易失误，`render_preview` 的自动取景（算场景包围盒 + 临时相机）更可靠。手写相机仅用于局部特写。
- ✅ **确定性验证是有效的**：孔位实测 208–278px vs 理论 207.6–285.8；侧视宽高比实测 2.06 vs 理论 2.06；顶视图宽高比 1.452 vs 理论 1.4545。
