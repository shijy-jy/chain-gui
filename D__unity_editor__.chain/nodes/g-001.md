# 目标

做出一个**可用的 Unity 曲线调色工具链**：能抓帧、提取直方图、用亮度/RGB 曲线调节，
并实时看到调节效果；调色语义必须与《曲线调色·一页读懂》笔记一致（S 曲线去灰等）。

工具本体：
- 编辑器侧 `Assets/Project/Editor/CurveGrading/`
- 运行时侧 `Assets/Project/Runtime/CurveGrading/`（抓帧 RendererFeature，**必须在运行时程序集**）
