# 任务目标

掌握 M1：sampling importance resampling（SIR）、weighted reservoir sampling（WRS）、reservoir 数据结构，并理解它们为什么是 ReSTIR 时空复用的地基。

验收（d-001 M1 + g-001 R2-1 的核心一半）：能**独立推导**无偏 RIS 估计量的无偏性条件（M 个候选的权重如何参与、为什么）；能讲清 SIR ↔ WRS 的等价关系；能预判 M 钳制为何引入偏差。

# 理论笔记（自包含，离线可读）

## 1 动机：p ∝ f 常常不可采样

M0 的结论是"最优 pdf ∝ |f|"，但 f 恰恰是要算的东西——直接从 p ∝ f 采样通常不可能。**重采样的思想：先用一个简单的源分布 $p_{src}$ 抽 M 个候选，再按权重 $f/p_{src}$ 从中"再抽一次"**，用两阶段逼近目标分布。这就是 SIR（Sampling Importance Resampling）。

## 2 SIR 与无偏 RIS 估计量（核心推导）

**步骤**：
1. 候选 $Y_1,\dots,Y_M \sim p_{src}$（i.i.d.）
2. 目标未归一化密度取 $\hat p(y) = f(y)$，权重 $w(y) = \hat p(y)/p_{src}(y)$
3. 以概率 $w(Y_i)/W$ 选中 $Y^*$，其中 $W = \sum_{i=1}^{M} w(Y_i)$

**朴素 SIR 有偏但一致**：M 有限时 $Y^*$ 的分布 ≠ $\hat p$（归一化常数未知），只有 $M\to\infty$ 时才收敛到 $\hat p$ 的归一化版本。直接用 $Y^*$ 当目标样本 → 有偏。

**无偏 RIS 估计量**：把归一化常数一并估计——用 $W/M$ 估计 $\hat p$ 的归一化常数 $Z = \int \hat p$（因为 $\mathbb{E}[W/M] = \mathbb{E}_{p_{src}}[w(Y)] = \int p_{src}\cdot(\hat p/p_{src}) = Z$），然后：

$$F = \frac{W}{M}\cdot\frac{f(Y^*)}{\hat p(Y^*)}$$

**无偏性完整推导**（M1 的必背推导）：

$$\mathbb{E}[F] = \mathbb{E}_{c}\big[\mathbb{E}_{J|c}[F]\big] = \mathbb{E}_{c}\!\left[\sum_{j=1}^{M}\frac{w(Y_j)}{W}\cdot\frac{W}{M}\cdot\frac{f(Y_j)}{\hat p(Y_j)}\right] = \frac{1}{M}\sum_{j=1}^{M}\mathbb{E}_{c}\!\left[w(Y_j)\cdot\frac{f(Y_j)}{\hat p(Y_j)}\right]$$

$$= \mathbb{E}_{p_{src}}\!\left[\frac{w\,f}{\hat p}\right] = \int p_{src}\cdot\frac{\hat p}{p_{src}}\cdot\frac{f}{\hat p}\,\mathrm{d}x = \int f = I$$

**关键观察**：选中概率里的 $W$ 与补偿因子里的 $W$ **恰好约掉**——这就是"权重总和 $W$ 必须参与估计"的原因。朴素 SIR 丢掉了 $W/M$，只留下"按目标分布近似选一个样本"，于是有偏。**无偏性来自"选中概率 w/W"与"归一化补偿 W/M"成对出现。**

## 3 WRS 与 reservoir（流式版本）

SIR 需要"先抽完 M 个候选、算完权重和、再选中"——两遍且要存 M 个候选。流式场景（在线到来、逐帧、逐像素）需要 O(1) 空间：

**reservoir 数据结构**（三个字段，ReSTIR 的灵魂）：

```
reservoir = { y, w_sum, M }      // 样本、权重和、候选计数
```

**算法**：对每个新候选 $(y_i, w_i)$：
1. `w_sum += w_i;  M += 1`
2. 以概率 `w_i / w_sum` 用 $y_i$ 替换当前样本

**不变式（归纳可证）**：处理完任意前缀后，`y` 的分布 = 按权重从该前缀中选一个的分布——**与离线 SIR 在同一个前缀上的结果等价**。流式 RIS 估计量与 SIR 同构：

$$F = \frac{r.w_{sum}}{r.M}\cdot\frac{f(r.y)}{\hat p(r.y)}$$

**结论：WRS 把"两遍、存全部候选"压缩成"一遍、O(1) 空间"，分布逐前缀一致。**

## 4 与 ReSTIR 的衔接（M2 预告）

- **reservoir 三字段就是时空复用的 merge 对象**：把邻居像素/上一帧的 reservoir 当作"另一串候选"，流式并入自己的 reservoir——空间复用与时间复用 = 合并 reservoir（M2 的核心操作）。
- **M 无界问题**：历史不断并入 → $w_{sum}\to\infty$ → 新候选被选中的概率 $w_i/w_{sum}\to 0$ → 画面"冻住"。解法是**M 钳制**：$M \le M_{cap}$ 且 $w_{sum} \leftarrow w_{sum}\cdot M_{cap}/M$——但丢弃的那部分权重和就是**偏差**。这是"有偏但一致"交易的又一个实例（辩证卡⑧⑨ 在 M2 兑现）。

# 概念辩证卡：M1 篇（编号接 M0 篇 ①–⑨，格式同 M0：性质对 + 辩证关系 + 你的判定）

## 📌 概念辩证卡⑩：能求值 ↔ 能采样（点查询 ↔ 全局操作）

- **能求值**（管"信息获取"）：给定点 y，O(1) 时间算出 f(y)——渲染里是一条阴影射线。**最便宜的能力**。
- **能采样**（管"样本生成"）：生成密度与目标一致的随机点——是**全局操作**，需要目标在整个定义域的形状。分两档：简单 p 采得了（CDF 反解），$\hat p\propto f$ 采不了（它的 CDF 就是算不出的积分本身）。
- **辩证关系**：求值是局部的、采样是全局的——两者分属不同难度。**RIS 的全部存在理由：只借用"求值"，把"全局的采样"降级为"M 次点查询 + 一次加权抽签"**。反例 $e^{x^2}\sin x$：写得出来、求值纳秒、积分无闭式、不能直接按它采样。
- **你的判定**：❌ "构造 f̂ 近似 f"——p̂ 就是 f 本身（亮度 ρLeG），从头到尾只求值、不近似；且近似 p̂ 也不破坏无偏性（p̂ 只影响方差）。附带结论：p̂ 去掉 V 是**成本账**（无 V 版 $F=(W/M)\cdot V(Y^*)$ 仍无偏，选中补 1 条阴影射线；含 V 版 $f/\hat p=1$ 但每候选 1 条射线变贵）。

## 📌 概念辩证卡⑪：CDF 反解 ↔ 打分重采样（三轴对齐）

- **CDF 反解**（管"采简单 p"）：逆变换法是主力且非唯一（Box-Muller 采高斯不反 CDF、alias、拒绝采样、MCMC）。硬前提：**CDF 要反得出来**。我们代码里的 Malley 法就是它的几何马甲：`r=√u` = 圆盘径向密度 $p(r)=2r$ 的 CDF $r^2$ 反解；`z=√(1-u)` = cosθ 密度 $p(c)=2c$ 的 CDF $c^2$ 反解。
- **打分重采样**（管"采不了的目标"）：$\hat p\propto f$ 的 CDF 反不出来（CDF 就是那个积分）→ 用"源层 CDF 采样 + 目标层打分选中"顶替。
- **辩证关系（三轴对齐表）**：积分轴（解析积分做不到 → MC）/ 采样轴·简单 p（CDF 反解主力）/ 采样轴·p̂∝f（CDF 反不出来 → RIS 打分顶替那个反不出来的 CDF）。**一句话收口：MC 需要能采样 p；能采样 p 的主力是 CDF 反解；p̂∝f 采不了 = 它的 CDF 反不出来；RIS 用打分顶替了这最后一个反不出来的 CDF。**
- **你的反驳**："采样点不是用 CDF 得到的吗"——**成立**（已承认并修正早前"CDF 与 MC 无关"的易误读表述）。

## 📌 概念辩证卡⑫：概率选中 ↔ 硬过滤（无偏 ↔ 有偏的分水岭）

- **概率选中**：每个候选以 $w_i/W$ 概率被选中，低贡献样本留在池子里只是"概率闭嘴"。选中概率与补偿因子成对出现（W 与 W 约掉）→ **精确无偏**。
- **硬过滤**：删除低贡献候选（或 max-pick 取最大权重）→ 成对结构断裂 → **有偏**（原项目 max-pick 教训："max-pick biases toward the heavy pdf tail；weighted-random is the unbiased paper behavior"）。
- **辩证关系**：无偏性不是一个连续量——是"按概率选中"与"确定性挑选"的**分水岭**。同族的断裂还有 M-cap（被丢弃权重的候选已参与选中、却不在 W 里）——卡⑫ 是理解 ReSTIR 偏差哲学的前置（ReSTIR 篇卡⑰ 同构）。
- **你的判定**：❌ "筛掉低贡献样本"——应为"按权重概率选中"；❌ "f/f̂ 比值不为 1 导致不正确"——标准形式 p̂=f 比值恒为 1，即便不等无偏性也不受损。口诀：**抽候选 → 算权重 → 概率选中 → W/M 归一化补偿**。

## 📌 概念辩证卡⑬：均值收敛 ↔ EMA（RIS 的收敛轴）

- **均值收敛**：N 个独立 RIS 估计等权平均，方差 $1/N$，无遗忘（相机移动清零重来）。RIS 的收敛就是它。
- **EMA**：指数滑动平均，历史权重几何衰减 $(1-\alpha)^k$，稳态方差 $\frac{\alpha}{2-\alpha}\sigma^2$ 永不为零；优点能跟运动。
- **辩证关系**：ReSTIR 的跨帧机制是**时间复用（reservoir 合并）**——论文定位为"temporal accumulation 的泛化"：继承"跨帧累积样本"的职能，载体是合并而非指数平均。**时间复用 ≠ EMA**；它是把均值收敛"赊样本"的思路升级成"借样本本身"。
- **你的判定**：⚠️ "EMA 收敛"——实为均值收敛；✅ 主线（无偏、M 候选、修正因子）全部正确。

## 📌 概念辩证卡⑭：MIS ↔ RIS（组合器 ↔ 采样器）

- **MIS（组合器）**：输入是**可采样策略集** $\{p_i\}$（每个都能抽样+能算 pdf）；输出是"策略集内的稳健组合"（Σw=1 无偏、balance 方差最优）。**它不能凭空造出新分布**——当目标分布不属于任何可采样策略时，MIS 无米下锅。
- **RIS（采样器）**：输入是**任意目标 p̂ + 求值能力**（M1 卡⑩）；输出是"目标的近似样本"。它专门解决"没有任何策略能采样目标"的场景——这是它**不可替代**的位置。
- **RIS 不可替代的三点**：①目标域超出策略集（p̂∝ρLeG：多光源按贡献加权、环境贴图、BSDF×光源乘积——CDF 反不出来，MIS 组合不出来）；②多光源选择（"每像素按贡献选光源"本身就是 RIS 目标）；③流式可合并（WRS 三字段支撑时空复用，MIS 没有跨像素/跨帧合并机制——ReSTIR 的复用地基）。
- **辩证关系（同一复杂场景里分层嵌套、互不替代）**：**MIS 管"给定策略集内的最优组合"，RIS 管"策略集之外的目标采样"**——两者正交。内层（顶点级）：MIS 组合 NEE/BSDF（power heuristic）保证单条路径贡献稳健；外层（样本级）：RIS 按路径贡献从候选池重采样保证抽到的路径高贡献。甚至可以互嵌：RIS 的目标里嵌 MIS 权重（参考实现 lum(f)·wMis），MIS 的策略之一也可以是 RIS 输出。**ReSTIR DI 全用 RIS；ReSTIR GI 两者都用（MIS 内嵌 + RIS 外选）——这就是两者在真实复杂场景中的关系。**

> **数学注（狭义 vs 广义 MIS，2026-08-31 口径定稿）**：共同骨架 $F=\sum_i w_i f/p_i$（$\sum w_i=1$ ⟺ 无偏）。**狭义 MIS**：同域 $(\Omega,\mu)$，$w_i^{bal}=c_ip_i/\sum_j c_jp_j$（同点密度份额）。**广义 MIS**（Sbert 2018 / GRIS 2022）：异域采样 + 映射 $T_i$，公共域诱导密度 $p_i = q_i\circ T_i^{-1}\cdot|J_i|^{-1}$，其余机械不变——**新增的唯一实体是 Jacobian**。落点：DI 空间复用的 target-ratio = 广义 MIS 的 $T=id,\ J=1$ 特例（策略 = 邻居蓄水池隐式分布 $q_j\propto\hat p_j$；$\frac{f_{cur}}{q_j}\propto\frac{\hat p_{cur}V}{\hat p_j}$，归一化常数被 W/M 吸收，只需精确到常数倍）；GI/GRIS 移位映射 = $J\neq1$ 的完整形态。**完整数学对比见 G:\learning 知识库 [方案 · SIR重采样] 附录。**
