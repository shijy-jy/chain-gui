# 工程最终目标

帮助用户**完全学会**路径追踪的时空复用 **ReSTIR DI/GI**。

> 注：用户原话为"ReSTRI"，正确拼写为 **ReSTIR**（Spatiotemporal Reservoir Resampling）。目录名 `RESTRI` 保留不动，图内一律使用 ReSTIR。

# 原则清单（为什么 / 刚性 / 弹性 / 边界）

## 为什么

"完全学会"不等于"看过论文"。它意味着：**理论能独立推导、实现能独立写出、演进能独立判断**。

## 刚性约束（不可妥协，验收的唯一标准）

- **R1 图谱必须离线可用**：全部知识结论必须自包含地沉淀在节点正文里；节点正文不依赖任何外部链接即可读懂；引用的论文/资料以书目形式记录（标题/作者/年份），其关键要点必须写在链内。
- **R2 完全学会的可检验标准**（四个里程碑级命题，全部通过才算达成目标）：
  1. **理论层**：能不查资料讲清 RIS（sampling importance resampling）与 WRS（weighted reservoir sampling）的推导、ReSTIR DI 的时空复用机制、无偏性条件与有偏化（流式/M 钳制）的原因。
  2. **DI 实现层**：独立写出一个可运行的 ReSTIR DI 参考实现，并用它渲染出与光采样/BSDF 采样对比正确的图像。
  3. **GI 实现层**：独立写出 ReSTIR GI 实现（path resampling + reconnection），渲染正确图像。
  4. **扩展层**：能讲清 GRIS（广义重采样）等后继工作的演进逻辑——知道 ReSTIR 的局限在哪里、后继工作补了什么。
- **R3 真实性**：不以"读了一篇论文"冒充"学会了"；每个里程碑必须有可检验产物（代码 / 渲染图 / 讲解稿）并通过 v 节点验收。
