> 触发：UI 乱码修复；字体 DPI 现代化

# 用户反馈

"现在的 UI 运行后有些字体没有正常显示，显示的是乱码，能不能引入额外的工具使得整个 ui 现代化"

# 根因分析

- 已查证 vcxproj：CXX 编译项带 `/utf-8`（CMakeLists 的 generator expression 生效）→ **排除编译字符集问题**
- 乱码来自**字体环节**：原方案 = 默认像素字体(ASCII) + msyh 合并(CJK)。msyh 合并失败（加载失败/合并配置异常）→ 中文退化到无 CJK 字形的默认字体 → 问号/乱码

# 方案：不换工具（ImGui 就是主流渲染器调试 UI 标准），做三件事现代化

1. **单一现代字体**：微软雅黑直接作主字体（自带 ASCII+中文，观感统一），不再"默认字体+合并"；候选链 msyh.ttc → msyh.ttf → simhei.ttf；自定义 glyph ranges（Basic Latin + 通用标点 + CJK 标点 + 0x4E00-0x9FFF + 全角）
2. **DPI 高清适配**：`ImGui_ImplWin32_EnableDpiAwareness()`（Per-Monitor V2，建窗前调用）+ 字体/样式尺寸 × dpiScale（`GetDpiScaleForHwnd` + `ScaleAllSizes`）→ 高分屏不再模糊
3. **防乱码兜底**：`cjkLoaded_` 标志 + `T(zh, en)` 双语标签 lambda → 字体加载失败时全部标签自动退回英文（彻底消灭乱码）

# 文件改动

- `application.h`：+cjkLoaded_/dpiScale_
- `application.cpp`：initialize 建窗前 EnableDpiAwareness；initImGui 单一字体 + 候选链 + 自定义 ranges + ScaleAllSizes；renderImGui 所有中文标签改 T() 双语

# 验证点（用户）

1. 中文正常显示（微软雅黑字形，无方框/乱码）
2. 控制台日志 `[UI] font loaded: C:/Windows/Fonts/msyh.ttc (dpi x.xx, size xx)`——若显示 NOT found 请把日志发来
3. 高分屏（125%/150%）下 UI 锐利不模糊
4. 万一字体全失败 → 界面自动英文，不乱码
