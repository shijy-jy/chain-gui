> 触发：chain-gui 力导向标定；堆叠爆开钳制

# 用户反馈

选完文件夹加载时节点全部堆在一起；点击一下所有节点爆开。问：是否应给受力移动加钳制？（并询问此前的术语替换是否动了源码——没有：只改了 ai_workspace 文档、alive_data 链节点、渲染器注释，chain-gui src 未动）

# 根因（数学验证）

1. **堆叠**：默认斥力 6000 + 弹簧刚度 0.15 + 理想长 120 → 平衡方程 K/d² = SPRING×(REST−d) 解 d≈21px，小于节点直径 → 相连节点塌缩成堆
2. **爆开**：近距离 K/d² 无钳制（d² 下限 4 → 单帧力 1500）→ 拖动松手重排时速度爆炸
3. 散点圆环未首帧写入 → 加载瞬间有 (0,0) 堆叠画面

# 修复（提交 387d4c9，已推送）

1. 斥力默认 30000（范围 2000-80000）：新平衡距离 ≈55px，铺开不塌
2. **单次力上限 MAX_F=60 + 每帧位移钳制 MAX_STEP=10**：任何参数下都不会飞出/爆开
3. 散点首帧立即写入 position：加载即圆环
4. 冷却 0.985→0.97、迭代 700→400（~2.5s 收敛）
5. 节点集合签名 lastSig：watcher 重推同一批节点/滑条调整 → 从当前位置续排（scatter=false），不再随机重散

# 教训

力导向的默认参数必须**先解平衡方程**再定值；所有基于 1/d² 的力都要做**双钳制**（力上限 + 位移上限）——这是 d3-force 等成熟库都内置的防护。
