# 实际做了什么

通读天空/水面/水下三部分代码，产出有代码依据的优化方案（已交付，待用户评审）。

## 关键结论（见 evidence 优化方案文档）

- **现状诊断 7+4+4 项**：大气散射是"平面地球近似家族"（平面垂直 LUT + 4 步积分 + 拍脑袋多散射公式 + 每帧 128²×6 cubemap 重算 + 太阳盘低分辨率烘焙 + CPU/GPU 不同构 + 无预滤波）；水面 4 项；水下 4 项（半分辨率 Pass 已规划未实施等）
- **核心优势**：windy 工程已有球形 (r,μ) LUT + 球面单次散射 + per-pixel 太阳盘——解药在自己仓库
- **方案**：P0-1 球形模型移植 / P0-2 Bruneton 多散射 / P0-3 干掉每帧 cubemap（改 per-pixel sky + 降频 cubemap）；P1-1 环境一致性 / P1-2 cubemap 预滤波（代码 TODO 落地）/ P1-3 水下增强（半分辨率 +50% RM、God Rays、界面、参数分层）；P2-1 参数与美术面板（物理/艺术分层 + 预设 + 实时调参面板，移植 render_unified_oss 模式）/ P2-2 焦散调优
- **实施分期**：阶段 1 = P0 大气三大件 → 阶段 2 = P1 → 阶段 3 = P2
