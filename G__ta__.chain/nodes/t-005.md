# 实际做了什么

通读主内核 path_trace_gpu_backend.cu（2586 行）的 ReSTIR DI/GI 全链 + 降噪层三件套（temporal_reproject / svgf_atrous / restir_simplified），重建了从渲染方程到实时帧的完整技术决策链。

## 关键结论（见 evidence 案例深挖文档）

- **ReSTIR DI 链**：候选（4 样本 + per-sample G-reject 贴灯奇异点防御 + RIS p̂=ρ·ndotl·Le·G·Vis）→ 时序（重投影 + 深度/法线门控 + 重评估作有效性闸门 + **M-cap 权重重缩放 Bitterli 2021** + 累积 wSum 合并——实测重评估权重压暗 23%）→ 空间（k=4 固定邻居 + 门控 + 不做可见性重追踪，省 0.9ms，注释明示恢复路径）→ 着色 f/p̂·(wSum/M)
- **ReSTIR GI 链**：路径储层存顶点（x1/n1/alb1/x2/n2/alb2/beta0/flags），6 类路径 flags；金属导体菲涅尔（铝 η/k）；玻璃 3 段穿透循环 + TIR；漫反射 x1 撞灯丢弃（双计 +10..24% 实测）；镜面 x1 撞灯保留；NEE 用 MIS balance 钳制 1/dist²；时序/空间**全储层合并**；玻璃透明阴影射线
- **SVGF**：3-check clamp + 颜色钳制 [μ-γσ, μ+γσ] + moment 方差 + 方差引导 a-trous（核 {1,2/3,1/6}、方差传播 sum(w²var)/(sum w)²、发射体边界门控 t-021）；修复 off-by-one（像素 900→899）与背景像素法线误拒（9.5% 永不累积）
- **工程**：BVH 发射体快路径、PCG32 + 自研蓝噪声（bit-verified）、CUDA-GL 互操作 PBO 双缓冲、11 参数实时调参、dbgCounters + 单像素追踪
- **性能**：~95ms/帧 @720p（RTX 4060 Laptop），模式 3（CPU 128-pass）作 Ground Truth 对照
