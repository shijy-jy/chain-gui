> 触发：chain-gui 案例拆解；Tauri 工具链；面试案例

# 案例定位

把 chain-gui（工程推进器，Tauri 2 + Svelte 5 + Cytoscape + Rust 桌面工具）拆解成面试可讲案例。这是作品集的"工具链开发（TD/Tooling）"主线——证明 TA 的另一半职能：给工程/美术造工具。

## 已确认的技术全景（读源码核实）

- 桌面壳 Tauri 2.11.3（Rust 后端 + WebView）+ 前端 Svelte 5/Vite/TS + 图谱 Cytoscape + dagre
- 后端 ~2000 行 Rust：scanner（walker 499 / frontmatter 165 / validator 528）、watcher（300ms 去抖）、commands（scan/init/update/fold/snapshot/process_log/ai_guide）
- validator：9 字段逐项校验 + 结构校验（id 唯一/root 唯一/悬空/DFS 环检测去重）+ 手写 Howard Hinnant days_from_civil 日历算法 + 18 单测
- fold：协议红线代码化（failed/blocked 拒绝折叠、非 success 子节点拒绝）、_self.md 自备份、UTF-8 安全截断（中文 100 字节边界测试）
- 工程文化：M1~M11 里程碑闭环、多 AI 协作工作流、BL 缺陷编号、cargo test 40 全绿、v1.1.0 交付内测、v1.3.0 发布

## 讲解叙事线设计（草稿）

1. 一句话定位 + 产品解决的问题（把 markdown 图谱变可视化工程记忆）
2. 架构：为什么 Tauri（vs Electron）→ 前后端职责切分 → 事件流（文件监听 → 重扫 → 校验 → 前端事件）
3. 核心难点逐个：校验器（规则引擎 + 环检测）、折叠（协议红线代码化 + 数据安全）、监听（去抖 + 可测试纯函数）
4. 工程质量：单测覆盖边界（UTF-8/环/多根）、里程碑管理与多 AI 协作、真实 bug 修复案例
5. 元叙事：这个工具正在管理本作品集
