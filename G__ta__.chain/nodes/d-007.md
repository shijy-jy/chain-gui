# 设计要点

基于场景事实（MapMagic 单面地形底面 y=0、海面 Cull Back、可潜相机）与多源参考（Catlike Coding / EG 2024 / 知乎两篇），水下方案分三层：

- **Layer C**：深度逻辑米制修复（岸边泡沫/遮挡正确性的基础）
- **Layer A**：水面 shader 水下分支（Cull Off + Snell 窗口 + 折射真实天空 + 水柱吸收）
- **Layer B**：水下雾全屏后处理（挂 HighFidelity；覆盖地形/水面/窗口天空的统一潜水氛围）

详见 evidence 方案文档。待用户评审后按 C→A→B 实施。
