> 触发：windy 案例拆解；体积云大气散射；面试案例

# 案例定位

把 windy（体积云 + 大气散射天空）拆解成面试可讲案例。与水面渲染主线共享大气散射理论基础（waterrenderer.test 的天空系统），本案例侧重**天空渲染的另一个形态：云**。

## 已确认的技术全景（读源码核实）

- 大气散射：Transmittance LUT（256×128，(r,μ) 非线性映射）+ Rayleigh/Mie/Ozone + HG Mie 相位 + 单次散射积分（LUT 加速太阳透射）+ 太阳盘 + 地面阴影项
- 太阳光衰减：CPU 端 ray march（与 GPU HLSL 数学完全一致）→ 调制 Directional Light 颜色 → 全场景光照与天空一致
- 体积云：全屏 ray march（AABB slab 求交 + 64 步 + 蓝噪声抖动）、密度 = 天气图 × 高度渐变 × 边缘淡出 × 形状 FBM（4 通道 Perlin-Worley 加权）+ 边缘加权细节侵蚀、双 HG 相位（前向 0.6/后向 0.2）、8 步向日光步进吸收、Beer-Lambert 合成、T<0.01 提前退出
- 大气耦合：CloudAtmosphereBridge 桥接层（坐标系转换 + LUT 查询，编译期可禁用）——云的光照来自大气透射 LUT 而非固定光色
- 工具：InteractiveEditor 实时调参（242 行）、程序化 fallback 纹理生成（Perlin/Worley 4-pass Blit 切片）、3 种调试模式

## 讲解叙事线设计（草稿）

1. 一句话定位 + 与水面案例的关系（同一个大气散射理论的两个消费端）
2. 大气散射：为什么 LUT 预计算（Bruneton 方法）→ (r,μ) 参数化与非线性映射 → 单次散射 + 太阳盘
3. 全场景光照一致性：太阳光衰减的 CPU 端镜像实现——天空、云、场景物体共享同一透射模型
4. 体积云：密度模型（Perlin-Worley 为什么是事实标准）→ ray march → 双 HG → 向日光步进 → 大气耦合点（GetAtmoSunColor）
5. 工程：fallback 纹理生成、调试模式、InteractiveEditor
