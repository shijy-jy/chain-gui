> 触发：chain-gui 力导向布局；神经元式铺开

# 用户反馈

"我希望的节点之间吸引排斥是所有节点，不是有关系的节点……就像神经元链接一样，现在的节点吸引排斥调节后只是有关系的几个节点有变化导致全局变成一个个的团块，看不出联系"

# 根因

cose 布局在链式（树状）图上：边吸引强、有效排斥弱 → 每条链缩成一个团，团与团之间只被弱斥力推开 → "一个个团块"。调节滑条只改变团内形状，全局结构不变。

# 方案：自研 d3-force 风格全局力导向（零新依赖，替换 cose）

物理模型（App.svelte，~130 行）：

1. **全节点两两库仑斥力** F = K/d²（O(n²)，n≈50-200 无压力）—— 正是用户要的"所有节点互斥"
2. **边弹簧吸引** F = 刚度 × (当前长 − 理想长)，沿边方向 —— 相连节点聚而不塌
3. **弱中心引力** 0.05 —— 防整体漂移
4. 阻尼 0.86 + 冷却 alpha×0.985/帧 + 700 帧上限 → 收敛后自动 fit 视野
5. 初始散点：圆环 + 随机抖动；写回用固定 nodeArr（toArray 一次，成员在模拟期间不变）

三滑条直接映射物理参数：
- 排斥 = K（1000-15000，默认 6000）
- 引力 = 弹簧刚度（0.05-0.6，默认 0.15）
- 边距 = 弹簧理想长度（80-260，默认 120）

交互：
- 拖动节点：grab → stopForce；free → runForceLayout(scatter=false) 从当前位置续排
- 点击聚焦/滚轮缩放/图例（v1.4）保留；点击时先 stopForce 避免与镜头动画抢位
- onDestroy 取消 rAF
