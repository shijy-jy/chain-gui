# 已实施改动（water 工程）

## 大气散射（共享基础设施）

- 🆕 `Atmosphere/Shaders/MultiScatterLUTGen.compute` — 多散射 LUT（32×32，Bruneton 2017 迭代结构各向同性简化，2 次迭代，适配 windy 参数化 (r,μ)/rho-H 映射）
- 🆕 `Atmosphere/Shaders/SkyCubemapGen.compute` — 天空 Cubemap（128²×6，球形单散射 16 步 + 多散射 + 太阳盘，Unity/D3D 标准面方向约定）
- ✏️ `Atmosphere/Shaders/AtmosphereLib.hlsl` — SingleScattering / SingleScatteringToPoint 加多散射源项（σ_s × I_sun × LUT_ms × T2）
- ✏️ `Atmosphere/Scripts/AtmosphereConfig.cs` — multiScatterStrength + cubemap 分辨率/更新阈值
- ✏️ `Atmosphere/Scripts/AtmosphereController.cs` — MS LUT 生成（init + config 变更）、天空 cubemap 按需生成（太阳角度/观察者高度阈值）、SetGlobalTexture("_SkyCubemap")、释放管理

## FFTVerify 水面接线（真正的目标）

- ✏️ `WaterSplit/FFTVerify/FFTOcean_Render.shader` 三处：
  1. **真实天空反射**：`GlossyEnvironmentReflection`（URP 探针）→ 大气 `_SkyCubemap`（粗糙度→mip），cubemap 未生成时回退探针
  2. **波峰微高光**：超窄 Beckmann 瓣（roughness×0.35）叠加到现有高光，FFT 斜率细节驱动
  3. **海天衔接**：指数雾的固定 `_FogColor` → 视线方向地平线天空色（采样 cubemap，85% 权重），未生成时回退原雾色
