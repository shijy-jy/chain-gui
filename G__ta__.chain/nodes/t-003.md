## 盘点结论（含金量评估：本工程为当前最高价值渲染资产）

### 项目本质

四模式自研渲染器，同一 Cornell Box 场景，零第三方渲染依赖（GLEW 仅加载扩展；GLM/rapidobj/Cornell 模型按协议注明）：

| 模式 | 技术 | 定位 |
|---|---|---|
| 1 RasterCPU | 重心插值光栅化 + z-buffer + 4x SSAA + Lambert/Blinn | 教学基线 |
| 2 RasterGPU | CUDA 光栅化（一像素一线程） | 教学基线 |
| 3 PathTraceCPU | CPU 路径追踪，128 pass 渐进式，BVH + MIS + NEE | **渐进式 Ground Truth** |
| 4 PathTraceGPU | 实时 GPU 路径追踪：**ReSTIR DI + ReSTIR GI + SVGF 降噪**，~95ms/帧 @720p（RTX 4060 Laptop） | **实时展示** |

### 核心实现确认（已读源码核实）

- **真 ReSTIR DI**：4 样本候选生成 → RIS 目标 = (bc/π)·ndotl·Le·G（真实贡献）→ 时序复用（M-cap）→ 空间复用（k=4 邻居 + 深度/法线门控）→ **Bitterli 2020 全储层合并**（wSum+M 整体合并）→ final shade f·(wSum/M)/p̂
- **真 ReSTIR GI**：4 样本池 RIS、x0→x1→NEE@x1/x2 路径、MIS balance 权重、时序+空间全储层合并——甚至处理了玻璃透射、金属镜面反射光源、发射体主光线的边界 case
- **SVGF（Schied 2017 忠实实现）**：3-check clamp（视口/深度/法线）+ 颜色钳制 [μ-γσ, μ+γσ]（γ=1.0）+ moment 方差累积 → 方差引导 a-trous（color weight = exp(-|ΔL|/(COLOR_PHI·√var))，核 {1, 2/3, 1/6}，方差传播 sum(w²·var)/(sum w)²）
- **工程成熟度证据**：代码内嵌 [BL-日期-编号] 缺陷修复记录（引用论文：Bitterli 2020、Schied 2017；off-by-one 像素映射、背景像素法线 gate 误拒 9.5% 像素、TheVaffel 参考实现 phi_color 未使用 bug、发射体光晕 t-021）；调试计数器（viewportRej/depthRej/normalRej/accept）+ 单像素调试追踪；自研 blue-noise 生成脚本（bit-identical 验证）；OptiX 降噪器作为对照；11 参数实时调参面板
- 代码注释全英文（nvcc + codepage 936 兼容）——开源工程意识
