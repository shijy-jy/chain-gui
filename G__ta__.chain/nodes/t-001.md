> 触发：技术美术项目素材盘点；7 个 Unity 工程勘察

# 实际做了什么

勘察 `D:\unity\unityProjectLocation` 全部 7 个 Unity 工程（统一 2022.3.62f1c1），结合目录结构、脚本清单与 git 历史完成盘点。

## 盘点结论

### 主线一：水体渲染（核心资产，面试含金量最高）

- **waterrenderer.test**（git 历史 2026-06-26 ~ 07-02，有完整文档体系）：水面渲染器测试工程。WaterRenderSystemV2 + OceanFFTGenerator + SeaFloorGen + VolumetricSkyManager；Deprecated 目录保留完整迭代痕迹（TAA 升采样、体积天空、Cubemap 计算通道）。git 历史含：FFT 海浪频域 Gerstner 位移、非线性增强、白沫、毛细波双速率、Per-Pixel Jacobian 法线、水下体积、深度颜色渐变、HDRI Cubemap 工具等
- **water**（2026-08-11，最大工程，195 cs / 47 shader）：完整场景级工程。自研 WaterSplit 模块：FFTVerify（FFTOcean_Complete/Render/SpectrumVerify）、Water（WaterRenderPipeline、WaterRenderSystem、WaveEngine、焦散系统、涟漪系统、MaterialBridge）、Seafloor、Scanner（地形深度扫描、WaterFillPlane）；Legacy 保留 Gerstner 动画器与频谱生成器演进痕迹；集成 MapMagic（地形插件）、Pure Poly（资产）
- 两者关系：waterrenderer.test 是验证/试验场，water 是整合落地版

### 主线二：GPU 流体模拟与并行计算（核心资产）

- **particle**（git 历史 2026-07-18 ~ 07-20）：技术演进完整：SPH → PBF（Macklin & Müller 2013，参考 kuriishi 实现）→ FLIP（particle-grid hybrid，参考 lamp-cap/Unity_FLIP_Fluid_Simulation）。自研 GPU 并行原语：GPUPrefixScan、GPURadixSort、GPUFiltering；Sort 模块含 DeviceSort / OneSweep 现代 GPU 排序；MarchingCubesGPU + ImprovedPerlinNoise 渲染
- **finall_particle**（2026-08-16，今天刚整理）：particle 的成品精简版（GPU_FLIP + MarchingCubesGPU + GPUUtil），7 cs / 21 hlsl——疑似最终作品版

### 主线三：天空大气与体积云

- **windy**（2026-07-17）：体积云渲染（VolumetricCloudFeature/Renderer + InteractiveEditor）+ 大气散射天空/雾（AtmosphereSkyRendererFeature、AtmosphereFogRendererFeature、AtmosphereLib.hlsl、CloudAtmosphereBridge）
- **windtest**：空工程（仅 TutorialInfo），无讲解价值，忽略

### 补充案例：游戏工程

- **DreamGame**（2026-07-17）：叙事互动游戏（StoryEngine、SaveSystem、AudioEngine、GestureDetector、VisualStyleSystem、情绪记录/视觉风格切换 UI），3 shader。非渲染向，可作"工程与玩法系统能力"的补充案例
