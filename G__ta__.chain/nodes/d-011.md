# 16 讲课程映射

1. 光线步进基础（球体 + sphere tracing + 天空渐变）
2. 基本图元（球/盒/圆角盒/胶囊/圆环/圆柱/圆锥/平面/棱柱/椭球, 时间切换展示）
3. 布尔运算（并/差/交 + 平滑三件套 opSmooth*）
4. 变换（平移/旋转/缩放 opMove/opRotX/Y/Z/opScale）
5. 域重复（opRep/opRepLim 网格阵列）
6. 对称（opSymX/Y/Z + 无限重复组合）
7. 变形（位移/扭转/弯曲）
8. 法线与光照（四面体法线 + 兰伯特/高光/菲涅尔）
9. 软阴影与 AO（calcSoftshadow/calcAO）
10. 材质与多物体（SDF 返回 float2(距离,材质ID) 多材质场景）
11. 动画（时间驱动旋转/呼吸/相机运动）
12. 综合1：柱廊大厅（域重复+布尔+软阴影+AO 组合）
13. 综合2：发光体（辉光/菲涅尔边缘光）
14. 综合3：山脉地形（噪声地形 SDF + 分层着色）
15. 综合4：体积云（噪声 SDF + 密度积分）
16. 总结：完整场景合成

# 技术约定

- Quad(8×8) + `UNITY_MATRIX_I_P` 反投影重建视线（NDC→视空间→世界空间）
- URP 兼容: `UniversalPipeline` tag + Core.hlsl + HLSLPROGRAM
- castRay: 64 步 sphere tracing, 命中阈值 0.001, 最大距离 50
