> 触发：chain-gui 图谱交互；自适应缩放聚焦图例

# 需求（基于多轮使用经验）

自适应 UI/节点位置；滚轮缩放全局（节点多时放不下）；点击节点自适应看到节点+邻居；参考 Obsidian 图谱的点击动态与引力/斥力开放调节；节点颜色在 UI 上有图例提示；节点大小对比不要太明显。

# 实施（源码 G:\test1.x，提交 274fbde）

1. **点击聚焦（Obsidian 式）**：tap 节点 → 全图 addClass('focus-dim') 淡出（node 0.10/edge 0.05 + text-opacity 0）→ closedNeighborhood 点亮（focus-lit，edge 提亮加粗）→ `cy.animate({ fit: { eles: nbh, padding: 110 }, duration: 450 })` 平滑缩放聚焦；点空白/关闭侧栏/保存/折叠 → 解除聚焦；transition 0.25s（property 白名单）
2. **滚轮缩放**：`wheelSensitivity 0.3 / minZoom 0.08 / maxZoom 4`（默认即开启，现在范围更实用）；右下角 +/−/⤢ 按钮
3. **力导三参数开放**：排斥力/引力（已有）+ 新增**理想边长**滑条（60-240，与节点数自适应叠加）
4. **颜色图例**（左下角可开关）：4 类型配色 + 状态样式提示（发光=进行中/红=失败/半透明=待开始/虚线=阻塞）+ "大小=连接数（平缓）"+"点击=聚焦 · 滚轮=缩放" 使用提示
5. **大小对比缓和**：`16 + degree*6` → `14 + min(√degree,6)*4`（14-38px 封顶）
6. **自适应**：工具栏 flex-wrap 换行；Sidebar `width: min(360px, 92vw)`
