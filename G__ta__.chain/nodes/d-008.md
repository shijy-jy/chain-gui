> 触发：water 展示点筛选；技术美术双维度

# 展示点筛选（面试口径）

## 主展示（技术深度 + 美术表现双高，按叙事顺序）

1. **大气散射系统**（AtmosphereLib / Skybox / Fog / 3 个 LUT）
   - 技术：Rayleigh/Mie/臭氧单次散射积分；透射率 LUT 的 (r,μ) 参数化（sqrt μ + rho/H 映射）；Bruneton 多次散射近似（各向同性 32×32 LUT）；天空 cubemap 128²×6；空气透视全屏雾统一色调；km 单位
   - 美术：太阳高度驱动全天颜色变化；雾与天空同源
   - 卖点：从移植 windy 到自研改进（多次散射、cubemap、雾桥接）的过程叙事
2. **FFT 海洋**（FFTOcean_Complete / FFTOcean_Render / SpectrumVerify）
   - 技术：Phillips 频谱 + 高斯随机 + GPU IFFT（ping-pong 蝴蝶）；choppy 位移；频谱离线验证（EXR 统计）
   - 美术：风/振幅/波长 → 湖面到风暴海
   - 注意：渲染侧深度逻辑基线有 3 处翻转（t-021），当前按用户约束不动 shader——展示聚焦"频谱生成与验证"
3. **水下后处理**（UnderwaterEffect，纯后处理零水面 shader 改动）
   - 技术：每像素深度重建 + 视线-水面求交；Snell 窗口 48.6° 临界角 + refract(eta=1.33, N 朝入射介质)；折射线复用大气 SingleScattering（系统桥接）；Beer-Lambert + 距离雾
   - 美术：能见距离/深水色/太阳辉光中文面板
   - 卖点：约束驱动设计（Cull Back 从下不可见 → 后处理合成）+ 参数口径设计

## 过程类加分（面试故事）

4. **左右镜像调试**（t-023）：假设-验证-二分-根因（_BlitScaleBias 缺失）-修复-回归，完整方法论展示
5. **参数面板设计**：能见度(米) 替代 吸收系数(1/米)——TA 为美术翻译物理量
6. **验证手段**：SpectrumVerify 离线 EXR；水下品红诊断色；备份/回滚纪律

## 不主展示（避坑）

- MapMagic 地形（第三方，讲不出设计）
- 没吃透的拼接代码（面试深挖风险）
- 误诊路径（天空盒 roll 尝试）→ 只可作"失败教训"小故事，不作成果

## 叙事线（一个连贯故事）

光从哪来（大气散射）→ 光与海面如何互动（FFT 频谱）→ 光入水后发生什么（Snell/Beer-Lambert 后处理）→ 美术怎么调（参数面板）→ 我怎么证明它对（验证与调试）
= 从物理 → 画面 → 工具 → 验证 的 TA 能力闭环。
