# 管线数据流（吃透）

```
云容器 Cube (200×20×150, Layer10, 仅 RenderPass 直接 DrawRenderer)
  ↓ CloudMarching.shader (MRT 双目标, 每像素 256 密度步 × 8 光步)
      color0(RGBAFloat) = (云位置估计, 密度)      ← 密度=Σ饱和累积
      color1(RGBAFloat) = (运动向量, 光照强度)    ← 光照=曲线查表(平均深度)
  ↓ CloudRendering.shader (Blit → ARGB32): rim=Light^RimPower×2, dark=(1-Light)^DarkPower,
      前向散射=dot(viewDir,LightDir)^Power, alpha=密度
  ↓ BilateralBlur (ping-pong ×4): 3×3 稀疏采样 + 空间/色调高斯权重
  ↓ TAA.shader: 重投影(cloudPos-运动向量→上一帧VP→prevUV), 拒绝(出屏/位置差>1→blend=1), EMA 0.05
  ↓ BlitCloudToScreen (SrcAlpha OneMinusSrcAlpha 混合到 cameraColor, 无深度遮挡)
```

# 代码级问题清单（优化依据）

1. **RayBoxDistance NaN 隐患**: `1.0/ray` 分量=0 → inf → 0×inf=NaN（windy 同款病）
2. **光步进量纲错误**: `depth/=_LightIteration` = 平均密度而非 ΣD×步长——光照衰减曲线靠人肉拟合补偿
3. **密度求和饱和**: `cloudDensity=saturate(Σd)` 非透射率累积 → 深处快速饱和, 无厚度感
4. **性能**: 最坏 256×8=2048 噪声采样/像素; 光步进仅 `lightIntensity>=1` 才早退
5. **共享材质污染**: `sharedMaterial.SetVector/SetTexture` 每帧改项目资产（EditMode 持久化风险）
6. **BilateralBlur 资源泄漏**: GetTemporary 的 RT 用 `.Release()`（应为 ReleaseTemporary）
7. TAA 设计合理（静态相机靠噪声动画 EMA 收敛; 拒绝路径正确）——**这是 windy 没有的资产**
8. 云无深度遮挡（参考版设计, 可接受）; 旧版 cmd.Blit API（URP14 shim 可跑）

# 优化方案（成为"我们的项目"）

# 性能优化（r8, 用户反馈设备很卡）

卡点分析：最坏每像素 256 密度步 ×(5+8×5)=**11,520 次纹理采样**（云盒 20m 内密集步进 ×3D 纹理采样贵）
1. **光步进廉价密度 SampleLightDensity**：5 采样 → 2 采样（高度曲线A+3D噪声A；光照是低频量——HZD 同思路）
2. **默认值重调**（面板/场景/.mat 三处同步）：densityIteration 256→160、lightIteration 8→6、lightOdEarlyExit 3→2.5
3. **cloudDownSample 2→4**（renderer 资产）：整链 1/4 分辨率（云天然模糊，视觉损失小）
4. **bilateralBlurIteration 4→2**：模糊开销减半
综合最坏路径 ~16× 加速（256×45 → 160×17 且像素数 1/4）；质量档位可面板回升
注意：用户已自己改过场景——所有改动前先读当前实际值，未覆盖用户调参

# 天空-云耦合 + 质量档位（r11, 用户: 云模糊/自然天空）

**数据诊断（云模糊根因）**：云渲染于 cloudDownSample=2（半分辨率）+ 双边模糊 4 次迭代（radius 2, tonalWeight 0.1）→ 半分辨率放大到全屏 + 模糊 = 柔和发虚；采样确实降了（参考架构本身就是半分辨率设计，靠 TAA 补偿）。

**实现**：
1. **云环境光采样天空 Cubemap**（真同源光照）：CloudRendering 新增 Tex2DArray 面映射函数（Unity/D3D 约定, 与 SkyCubemapGen 逐面对应）+ `_UseSkyAmbient` 开关——ambientDir = 天顶×0.75 + 太阳方向×0.25，云暗部颜色随天空/日落自动变化
2. **运行时质量档位**（面板 ⑨）：RenderPass 新增静态覆写 DownSampleOverride/BlurIterationOverride（-1=用资产 setting）；面板新增 renderDownSample(1/2/4, 默认2) + blurIterations(0-6, 默认4) + useSkyAmbient(默认开)——**不降效果原则下默认行为不变，用户可实时切换 1=全分辨率看锐利度**
3. 当前架构行为不变（默认 = 原质量基线），新能力全部面板可选
