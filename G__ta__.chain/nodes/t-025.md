> 触发：水下纯后处理；零 shader 改动

# 用户约束

"退回修改，不要改 shader，只用后处理"——FFTOcean_Render.shader 已回退基线（零改动），水下全部由后处理完成。

# 方案（单 pass 双分支，每像素深度重建判定）

新增 `FFTVerify/UnderwaterEffect.shader` + `UnderwaterEffectRendererFeature.cs`：

1. **视线命中水面**（上行且水面在场景之前，含被剔除地形洞透出的天空像素）：合成"从下看水面"——Snell 窗口（48.6° 几何判定）内 `refract` 折射采样真实大气天空（虚拟观察点），窗外 TIR 深水色，水柱 Beer-Lambert 吸收
2. **视线未命中水面**（看水下场景/地形）：场景色按距离做水下雾 + 朝太阳辉光

关键点：
- Blitter Vert（_BlitScaleBias 翻转校正，t-023 已验证模板）——不会重蹈左右镜像
- 品红诊断：窗口内天空采样失败 → 品红
- 相机 y < waterSurfaceY 才入队（Scene/Game 均生效）

# 用户操作（验收）

1. **URP-HighFidelity-Renderer.asset** → Add Renderer Feature → **Underwater Effect Renderer Feature**（材质留空自动创建，waterSurfaceY=0）
2. Play → 相机移到 y<0：抬头 = Snell 窗口真天空；看地形 = 蓝绿距离雾；品红 = 大气 LUT 未就绪
3. 移回水上：效果自动消失

# 用户反馈："完全没生效，调节参数零变化"（r2 诊断）

接线已核实全部正确：三个 Renderer 资产均有 feature（用户自己添加）、活跃管线 = HighFidelity、shader+meta 已导入。静态核对排除 shader 编译风险（与已验证的 AtmosphereFog.shader 同源结构：core Blit.hlsl 的 Vert/Varyings + `SAMPLER(sampler_BlitTexture)` 重声明、AtmosphereLib CBUFFER 路径 `_Atm_SunDirection` 在 CBUFFER 内）。

**核心判断：pass 从未执行**（若执行，天空区 Snell 分支必改画面）。三入口：
1. 相机 y ≥ 0 门控跳过（测试时是否真的在水下？）
2. 材质 null——`Create()` 时 shader 未导入 → `Shader.Find` 失败 → 材质永远为空。**已加惰性自愈**：AddRenderPasses 内补找（重 Play 自动修复）
3. shader 编译错误 → `Shader.Find` 永久 null → pass 静默不画（画面不变粉，与症状吻合）

待用户回报：Console 是否有 `Shader error in 'URP/Water/UnderwaterEffect'`；y=-2 测试是否仍无变化；若无错误仍无变化 → 删除并重新 Add feature（重触发 Create 双保险）。

# 参数面板中文重组织（r3）

美术直觉面板（Inspector 内中文 Header+Tooltip，全部实时生效）：

- **① 水面**：waterSurfaceY（水面高度，低于即启用）
- **② 水下颜色**：waterFogColor（水体主色/雾色）、**visibilityMeters**（能见距离米, Range 2-60, 默认 10——C# 内换算为每米吸收系数 (3.0,0.8,0.3)/V，10 米时精确还原原默认 (0.30,0.08,0.03)，红光吸收最快）、**underwaterDeepColor**（Snell 窗口外 TIR 深水色——原 shader 硬编码值提出，新增 `_UnderwaterDeepColor`）
- **③ 太阳**：sunGlowStrength（Range 0-2）
- **④ 技术**：renderPassEvent、effectMaterial（美术不动区）

字段变更：Settings.underwaterAbsorption (Vector3) 已删除 → visibilityMeters 替代（旧序列化值自动丢弃，无迁移问题）。shader 仅新增 `_UnderwaterDeepColor` 声明 + lerp 引用，逻辑不变。
