# 案例定位

把 render_unified_oss（C++17 + CUDA 四模式自研渲染器）拆解成面试可讲的技术案例，核心叙事聚焦模式 4：**ReSTIR DI + ReSTIR GI + SVGF 的实时路径追踪管线**。

## 已确认的技术全景（读源码核实）

- 四模式：RasterCPU / RasterGPU / PathTraceCPU（渐进 Ground Truth）/ PathTraceGPU（实时）
- ReSTIR DI：4 样本候选 → RIS（目标 = (bc/π)·ndotl·Le·G）→ 时序 M-cap → 空间 k=4 门控 → Bitterli 2020 全储层合并 → final shade f·(wSum/M)/p̂
- ReSTIR GI：4 样本池 → x0→x1→NEE@x1/x2 → MIS balance → 时序 + 空间全合并 → 处理玻璃/金属/发射体边界 case
- SVGF：3-check clamp + 颜色钳制 [μ-γσ, μ+γσ] + moment 方差 + 方差引导 a-trous（Schied 2017 忠实实现）
- 工程：BVH、PCG32/蓝噪声（自研生成器 bit-verified）、CUDA-OpenGL 互操作、OptiX 降噪对照、11 参数实时调参、[BL-*] 缺陷记录引用论文

## 讲解叙事线设计（草稿）

1. 一句话定位 + 为什么做四模式（教学递进：光栅化 → CPU PT → GPU PT）
2. 渲染方程 → 路径追踪 → 为什么实时化需要"降采样 + 复用 + 降噪"三件套
3. ReSTIR DI 原理链：RIS → 储层 → 时序/空间复用 → 为什么 M-cap 与全储层合并
4. ReSTIR GI 的设计难点（路径复用、MIS balance、镜面边界 case）
5. SVGF 原理链：方差估计 → 时序累积 → 颜色钳制 → a-trous
6. 调试方法论：dbgCounters + 单像素追踪 + 论文对照修复记录
7. 性能数据 + 复盘
