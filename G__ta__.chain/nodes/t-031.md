> 触发：面板不显示；字体图集超限

# 用户反馈

"重新检索代码。现在面板都不显示了"（t-030 字体/DPI 改动后）

# 根因链（已在 vendored 源码中核实）

1. t-030 自定义字形范围含**全量 CJK 块 0x4E00-0x9FFF ≈ 2.1 万字形**，且未降过采样（默认 3×）
2. 高 DPI（笔记本常见 150%）→ 字号 22.5px → 图集所需面积 ≈ 2.1万 × (22.5×3)² 远超 4096² 上限 → **`ImFontAtlas::Build()` 失败**
3. `GetTexDataAsRGBA32` 返回 NULL/0×0（imgui_draw.cpp L2538 `if (TexPixelsAlpha8 == NULL) Build()` 后仍是空）
4. `ImGui_ImplOpenGL3_CreateFontsTexture` 对 0×0 照样 `glTexImage2D` 并 **return true** → Init "成功"但字体纹理 0×0 → **所有文字消失**：面板变空条、统计卡无字 = 用户感知"面板不显示"

# 修复（application.cpp）

1. 字形范围：`FontGlyphRangesBuilder` = Default(ASCII) + **ChineseSimplifiedCommon（~2500 字，覆盖本 UI 全部标签）**，砍掉全量 CJK 块
2. 过采样 3× → 2×（小字号足够清晰，图集占用可控）
3. `dpiScale_` 钳制 [0.75, 3.0] 防御异常
4. **显式 `io.Fonts->Build()` + 日志图集尺寸**；构建失败 → `Clear()` + 默认字体重建（任何情况下 UI 必有文字）
5. 兜底 HUD：ImGui 层失活时退回 display 位图 HUD 显示状态行（PREVIEW/RENDERING + ms/fps + 按键提示）

# 验证点（用户）

1. 面板/统计卡文字恢复显示（中文）
2. 控制台应有 `[UI] font atlas: <W>x<H>`（正常应 ≤ 4096×4096）与 `[UI] ImGui ready`
3. 若仍不显示：把控制台最后 10 行日志发来（`[UI]` 开头的行是关键证据）

# 教训

ImGui 字体图集是**全局失败点**：图集坏 = 整个 UI 层无文字，且 OpenGL 后端不会报错（0×0 纹理"成功"上传）。任何字体范围变更必须显式 Build + 校验 TexWidth/Height。
