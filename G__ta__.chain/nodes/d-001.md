## 战略转向（用户指示，2026-08-16，仍然有效）

用户确认各工程基于复现/拼接他人代码——作品集策略从"深挖已有代码"转向**"全量优化 + 自主设计"**：逐项目优化并设计自己的参数与美术调节面板，形成真实个人贡献，再更新案例文档、最后统一模拟面试。首个优化对象：waterrenderer.test 大气散射 + 水面/水下渲染（见 d-006 子链）。案例深挖文档（portfolio/01~04）随优化进度修订；模拟面试（v-001~v-004）推迟到优化完成后。

## 方案设计

### 案例深挖链结构（每个案例一组）

```
d-XXX 案例技术拆解与讲解设计（技术方案 + 叙事线）
  ├─ t-XXX 实现细节复盘（读代码 + git 历史，重建关键决策）
  └─ v-XXX 模拟面试验收（QA 预判 + 讲解完整性检查）
```

### 深挖顺序（按面试含金量，修正版）

1. **render_unified_oss** — 实时光线追踪（ReSTIR DI/GI + SVGF）——最高价值资产，实时光追是 TA 面试最热考点
2. **water** — FFT 海洋（JONSWAP + TMA 浅水修正 + 共享内存 IFFT + 曲面细分 + Beckmann/Smith + 四散射项）+ 大气散射（透射 LUT + 多散射 LUT + 天空 Cubemap + 雾桥接）
3. **windtest** — 体积云（11 个渐进学习模块：密度场 ray march + HZD powder + MRT 运动矢量 + TAA + 天空 Cubemap 环境光）
4. **chain-gui** — 工具链开发（TD/Tooling 职能证据，v1.6.1 自研力导向布局）

### 案例模板（每个深挖链的产出物）

1. 项目背景与目标（一句话 + 为什么要做）
2. 技术选型与依据（候选方案对比，为什么选这个）
3. 核心实现（算法原理 + 关键代码路径 + GPU/管线设计）
4. 迭代与踩坑（从 git 历史与 Deprecated/Legacy 目录重建真实过程）
5. 效果与性能数据（参数、帧率、粒子数等可量化指标）
6. 复盘（哪里做得好、哪里可以更好）
7. QA 预判（面试官可能追问的 10 个问题 + 答案要点）

### 载体方案

- 当前阶段：以本 chain 图谱 + 每项目 Markdown 案例文档为产出
- 后续可选：打包为静态站点（VitePress/GitHub Pages）——留作弹性项，不提前投入
- 演示资产：截图/录屏/交互 Demo 按需补充（用户可提供）

## 验收标准

- 每个案例能独立支撑 10-15 分钟完整讲解
- 每个案例有 QA 预判且答案经得起追问
- 讲解内容真实可追溯（代码/git 历史为证）
