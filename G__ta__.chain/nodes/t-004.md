> 触发：chain-gui 盘点；工程推进器

# 实际做了什么

勘察 `G:\test1.x`（注意：是目录不是 .x 文件），确认这是 chain-gui（工程推进器）——Chain Protocol 的可视化编辑工具，即本工程正在使用的软件。通读 README、目录结构、Rust 源码清单与 git 历史。

## 盘点结论（工具链开发主线，TA 面试的 TD/Tooling 方向弹药）

### 项目本质

把 `.chain/nodes/*.md` 图谱文件夹渲染成可拖拽/缩放/点选的关系图谱的桌面工具，含扫描、校验、编辑、监听、快照、折叠、初始化向导、AI 指南管理等完整功能。

### 技术栈

| 层 | 选型 |
|---|---|
| 桌面壳 | Tauri 2.11.3（Rust 后端 + WebView） |
| 前端 | Svelte 5 + Vite + TypeScript |
| 图谱 | Cytoscape + cytoscape-dagre |
| 后端 | Rust：serde/serde_yaml、walkdir（扫描）、notify（文件监听） |

### 架构与规模

- Rust 后端 ~2000 行：model（node/chain/validation）+ scanner（frontmatter 解析 165 行 / walker 499 行 / validator 528 行）+ watcher（115 行，300ms 去抖）+ commands（scan/init/update/fold/snapshot/process_log/ai_guide）
- 前端 Svelte：App + Sidebar + StatusBar + chain_to_cytoscape 转换层
- 测试：scan_chain_test、real_dir_verify 集成测试，**cargo test 40 全绿**
- 打包：NSIS 安装包，v1.1.0 已交付内测，v1.3.0 已发布（活跃链摘要/快照/折叠/项目画像）

### 工程成熟度证据（git 历史 08-12 ~ 08-15）

- **里程碑管理**：M1~M11 全部有任务卡、验收记录（reviews/）、台账（CODE_STATE）闭环
- **多 AI 协作工作流**：ai_workspace/ 下 ai-coordinator 调度 + ai-rust/ai-frontend/ai-qa 分工，每 AI 有加入协议
- **缺陷记录规范**：BL-日期-编号（如 BL-20260815-02 布局竞态：布局锁+前端去抖）
- **自我验收文化**：每次 feat 伴随 self_review + 验收通过后台账翻状态
- 真实 bug 案例：cose 布局参数（nodeRepulsion 45000→8000）、CSS 孤儿属性、AI 操作时节点堆叠竞态

### 与 TA 面试的关联
