> 触发：ImGui 暗色 UI；UE5 Unity 风格

# 需求

"参考 UE5 以及 Unity 或者一些主流渲染器的 UI 设计，帮我优化现在的界面，帮我搞一个小而简洁的学习验证用渲染器"

# 方案：Dear ImGui（v1.91.8, 已 vendored 到 thirdparty/imgui/）

选择 ImGui 的理由：主流渲染器调试 UI 的事实标准；immediate-mode，直接画在 GL 视口里；零外部运行时依赖。

## 界面设计（参考点）

- **暗色主题**（VS/UE 面板配色）：窗口 #19191B、蓝色滑块抓点（UE 强调色）、#1E1E20 控件底
- **中文字体**：加载 `C:/Windows/Fonts/msyh.ttc`（微软雅黑，系统自带）+ GlyphRangesChineseSimplifiedCommon；失败退回内置字体
- **视口统计叠加层**（UE5 风格）：图像右上角半透明暗卡 + 绿色等宽文本（状态/后端名、分辨率+ms+fps、帧号）
- **右侧主面板**（Unity Inspector 风格分区）：
  - 标题 + 状态徽章（PREVIEW 灰 / RENDERING 绿）
  - Start Render（绿）/ Stop（红）大按钮
  - "Mode 渲染模式" radio：4 模式（RasterGPU 光栅预览 / RasterCPU / PathTraceGPU / PathTraceCPU）
  - "Render Params 渲染参数"：11 滑条（名字左、滑条右；拖动暂存、**松手写入** → 下一帧生效，不再需要 Apply 按钮）
  - "Stats 统计" + 底部快捷键提示
- **toast**：图像区底部居中淡出（2.5s）
- 面板 [P] 显隐 → 图像自动扩满；窗口 1600×900 + 面板 320 → 图像区恰为 1280×720（渲染分辨率，信箱黑边最小化）

## 技术改动

- `thirdparty/imgui/`：vendored v1.91.8（imgui core 5 文件 + win32/opengl3 后端 + loader）
- `CMakeLists.txt`：+6 个 imgui 源文件、+include 目录
- `display.h/.cpp`：`present()` 不再 SwapBuffers，新增 `swapBuffers(HDC)`（ImGui 需在图像上屏后、交换前绘制）
- `application.h/.cpp`：
  - 删除 Win32 弹窗面板全家桶（createTunePanel/rebuild/dock/toggle/onTuneScroll/onApplyTune/PanelProc/commctrl）
  - +initImGui/shutdownImGui/renderImGui/syncUiPending/computeImageRect
  - handleMessage：先喂 `ImGui_ImplWin32_WndProcHandler`；WantCaptureMouse/Keyboard 门控相机与快捷键
  - run 循环：图像上屏 → ImGui → 交换；**每帧 updateViewport()**（ImGui 渲染会重置 glViewport）
  - 窗口/渲染分辨率分离：WINDOW 1600×900、RENDER 1280×720（后端与 Display 仍渲染 1280×720）
  - `IMGUI_IMPL_OPENGL_LOADER_GLEW` 复用 GLEW，避免 imgui 自带 loader 与 GLEW 的宏冲突
- 状态机（t-028 双后端常驻 + Start/Stop）语义完全保留
