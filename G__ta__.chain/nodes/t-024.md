# 已实施（FFTOcean_Render.shader，4 处）

1. **深度逻辑米制重写**（t-021 审查的 3 处翻转全部修复）：
   - `depthDiff = LinearEyeDepth(scene) - length(worldPos-cam)`（米，统一约定）
   - `clip(depthDiff)` 水上真正生效（水前物体遮挡水面）
   - `intersect`：水深 < `_ShoreFoamRange`(3m) → 岸边交叉泡沫首次真实生效
   - 深度采样 UV 改用 `pos.xy / _ScaledScreenParams.xy`（URP 规范，废弃顶点手工 y 翻转）
2. **水下视角**：
   - `Cull Off`（水上背面被深度测试自然淘汰）
   - Snell 窗口：`cos(视线,+Y)` vs 48.6° 临界角（纯几何，不依赖面朝向）
   - 窗口内：`refract(toSurface,(0,-1,0),1.33)` 折射方向采样真实大气天空（虚拟观察点规避地表下截断）
   - 窗口外：深水色；水柱吸收就地 Beer-Lambert（无需额外 pass）
   - 天空采样失败 → 品红诊断
3. 新参数默认值：`_ShoreFoamRange=3m`、`_UnderwaterAbsorption=(0.30,0.08,0.03)/m`、`_UnderwaterFogColor=(0.02,0.15,0.20)`
