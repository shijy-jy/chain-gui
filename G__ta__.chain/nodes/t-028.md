> 触发：四模式渲染器启动预览；左右布局状态机

# 需求

"启动程序之后在程序内部有独立按键选择点一下才启动渲染，否则就是一个类似 scene 的预览模式，然后程序内置调参的 ui 面板（左侧是预览页面，右侧是 UI 调参面板），这样启动前或者启动时都能调节"

# 方案（零新依赖, 扩展现有 Win32 面板）

工程 `G:\openGL\render_unified_oss`（备份 `G:\ta\backup\restir-2026-08-17-previewui`）。

## 状态机：双后端常驻

- `previewBackend_`（RasterGPU，失败→RasterCPU）= 预览（类似 Unity Scene 视图，相机可旋转）
- `renderBackend_`（PathTraceGPU，失败→PathTraceCPU）= 渲染后端，**启动即创建但空闲** → 启动前即可调参
- `backend_` = 当前活跃指针；`previewMode_` 布尔状态
- **Start/Stop 按钮只切活跃指针，不重建后端** → 启动前调好的参数不丢（关键设计）
- 键盘 1/2 = 换预览后端；3/4 = 换渲染后端（重建+面板重绑）；与按钮语义一致

## 右侧面板（t-026/t-027 的进化）

- 面板**始终绑定 renderBackend_**（不再绑活跃后端）：预览中调参 = 启动时生效；渲染中调参 = Apply 下一帧生效
- 新增控件：状态行（PREVIEW/RENDERING + 后端名）、Start Render / Stop 按钮
- `rebuildTunePanel()`：渲染后端换新时销毁重建面板（值取新后端）

## 左侧视口

- `updateViewport()`：可用宽度 = 客户区宽 − 面板宽，16:9 信箱适配（画面不被面板遮挡、比例不变形）
- WM_SIZE / 面板 P 键显隐 / 面板重建 时刷新；run 循环每帧 glClear（信箱黑边干净）
- `display_->present()` 画全屏四边形跟随 glViewport，HUD 文字经 ortho 随视口缩放 → Display 零改动

## 文件改动

- `include/app/application.h`：新增双后端成员 + 状态机方法 + 面板按钮成员
- `src/app/application.cpp`：initialize 预览优先；createBackend/switchPreviewMode/switchRenderMode/activateBackend/onStartRender/onStopRender；面板重写（状态行+按钮+绑定渲染后端）；updateViewport；run 循环清屏
- 其他文件零改动

## 验收（用户在 exe 上验证）

1. 启动 → 预览模式（光栅化 Cornell + 可旋转相机），右侧面板可先调参数
2. 点 Start Render → 路径追踪开始；Stop → 回到预览（参数保留）
3. 渲染中 Apply → 下一帧生效；预览中 Apply → 启动时生效
4. 画面在面板左侧，无遮挡；P 隐藏面板 → 画面扩满
