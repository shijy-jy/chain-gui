## 一、综述

### 1.1 记忆系统侧：Engram 的两代架构与记忆层理论

**定位**（重构后）：Engram = 开发者与 AI 共用的工程记忆图谱。**对话是唯一原始输入，节点是记忆脉络，图谱与文件树是观察面**；AI 是唯一的记忆生产者与消费者，软件提供规则容器与观察窗口。

#### 1.1.1 记忆层理论 v3.0 的骨架（2026-09-08 定稿）

- **三重记忆断裂**：模型无持久记忆 / 上下文有界 / 记忆绑定单一客户端；**四个硬需求**：可接入、可理解、可维护、透明可携带。
- **三命题**：P1 文件即唯一事实源（派生物全可重建）；P2 工具即交互翻译；P3 遗忘是特性（降权归档而非删除）。
- **数学骨架**：约定 0（双时钟，衰减间隔用使用序数 τ 而非墙钟）→ 公理 A 衰减叠加（F2a 贡献和）→ 公理 B 相对增益（F2b 强度 S=ln(w+ε)+C）→ 公理 C 双约束最大熵唤起（F3：p(n|q) ∝ exp[(sim(q,n)+γ·S_n)/τ]）→ 公理 D 容量淘汰（F5 按强度截断）→ 公理 E 骨架合并（F6 质量守恒蒸馏）。合成**环方程**（M4：衰减∘淘汰∘唤起∘触达更新），F7 谱半径 ρ(M)<1 为局部稳定判据（γ 的上限来源），ε/τ 构成"探索-精度"对偶旋钮。
- **检索阶梯 L1–L5**：L1 trigger 编码 → L2 向量召回（两档阈值 0.35/0.2）→ L3 图扩散 PPR（未实现）→ L4/L5 关键词兜底（归档/derived 自此可见）；**铁律**：任何增强失效降级为关键词 + `degraded:true` 显式声明。
- **生命周期机制**：写入守门（词表/乐观锁/原子写/串行队列）、双时钟强度（ACT-R）、遗忘的竞争淘汰制（新生保护期 + importance 人治偏置 + 归档复活通道）、重复检测（余弦 0.9 + alternative 边）、蒸馏（derived 骨架 = 事实源候选态，人审摘帽转正）、痕迹模型（逐字/要点双痕迹 + 事实校验）、M-5 图注意力（转移概率 = sim × rel_weight × life_prior，克制原则：先冻结不训练）。
- **治理权演进**（本报告覆盖期内最重要的变化）：v3.0 定"冲突即冻结、人裁决"（ADR 0003）；**3.1.0 三层重构将其改写**（ADR 0015）——治理权全在 AI，**验证权在痕迹**；冻结从"治理落点"变为"并发保护信号"，裁决出口是 `resolve_conflict`（AI 自愈）。
- **实证状态（理论自己的诚实口径）**：机制正确性（L1）有 148+ 单测与 golden 契约支撑；**"语义召回优于关键词""强度预测再使用""双时钟优于墙钟""遗忘即检索闭环"四个核心主张全部处于 L0 论证态**；D1–D14 验证数据几乎全零。已知断裂：F2 时间轴已修（2.10.0 切记忆时钟序数），**强度 clamp 归零、墙钟恒空两个缺陷仍在**（重构后单独立项）。

#### 1.1.2 三层重构（3.1.0）的核心增量

| 项 | 内容 |
|---|---|
| 三层边界 | 文件层（纯字节，不认识语义）/ 记忆层（规则+记忆动力学）/ 显示层（只吃 `MemoryView`、只发 `Intent`），依赖单向、P4 起编译期强制 |
| 四条不变量 | I1 对话 append-only；I2 记忆入口唯一（AI 经 MCP）；I3 写路径唯一（守门+留痕）；I4 显示层不直读派生物、不直写文件 |
| 对话账本 | `.chain/dialogue/log.jsonl`：一工作区一份，`head/msg/tool/decision` 四类记录；`decision.covers=[from,to]` 同时充当消费锚点与审计证据；**skip 决策也必须留非空 reason**（"AI 自主"与"AI 遗漏"的唯一区分证据） |
| 入口唯一 | `remember` 取代五个节点直写工具（契约 v6/v7）；`dialogue_status` 只读账本；`resolve_conflict` 冻结自愈（v8）；所有响应携带 `guide_version` |
| 人治下线 | GUI 写通道全删（ADR 0015，对 ADR 0012"GUI 零破坏"的显式豁免）；文件树降为只读阅读面 |
| 存量数据 | `origin: legacy` 祖父条款：只读不改、可引用可归档，**不得作为新记忆的扩写基础**（防历史被继续放大）；bootstrap 通道一次性导入 |
| 贯穿性 DoD | 删光 `index/`、`stats.json`、`audit.jsonl`、`code_map/` 后系统仍可用，只有向量召回与强度显示降级并显式声明 |

### 1.2 图结构侧：GNN × 因果推断文献主线

**问题定义（图结构混淆）**：图的标签只由因果子图决定，但观测图中混有与标签"相关但不因果"的子图（confounder 产生的捷径）；GNN 的消息传递把这些虚假关联一路传播进表示，导致**精度掉（OOD 失败）**与**可解释性假（解释子图实为同现噪声）**。

**三条解法主线与代表文献**（共 10 篇论文 + 2 篇综述）：

| 主线 | 代表工作 | 核心机制 |
|---|---|---|
| ① 不变子图提取 | CIGA（NeurIPS'22，奠基）· DIR（ICLR'22）· GALA（arXiv'23，批判性） | 只保留跨环境稳定的因果子图；GALA 证明**没有额外假设时仅靠环境增强学不到不变性**，需最小假设（变化充分性 + 一致性） |
| ② 去偏 / 去混杂 | CAL（KDD'22 + TKDD'24 扩展）· DSE（WSDM'22） | 显式识别 confounder 子图并用因果注意力剔除；DSE 指出**子图与全图的分布偏移本身就是 confounder**，直接后门调整不可行 → 前门调整 + 代理变量做无偏评估 |
| ③ 因果解缠与干预 | CD-GNN（arXiv'26）· CNL-GNN（arXiv'26）· CIGPose（arXiv'26） | 同时阻断混杂路径与溢出路径（异配图）；直接对图结构做 do-干预、生成反事实邻域 |

**五个关键结论**（本报告后续全部引用）：

1. **relevance ≠ causal dependence**（ICL）：特征与标签相关但因果无关的子图会通过消息传递污染表示——优化目标应是因果信息流而非相关性。
2. **解释与精度来自同一个因果约束**（ICL）：可解释性不是外加模块，而是"只学因果子图"的副产物。
3. **不变性需要最小结构假设**（GALA）：加环境、加数据都不够；必须把假设做成结构性的。
4. **分布偏移本身是 confounder**（DSE）：解释评估不可靠的根源；解法是引入代理变量（surrogate）做前门调整。
5. **干预必须显式**（CD-GNN / CNL-GNN）：历史改写 = do-operator，必须走显式通道；并发/跨路径污染要同时阻断混杂与溢出两条路径。

## 二、交叉分析：Engram 图谱中的混淆源与已有防线

### 2.1 混淆源盘点（把 GNN 因果语言映射到 Engram 机制）

| # | Engram 机制 | 潜在虚假关联（confounder） | 对应文献 | 严重度 |
|---|---|---|---|---|
| C1 | `recall` 强度加成 γ·S_n（唤起分布指数项） | **使用强度 = 流行度**，与当前查询只有"历史相关"；理论自认马太效应坍缩风险（ρ(M)≥1 时扰动被放大） | CAL（混淆子图）、ICL（相关≠因果）、F7 | **高** |
| C2 | 冷启动排序（创建时间 + 图谱度数） | **度数是拓扑流行度混淆**，与新问题无关；新生保护期只缓解写入侧 | CD-GNN（归纳子图捷径） | 中 |
| C3 | `consolidate` 连通分量聚类 | **拓扑近邻 ≠ 语义因果簇**；骨架固化后会被检索反复放大（GIGO 的延续形态） | GALA（聚类是相关性代理）、CIGA（子图选择器可被虚假关联骗过） | **高** |
| C4 | rel 三类型 + rel_desc；L3 图扩散 rel_weight（contains 1.0 / solves 1.2 / alternative 0.8） | 边语义滑移（solves/contains 混用）是**结构混淆的生成源头**；rel_weight 无校准依据（理论判"存疑"） | ICL（相关性沿边传播）、L3 存疑判定 | 中 |
| C5 | `search` 关键词子串匹配 | 词共现 = 相关非因果（理论 B3 语义干扰）；重构已修"对话混入召回污染 gaps"的一半 | B3 语义干扰、DSE | 低 |
| C6 | `entry_hubs` / 热度展示 | 度数集中 → 注意力垄断（理论判"实践上亚稳态长期存在"） | 环方程 ε 相变、亚稳态垄断 | 中 |
| C7 | derived 骨架 = "事实源候选态" | 错误骨架若被摘帽转正，错误进入事实源并继续被蒸馏（历史放大） | GIGO、CIGA（错误子图被当作因果子图） | 中（已有摘帽防线） |
| C8 | 双时钟缺陷：强度 clamp 归零、墙钟恒空 | **强度信号失真** → 排序被"假零/假空"支配；昨天用过的节点可能排在从未用过的节点之下（历史同款事故） | DSE（评估被偏移污染）、§18 断裂 | **高**（已立项待修） |

### 2.2 已有防线与文献机制的对应（哪些做对了）

| Engram 机制 | 文献原型 | 状态 |
|---|---|---|
| P1 事实源/派生物分离 + 宪法第 2 条 + DoD | 因果子图 / 环境子图分离（CIGA 的 SCM 设定） | 已实现；H1 部分验证，建议补端到端重建断言 |
| 唯一写路径 + 审计留痕 + decision 账本（含 skip 必留 reason） | 显式 do-干预 + DSE 代理变量（covers = surrogate） | 3.1.0 已实现；**线上未部署**（见 P0-1） |
| freeze + `resolve_conflict` | CD-GNN 阻断溢出路径 + 反事实修复 | 已实现（golden 28 条含完整自愈循环） |
| 降级链 + `degraded:true` + caps 声明 | GALA 式"显式假设声明" | 已实现 |
| 四条不变量 + P4 三 crate 编译期分层 | GALA 的"最小结构假设" | I1–I3 已实现，P4 待做 |
| 检索 scope 显式化（节点优先是结构性默认，对话是显式下钻） | 目标切换 vs 降级的语义分离（正确性问题而非风格问题） | 已实现 |

| 痕迹模型的事实校验（生成草稿 → 事实对账） | 建设性回忆（Bartlett）的工程化 | 未实现（H10 POC） |

### 2.3 关键缺口判断（按影响排序）

1. **线上部署缺口**：仓库 3.1.0（契约 v8，golden 28 条全绿）与线上运行实例不一致——本会话可见的挂载实例仍是**契约 v4 时代工具集**（13 工具：六读 + recall + 五直写 + consolidate，无 `remember`/`dialogue_status`/`resolve_conflict`；指南 v8/v14 vs 仓库 v17/v11）。后果：**I2"入口唯一"在线上不成立**，且对话账本在真实使用中零数据积累。
2. **强度与相似度未分账**（C1）：唤起分布把 sim 与 γ·S 合并在一个指数里，AI 无法判断"这条命中是因为像，还是因为常被翻"——这正是 ICL 警告的 relevance≠dependence 的运行时形态。
3. **consolidate 无稳定性验证**（C3）：GALA 的教训是聚类（环境增强）本身不保证不变性；骨架摘帽前缺少"跨快照/跨工作区重聚类一致性"这道最小假设检查。
4. **全部参数仍是先验**：阈值 0.35/0.2、dup 0.9、derived 0.85、γ 0.3、d 0.5——D2/D1/D3 数据为零，属于 GALA 意义上的"无假设"状态；理论自评 dup 0.9"对中文嵌入几乎必过严"。
5. **M-5 图注意力未实现且无消融基线**（H9）：若未来直接落地 GAT，会重演"先上车后校准"的模式。

## 三、优化建议（P0 / P1 / P2）

> 每条含：动机（文献/理论依据）→ 方案 → 验收判据。

### P0（本周内，先止血）

**P0-1 线上契约切 v8**
- 动机：I2 入口唯一是本次重构的支柱；新旧双写路径并存是最严重的结构混淆（两个事实源）。
- 方案：升级 `D:\AIworkspace\Engram` 部署到 3.1.0；重启 DSH 侧全部 engram-mcp 挂载；运行 `dialogue_status` 确认账本开始积累；旧工具从工具列表消失。
- 验收：8 个工作区挂载均只暴露 v8 工具集；`create_node` 等五工具调用返回"工具不存在"；golden 28 条在部署机上重跑全绿。

**P0-2 修复强度双缺陷 + recall 因子分账（C1/C8）**
- 动机：强度信号是唤起排序的支柱；"假零/假空"让排序被偏移支配（DSE 同款失效）；强度与相似度混算让 AI 无法区分"像"与"常翻"（ICL）。
- 方案：① 修 clamp 归零与墙钟恒空（重构 doc §14 已立项，提前执行）；② recall 返回拆分为 `sim` 与 `strength` 两个显式因子（或加 `explain: {sim, usage}` 注解），排序公式不变、展示分账——契约加性变更，走 golden 增量。
- 验收：昨日使用过的节点强度为正且高于从未使用节点（H5 判据）；recall 结果可读出双因子。

**P0-3 混淆-命中标注（C1/C2）**
- 动机：CAL 的核心动作是"识别并标注 confounder 子图"；Engram 的最低成本等价物是标注而非改排序。
- 方案：对"低 sim 高 S""冷启动度数命中"两类结果附加 `confound: "usage" | "degree"` 标记（只读提示，不改得分）。
- 验收：AI 收到标注后，对 confound 命中的直接采用率可被 audit 观测（为 P2-3 采集埋点）。

### P1（本月内，补最小假设）

**P1-1 consolidate 稳定性前置（C3）**
- 动机：GALA——环境增强（单次聚类）学不到不变性；需变化充分性检验。
- 方案：dry_run 输出增加"稳定性"维度：对同一工作区在不同 `k`、不同时间快照（或等价：随机种子扰动下的连通分量）重聚类，报告簇内一致率；一致率低于阈值的簇不得进入骨架，仅提示。
- 验收：D10 样本（≥10 簇人工评分）中，稳定簇的骨架可追溯率 100%，不稳定簇被正确拦截。

**P1-2 离线基准 D2→D1→D3（C1 的校准前提）**
- 动机：γ、阈值、derived 0.85 全为先验；理论自评 dup 0.9 必过严——不改参数而继续加机制，等于在无假设状态上叠假设。
- 方案：按理论 v3.0 既定顺序执行：BGE 同义/相关/无关分布（≥100 对/类）→ 检索质量基准集（≥30 查询 × ≥100 节点三层标注）→ search vs recall 对照；阈值改分位、dup 按假阳性率 ≤10% 重定、γ 上限用 F7 谱半径复核。
- 验收：D2 数据使阈值落地有分位依据；参数变更全部走"采集→人确认→防回归"四步循环。

**P1-3 决策账本交叉审计（DSE 的实证环节）**
- 动机：covers 账本是 surrogate（代理变量）——代理有效性的唯一证据是它与真实状态一致。
- 方案：定期抽样（每 50 条 decision）：核对 `decision.nodes` 指向的节点是否存在、origin 是否指向对应 `log.jsonl#seq`、skip 记录覆盖的区间是否真无新知识产生；不一致写入 audit 并汇总为"交接保真度"指标。
- 验收：连续四周抽样一致率 ≥95%；不一致条目全部可回溯到具体行。

**P1-4 rel 语义质量控制（C4）**
- 动机：边语义滑移是结构混淆的生成源头；L3 图扩散依赖的 rel_weight 无校准。
- 方案（克制版）：不新增机制——在 remember 的 commits 意图里对 solves 边强制 rel_desc 非空（与 decision reason 同款"宁拒绝不污染"），并对 rel 三类型的分布做季度统计；L3 的 1.2/0.8 权重暂不改动，等 D13 消融数据。
- 验收：新增 solves 边 rel_desc 覆盖率 100%；无校准参数保持冻结（克制原则）。

### P2（季度内，实证与结构收尾）

**P2-1 反事实接管演练（CNL-GNN 思路 + 重构 P3 验收）**
- 动机：反事实邻域 = "如果当初不同会怎样"；接管保真度是对话/节点分工的唯一外部判据。
- 方案：从 2–3 个真实工作区重放 `log.jsonl`，让新 AI 仅持 MCP 在 N 次调用内还原"根目标/走到哪/失败过什么/为什么这么走"，并列出被有意 skip 的对话；与账本比对。
- 验收：达成 P3 判据；还原偏差清单回填指南。

**P2-2 M-5 图注意力消融先行（H9）**
- 动机：文献有支撑（GraphRAG、GAT），但 Engram 自身零校准数据；未做消融就上 GAT 会污染整个检索链路。
- 方案：先建"向量-only"基准（D1 数据），再做 sim × rel_weight × life_prior 的逐因子消融；增益可归因才落地，否则维持冻结。
- 验收：NDCG(GAT) ≥ NDCG(向量) 且消融归因清晰；γ 上限经 F7 复核。

**P2-3 混杂度量与亚稳态观测（C6 + 理论 D4）**
- 动机：环方程的亚稳态垄断"收敛极慢、谱半径检测不到"，只能纵向观测；CAL 的注意力熵/背景子图指标是现成度量。
- 方案：stats 增加 top-k 命中集中度（HHI/熵）与强度分布偏度；D4 纵向数据（≥50 条触达序列）上线后自动回填。
- 验收：垄断趋势可在发生前一个观察窗被预警；ε 下限有数据依据。

**P2-4 P4 三 crate 拆分（结构收尾）**
- 动机：GALA 的最终形态——把不变量写成编译期事实，而非文档承诺。
- 方案：拆 `engram-file` / `engram-memory` / `engram-api`，跨层 import 编译期不可能；`MemoryView`/`Intent` 字段集入 golden，加性变更走 CHANGELOG + 版本矩阵。
- 验收：cargo 依赖图检查无逆向边；降级冒烟（删光派生物跑 GUI 最小路径）通过。
