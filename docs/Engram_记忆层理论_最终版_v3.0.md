# 第一部分 · 问题与命题

## 1 · 面对的问题

**三重记忆断裂**：①模型无持久记忆（每次对话从零开始）；②上下文窗口有界（长周期工程装不下）；③记忆绑定单一客户端（换客户端即失忆）。

**四个硬需求**（一切设计的验收标准）：可接入（任意 AI 经标准协议读写）、可理解（读到的是关系叙述而非孤立文件）、可维护（长期不膨胀不腐化）、透明可携带（纯文本、人可读、本地优先）。

## 2 · 三个命题（生态位）

| # | 命题 | 含义 |
|---|---|---|
| **P1** | 文件即唯一事实源 | 节点 `.md` 只存干净事实；关系叙述读取时动态拼装；一切派生物可重建 |
| **P2** | 工具即交互翻译 | AI 无眼睛，机器接口 = GUI 交互（搜索/涟漪/聚焦/全局）在文字域的等价物 |

生态位：不与通用记忆 API 竞争；护城河 = 透明 + 可携带 + 有遗忘。

# 第二部分 · 公理与推导

> 全部公式从理论自身的原始数据（触达流）与两条原始信念出发推导。自命名抽象，推导即定义。（脚注：部分公式与点过程、统计物理吉布斯分布、重正化粗粒化恰好同构——事后发现的长相相似，非推导依据。）

## 4 · 原始数据与两条原始信念

**唯一原始数据**：每条记忆的**触达流** $H_n = (\tau_1, \tau_2, \dots)$——「这条记忆在第几次使用时被翻出来过」。

**两条原始信念**：①遗忘是提取失败，不是存储丢失（信息不灭）；②强度零人工权重（一切权重从触达流长出来）。

## 5 · 约定与公理

**约定 0（时间域约定）**：公理 A 中的「间隔」用使用序数 τ（记忆时钟 = 工具调用序数）度量，不用日历秒。

*推导依据*：遗忘是提取失败的属性，提取机会由使用流提供，故衰减间隔 = 两次提取机会之间的「使用量」；日历秒仅在使用密度均匀时与之成正比，而 AI 的使用密度极端不均匀。本约定同时推出：①双时钟分工（墙钟管日历、τ 管老化）；②§18 时间轴修复的必要性（现实现违背本约定，是可判定错误）；③H5 实验判据。

**公理 A（衰减叠加）**：一次触达对「今后想起它」的贡献只随间隔衰减；多次触达的贡献互不干扰、直接相加。

→ 设衰减核 $K(\Delta)$（$K(0)=1$、单调降、远处趋零），得**贡献和**（F2a）：

$$w_n(\tau) = \sum_{j} K(\tau - \tau_j)$$

→ 核的选型（幂律 $\Delta^{-d}$ vs 指数 $e^{-\lambda\Delta}$）是实验问题（D4 回答），核保持抽象。

**公理 B（相对增益）**：每次触达带来的感知增量与当前总贡献成反比：$dS \propto dw/w$。

→ 积分唯一得**强度**（F2b）：

$$S_n = \ln(w_n + \varepsilon) + C$$

→ ε 为**探索底噪**：从未触达的记忆也有微小强度——由「遗忘不灭」推出「任何记忆永远有非零概率被想起」，非外加补丁。若数据反驳对数形式，换 B 的微分形式，A 不动。

**公理 C（双约束最大熵唤起）**：唤起分布满足三条约束，其余信息一律不预设：①归一化；②**支持集约束**——分布仅在可见集 $V(q)$ 上非零（L4/L5 可见性规则与 include_archived 的数学落点）；③同时约束平均语义匹配与平均强度（$\sum p_n\,\text{sim}(q,n) = \bar{Q}_1$，$\sum p_n S_n = \bar{Q}_2$）。

→ 在此约束下最大化熵 $H(p) = -\sum p_n\ln p_n$，唯一解为**唤起分布**（F3）：

$$p(n\mid q) = \frac{\exp\!\big[(\text{sim}(q,n) + \gamma\,S_n)/\tau\big]}{\sum_{m\in V(q)} \exp\!\big[\cdots\big]}\qquad(n\in V(q))$$

→ 两个参数的**推导出处**：τ = 约束松紧的倒数 = **精度预算**（τ→0 分布尖锐只想起核心；τ→∞ 均匀唤起只剩概括）；**γ = 两拉格朗日乘子之比 = 语义-强度兑换率**。查询连续性由解的形式自然满足。

→ **渐进唤起**：公理 C 只给出每点 (m, τ) 的分布；检索阶梯 = 参数化路径 $\{(m_r, \tau_r)\}$（m 递增、τ 递减，由粗到细），**路径形状是待定策略**，由唤起-失真曲线与 H10 数据确定——不由 C 单独决定。m 命名**唤起预算**。

**公理 D（容量淘汰）**：活跃注意力有限，活跃集合总权重有预算。

→ 交换论证（淘汰权重大而留下小的必增损失）推出**快照最优**淘汰 = 按强度排序截断尾部（F5）：

$$\text{淘汰候选} = \{n : S_n < \theta\},\quad \sum_{\text{active}} w_n \ge 1-\alpha$$

→ **声明**：淘汰策略是**启发式 + 人治**，不主张动态最优。动态修正两条：①**期望价值准则**——淘汰按「未来期望价值」而非当前权重排名（新记忆当前权重≈ε 但期望价值高，由此推出新生保护期）；②**复活通道**——归档节点经 include_archived 召回命中 → 恢复建议 → 人确认，抵消淘汰自证预言（自证预言本身是「遗忘=检索成本升高」的意图行为）。α 命名**活跃预算**，θ 命名**淘汰阈值**。

**公理 E（骨架合并）**：一个簇的记忆共享大量内容时，维护全部细节的成本高于信息增益；骨架 = 簇的共识部分。

→ 质量守恒：骨架权重 = 簇内权重和（F6）；细节（差异）转冷存储（不灭）；逐条引用保证可回溯。命名**骨架合并**（蒸馏的数学形式）。

**F1（嵌入 $f: V\to\mathbb{R}^d$）**：编码器，由「检索话术与内容的可对齐性」需求直接定义，选型由 D2 分布数据验收。

## 6 · 环方程与动力学性质

**环方程**（约定 0 与公理 A–E 合成，M4）：

$$\mu_{t+1} = \text{衰减}(\mu_t)\circ\text{淘汰}(\mu_t)\circ\text{唤起}(\mu_t)\circ\text{触达更新}(\mu_t)$$

**非自治声明**：查询流是外部输入，环方程是**非自治迭代**；一切稳态性判断以「查询流平稳、触达率有界」为前提。

**有界性**：衰减核 + 有界触达率 ⇒ 贡献和有上界 ⇒ 状态空间存在不变域。（淘汰算子不连续，不主张不动点存在性。）

**局部稳定判据（F7）**：均衡态附近线性化 $\delta' = M\delta$，由迭代收敛条件：

$$\rho(M) < 1 \iff \text{局部稳定（条件判据）}$$

$\rho(M)\ge 1$ 时扰动被放大 = 马太效应坍缩（赢家通吃）。γ 的上限由本判据定。

**遍历性与亚稳态**：ε>0 ⇒ 唤起分布处处非零 ⇒ 活跃集上不可约 ⇒ 唯一不变分布存在（严格意义的多稳态退化为亚稳态）；但收敛时间可极长——**实践上注意力垄断仍会长期存在**，谱半径检测不到，需 D4 纵向数据观测。

**ε 的相变角色**：ε→0 = 结晶态（少数记忆垄断）；ε→∞ = 液态（均匀流动）。**设计判据**：ε 下限由「不结晶」约束给定，τ 上限由「不糊化」约束给定——ε 与 τ 构成精度-探索对偶旋钮。

**图-强度耦合**：采用**拟静态近似**——图结构变更频率远低于触达频率时，谱半径约束逐段有效；图高速演化下的耦合动力学列为边界（§21 B4）。

**唤起-失真曲线（F8）**：失真 $D(m) = 1 - \text{相似度}(\text{重建}, \text{原文})$；由公理 A 核单调性推出 $D(m)$ 单调不增；**默认 m 取失真曲线拐点**，拐点由数据（D1）定。

# 第三部分 · 机制全貌（生命周期）

## 7 · 写：编码与守门（M-1）

- **L1 编码规范**（✅）：trigger 句（`> 触发：<同义话术>（；分隔）`）+ tags（≤5 个、≤20 字）。信息论目标：最大化 I(触发词; 未来检索话术)。
- **写入守门**（✅）：同名拦截（force 放行）· rel 三类型词表（contains/solves/alternative + rel_desc）· 乐观锁（CONFLICT 不落盘）· tmp+rename 原子写 · 串行队列。
- **线索衰减**：写入的 AI 无法预知未来 AI 的话术 → 召回失败日志 → 线索缺口清单（⏳ M8' 由 consolidate 同期产出）。L1 的诚实定位：**加性优化**，真实检索上限由 L2 决定。

## 8 · 存：事实源/派生物分离与双时钟（M-2）

- **事实源**：`.chain/nodes/*.md`（YAML 头 + 正文），只存干净事实（P1）。
- **派生物**：`index/`（嵌入）、`stats.json`（强度）、`audit.jsonl`（审计）、`code_map/`（骨架）——全部可重建、可删除、**绝不写进 YAML**。
- **双时钟**（约定 0）：墙钟管日历，记忆时钟 τ 管老化；**所有衰减核定义在 τ 上**。

## 9 · 读：检索阶梯 L1–L5（M-3）

| 级 | 查询表示 ↔ 记忆表示 | 机制 | 可见性 |
|---|---|---|---|
| L1 | 精简线索 ↔ trigger | 编码侧 ✅ | — |
| L2 | 多线索 ↔ trigger | 向量召回（F3 排序）✅ | — |
| L3 | 大意 ↔ 线索 | 图扩散（PPR，🔲） | — |
| L4 | 三内容 ↔ 关键线索 | 关键词兜底 ✅ | 归档节点自此可见 ⏳ |
| L5 | 三内容 ↔ 大意 | 关键词兜底 ✅ | 蒸馏骨架自此可见 ⏳ |

**渐进唤起**：阶梯 = 参数化路径 {(m_r, τ_r)}（§5 公理 C 注），由粗到细——与「先要点后细节」的回忆顺序同构。

**铁律**：①降级链——任何增强失效退化为关键词 + `degraded:true` 显式声明，检索永远可用（✅）；②冷启动——强度全空时退化为「创建时间 + 图谱度数」排序并声明（✅）。

## 10 · 维护①：强度信号（M-4.1）

- **F2（公理 A+B 推导）**：零人工权重；图谱度数被访问历史自然吸收；d 由命中/未命中反馈校准（50 次窗口，真实数据回归后调）。
- **importance**：单档 `high`，作为**唤起阶段的人设偏置**（δ·I 加入唤起分布的指数项），不参与强度演化与自动淘汰——人的干预权 = 顶层排序偏置，强度动力学严格零人工（防 AI 自评注水）。
- **闭环**：触达回写 = 环方程的触达更新项；**遗忘与检索是同一个变量（权重）的两个方向**。

## 11 · 维护②：遗忘的竞争淘汰制（M-4.2）

**裁定**：遗忘由权重排名驱动，而非绝对时间。**低权重的先遗忘**。

- **淘汰算子（F5）**：每次「睡眠」（离线重嵌/蒸馏时）按 S 排名，尾部（低于淘汰阈值 θ 或活跃预算 α 之外）标记为归档候选，**人确认后**移入 `.chain/archive/`（归档而非删除，可恢复）。
- **新生保护期**：新节点权重为零，若不保护会被第一个淘汰（方向错误）——按期望价值准则（§5 公理 D）参与排名，或以「创建时间+度数」冷启动因子兜底。
- **importance 豁免**：仅人可标记，豁免或减缓衰减。
- **复活通道**：归档节点经 include_archived 召回命中 → 恢复建议 → 人确认。
- **90 天规则降级为兜底**：长期未触达的节点权重自然衰减至垫底，90 天规则命中者与竞争淘汰者是同一批——保留作为提示阈值。
- **两层遗忘**：**一阶遗忘** = 可及性下降（归档、可逆、信息不灭，对应 Ebbinghaus 的可及性下降）；**二阶遗忘** = 信息有损（蒸馏的细节舍弃、不可逆）。「遗忘是特性」的主张主要由二阶承载。

## 12 · 维护③：语义冲突与重复检测（M-4.3）

- 两阶段：①标题相似度启发式（归一化编辑距离/公共子串，零依赖）②嵌入余弦 > 0.9 → 提示「疑似重复」。
- 复用 `alternative` 边表达竞争（零新增概念）；force 放行。
- 并发冲突：要么 `CONFLICT:`（✅）要么冻结 `[待裁决]`（status=blocked + 前缀，⏳）——**绝不静默覆盖**。

## 13 · 维护④：巩固蒸馏（M-4.4）

- **consolidate**：dry_run 默认；BFS/共现聚类；产物 = 骨架节点（`derived:true` + `[蒸馏]` 前缀）+ 逐条来源引用；检索自 L4 可见 + 默认降权；**人审摘帽**。
- **本体论定位**：derived 节点 = **事实源的候选态（待人审）**，摘帽 = 转正为事实；生成记录（引用/来源）才是派生物；长期未摘帽且未采用的骨架走竞争淘汰。骨架保留在 nodes/ 以参与图谱（contains 回指）与摘帽生命周期。
- **数学形式（F6）**：骨架合并——簇内质量守恒，细节（差异）转冷存储，共识（一致部分）保留；「细节忘了大纲还在」。
- **GIGO 防线**：只陈述共识事实 + 逐条引用 + 人审。

## 14 · 治理权

**冲突即冻结**：CONFLICT 后节点进入 `[待裁决]`，人裁决。理由：人可治是立身之本，裁决权交给人是唯一自洽选择。信任矩阵：人（GUI）最高权威；本机 AI（stdio）可信；云端 AI（HTTP+token）半可信（⏳）。

## 15 · 痕迹模型（双痕迹理论的工程化）

| 记忆理论 | 工程落点 |
|---|---|
| 逐字痕迹（精确、衰减快） | `.md` 事实源（不删） |
| 要点痕迹（模糊、抗遗忘） | 节点词分布（唤起分布的采样对象） |
| 先要点后细节 | 渐进唤起（参数化路径：m↑、τ↓） |
| 回忆是建设性的（Bartlett） | 生成草稿 → 事实校验（防幻觉对账） |
| 再巩固 | 触达回写（唤起改变痕迹） |

**核心假设**（H10 验证）：唤起-失真曲线单调（m↑ → 语义相似度↑）；事实校验后实体/数字错误率显著下降。

## 16 · 终态：记忆图网络（M-5）

- **QKV 图元**：Q 现算 / K = 嵌入索引 / V = `.md` 文件 / 图结构 + 生命周期 = 先验。
- **图注意力**（4.2，🔲）：转移概率 = `sim × rel_weight × life_prior`（度归一化；contains 1.0 / solves 1.2 / alternative 0.8），权重分解 `{sim, rel, life}` 可解释输出。
- **克制原则**：不训练、先冻结；微调有明确门槛（可解释权重实测不足才评估）。
- **稳定性**：life_prior 权重上限由环方程线性化的谱半径 < 1 给出（F7）；探索底噪 ε 与精度预算 τ 保证唤起分布处处非零。

## 18 · 已知理论-实现断裂（最紧迫）

**F2 的时间轴**：约定 0 规定衰减间隔用使用序数 τ；实现却把触达记在墙钟秒上。数值后果（d=0.5）：

| 触达年龄 | 贡献 | 单触达 S |
|---|---|---|
| 1 秒前 | 1.000 | 0 |
| 1 小时前 | 0.017 | −4.1 |
| 1 天前 | 0.0034 | −5.7 |

未触达节点按 life=0 处理 → **昨天用过的节点（boost≈−0.71，负分被阈值滤掉）排序低于从未用过的节点**。修复：触达时间戳改用记忆时钟序数（H5 为修复验收实验）；这是单位错误，不是参数问题。

## 20 · 失效模式

- **马太效应坍缩**：环方程触达反馈放大扰动 → 赢家通吃。防线：F7 谱半径 <1、探索底噪 ε、精度预算 τ。
- **亚稳态垄断**：ε>0 时理论上是亚稳态，但收敛极慢——实践上注意力垄断长期存在。观测：D4；干预：ε 下限 + 人治。
- **建设性污染**：唤起是建设性的（Bartlett）→ 生成草稿必须事实对账（痕迹模型）。
- **GIGO**：AI 生成内容入事实源 → 蒸馏三防线（共识/引用/人审）+ 候选态生命周期。
- **冷启动误杀**：零权重新节点被竞争淘汰 → 期望价值准则（保护期）。
- **参数自毁**：单变量变更、约束区间、置信门槛、建议而非自动（§22）。

## 21 · 理论边界（本理论不回答什么）

- **B1 语义质量**：本理论优化**可及性**，不优化**正确性**；真假判断由事实校验（痕迹模型）与人治外部完成。
- **B2 查询流非平稳**：兴趣漂移下强度系统存在响应滞后；d 的双重角色——衰减速度 = 响应速度（大 d 响应快记忆短，小 d 反之）；该权衡未量化，D4 实验应同时测响应速度。
- **B3 语义干扰**：唤起模型是**联想性近似**（相似记忆一起唤起），不建模认知科学中的提取抑制/混淆；重复检测（alternative 边）在治理层部分补偿。
- **B4 图-强度耦合演化**：图结构高速演化下的耦合动力学未解；当前采用拟静态近似（§6）。

# 第五部分 · 验证体系

## 22 · 参数迭代方法论（四步循环）

**前提**（随 M7'/M8' 落地）：①参数外置（派生文件，快照版本化）②决策点留痕（audit.jsonl）③行为信号定义（隐式标注：recall 后 T 秒内 read_node 且 id∈results = 正样本；force=true = 重复误报；归档被恢复 = 误判）。

```
① 观察窗：先验值运行只采集（每参数 ≥50–100 样本或两周，先到者触发）
② 校准：分位/回归取统计量，不重拍脑袋
③ 回填生效：快照入 audit.jsonl，人确认生效（人治）
④ 防回归：同义词测试集 + 行为日志回放对比，退化即回滚
```

**纪律**：单变量变更；约束区间（越界即异常）；小样本诚实（置信度不足不调）；契约与参数解耦（golden 锁形状，参数只改数值）。

## 26 · 审核判据

1. **三条红线优先**：事实源不脏 / 检索降级链 / 人治兜底——机制设计冲突时红线优先，违反红线 = 一票否决。
2. **理论引用正确性**：每条认知科学依据是否被正确使用（如 ACT-R 的 t 是实验内相对时间，Engram 必须用主观时间轴——§18 正是这个错位）。
3. **因果链闭合**：每个信号（权重、触达、缺口、采用）必须有明确的「产生 → 存储 → 消费」路径，断链的主张降级为未验证。
4. **失效模式声明**：每个机制必须声明在什么条件下失效（§20），未声明失效模式的主张视为不完备；不回答的问题必须进理论边界（§21）。
5. **证据等级诚实**：L0 论证 / L1 机制 / L2 基准 / L3 纵向 / L4 因果——按最高达到的等级陈述，不允许用 L1 证据支撑 L3 主张。

# 结论

**当前实证状态**（诚实口径）：机制正确性（L1）有 148 单测 + 12 条 golden 契约支撑；效果存在性（L2）仅 4 组同义词弱证据；**「语义召回优于关键词」「强度预测再使用」「双时钟优于墙钟」「遗忘即检索闭环有效」四个核心主张全部处于 L0 论证态**。

**下一步顺序**：①F2 时间轴修复（H5 验收）→ ②D2/D1/D3 离线基准（阈值与检索质量）→ ③M7'/M8' 落地时同步埋采集点与参数外置 → ④按 D4–D14 顺序补数据 → ⑤M-5 4.2 与痕迹 POC。

**一句话总结**：理论已完成闭环（问题 → 命题 → 公理推导 → 机制 → 评估与边界 → 验证），数学骨架（约定 0、公理 A–E、F1–F8、环方程）已立；现在缺的不是理论，是 D1–D14 的数据——理论的可信度由 H1–H12 的通过率决定，不由文档厚度决定。
