# Engram 记忆层第一阶段 · 源输入建立节点 设计 v1

> **状态**：设计稿（待评审）· **日期**：2026-10-04
> **范围**：记忆层写路径的前半段——从"源输入（对话账本未消费区间）"到"节点落盘 + 决策留痕"。
> **不含**：检索侧改动、跨工作区泛化、蒸馏、遗忘、任何模型训练。
> **关系**：本文是《三层重构设计 v1》§5（对话文件）与《记忆层理论 v3.0》§7（编码）在写路径上的展开；复用全部既有基础设施（remember 唯一入口 / 守门 / 乐观锁 / 原子写 / covers / origin / dialogue_status）。
> **来源**：本轮讨论沉淀——多头关注（三痕迹编码）、伏笔登记、候选方向加权、多峰建节点、写侧 ε/τ 对偶、保留式抽取。

## 1 · 定位与边界

**第一阶段要解决一句话**：AI 消费一段源输入时，**不再"一次生成一个节点"，而是"多遍关注 → 候选方向加权 → 按分布形状决定建几个节点 → 承诺并全量留痕"**。

| 项 | 内容 |
|---|---|
| 输入 | `.chain/dialogue/log.jsonl` 未消费区间（`unconsumed_from` 起）+ 图上下文 |
| 输出 | 一个或多个节点（各带 `origin` 与权重）+ 扩展的 decision 痕迹（候选/权重/抽取记录/伏笔登记） |
| 载体 | 全部经由 `remember`（唯一入口，I2/I3 不变）；新字段全部加性 |
| 明确不做 | 检索、遗忘、蒸馏、跨区、训练；LLM 权重只作序数分 |

## 2 · 设计原则（七条，从讨论沉淀）

1. **分布保留**：一个上下文永远不止一种读法；读法连同权重一起记住——多峰进图、单抽进痕迹。
2. **写侧 ε/τ 对偶**：与读侧同一哲学——ε_写 保证次要方向有非零机会（不结晶），τ_写 由分布形状决定建几个（不垄断）。
3. **三痕迹编码**：要点痕迹（主方向节点）/ 潜在痕迹（伏笔登记）/ 逐字痕迹（对话原文，I1 已保证）——对应"现在懂了 / 注意到但没懂 / 原文永不丢"。
4. **痕迹优先于抽样**：无偏性靠保留分布，不靠抽样器；任何抽取必留记录，复盘可重放。
5. **事实底线**：无论权重高低，落成节点的内容必须对源文本可验证（痕迹模型的事实对账），否则降为伏笔登记或丢弃。
6. **校准先于抽样**：LLM 自评分只作序数（谁比谁强）；概率化使用须等 D 数据校准。
7. **自适应成本**：默认单遍消费（argmax 直写）；多假设只在触发条件下开启（§9）。

## 3 · 总体流程（一次消费的完整链路）

```text
dialogue_status: 取未消费区间 [unconsumed_from, last]
        │
        ▼
① 三遍关注（同一区间，不同关注点）
   ├─ 要点关注：主线判定 keep/skip/merge → 主方向候选
   ├─ 残余关注：未被要点消费的细节 → 伏笔登记 或 低权方向候选
   └─ 结构关注：type/status/parent/rel 候选集 + 规则评分
        │
        ▼
② 候选与权重
   方向候选（语义开放集，LLM 生成）∪ 结构候选（词表枚举，规则评分）
   权重 = 语义贴合 × 结构贴合 × 效用（规则分确定，LLM 分序数化）
        │
        ▼
③ 多峰检测（分布形状）
   单峰 → 建 1 个节点；多峰 → 每峰各建 1 个节点（covers 划分子区间）
        │
        ▼
④ 提交（ε_写 / τ_写）
   默认 argmax；探索模式：保留式抽取（抽中写图、未中进痕迹/alternative 边）
        │
        ▼
⑤ 痕迹写入（decision 扩展字段，见 §8）
        │
        ▼
⑥ 守门 + 原子写（既有写路径，不变）
```

## 4 · 三遍关注（编码阶段）

| 遍 | 关注点 | 产物 | 关键规则 |
|---|---|---|---|
| ① 要点关注 | 这段在讲什么、是否值得记 | keep / skip / merge 判定 + 主方向候选 | skip 必留 reason（沿用）；merge 给目标节点 |
| ② 残余关注 | **要点没消费的细节** | 伏笔登记 或 低权方向候选 | 残余 = 伏笔候选，不需要第二套模型判断"哪个重要"——主注意没吸收的自动就是"易被忽略处" |
| ③ 结构关注 | 挂哪、什么类型、什么关系 | type/status/parent/rel 候选集 | 词表笛卡尔积，可枚举；规则评分确定性（词表外即拒绝，守门 D2 同源） |

**伏笔登记（潜在痕迹）**：`decided:"foreshadow"` 的决策行，含源区间 `covers`、一句摘录、当时明确标注"方向未定"。**不进图谱主链、不建节点、不进事实源**——只活在痕迹里，可由 `dialogue_status` 聚合视图浮出。理由：伏笔的重要性在写入时刻原则上不可知（信息不可得，非推理能力问题），此时建节点只会产出失去上下文的孤立断言。

## 5 · 候选与权重

### 5.1 两类候选

| 候选 | 空间性质 | 生成方式 |
|---|---|---|
| 方向候选（语义） | 开放 | LLM 多样本（k 由 §9 触发条件决定）；差异化指令（不同抽象层级/不同侧重）防模式坍缩 |
| 结构候选（挂载） | 有限（type 4-5 类 × status 5-6 态 × rel 3 类 × parent 候选集） | 枚举 + 规则评分，确定性 |

### 5.2 权重三分量

$$w(\text{方向}, \text{结构}) = \underbrace{s_{\text{语义}}}_{\text{对源覆盖、无编造}} \times \underbrace{s_{\text{结构}}}_{\text{词表/链协议}} \times \underbrace{s_{\text{效用}}}_{\text{是否重复、是否纯回执}}$$

- `s_语义`：LLM 自评（**序数化**，不进概率计算）+ 可选自一致性票数（多假设时）；
- `s_结构`：规则分，确定性，词表命中/环与悬空检查（与守门同源）；
- `s_效用`：重复检测（标题相似 + 余弦，沿用 0.9 先验）、"纯工具回执"判定 → 效用为 0 即 skip。

## 6 · 多峰检测：建几个节点

| 分布形状 | 决策 | 理由 |
|---|---|---|
| 单峰（top1 ≫ top2） | 建 1 个节点 | 这段文本承载一条主导记忆 |
| 多峰（多个方向各有实质权重） | 每峰各建 1 个节点 | 同一段文本承载多条独立记忆；`remember` 的 commits 本就支持多节点意图 |
| 全低（最大权重低于阈值） | skip 或全走伏笔登记 | 无可靠方向时不污染事实源 |

- 判据（先启发式，后 D 数据校准）：top2/top1 比值 或 权重分布熵；
- 多峰时每个节点覆盖的 `covers` 为子区间，`origin` 各自记录权重与方向编号。

## 7 · 提交与抽取（ε_写 / τ_写）

| 旋钮 | 读侧（已有） | 写侧（本设计） |
|---|---|---|
| 探索底噪 ε | 任何记忆有非零概率被想起 | ε_写：权重高于 ε 的方向有非零概率被建节点（次要解读不被垄断淘汰） |
| 精度预算 τ | τ→0 尖锐、τ→∞ 均匀 | τ_写：单峰→1 节点（尖）、多峰→每峰 1 节点（平），由分布形状定 |

**提交规则**：

1. **默认模式（commit）**：argmax 承诺——最高权重方向落节点。
2. **探索模式（sample）**：保留式抽取——抽中的落节点；**未抽中的方向全部进 decision.candidates 并可选挂 `alternative` 边**（rel 三类型中 alternative 本来为此存在）。
3. **抽取必须可重放**：种子 / 抽中序号写入痕迹；复盘时"分布 [0.6,0.3,0.1]，抽中 #2"一目了然——抽样因此不损失可回溯性。
4. **事实底线独立于抽样**：无论抽中哪个方向，落盘前对源文本做覆盖校验（痕迹模型事实对账）；对不上 → 降级为伏笔登记或丢弃，不允许"抽歪了就写进事实源"。
5. **模式显式**：commit / sample 写入痕迹，当前模式可被 audit 统计。

## 8 · 痕迹扩展（decision 记录）

```jsonl
{"k":"decision","seq":7,"session":"s-2026-10-04-a","ts":"...",
 "decided":"keep","covers":[5,6],"mode":"sample","seed":"a3f9",
 "nodes":[{"id":"t-042","dir":"提炼为方案节点","score":0.62,"selected":true}],
 "candidates":[{"dir":"提炼为方案节点","score":0.62},
               {"dir":"并入 t-030 作为子节点","score":0.24},
               {"dir":"仅登记伏笔","score":0.14}],
 "foreshadowing":[{"covers":[5,5],"note":"第 5 条消息提到一个未解释的常量，方向未定"}],
 "reason":"……"}
```

| 字段 | 说明 | 性质 |
|---|---|---|
| `candidates[]` | 所有实质候选方向 + 权重（含未选中） | **加性**（旧记录无此字段照常读） |
| `mode` / `seed` / `selected` | 提交模式与抽取记录 | 加性，可重放 |
| `foreshadowing[]` | 伏笔登记（区间 + 摘录 + "方向未定"） | 加性，纯痕迹不进图 |
| `decided:"foreshadow"` | 整段方向未定的登记决策 | 复用现有词表扩展 |

**一笔账三种用途**：审计证据（为什么这么写）/ 不确定性快照（当时还认真考虑过什么——将来发现选错，替代方案就在痕迹里，无需重推历史）/ 未来训练样本（`(源输入,图上下文) → 候选分布`，为远期节点策略模型积累数据）。

## 9 · 自适应成本（多假设的触发条件）

默认：单遍要点关注 + argmax 直写（与现状同成本）。

触发多遍关注与多假设的条件（任一命中）：

1. 要点自检矛盾（主方向与源文本明显不一致）；
2. 重复检测分数逼近阈值（0.85–0.9 区间）；
3. 源段本身多义（含多条独立线索/结论）；
4. 用户或探索模式显式要求。

## 10 · 验收（DoD + 假设编号）

| # | 判据 | 数据 |
|---|---|---|
| H-A | 残余通道有效：构造含伏笔样例，伏笔登记召回率 ≥ 人工标注基线 | 离线小基准（≥10 段） |
| H-B | 多峰检测：人工标注多义段，建节点数与标注一致率 ≥ 80% | 同上 |
| H-C | 痕迹可重放：sample 模式按种子重放，选中结果逐字段一致 | 单测 + golden |
| H-D | 事实底线：幻觉方向（对不上源文本）被拦截或降级为伏笔登记 | 同上 |
| 契约 | decision 新字段为加性变更；旧 golden 记录零变化；新增 golden 覆盖多峰/伏笔/抽取三路径 | golden 增量 |
| 既有 DoD | 删光派生物仍可用不受影响（伏笔登记活在 log.jsonl 痕迹，非新事实源） | 降级冒烟 |

**统计纪律**（沿用理论 v3.0）：小样本报效应量 + 置信区间；权重在校准前不进概率；参数变更走四步循环。

## 11 · 阶段内分步（每步独立验收）

| 步 | 动作 | 验收 |

## 12 · 与后续阶段的关系

| 钩子 | 归入 |
|---|---|
| 伏笔登记的回报钩子（未来节点揭示旧细节作用 → 升级为节点 + 反链） | 第二阶段"新证据回写" |
| 权重概率化（校准） | 依赖 D2/D4 数据，校准后开启 |
| 节点策略模型（学"何时建几个、选哪个方向"） | 远期；本阶段痕迹即训练数据 |
| 跨工作区泛化 / 修正传播 / 主动复习 | 独立立项，不在本阶段 |

---

**结论**：第一阶段不引入任何新存储、新模型、新工具——只做三件事：**多遍关注**（把"一次生成"改为"三次关注"）、**分布留痕**（candidates/weights/foreshadowing 全进 decision）、**形状驱动**（单峰一节点、多峰多节点、全低登记）。写侧 ε/τ 与读侧对齐后，记忆系统的"不结晶、不垄断"在编码端与唤起端同时成立。
