# 第一部分 · 理论全貌

## 1 · 问题与总命题

**三重记忆断裂**（背景）：模型无持久记忆；上下文窗口有界；记忆绑定单一客户端。由此产生总问题 Q0：如何构建一个**可接入（任意 AI 可读写）、可理解（读时有关系叙述）、可维护（长期不膨胀不腐化）、透明可携带（纯文本、人可读、本地优先）**的工程记忆系统。

**三个核心命题**（生态位定义）：

| 命题 | 内容 | 状态 |
|---|---|---|
| P1 文件即唯一事实源 | 节点 `.md` 只存干净事实；邻域/路径叙述在读取时动态拼装，关系变更零同步成本 | ✅ 宪法 1/2 条 |
| P2 工具即交互翻译 | AI 没有眼睛，一切机器接口都是 GUI 交互（搜索/涟漪/聚焦/全局视图）在文字域的等价物 | ✅ 9 工具成立 |
| P3 遗忘是特性 | 记忆强度 = 突触强度 × 平行通道数；长期未触达的图元降权归档而非删除 | ⏳ 理论已定，M7'/M8' 落地 |

**生态位结论**：不与通用记忆 API 竞争（Mem0/MemGPT 是云端黑盒），护城河 = **透明（人可读可治）+ 可携带（文件夹即资产）+ 有遗忘（生命周期）**。

## 2 · 理论根基（认知科学依据）

| 依据 | 出处 | 在 Engram 中的落地 |
|---|---|---|
| 编码特异性原则 | Tulving, 1973 | 检索上限由「写入时的线索」决定 → L1 编码规范（trigger 句 + tags） |
| 记忆强度 = 突触强度 × 平行通道数 | 记忆巩固文献 | 访问次数（突触强度）× 图谱度数（平行通道）→ 强度信号两因子 |
| 海马体索引理论 | 神经解剖学 | 索引与内容分离 → 事实源存内容，`.chain/index/` 存派生索引 |
| ACT-R 基础激活方程 | Anderson 认知架构 | S = ln(Σ (now − t_j)^(−d))，零人工权重 |
| 遗忘曲线 / 遗忘=提取失败而非存储丢失 | Ebbinghaus, 1885 | 归档而非删除；遗忘 = 检索成本升高（ADR 0006） |
| 记忆核心是注意力分配 | Titans, 2024 | 「遗忘即检索」闭环：强度信号直接驱动检索排序 |
| 图结构是强语义索引 | GraphRAG, 2024 | 先结构后向量；检索三层中图结构先于向量 |

## 3 · 记忆生命周期状态机

```
        写入(守门)          检索命中            长期未触达(90d 建议)   人审摘帽
新建 ──────────► 活跃 ────────► 强度↑(巩固) ──┐                 ┌──► 蒸馏骨架(derived)
                 │ ▲                        │ 建议归档        │
                 └ └── 触达回写 stats ◄── 归档([归档]前缀) ────┘
                                             └── unlink 断边 / 人可恢复
```

四个环节闭环：**写（编码）→ 存（组织）→ 读（检索）→ 维护（巩固/遗忘）**；遗忘与检索不是两个系统，而是同一个闭环的两面（M-4 ↔ M-5 合流点）。

## 4 · 写：编码规范与写入守门（M-1）

- **L1 编码规范**（指南 v8 分析 / v3 开发，✅）：trigger 句（`> 触发：<同义话术>（；分隔）`）+ tags（≤5 个，每个 ≤20 字）。定位：**检索上限的决定者**（编码特异性）。
- **写入守门**（✅）：同名拦截（force 放行）· rel 三类型词表（contains/solves/alternative，语义细节走 rel_desc ≤60 字）· 乐观锁（CONFLICT 不落盘）· tmp+rename 原子写 · 串行队列。
- **线索衰减（C3）**：写入的 AI 无法预知未来检索话术 → 召回失败日志入 stats（✅ M6' 已记 gaps）→ consolidate 同期产出「线索缺口清单」（⏳ M8'）。

## 5 · 存：事实源 / 派生物分离（M-2）

| 层 | 载体 | 规则 |
|---|---|---|
| 事实源 | `.chain/nodes/*.md`（YAML 头 + 自由正文） | 纯文本、人可读、只存干净事实（不变式 I1） |
| 派生物 | `.chain/index/`（嵌入，✅）· `stats.json`（强度，✅）· `audit.jsonl`（审计，⏳）· `code_map/`（骨架，🔲） | 全部可重建、可删除、**绝不写进 YAML**（防 git 噪音与 watcher 风暴，不变式 I2/I8） |

蒸馏产物原则：**骨架而非全文摘要**（海马体索引理论的工程化）。

## 6 · 读：五级检索阶梯 L1–L5（M-3，ADR 0006）

| 级 | 查询表示 ↔ 记忆表示 | 机制 | 可见性 |
|---|---|---|---|
| L1 | 精简线索 ↔ trigger | 编码侧（指南规范）✅ | — |
| L2 | 多线索 ↔ trigger | 语义召回 `recall`（向量）✅ | — |
| L3 | 大意 ↔ 线索 | 联想扩散（expand 升级，rel_desc 作边权，度归一化）🔲 | — |
| L4 | 三内容(title/body/tags) ↔ 关键线索 | 关键词兜底 ✅ | **归档节点自此可见**（⏳ M7'） |
| L5 | 三内容 ↔ 大意 | 关键词兜底 ✅ | **蒸馏骨架自此可见**（⏳ M8'） |

配套铁律：

- **降级链**（宪法第 6 条，✅）：任何增强失效（无索引/无模型/维度损坏）→ 退化为关键词检索 + `degraded:true` 与原因显式声明。检索工具永远可用。
- **冷启动**（C4/T4，✅）：强度全空（新库）→ 退化为「创建时间 + 图谱度数」排序并显式声明。
- **已落地实现形态**（M6'）：向量打分 = 余弦 ×(1 + 0.3×life)；阈值 0.35 常规、不足 k 放宽至 0.2（逐级放宽的工程近似）；derived ×0.85 降权；归档默认过滤、include_archived=true 纳入；无索引/无模型降级关键词。

## 7 · 维护四组件（M-4）

### 7.1 强度信号与双时钟（T2/T3/T5，✅ 主体）

- **ACT-R 激活**：`S = ln(Σ (now − t_j)^(−d))`，d 初始 0.5。**零人工权重**——图谱度数被访问历史自然吸收；d 由命中/未命中反馈校准（50 次窗口，真实数据回归后调）。
- **双时钟**（ADR 0008）：墙钟（客观时间，指数半衰期遗忘）+ **记忆时钟（每次工具调用 +1）**——表达 AI 的使用强度：忙时老化慢、闲时不凭空变老。节点触达另计于 per_id；两者是不同计数器，勿混。
- 强度信号 `f(访问次数, 最近访问, 图谱度数, importance)`；importance 首版单档 `high`，**只影响排序不参与归档**（防 AI 自评注水）。

### 7.2 遗忘与归档（T6，⏳ M7'）

- **归档而非删除**：`archived: true` + 标题 `[归档]` 前缀，文件移入 `.chain/archive/`；90 天未触达仅为**建议阈值**（提示，不自动执行）；`unlink_nodes` 补断边；人可随时恢复。
- 遗忘语义（ADR 0006 后果）：遗忘 = 检索成本升高（L4 起才可见），而非不可见。

### 7.3 语义冲突检测（T8，⏳ M8'）

- 重复检测两阶段：①标题相似度启发式（归一化编辑距离/公共子串，零依赖）②嵌入余弦 > 0.9 → 提示「疑似重复」。
- 复用 `alternative` 边表达竞争关系（**零新增概念**）；force 放行。
- 并发冲突：要么 `CONFLICT:`（乐观锁，✅）要么冻结 `[待裁决]`（status=blocked + 标题前缀，⏳）——**绝不静默覆盖**（ADR 0003）。

### 7.4 巩固蒸馏（T9，⏳ M8'）

- `consolidate`：**dry_run 默认**（先看计划再执行）；BFS/共现聚类；产物 = 骨架节点（`derived:true` + `[蒸馏]` 前缀）+ 正文逐条来源引用；检索自 L4 可见 + 默认降权（×0.85）；**人审摘帽** = 删除 derived 标记转普通节点（GUI 徽标 + 按钮）。
- GIGO 防线（C6 裁决）：只陈述共识事实 + 逐条引用 + 人审——「AI 生成内容入事实源」的唯一安全通道。

## 8 · 治理权（软件层 C1/S-3）

- **冲突即冻结**：CONFLICT 后节点进入 `[待裁决]` 前缀，人处理。理由：Engram 的立身之本是「人可治」，裁决权交给人是唯一自洽选择。
- 信任矩阵：人（GUI）最高权威；本机 AI（stdio）可信；云端 AI（HTTP+token）半可信（⏳）。

## 9 · 终态：记忆图网络（M-5，🔲 4.2 接口已预留）

**QKV 图元映射**：

| 角色 | 记忆图实体 | 载体 |
|---|---|---|
| Q 查询 | 当前对话意图编码 | recall 时现算 |
| K 检索签名 | title+body+rel_desc 嵌入 | `.chain/index/` 派生 ✅ |
| V 内容 | 正文 + 邻域/路径叙述 | `.md` 文件本身 ✅ |
| 图结构 | 注意力传播先验 | 图谱 ✅ |
| 生命周期 | 强度信号 | stats.json ✅ |

**注意力权重** = `sim(child, query) × rel_weight × life_prior`（度归一化消 hub 偏置；rel_weight：contains 1.0 / solves 1.2 / alternative 0.8）；`expand` 输出权重分解 `{sim, rel, life}`（可解释性承诺）。

**三阶段**：4.1 向量索引（✅）→ 4.2 图注意力检索（个性化 PageRank 变体，🔲）→ 4.3 自适应（**微调有明确门槛**：仅当可解释权重实测不足时才评估）。

**「遗忘即检索」闭环**：M-4 的强度信号直接成为 M-5 的生命周期先验——这是 Engram 区别于一切通用记忆 API 的生态位。

# 第二部分 · 理论评估（能否达到预期效果）

## 10 · 评估方法

每个命题查三件事：①理论引用是否恰当（有没有用错出处）②机制因果链是否闭合（信号从哪来到哪去）③预期效果在什么条件下成立、什么条件下失效。结论分四档：**成立 / 条件成立 / 存疑 / 当前不成立**。

## 11 · 逐命题评估

| 命题 | 判定 | 依据与失效模式 |
|---|---|---|
| P1 文件即事实源 + 派生物分离 | **成立** | 这是全项目最扎实的命题：证据链完整（宪法 1/2、ADR 0004、schema 体系），且已被 git 噪音、watcher 风暴、双库漂移三个现实问题反向验证。无理论弱点。 |
| P2 工具即交互翻译 | **成立** | 9 工具 ↔ GUI 交互的映射已由 31 项 E2E 实证。剩余风险在 L3（联想扩散）的 GUI 联动，但那是扩展而非基础。 |
| L1 编码规范（trigger 句） | **条件成立** | 编码特异性引用正确，但有个跨主体陷阱：人写笔记时「编码者=提取者」，而 Engram 里**编码者是写入时的 AI，提取者是未来的另一个 AI**——话术分布漂移，线索必然衰减（C3）。补救（失败日志→缺口清单、L4/L5 兜底）方向对，但「检索上限的决定者」的定位被高估：**L1 是加性优化，真实上限由 L2 嵌入质量决定**。建议在指南中降格表述为「提升命中率上限」。 |
| L2 语义召回（向量） | **条件成立** | 机制自洽，降级链保证了「永远可用」。失效模式：①阈值 0.35/0.2 是拍板值，未按 BGE-small-zh 相似度分布校准（同义词测试集只验证了相对排序，未验证绝对阈值）②硬编码阈值无法随库规模/内容域自适应。预期「凭语义想起」可达，排序质量存疑待真实数据。 |
| L3 联想扩散 | **存疑** | 平行通道假说方向正确（GraphRAG 亦证明图结构是强语义索引），但 rel_desc 作边权的「权重值」无任何校准依据；度归一化是 PPR 的既有结论，需防重复造轮子。可解释性输出 `{sim, rel, life}` 是加分项。未实现，无法实证。 |
| L4/L5 可见性规则（遗忘=检索成本升高） | **成立（待落地验证）** | 理论优雅：遗忘不是删除而是「更费力才想起」。落地风险点：关键词兜底层（search）与向量层必须共享同一套归档过滤，否则归档节点在 search 里「白嫖可见」，L4 语义失效——M7' 验收必须覆盖 search/recall 两端的归档一致性。 |
| 降级链 + 冷启动兜底 | **成立** | 已实现并实测（degraded:true 显式声明、冷启动按创建时间+度数）。粒度瑕疵：冷启动判定是**全库二值**（all_touches_empty），库中一旦有任何一次触达即全局切向量模式——对个别无触达节点 life=0 无加成，但 sim 仍主导排序，实际无害，文档标注即可。 |
| ACT-R 强度方程 + 双时钟 | **当前不成立（最紧迫断裂）** | 见 §12 详析。结论先行：强度公式用了**墙钟秒**作时间轴，而 ADR 0008 的理论意图是「记忆时钟=工具调用序数」。d=0.5 对秒级时间戳衰减极陡（1 天前的触达贡献 ≈ 0.0034，仅为「刚才」的 0.3%），且 S 恒为负值域，未触达节点按 0 处理 → **昨天用过的节点排序低于从未用过的节点**（life 加成变惩罚，审计已提的负值反转）。「遗忘贴近 AI 主观体验」的预期当前达不到。 |
| 归档而非删除（90 天建议阈值） | **成立** | Ebbinghaus 引用正确（提取失败而非存储丢失）；「建议而非自动」符合人治原则。但归档只解决「旧记忆沉淀」，不解决「AI 乱写膨胀」——后者靠守门 + 蒸馏 + 人审，四组件缺一不可。 |
| 重复检测两阶段（余弦 0.9） | **存疑（参数）** | 机制方向对（零新增概念、alternative 边）。但 0.9 对中文嵌入是**极严**阈值：BGE 同义对的相似度通常只有 0.7–0.85，0.9 意味着几乎只有「近乎复制的文本」才报警——召回率可能过低，重复检测形同虚设。阈值应从同义词测试集的分布（同义对相似度下分位）校准，而非拍板。 |
| 蒸馏 consolidate | **条件成立** | 理论防线（共识事实 + 逐条引用 + 人审摘帽 + dry_run 默认）是 GIGO 的正确解法。两个隐忧：①BFS/共现是**结构聚类**，质量取决于建链质量——AI 建的边本身有噪声，GIGO 会经聚类传染②「人审摘帽」依赖 GUI 按钮，纯 MCP 场景下 AI 无摘帽通道，需要 CLI/MCP 侧的 unmark 手段。 |
| 记忆图网络 4.2（图注意力） | **存疑（方向正确，未验证）** | PPR 变体有文献支撑；三因子相乘的权重合成无校准依据；「不训练、先冻结、可解释」是明智的克制（与 Titans 的注意力分配论点一致）。风险：life_prior 若权重过大，触达回写→强度↑→排序↑→触达↑形成**马太效应正反馈**，冷门但相关的记忆永远沉底。安全条件：sim 主导 + life 权重上限（当前 0.3 系数可接受，应文档化上限）。 |
| 治理权（冲突即冻结） | **成立（语义待细化）** | 人治自洽。落地前需定：冻结粒度（整节点 or 冲突字段）、冻结态的可读/可链权限、GUI 徽标与 MCP hint 的可见性。 |
| 校准机制（d 回归，50 次窗口） | **存疑** | 机制存在但可能永远不运行：①「命中/未命中」的标注依赖 AI 使用行为，噪声大（AI 点了结果 ≠ 相关）②50 次窗口对 d 的可靠估计样本不足③没有强制触发与看板，真实数据回归可能永远等不到。建议：d 校准降级为「诊断辅助」，不承担正确性关键路径。 |
| HTTP 接入面 | **存疑** | localhost + 配对 token 的信任边界最小化是对的；但「云端 AI 经用户本机转发」的性能与可用性（配对、轮换、失败模式）无实证。独立主线评估，不阻塞记忆层。 |

## 12 · 最紧迫的理论-实现断裂：强度的时间轴

这是全文最重要的发现，用数字说话。当前实现（`stats.rs`）：触达时间戳 = **墙钟 epoch 秒**；强度 `S = ln(Σ (now − t_j)^(−0.5))`。

| 触达年龄 | 贡献 (age^−0.5) | 单触达 S |
|---|---|---|
| 1 秒前 | 1.000 | 0 |
| 1 小时前 | 0.017 | −4.1 |
| 1 天前 | 0.0034 | −5.7 |
| 1 周前 | 0.0013 | −6.7 |

后果链：`boost = 1 + 0.3 × life`，其中未触达节点 life=0（boost=1.0），**昨天触达的节点 life≈−5.7（boost≈−0.71，得分为负，直接被 0.35 阈值滤掉）**——昨天用过的记忆，排序上不如从未用过的记忆。「强度反映真实触达」（论文 §6.2 Q3.1 验收）与「忙时老化慢」（ADR 0008）双双落空。

**根因**：ADR 0008 定义记忆时钟 =「每次工具调用 +1」——单位是**调用次数**，是主观时间；实现却把触达记在墙钟秒上。理论本身没有错，错在实现用了错误的时钟。修复方向（M7' 前定案）：

1. **触达时间戳改用记忆时钟序数**（t_j = 触达发生时的 memory counter）：d=0.5 下，100 次调用前的触达贡献 0.1、1000 次前 0.03——尺度符合直觉（活跃库每天数百次调用，几天前的记忆仍有可感贡献）；
2. 或 d 重新校准到 ~0.05–0.1（对秒级时间轴），但这是迁就实现而非忠于理论；
3. 无论选哪个，**负值必须归一化**（S 与排序阈值的关系要重定，如 clamp 到 [0,1] 或改用相对排名）。

## 13 · 参数先验风险清单

所有「拍板初值」都是先验参数，当前无一经过真实分布校准：

| 参数 | 值 | 风险 |
|---|---|---|
| recall 常规阈值 | 0.35 | BGE 中文分布未知，可能太严/太松 |
| recall 放宽阈值 | 0.2 | 同上；放宽即召回、放宽的代价是噪音 |
| 重复检测余弦 | 0.9 | 几乎必太严（中文同义对通常 0.7–0.85），召回率低 |
| derived 降权 | 0.85 | 固定乘数，未验证 |
| ACT-R d | 0.5 | 配墙钟秒必然失效（§12），配记忆时钟待验证 |
| 归档建议阈值 | 90 天 | 安全（仅建议），风险低 |
| d 校准窗口 | 50 次 | 统计意义不足（§11 校准项） |

**对策（统一）**：把「同义词测试集」升级为「阈值校准集」——记录同义对/无关对的相似度分布，阈值取分布分位而非拍板值；M7'/M8' 各阶段验收时回填实测分布。

## 14 · 结论：预期效果能否达到？

**总判定：理论框架成立，预期效果「条件达成」——取决于四个前提。**

1. **强度时间轴必须切换到记忆时钟**（§12）。这是当前唯一「理论预期与实现相悖」的硬伤，不修则「遗忘是特性」退化为「刚用过就等于没用过」。
2. **阈值参数从拍板值升级为分布校准值**（§13）。否则检索/重复检测的排序质量与召回率不可预期。
3. **L1 定位降格**：trigger 句是加性优化而非「检索上限的决定者」；效果押注应放在 L2 嵌入质量 + 线索缺口反馈回路上。
4. **人审闭环的 GUI/MCP 支持必须与机制同批交付**（摘帽、[待裁决] 徽标、归档视图开关）——人治是这套理论的兜底，兜底缺席时 GIGO 与冲突冻结都会空转。

理论最扎实的部分（可直接作为论文主张）：事实源/派生物分离、降级链永远可用、归档优于删除、dry_run 默认的治理哲学、「遗忘即检索」闭环的生态位。理论最薄弱的部分：强度方程的时间语义（实现已跑偏）、参数先验性、图注意力与校准机制（未验证）。**方向不需要改，需要的是把「时间语义」和「参数校准」两处从拍板态推进到实测态。**

# 第三部分 · 参数迭代方法论（补丁 1，已应用）

> 本部分由《补丁 1：参数迭代方法论》追加（v1.0，2026-09-08），回答「先全部落地再迭代参数是否可行、如何迭代」。

## 15 · 先落地、后迭代的可行性裁定

**裁定：可行。条件是落地清单必须带上三个前置，且有一处例外。**

- **例外（必须在落地时修复，迭代救不了）**：§12 强度时间轴错用墙钟秒——单位错误不是参数问题，在错误时间轴上迭代 d 是拟合噪声。时间轴切换到记忆时钟序数是 M7' 落地的一部分。
- **可带先验落地、后迭代的参数**：0.35/0.2（recall 阈值）、0.9（重复检测）、0.85（derived 降权）、d（ACT-R 衰减）、90 天（归档建议）、50 次（校准窗口）——先验只保证「能用」，不保证「最优」。
- **三个前置条件**（随功能一起落地，事后补埋要动已冻结接口）：参数外置可配置（§16）、决策点全程留痕（§17）、反馈信号定义（§18）。

## 16 · 前置一：参数外置可配置

- **落点**：`stats.json` 的 `calibrate` 区扩展为参数区（或同级派生文件），记录：参数名 / 当前值 / 生效时间 / 来源（`先验 | 校准 | 人工`）。
- **硬约束**：参数绝不进节点 YAML 事实源（宪法第 2 条）；删除派生文件后以默认先验重生（可重建，ADR 0004）。
- **快照**：每次变更写一条 `audit.jsonl`：旧值 → 新值、效果指标、样本量、触发原因。

## 17 · 前置二：决策点全程留痕

| 决策点 | 必须记录 |
|---|---|
| recall | query、mode、degraded、所用阈值、score 分布（min/max/分位）、top-k 的 id 与分数、是否被采用（§18） |
| 重复检测 | 命中阈值、提示的 id 对、用户动作（force / 接受 / 忽略） |
| 归档建议 | 建议的 id、最后触达、用户动作（接受 / 恢复） |
| consolidate | dry_run 结果；执行后 derived 节点的采用情况 |
| 参数变更 | 快照（§16） |

## 18 · 前置三：反馈信号（隐式标注）

单用户、无遥测 → **行为信号是唯一标注来源**：

| 信号 | 定义 | 含义 |
|---|---|---|
| 正样本 | recall 后 T 秒内 `read_node` 且 id ∈ results | 想起了（真命中） |
| 负样本 | recall 后无 read / gaps 缺口记录 | 没想起（未命中） |
| 重复-真阳性 | 提示后放弃创建或建 alternative 边 | 检测正确 |
| 重复-假阳性 | 提示后 `force=true` | 检测误报 |
| 归档-误判 | 归档后被恢复 / 被 include_archived 召回 | 阈值太激进 |
| 蒸馏-质量 | derived 节点采用率 vs 普通节点采用率 | 降权系数是否合适 |

**噪声声明**：AI 的 read_node 不总因 recall（可能顺手读）——用时间窗 + 结果集内约束降噪；残余噪声由样本量门槛吸收。

## 19 · 迭代循环（四步）

```
① 观察窗：先验值运行，只采集不调；触发 = 每参数 ≥50–100 个反馈样本 或 固定周期（如两周），先到者触发
② 校准：对采集数据取统计量（§20 配方表），不重拍脑袋
③ 回填生效：参数快照入派生文件 + audit.jsonl 记录；校准输出「建议值」，人确认后生效（人治，C1 治理权）
④ 防回归：变更后用固定基准对比（同义词测试集 + 最近 N 条行为日志回放）；效果退化即回滚快照
```

## 20 · 各参数迭代配方

| 参数 | 观测信号 | 校准统计量 | 判定规则 |
|---|---|---|---|
| recall 常规阈值 0.35 | 「分数 → 采用率」曲线 | 分位点 | 阈值 = 使「忽略率」达标（如 ≤30%）的最高分位；约束区间 [0.15, 0.6] |
| recall 放宽阈值 0.2 | 放宽档触发的补足率 | 分位点 | 常规档缺 k 时的补足效果平衡点；约束区间 [0.05, 0.3] |
| 重复检测 0.9 | 提示后 force 与否 | 假阳性率 | 降到假阳性率 ≤10% 的最低阈值；约束区间 [0.7, 0.95] |
| derived 降权 0.85 | derived vs 普通采用率 | 两组比率 | 乘数 = derived采用率 / 普通采用率；约束区间 [0.5, 1.0] |
| ACT-R d 0.5 | 触达年龄（记忆时钟序数）→ 再想起 | 衰减回归 | 置信区间不重叠才调；约束区间 [0.1, 0.7]；零样本保持 0.5 |
| 归档建议 90 天 | 归档建议接受率 / 恢复率 | 比率 | 恢复率 > 20% = 太激进，调大；约束区间 [30, 365] 天 |
| 校准窗口 50 次 | 校准触发频率 | — | 样本不足不触发（置信度门槛） |

## 21 · 迭代纪律（防自毁）

1. **单变量变更**：一次只动一个参数，便于归因；
2. **约束区间**：校准不越界（§20 表），越界建议视为异常；
3. **小样本诚实**：单用户数据少，置信度不足宁可不调；
4. **建议而非自动**：校准输出建议值，人确认生效（符合治理权「人治」哲学）；
5. **快照可回滚**：每次变更留 audit.jsonl，效果指标伴随；
6. **契约与参数解耦**：golden 契约锁行为形状，参数只改数值不改形状——迭代无需重固化契约。

## 22 · 顺序裁定（结论）

M7'/M8' 落地清单 = 功能 + 三个前置（修时间轴、埋采集点、参数外置）。落地完成后进入 §19 循环。

**先落地后迭代是正确顺序；但「落地」的定义里必须包含采集点——否则迭代无从谈起。**

# 第四部分 · 记忆痕迹模型（软分布与沉淀/唤起的对应，补丁 2，已应用）

> 本部分由《补丁 2：记忆痕迹模型》追加（v1.0，2026-09-08），回答「带权词向量语义分布能否联系记忆沉淀与唤起」，理论主线为双痕迹理论（Fuzzy-Trace Theory）。

## 23 · 总对应：双痕迹理论的工程化

认知心理学的双痕迹理论（Brainerd & Reyna, Fuzzy-Trace Theory）：记忆同时存储两种痕迹——**逐字痕迹**（verbatim trace，原文本身，精确但衰减快）与**要点痕迹**（gist trace，语义概要，模糊但最抗遗忘）。人的回忆顺序是**先要点、后细节**：细节错了骨架还在。

「带权词向量语义分布」的压缩/还原方案是它的精确翻版：

| 记忆理论 | 软分布方案 | Engram 落点 |
|---|---|---|
| 逐字痕迹 | 原始文本（不应删除） | `.md` 事实源（宪法第 1 条） |
| 要点痕迹 | `{(v₁,p₁),…,(v_k,p_k)}` 带权分布 | `.chain/index/` 派生物（宪法第 2 条） |
| 先要点后细节的回忆 | 渐进式采样、迭代修正 | 检索阶梯 L1→L5 逐级放宽 |

**由此消解「事实保真」硬伤**：分布从来不替代原文，而是原文旁的一条慢衰减痕迹——事实靠逐字痕迹对账，语义靠要点痕迹唤起。这正是海马体索引理论（索引与内容分离）的另一表述。

## 24 · 沉淀侧对应（巩固/遗忘）

压缩阶段 = 记忆沉淀，四个机制一一对应：

**① 打分 = 重要性编码**。词权重打分即「编码特异性」的判定：什么词值得进入要点痕迹。Engram 现有 `importance`（单档 high，只影响排序不参与归档）与 ACT-R 强度是打分器原型。

**② 归一化分布 = 痕迹本体**。`{(vᵢ,pᵢ)}` 是 gist trace 的数学形式；与蒸馏原则「骨架而非全文摘要」同源。

**③ 离线重建 = 睡眠巩固（systems consolidation）**。海马体在睡眠中向皮层重放巩固记忆；Engram 的 `reindex` 全库重嵌与 M8' `consolidate` 蒸馏即「睡眠」。分布不是写入时一次性算好，而是在离线重放中沉淀。

**④ 遗忘 = 权重衰减，不删除**。分布保留全部词（信息不丢），遗忘只让权重按强度公式衰减、采样概率下降——**「遗忘 = 提取失败而非存储丢失」（Ebbinghaus）与 ADR 0006「遗忘 = 检索成本升高」被字面实现**。90 天未触达不是删除，而是其词在分布中的采样概率趋近于零。

## 25 · 唤起侧对应（检索阶梯）

**① ACT-R 强度直接成为采样概率**：

\[
p_i = \frac{e^{S_i/\tau}}{\sum_j e^{S_j/\tau}},\qquad S_i = \ln\sum (now-t_j)^{-d}
\]

温度 τ 是「可调精度」的第二个旋钮：τ 小 → 分布尖锐 → 只采核心词（高度概括）；τ 大 → 分布平坦 → 细节词也有机会（详细重建）。**m 控制数量，τ 控制选择性**。

**② 检索阶梯 = 采样预算**。L1（精简线索）≈ 小 m 只采最高权重词；L2/L3 增 m；L4/L5（三内容兜底）≈ 大 m 或全量。阶梯「逐级放宽」与渐进式采样是同一件事：每加一轮采样，等于往下走一级阶梯。

**③ 采样 = 线索依赖性提取 + 扩散激活**（Tulving 线索提取；Collins & Loftus 语义网络扩散激活）。采高权重词 = 激活从核心概念开始扩散；迭代修正加入的新词 = 激活扩散到更远节点。冷启动（新库无强度）时分布退化为均匀采样——与冷启动兜底（T4/C4）一致。

**④ 迭代修正 = 再巩固（reconsolidation）+ 多痕迹理论**。记忆每次提取后进入不稳定态并重新编码；Nadel & Moscovitch 多痕迹理论：每次回忆留下一条新痕迹。Engram 已实现其一半——**触达回写**（recall 命中 → strength↑）即再巩固，唤起改变痕迹。渐进式修正每轮生成的新草稿等价于叠加新痕迹。这是 M-5「遗忘即检索」闭环的字面机制。

## 26 · 痕迹闭环总图

```
沉淀（睡眠）                唤起（使用）               再巩固
 .md 事实 + 离线重嵌   ──►   分布采样(τ,m) ──► 生成草稿 ──► 事实校验 ──► 触达回写
（verbatim 痕迹）          （gist 痕迹唤起）    （渐进细化）  （防幻觉）    （权重↑=痕迹加深）
        ▲                                                                    │
        └──────────────────── 权重衰减（遗忘=采样成本↑）────────────────────────┘
```

**双向收益**：

- **对记忆层理论**：强度/双时钟/阶梯首次获得统一数学载体（一个分布）；L1–L5「逐级放宽」由 m/τ 精确表达，替代现在的两档硬阈值（0.35/0.2）；τ 纳入参数迭代方法论 §20 配方表（用「分数→采用率」曲线校准）。
- **对软分布方案**：获得理论合法性（双痕迹、再巩固），并解决「唤起是建设性的」这一根本问题——Bartlett 经典实验证明人回忆时会平滑化、合理化、编造，而工程记忆必须防建设性污染。双痕迹架构给出答案：**要点痕迹负责想起，逐字痕迹负责对账；「生成草稿 → 事实校验」循环即人类回忆的防错机制**。

## 27 · 落地形态与 POC

- **M-5 记忆图网络**：节点 gist 分布 = 图元 K 的带权版本；`life_prior` 直接取 pᵢ；QKV 映射中 K 升级为 `{vᵢ, pᵢ}`。
- **consolidate（M8'）**：蒸馏产物 = 人审过的 gist 痕迹；`derived: true` 节点的分布整体降权是 τ 的自然结果。
- **会话工作记忆**：每轮对话沉淀进分布，唤起时按 m 采样重建——「上下文窗口有限」断裂的压缩解法，事实锚点仍在库中。
- **免训练 POC**：分布 = 节点 top-k 加权 token（H2O 式注意力打分，不造新向量）→ τ/m 双旋钮采样 → 生成模型草稿 → `.md` 事实校验 → 评测「m-失真曲线」。两周可验证核心假设：**gist 痕迹能否在 τ/m 控制下达到可调精度的唤起**。

**结论：软分布方案不是记忆层的替代，而是「沉淀-唤起」闭环缺失的数学载体——把 ACT-R 强度变成可采样的分布，把检索阶梯变成采样预算，把触达回写变成再巩固。**

| L3 | 联想扩散 | 平行通道假说 | sim×rel×life | 🔲 | 图注意力 > 纯向量，消融可归因（E3） |
| L4/L5 | 可见性规则 | 遗忘=检索成本升高 | — | ⏳ | 归档/蒸馏默认不可见、放宽可见（E2） |
| M4.1 | ACT-R 强度 + 双时钟 | ACT-R/ADR 0008 | S=lnΣ(now−tⱼ)^(−d) | ⚠️ | 时间轴切换后「昨日用过的 > 从未用过」（E1，§12 修复验收） |
| M4.2 | 归档而非删除 | 提取失败而非存储丢失 | — | ⏳ | 归档可恢复、零破坏（E2） |
| M4.3 | 重复检测 | 竞争语义（alternative） | 余弦 > 0.9 | ⏳ | 假阳性率 ≤10%（E1/E4） |
| M4.4 | 蒸馏骨架 | 细节遗忘=主动精简 | derived×0.85 | ⏳ | 骨架可追溯、降权不伤排序（E1/E3） |
| M5 | 记忆图网络 | PPR/GraphRAG | QKV+注意力 | 🔲 | 4.2 消融三因子各自贡献（E3） |
| 补丁2 | 痕迹模型 | 双痕迹理论 | softmax(Sᵢ/τ) | 🔲 | m-失真曲线单调、事实校验降错（E1 POC） |
| 补丁1 | 参数迭代 | 数据驱动校准 | 分位/回归 | ⏳ | 回放对比新旧参数（E5） |

**一个闭环**（遗忘即检索）：触达回写 → 强度↑ → 采样/排序优先 → 触达……沉淀（睡眠/离线重嵌）与唤起（检索/采样）是同一闭环的两面，再巩固（触达回写）是闭环的更新算子。

## 29 · 实验方法论（五类实验 + 指标集）

**五类实验**：

- **E1 离线基准**：标准 fixture 工作区（含 ground truth 排序/命中标注）跑批，可重复、可入 CI。适合：检索质量、强度数值、阈值校准、痕迹 POC。
- **E2 故障注入与稳健性**：删派生物、改名模型、截断 embeddings.bin、并发双进程、写中途杀进程、BOM/CRLF 编码边界。适合：降级链、可重建性、归档一致性、守门。
- **E3 消融**：每次移除一个机制（life_prior / rel_weight / derived 降权 / trigger 句），测指标变化——归因每个机制的贡献。
- **E4 纵向真实使用**：单用户真实工作区，以行为信号（补丁 1 §18）为隐式标注，周期 2 周起。适合：采用率、恢复率、d 校准。
- **E5 参数校准回放**：audit.jsonl 行为日志回放，新旧参数对比（补丁 1 §19 防回归基准）。

**指标集**：

| 类 | 指标 |
|---|---|
| 检索质量 | top-1 命中率、NDCG@k、MRR、recall 后采用率（行为信号） |
| 事实保真 | 实体/数字对齐率、生成草稿与 .md 的 verbatim 重叠（痕迹模型） |
| 遗忘健康 | 归档恢复率、库膨胀率（节点数/月）、缺口清单命中率 |
| 效率 | recall 延迟、千节点重嵌时间（<60s 判据）、大图三档（<1k/1k–10k/>10k） |
| 可解释性 | 权重分解 {sim, rel, life} 的单因子归因（消融） |

## 30 · 逐命题实验矩阵

**H1 事实源可重建性（P1）**：删除 `.chain/index/` 与 `stats.json` → `reindex` 重建 → recall 输出与重建前逐字段一致。判据：一致（确定性哈希）。状态：部分（单测已有外部重建可见性，缺端到端一致性断言）。

**H2 L1 编码有效性**：构造配对节点集（同义内容，一组带 trigger 句、一组不带）→ 关键词降级模式 recall → 带 trigger 组命中率显著更高。判据：Δ命中率 > 0 且显著。状态：未做（real_model_recall 仅有单个正例）。

**H3 L2 语义召回与阈值分布**：扩展同义词测试集为「同义/相关/无关」三组 → 记录 sim 分布 → AUC 与可分性；阈值取「忽略率 ≤30%」分位（补丁 1 §20）。判据：AUC > 0.9 且 top-1 命中 ≥ 90%。状态：4 组同义词已过（相对排序），分布校准未做。

**H4 降级链永远可用（宪法 6）**：改名模型目录 / 删除索引 / 截断 bin → recall 仍返回且 `degraded:true` + 原因。判据：永不报错无输出。状态：单测已覆盖；真机故障注入（MCP 进程级）未做。

**H5 强度时间语义（§12 修复验收，最高优先级）**：切换到记忆时钟序数后，构造触达序列（1 / 100 / 1000 次调用前）→ 排序断言「昨日用过的 > 从未用过的」，且与手算 S 值一致。判据：全部通过。状态：未做（当前实现会在本实验失败——这正是修复的验收标准）。

**H6 冷启动**：全新工作区 recall → 排序 = 创建时间+度数且显式声明。判据：与 ground truth 一致。状态：单测已覆盖。

**H7 遗忘 = 检索成本（L4/L5 可见性）**：归档节点在默认 recall/search 均不可见；`include_archived=true` 可见且排序降低；恢复后可再次命中。判据：两端（向量+关键词）过滤一致。状态：未做（M7' 验收）。

**H8 蒸馏保真与降权**：consolidate 产物逐条引用可回溯到源节点（审计性）；derived 降权后，同 query 下排序 vs 不降权的 A/B 差异符合预期。判据：引用 100% 可回溯；降权不改变 top-1 正确性。状态：未做（M8' 验收）。

**H9 图注意力（M-5 4.2，消融）**：`sim×rel×life` vs 纯 sim vs 纯 life——NDCG@k 三组对比；权重分解可解释（每个因子单独移除的指标变化 = 该因子贡献）。判据：全因子 ≥ 任一消融。状态：未做（接口预留）。

**H10 痕迹模型 POC（补丁 2）**：免训练版——top-k 加权 token 分布 → (τ,m) 双旋钮采样 → 生成草稿 → .md 事实校验。判据：m-失真曲线单调（m↑ → 语义相似度↑）；校验后实体/数字错误率显著下降。状态：未做（两周 POC 计划）。

**H11 参数校准回放（补丁 1）**：行为日志回放 → 新旧参数对比 → 新参数不劣于旧参数。判据：NDCG@k 非劣。状态：基础设施未建（audit.jsonl 随 M8' 落地）。

**H12 纵向真实使用（E4）**：两周 stats 反映真实触达；gaps 清单有实质内容；归档建议接受率/恢复率进入配方表。判据：论文 §6.2 各条。状态：未启动。

## 32 · 局限性与未覆盖声明

- **单用户小样本**：E4 统计功效有限——用「分位/排序统计 + 置信度门槛」（补丁 1 §21）替代大样本检验；不达门槛不调参。
- **隐式标注噪声**：read_node ≠ 真命中（补丁 1 §18 已声明降噪手段）；结论以离线基准为主，纵向为辅。
- **外部效度**：所有 benchmark 在中文+工程领域内成立；跨语言/跨域效果未声明。
- **生成模型依赖**：H10 依赖外部生成模型质量，结果随模型版本漂移——POC 报告需附模型版本快照。
- **诚实披露惯例**：每阶段发布说明附「未覆盖项声明」（项目既有传统，三大层 §3.5）。

## 33 · 结论

记忆层理论至此完成「**全貌（§1–9）→ 评估（§10–14）→ 参数迭代（§15–22）→ 痕迹模型（§23–27）→ 实验验证（§28–33）**」的闭环梳理：每个命题都有理论出处、数学形式、实现状态、可证伪预测与实验编号。**理论的可信度不由文档厚度决定，而由 H1–H12 的通过率决定**——按 §31 优先级推进，先做 H5（时间语义）与 H3（阈值分布），它们是当前全部理论风险的源头。
