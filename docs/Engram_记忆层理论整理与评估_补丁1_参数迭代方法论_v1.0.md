# 第三部分 · 参数迭代方法论

## 15 · 先落地、后迭代的可行性裁定

**裁定：可行。条件是落地清单必须带上三个前置，且有一处例外。**

- **例外（必须在落地时修复，迭代救不了）**：§12 强度时间轴错用墙钟秒——单位错误不是参数问题，在错误时间轴上迭代 d 是拟合噪声。时间轴切换到记忆时钟序数是 M7' 落地的一部分。
- **可带先验落地、后迭代的参数**：0.35/0.2（recall 阈值）、0.9（重复检测）、0.85（derived 降权）、d（ACT-R 衰减）、90 天（归档建议）、50 次（校准窗口）——先验只保证「能用」，不保证「最优」。
- **三个前置条件**（随功能一起落地，事后补埋要动已冻结接口）：参数外置可配置（§16）、决策点全程留痕（§17）、反馈信号定义（§18）。

## 16 · 前置一：参数外置可配置

- **落点**：`stats.json` 的 `calibrate` 区扩展为参数区（或同级派生文件），记录：参数名 / 当前值 / 生效时间 / 来源（`先验 | 校准 | 人工`）。
- **硬约束**：参数绝不进节点 YAML 事实源（宪法第 2 条）；删除派生文件后以默认先验重生（可重建，ADR 0004）。
- **快照**：每次变更写一条 `audit.jsonl`：旧值 → 新值、效果指标、样本量、触发原因。

## 17 · 前置二：决策点全程留痕

| 决策点 | 必须记录 |
|---|---|
| recall | query、mode、degraded、所用阈值、score 分布（min/max/分位）、top-k 的 id 与分数、是否被采用（§18） |
| 重复检测 | 命中阈值、提示的 id 对、用户动作（force / 接受 / 忽略） |
| 归档建议 | 建议的 id、最后触达、用户动作（接受 / 恢复） |
| consolidate | dry_run 结果；执行后 derived 节点的采用情况 |
| 参数变更 | 快照（§16） |

## 18 · 前置三：反馈信号（隐式标注）

单用户、无遥测 → **行为信号是唯一标注来源**：

| 信号 | 定义 | 含义 |
|---|---|---|
| 正样本 | recall 后 T 秒内 `read_node` 且 id ∈ results | 想起了（真命中） |
| 负样本 | recall 后无 read / gaps 缺口记录 | 没想起（未命中） |
| 重复-真阳性 | 提示后放弃创建或建 alternative 边 | 检测正确 |
| 重复-假阳性 | 提示后 `force=true` | 检测误报 |
| 归档-误判 | 归档后被恢复 / 被 include_archived 召回 | 阈值太激进 |
| 蒸馏-质量 | derived 节点采用率 vs 普通节点采用率 | 降权系数是否合适 |

**噪声声明**：AI 的 read_node 不总因 recall（可能顺手读）——用时间窗 + 结果集内约束降噪；残余噪声由样本量门槛吸收。

## 19 · 迭代循环（四步）

```
① 观察窗：先验值运行，只采集不调；触发 = 每参数 ≥50–100 个反馈样本 或 固定周期（如两周），先到者触发
② 校准：对采集数据取统计量（§20 配方表），不重拍脑袋
③ 回填生效：参数快照入派生文件 + audit.jsonl 记录；校准输出「建议值」，人确认后生效（人治，C1 治理权）
④ 防回归：变更后用固定基准对比（同义词测试集 + 最近 N 条行为日志回放）；效果退化即回滚快照
```

## 20 · 各参数迭代配方

| 参数 | 观测信号 | 校准统计量 | 判定规则 |
|---|---|---|---|
| recall 常规阈值 0.35 | 「分数 → 采用率」曲线 | 分位点 | 阈值 = 使「忽略率」达标（如 ≤30%）的最高分位；约束区间 [0.15, 0.6] |
| recall 放宽阈值 0.2 | 放宽档触发的补足率 | 分位点 | 常规档缺 k 时的补足效果平衡点；约束区间 [0.05, 0.3] |
| 重复检测 0.9 | 提示后 force 与否 | 假阳性率 | 降到假阳性率 ≤10% 的最低阈值；约束区间 [0.7, 0.95] |
| derived 降权 0.85 | derived vs 普通采用率 | 两组比率 | 乘数 = derived采用率 / 普通采用率；约束区间 [0.5, 1.0] |
| ACT-R d 0.5 | 触达年龄（记忆时钟序数）→ 再想起 | 衰减回归 | 置信区间不重叠才调；约束区间 [0.1, 0.7]；零样本保持 0.5 |
| 归档建议 90 天 | 归档建议接受率 / 恢复率 | 比率 | 恢复率 > 20% = 太激进，调大；约束区间 [30, 365] 天 |
| 校准窗口 50 次 | 校准触发频率 | — | 样本不足不触发（置信度门槛） |

## 21 · 迭代纪律（防自毁）

1. **单变量变更**：一次只动一个参数，便于归因；
2. **约束区间**：校准不越界（§20 表），越界建议视为异常；
3. **小样本诚实**：单用户数据少，置信度不足宁可不调；
4. **建议而非自动**：校准输出建议值，人确认生效（符合治理权「人治」哲学）；
5. **快照可回滚**：每次变更留 audit.jsonl，效果指标伴随；
6. **契约与参数解耦**：golden 契约锁行为形状，参数只改数值不改形状——迭代无需重固化契约。

## 22 · 顺序裁定（结论）

M7'/M8' 落地清单 = 功能 + 三个前置（修时间轴、埋采集点、参数外置）。落地完成后进入 §19 循环。

**先落地后迭代是正确顺序；但「落地」的定义里必须包含采集点——否则迭代无从谈起。**
