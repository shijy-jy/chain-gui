> 触发：orbCurrentY 暴涨；12700；环平面读回异常；加权平均

# 任务：修复 orbCurrentY 暴涨到 12700+ 的读回缺陷

## 现象 (用户实测)
运行后 orbCurrentY 迅速暴涨到 12700 多且时刻变化。

## 数据链分析
1. orbCurrentY = m_OrbY ← ringY = max(m_RingY+0.08, 0.2)
2. m_RingY = (Σ_y固定点 / 1000) / (Σ_w固定点 / 4096)
3. **根因**: GPU 累积 Y 时没有乘权重 w (t-024 遗留缺陷):
   `InterlockedAdd(_AvgY, (int)(y·1000))` — 真正的加权平均应为 Σ(y·w)/Σ(w),
   实际算的是 Σ(y)/Σ(w)
4. t-044 的低平面偏置 (w *= exp(-2.5·Δy)) 把悬空粒子权重压到近 0 →
   收束期粒子被抬升后 Σ(w) 崩塌 (几千粒 → 固定点个位数), Σ(y) 不乘权重照常 →
   比值爆炸: 1000 粒 y≈3 → 3000/0.488 ≈ 6147; 随高度/数量变化 → 12700+ 且波动 ✓
5. 旧行为未暴露的原因: 低平面偏置之前权重 ≈0.5~1 且落地高度被 0.2 下限钳住

## 修复 (compute 一行)
`InterlockedAdd(_AvgY[0], (int)(p.position.y * w * 1000.0));`
分子分母同带 w → 读回 = 真加权平均 (低平面), 恒有界.

## 数值核验
- 溢出: 每粒 y·w·1000 ≤ 20000, 65536 粒 → 1.3e9 < int32 上限 2.147e9 ✓
- 修复后低平面读回 ≈ groundY+0.05~0.15 (贴地粒子权重主导), 落地 ≈ 0.2~0.23 ✓

## 验收标准
1. 编译无错误
2. 运行后 orbCurrentY 全程在 0~10 区间 (正方体中心≈4.25 → 0.2 → +orbRiseHeight),
   调试面板 环平面Y 同步恢复正常
3. 观感由用户 Game 视图裁决
