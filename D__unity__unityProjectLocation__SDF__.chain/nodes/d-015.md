# 攻击特效节奏感方法论

自验收：咨询/方法论节点（无执行改动）。

## 结论
时间曲线是**工具**；节奏感 = 节拍结构 + 每段一条缓动曲线 + 三个通用技巧的组合。

## 1. 节拍结构 (攻击模板)
蓄力 40~50% (慢, 制造期待) → 释放 5~10% (极快, 对比爆发) → 飞行 20~30% (快而稳)
→ 命中 1~2% (**顿帧 3~6 帧** + 冲击波 + 闪白) → 余波 20~30% (慢衰减)。
节奏 = 慢→快→停→慢 的速度反差。

## 2. 曲线形状
蓄力 Anticipation(反向起手) / 释放 EaseOut-Expo / 飞行 EaseIn / 命中 Elastic 过冲
(120~150% 再回落) / 余波长尾 exp 衰减。

## 3. 三个通用技巧
- 顿帧 hit-stop: 命中瞬间冻结世界 3~6 帧, 打击感 80% 来自这一下
- 预期 anticipation (迪士尼 12 原则之首): 动作前先反向, 蓄力即预期
- 挤压拉伸+过冲 squash&stretch: 形状变化传递力度

## 4. 映射本项目
模块化架构天然适配: 黑板加节拍包络 (每相位 AnimationCurve, 模块输出×weight×envelope)
+ 顿帧 (dt=0 冻结粒子与模块). 落地见 d-016.
