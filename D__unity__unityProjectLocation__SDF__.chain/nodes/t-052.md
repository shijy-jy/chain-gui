> 触发：燃烧条带看不到；烧掉部分不消失；溶解失效

# 任务：修复溶解失效回归 (PropertyBlock 二次 Get 丢弃写入)

## 现象 (用户实测)
燃烧条带看不到, 烧掉的部分也不消失 → 溶解材质参数完全没生效。

## 根因 (重构引入)
重构把原来的一段材质块写入拆成两段:
- 第一段: GetPropertyBlock → SetFloat(溶解 4 参数) → **无 SetPropertyBlock**
- 第二段 (暖光): **GetPropertyBlock (重读渲染器当前块, 丢弃第一段全部写入)**
  → SetFloat(暖光 3 参数) → SetPropertyBlock

`GetPropertyBlock` 是覆盖式拷贝 → 第二次 Get 清掉了溶解写入, 最终提交的只有暖光 →
`_DissolveProgress/_AutoBurn/_BurnMinY/_BurnHeight` 从未到达材质。

## 修复
合并为单次提交 (行 444-456): 一次 Get → 溶解 4 + 暖光 3 = 7 个 Set → 一次
SetPropertyBlock. 溶解块前移删除, 暖光段就地扩展。

## 验收标准
1. 编译零错误
2. Game 视图: 立方体按阶段溶解、火线带可见、暖光跟随正常 (三者在同一块提交)
