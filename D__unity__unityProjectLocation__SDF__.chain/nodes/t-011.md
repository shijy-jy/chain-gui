# 任务：溶解边界抗锯齿治理

## 需求原文
「我的 scene 视图效果无论视角远近效果都很好，尤其是清晰度，但是 game 视图锯齿感就比较明显」
→ 追加「还可以从哪里做抗锯齿，除了 MSAA」

## 诊断（关键判断）
用户提供的分析中「后处理+HDR 导致 MSAA 失效」**在 URP 14 Forward 路径下不成立**——URP Forward 的顺序是"不透明几何 → 带 MSAA 中间缓冲 → resolve → 后处理"，MSAA 抗锯齿发生在 resolve 之前，与后处理共存（该限制属于早期 LWRP 4.x/5.x 的历史记忆）。两视图差异的真实来源：
1. **后处理链只在 Game 相机执行**（Scene 视图默认不跑 Volume）：ACES 高光滚降 + Bloom 描出火线阶梯轮廓 + 对比度增强，把 shader 内部锯齿**放大**；
2. **像素密度**：20.6 距离下噪声格仅约 3px（欠采样），Scene 视图凑近时约 30px；
3. **噪声无 mipmap/预滤波**：程序化 Perlin 逐像素硬算，每格 2~3px 时严重欠采样 → shimmer。

## 实施方案（四层抗锯齿体系）
### 内容级（本任务核心，不依赖相机设置）
- **分析式 AA**：`float aaW = max(fwidth(d) * 1.5, 1e-4);` 保证火焰↔布料交界过渡至少占 1 像素；色带/暖光宽度同样钳制 `max(_EdgeWidth, aaW)`
- 重构 frag：火焰颜色统一计算（不再 `if (d<0) return`），可见性由 `lerp(flameOut, clothOut, smoothstep(0, aaW, d))` 决定
- **八度自适应淡出**：fbm3D 每层按 `fwidth` 检测自身屏幕频率，过密自动压掉（见 t-010）

### 输出级的其他手段（已给用户完整清单）
| 层面 | 手段 | 说明 |
|---|---|---|
| 采样级 | Render Scale 1.25~1.5 | URP 资产 Quality；整屏超采样，一切问题一起解决 |
| 后处理空间 | SMAA | 相机 Additional Camera Data；不解决噪声内部混叠 |
| 时间域 | TAA + CAS 锐化 | 唯一能压住动画 shimmer；与 MSAA 互斥 |
| 内容级 | fwidth 分析式 AA | 本任务实现，任意距离平滑 |

### 附带交付：CAS 全屏锐化
- `L17_Sharpen.shader`：AMD FidelityFX CAS 风格，3×3 邻域软 min/max 估计局部对比度 → 只锐化真边缘，平坦区不放大噪点；接在 AfterRenderingPostProcessing
- `L17_SharpenFeature.cs`：URP Renderer Feature，每帧写全局 `_Sharpness`

## 试错记录
- ❌ **URP MSAA 失效说的证伪**：用户提供的分析给了错误机制（"后处理需 resolve 中间缓冲 → MSAA 被跳过"），正确理解恰好相反——正因为有 resolve，MSAA 才能与后处理共存。本轮明确纠正，避免用户按错误前提关 HDR 杀 Bloom。
- ⚠️ **Scene/Game 对比方法的陷阱**：用户在 Scene 视图调参、Game 视图验收，但两视图后处理链不同 → 观感必然失配。给出对齐方法：Scene 视图开 Post Processing 预览 + Ctrl+Shift+F 对齐机位。
- 🔑 **fwidth 是内容级 AA 的关键**：`fwidth(d)` 给出 d 的屏幕空间变化率，用它钳制过渡宽度即可实现"任意距离边缘都占 1 像素"——这是 SDF/程序化特效的经典手法（iq analytic AA）。
