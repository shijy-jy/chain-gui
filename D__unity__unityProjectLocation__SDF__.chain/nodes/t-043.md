# 任务：Inspector 参数面板分组整理

## 用户需求
参数面板合理整理, 整理到合适的组里面, 比如元素球的参数整理到元素球组里面。

## 问题现状
并行会话把新功能组 (P0-2/P1-6/P2) 插进了原字段序列中间, 导致元素球核心参数
(orbBaseSize/orbRadius/orbRiseHeight/orbLandHeight/螺旋/吸积盘全套) 与
enableBurst/respawnDuration 被挤到 "P2 烟层" 组下面显示, 面板逻辑混乱。

## 新分组 (11 组)
引用 → 时序(全部阶段时长+groundY) → 火星(发射与物理) → 漩涡(燃烧力场+收束编排)
→ 元素球(动线/尺寸/外观: orbLandHeight/orbRiseHeight/orbBaseSize/orbRadius/
orbGlowBoost/enableBurst/orbCrown*/orbDistort*) → 吸积盘(凝聚吸入/螺旋: orbGravity/
coalescePull/diskFlatten/avgSigma/coalesceSpin/spinSoft/spiralKeep)
→ 暖光跟随(P0-3) → P0-2 地面余烬光斑 → P1-6 屏幕空间热扭曲 → P2 烟层 → 调试(showDebug)

## 要点
- 仅重排字段顺序 + 调整 [Header], 字段名/类型/默认值全部不变
  → Unity 按字段名序列化, 场景已存值不受影响
- coalesceDuration/holdDuration/respawnDuration 移入时序组 (本质是阶段时长)
- showDebug 独立成"调试"组
- 与并行会话后续字段添加无冲突 (各自字段独立)

## 验收标准
1. 编译无错误; Inspector 分组顺序如上
2. 场景序列化值不丢 (orbBaseSize 2.5 等依旧)
3. 观感由用户 Inspector 视图裁决
