# 溶解着色器子系统

自验收：架构概念节点。代码骨架挂 L17_Dissolve_3D.shader（骨架含公开接口与调用关系）。

## 职责
立方体火线溶解渲染：对象空间 3D Perlin 噪声（跨面连续）+ 火线前锋窄带 + 温度渐变
+ 4 带焦痕 + 边缘热环 + 灰烬 + 双色照明 + fwidth 解析 AA。

## 要点
- `_NoiseTex3D`（或程序化回退）+ `_NoiseScale` 与脚本发射筛选同参数 → 火线与火星天然同步
- `_DissolveProgress/_AutoBurn/_BurnMinY/_BurnHeight` 由 L17_EmberVortexFX 每帧驱动
- 2D 变体（DomainWarp/Sparks/AudioBeat/Ignition, 未挂骨架）: Assets/shader/L17_Dissolve_2D*.shader
- 实现链路: t-001~t-013（C¹ Perlin → 3D 跨面 → 火线/焦痕/辉光逐层迭代）
