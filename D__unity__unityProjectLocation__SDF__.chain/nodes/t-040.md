# 任务：脚本组件面板中文化补全 + 一键配置贴图

## 需求原文
（截图 L17_EmberVortexFX 组件面板）「这部分怎么没有中文提示，而且贴图怎么没有」

## 关键澄清：两套 Inspector 系统

用户截图的是 **MonoBehaviour 脚本组件面板**，而 t-039 做的是 **shader 材质面板**——
两者是完全独立的两套显示系统：

| | 材质面板 (Material) | 脚本组件面板 (MonoBehaviour) |
|---|---|---|
| 显示对象 | shader 的 `Properties` | C# 的 `public` 字段 |
| 中文提示方案 | ShaderGUI（t-039 已做） | `[Tooltip("中文")]`（本轮） |
| 中文 displayName | Properties 语法，天然支持 | 字段名是标识符，**无内置"显示名"属性** |

## 一、脚本字段中文提示

**根因**：`L17_EmberVortexFX` 原有字段其实都有 `[Tooltip]`，**恰恰是我前几轮新加的
21 个字段漏了**（`orbCrownTex` / `enableGroundGlow` / `enableSmoke` 等）——这正是用户
截图里那一块无提示的原因。

**修复**：为 21 个新字段全部补上 `[Tooltip("中文")]`，覆盖四大块：
- 元素球（火焰冠 / 扰动 / 暖光跟随）
- P0-2 地面余烬光斑
- P1-6 屏幕空间热扭曲
- P2 烟层

校验：扫描脚本全部 `public` 字段 → **44 个字段 0 个缺 Tooltip**。

**字段名为何仍是英文**：C# 字段名是标识符，`[InspectorName]` 只适用于 enum 值；
普通字段要改显示名只能自定义 `Editor`（会失去 Header 分组与自动布局，收益/成本比低）。
故采用用户可接受的"退而求其次"方案——字段名英文 + 悬停中文说明。

## 二、贴图槽为空

推荐贴图本应由用户手拖，但用户希望自动配。新增 `Assets/SDF/Editor/L17FXTools.cs`：
菜单 `Tools → L17 一键配置特效贴图`。

- 扫描场景中所有 `L17_EmberVortexFX`（含未激活），**只填空值、绝不覆盖已有设置**，
  支持 `Undo.RecordObject`（Ctrl+Z 可撤）
- 填入：`orbDistortTex`→T_Fire_Distort、`orbCrownTex`→T_Fire_Band、`smokeTex`→T_Fire_Smoke_1、
  `groundGlowNoise`→T_Noise_Turbulence_1、`heatDistortionNoise`→T_Noise_Turbulence_1
- 顺带补粒子材质：`_MainTex`→T_Fire_Ember、`_MainTex2`→L17_Glow（火星双形态）
- 找不到的推荐资源只提示、不中断；最后 `MarkSceneDirty + SaveAssets`

## 三、顺带修了一个隐患（smokeTex 为空 = 白团）

其余贴图留空只是"没效果"，但 `smokeTex` 留空时 shader 的 `_SmokeTex` 默认是 white
→ 会显示成**一团纯白**（与烟完全不像）。已加防护：Init 创建烟 quad 后检查
`GetTexture("_SmokeTex") == null` 则销毁并 `LogWarning` 提示拖图。
