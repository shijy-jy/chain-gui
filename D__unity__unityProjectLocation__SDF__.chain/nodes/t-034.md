## 一、P0-4 火星形态双通道

**现状**：`T_Fire_Ember` 只有星芒一种形态，火星群"整齐划一"。

**改动**（`Assets/shader/L17_EmberParticle.shader`）：
1. 新增属性 `_MainTex2`（光斑贴图 B，柔光型），默认 `white`
2. 采样两张贴图，按每粒 `seed` 分配形态：
   ```hlsl
   float starK   = smoothstep(0.35, 0.65, i.seed);   // 0 = 柔光型 → 1 = 星芒型
   half  texStar = SAMPLE_TEXTURE2D(_MainTex,  sampler_MainTex,  i.uv).r;
   half  texSoft = SAMPLE_TEXTURE2D(_MainTex2, sampler_MainTex2, i.uv).r;
   half soft = lerp(texSoft, texStar, starK);
   ```
3. 星芒项强度也随形态变化（原固定 0.35）：
   ```hlsl
   cross *= (0.18 + 0.45 * starK) * core;   // 柔光型几乎无星芒, 星芒型更锐利
   ```

**留空可用**：`_MainTex2` 默认 white → 柔光型 `soft=1` → 表现为纯径向 `core`/`halo` 叠加，
观感已接近柔光贴图。因此**不配图也能出效果**，不会静默失败。

**ShaderGUI 同步**（`L17EmberParticleGUI.cs`）：
- `s_Order` 加入 `_MainTex2` / `_Softness`（批次2 新增，此前未登记）
- `s_Tips` 补两条中文悬停提示；`_MainTex` 描述改为"星芒型"以匹配新语义
- 注：该 GUI 有"未登记属性自动追加绘制"的兜底，不登记也不会丢字段，但无提示且顺序靠后

  - `Assets/Scenes/SampleScene.unity` → `SampleSceneProfile`(a6560a91…)
- 结论：**Bloom 一直在工作**，只是搜索工具对 `.unity`/`.asset` 不可靠（与 t-030 记录的
  `.asset` 搜索失效是同一类问题）

**改动**（`Assets/Settings/SDFDemoPostProcessing.asset`，已备份 `.bak.20260914`）：

| 参数 | 改前 | 改后 | 理由 |
|---|---|---|---|
| `threshold` | 0.9 | **1.0** | d-011 建议：抬高阈值，让只有真正超亮的（元素球 `_Boost` 3~6、火线）爆开 |
| `highQualityFiltering` | 0 | **1** | 高质量滤波，减少高频亮点（火星）的闪烁与走样 |
| `intensity` | 1.5 | 1.5 | 暂不动，待实机裁决 |

未改：`scatter` 0.7 / `clamp` 65472 / `downscale` 0 / `skipIterations` 1。

**亮度分级分析**（供裁决参考）：
- 火星：`coreCol(≈1.15) × core(≤1) × soft(≤1) × 1.6 × alpha × _ColorBoost(2.5)` → 核心峰值 ≈ 4.6
- 元素球：`_Appear × _Boost`（3 → 驻留期 6）
- 两者峰值与 threshold=1.0 的关系决定"火星干净 / 球和火线爆开"能否成立——
  **需实机确认**，若火星仍过曝则继续抬 threshold 或降 `_ColorBoost`
