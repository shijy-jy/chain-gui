# 验证报告：t-025 元素球伴生场源模型

## 静态核对（读回源码确认, 行号见当前版本）
1. **不受漩涡力场影响** (行 392-402): orbPos 只由 m_OrbY (环平面平滑值) 决定,
   无 scriptedY/编排轨迹参与; 环数据缺失时冻结而非吸附 ✓
2. **共面且在中心**: XZ = 编排中心 XZ (环的中心), Y = 环平面高斯加权平均 ✓
3. **后出现的场源**: 阶段2 后半程亮斑出现 (SmoothStep 0.6→1 × 0.35),
   _CoalesceStrength=0 (无引力); 阶段3 启动 (strength = t² 渐强) ✓
4. **吸收数驱动膨胀** (行 302-304): absorbedFrac = 1 - alive/startCount,
   _Appear = 0.35+0.65×frac, _Scale = 0.45+0.55×frac; startCount 在阶段2→3 记录 ✓
5. **吸收完毕 → 发亮** (行 306-311, 314-334): 存活数=0 (或 3× 超时) 进阶段4;
   _Boost 3→6 (orbGlowBoost) 1.2s 攀升 + 轻微胀大, enableBurst=false 停留 ✓
6. **连续性**: 阶段2 末 scale = 0.45×基准 = 阶段3 起点; appear 0.35 衔接 ✓
7. **爆裂门控**: 阶段5 完整保留, 仅 enableBurst 决定是否进入 (行 329) ✓
8. **循环恢复** (enableBurst=true 时): 阶段0/1 元素球隐藏, m_OrbY 平滑回落到
   新环平面, 无跳变 ✓

## 结论
- 静态层面全部符合用户新模型（伴生环 / 场源 / 吸收驱动 / 发亮停留）
- **运行时画面裁决待并行会话执行**（编译 + Game 视图; 面板 吸收: 0→1 对照球体膨胀）
