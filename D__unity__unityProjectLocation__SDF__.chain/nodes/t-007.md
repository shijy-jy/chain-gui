## 修复记录（用户交付代码的两个 API 误用 bug）
- **Bug A（FX 脚本，17 处编译错误）**：`computeShader.SetFloat(kernelIndex, name, value)` 三参形式——**ComputeShader 的标量/向量参数无 kernelIndex 重载**（参数是全局命名空间，Dispatch 前设置即生效；只有 SetBuffer/SetTexture 有 kernel 重载）。全部去掉 kernel 首参。
- **Bug B（粒子 shader，形态 bug）**：`args = {6,0,0,0,0}`（6 索引/实例，索引表 0,1,2,2,1,3）但 vert 用 `(vertexID&1, vertexID>>1)` 顶点号公式——**SV_VertexID 是索引序号 (0..5)**，id 4/5 代入公式越界到 corner=(-1,3)/(1,3) → 每粒子拖 3 倍上翘长尾 + UV 越界。修复：6 项静态查表 `kQuadCorners[vertexID]` 严格匹配索引表。
