## 一、用 T_Fire_Distort 做湍流扰动（替代 perlin2D）

**选图说明**：`tx/vfx_fire_distort.jpg` 在 `tx/` 目录下，会被导入工具按**颜色贴图**处理
（sRGB 开），做扰动会偏色。项目内 `Assets/VFX/Fire/T_Fire_Distort.jpg` 是同一张图的规范化
副本且已按**数据贴图**配置（sRGB 关）→ 用后者。

**改动**（`L17_FireCore.shader`）：
- 新增 `_UseDistortTex`(Toggle, 默认 0) + `_DistortTex`
- frag 分支：
  ```hlsl
  if (_UseDistortTex > 0.5)
  {
      // 两次不同偏移采样取得 x/y 分量 (避免同值造成 45° 单向偏移)
      float2 dA = uv       + float2( flow * 0.30, -flow * 0.55);
      float2 dB = uv * 1.7 + float2(-flow * 0.22,  flow * 0.40) + 0.37;
      float nx = SAMPLE_TEXTURE2D(_DistortTex, sampler_DistortTex, dA).r;
      float ny = SAMPLE_TEXTURE2D(_DistortTex, sampler_DistortTex, dB).r;
      duv = cuv + (float2(nx, ny) - 0.5) * _Distort;
  }
  else { /* 原程序化 perlin2D 路径 */ }
  ```
- **默认关闭**：未配图时 `_DistortTex` 是 white → 会变成固定偏移，故保持 0
- 脚本新增 `orbDistortTex`；配图则 `SetTexture + SetFloat("_UseDistortTex", 1)`

**收益**：2 次纹理采样 << 2 次 perlin2D（后者需多次 hash + 插值）；纹理更自然。

## 二、用 T_Fire_Band 做火焰冠（修正长条贴图变形）

**发现的实际问题**：`T_Fire_Band` 是 **6240×2656 长条（约 2.35:1）**，而原火焰冠 UV 是
`clamp(cduv + 0.5, 0.01, 0.99)` —— 把长条硬塞进方形区域会**压扁变形**。

**修正**：改为沿条带长度方向流动 + 重复平铺（不 clamp，交给采样器 Repeat）：
```hlsl
float2 crownUV = float2(
    uv.x * _CrownRepeat - _Time.y * _CrownFlow,                       // 横向流动(左亮右暗特性)
    (uv.y - 0.40) * _CrownVScale + _CrownDistort * sin(flow * 1.6 + uv.x * 3.0));
```
新增 `_CrownRepeat`(1.2) / `_CrownVScale`(1.8)。
旋臂无需改：其角度方向本就沿条带长度，`_ArmTwist` 已控制重复次数。

## 三、烟层（新建 L17_Smoke.shader）

**关键设计：烟必须用 Alpha 混合，不能用 Additive**——Additive 会让烟变成亮片，完全不像烟。
故 `Blend SrcAlpha OneMinusSrcAlpha`（与项目其它三个 Additive 特效 shader 不同）。

- 缓慢旋转 + 向上流动（v 减小 = 图案上移）
- 径向淡出消除方形边界
- 软粒子：Alpha 混合下**乘 alpha 有效**（与 Additive 粒子必须乘 rgb 不同），
  同样加 `sceneD <= near` 防护
- 属性：`_SmokeTex` / `_SmokeColor`(可染元素色) / `_Intensity` / `_RiseSpeed` / `_RotSpeed` /
  `_Scale` / `_Softness`

**脚本驱动**：
- 阶段 1（燃烧）：`SmoothStep(0.55, 0.95, progress)` 渐显，尺寸随进度扩散
- 阶段 2（收束）：`1 - m_Rise` 消散
- 位置 = 立方体顶部 `b.max.y + smokeRise * m_Progress`
- 参数：`enableSmoke` / `smokeMaterial`(可留空) / `smokeTex` / `smokeScale`(2.5) /
  `smokeStrength` / `smokeRise`(1.5)

## 试错记录

- 🔴 **`_CrownRepeat` / `_CrownVScale` 只加 Properties 忘了加 CBUFFER 声明（已修）**：
  被本轮的属性声明校验脚本在**编译前**拦下（`MISSING -> _CrownRepeat, _CrownVScale`）。
  这是 `_TailFade` 的同类错误，**校验脚本证明有效**——每次改 shader 后必跑
- 🔑 **长条贴图不能 clamp 采样**：会把非 1:1 的贴图压变形。
  正确做法：沿长边流动 + 采样器 Repeat 平铺
- ⚠️ **烟的 Alpha 混合 vs 火光 Additive**：两者软粒子写法不同——
  Additive 乘 rgb（alpha 不参与混合），Alpha 混合乘 alpha

判定失败调参：

- 火焰冠条纹太密/太疏 → `_CrownRepeat`；位置偏上下 → `_CrownVScale`
- 烟太浓/太淡 → `smokeStrength`；太高/太矮 → `smokeRise`；大小 → `smokeScale`

裁决通过后建 v-* 节点并置 `success`。
