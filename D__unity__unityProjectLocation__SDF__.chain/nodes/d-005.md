# GPU 粒子模拟管线

自验收：架构概念节点。代码骨架挂 L17_EmberVortex.compute。

## 职责
65536 容量 GPU 粒子模拟：CSEmit（正方体 6 面采样 3D 噪声、火线窄带筛选发射）→
CSUpdate（重力/阻力 → 漩涡力场(切向+径向+轴向, 收束期 ramp² 编排) → 吸积盘(盘面共面
收紧+指数吸入+1/r 绕转+吸收吞没) → 末位搬移 swap 回收）→ CSClear/CSClearAvg（清场 +
环平面加权统计清零）。48B 粒子结构，计数器 = InterlockedAdd 普通缓冲。

## 要点
- 环平面统计: 存活粒子高度按水平距离高斯加权 (定点原子加 y×1000/w×4096, 全平台安全)
- 吸入先慢后快 = 拉力上限 orbGravity × 凝聚强度(t²); 绕转随强度衰减 = 角动量转移
- 漩涡中心 _VortexCenter（收束期=底部环, 其余=元素球）与 _OrbCenter（吸积盘中心）分离
- 实现链路: t-014~t-025；关键坑: CopyCount 读 Append 计数器（本系统无效）、
  3D 噪声采样需显式 SamplerState、float 原子加 Metal 不可用
