## 一、P1-7 元素球形状升级（`L17_FireCore.shader`）

三段，各自独立可关：

1. **火焰冠**：上半部（`uv.y` 越大权重越高）叠加向上流动的火舌
   - `crownMask = smoothstep(0.40,0.62,uv.y) * (1-smoothstep(0.72,1.0,d))`
   - v 随时间减小 → 图案上移（火舌上飘）
   - 属性：`_CrownTex` / `_CrownStrength` / `_CrownFlow` / `_CrownDistort`
2. **边缘强化**：billboard 无真实法线，用径向距离替代菲涅尔
   - `rim = smoothstep(_RimStart, 1.0, d)`，乘 `_CoreColor`
   - 属性：`_RimStrength`(0.6) / `_RimStart`(0.62)
3. **旋臂**：凝聚期极坐标螺旋 UV，随 `_Coalesce` 渐显
   - `spiral = atan2 + rad*_ArmTwist*2π - t*_ArmSpin`；不 `frac`（交给采样器 Repeat，
     避免 frac 在接缝跳变）
   - 属性：`_ArmStrength`(0.35) / `_ArmTwist` / `_ArmSpin` / `_ArmFlow`

**脚本**：`m_OrbMat.SetFloat("_Coalesce", coalesce)`（`coalesce` 已在 Update 作用域内）

## 二、P1-8 残火余温（`L17_Dissolve_3D.shader`）

**架构约束（重要发现）**：已燃穿区域被 `clip(d + flameDepth)` 剔除，
**"烧完之后"的区域根本不可见**。因此余温只能落在火焰区深处（`f = -d/flameDepth` 大的地方，
即最早烧到的位置）——这是当前架构下唯一可见的位置，已在 shader 注释中写明。

实现：
```hlsl
float deep = smoothstep(0.40, 0.90, f);
float en   = 0.5 + 0.5774 * fbm3D(np * 1.6 + float3(0, -_Time.y*0.12, _Time.y*0.05));
en = smoothstep(0.35, 0.85, en);                 // 打碎成颗粒, 避免整片同色
float3 emberCol = lerp(_EmberColor.rgb, _AshColor.rgb, saturate(f * 0.8));
flameCol = lerp(flameCol, emberCol, deep * en * _Afterglow);
```
用**程序化 fbm3D 而非噪声贴图**，保证"贴图模式/程序化模式"两种噪声来源下都可用。
属性 `_Afterglow`（默认 0.5，0 = 关闭）。

**未实现：炭化边缘顶点微位移**——见下方"取舍与未做项"。

## 三、P1-9 火星拖尾（`L17_EmberParticle.shader`）

- `_StretchMax` 默认 1.5 → **2.5**
- 新增 `_TailFade`(0.5)：`tail = 1 - _TailFade * saturate(-c.y * 2)` 乘到 col

**比原方案更简单**：d-011 原计划把拉伸轴 `vax` 作为 varying 传进 frag。实际读代码发现
vert 中 `p2 = uax*corner.x + vax*corner.y*(1+stretch)`，而 `uv = corner*0.5+0.5`
→ **`uv.y` 本身就是拉伸轴**，无需新增 varying。省一个 interpolator。

## 试错记录

- 🔴 **`_CrownTex` 默认 white 会导致白斑（已修）**：`_CrownStrength` 原本默认 0.8，
  配上默认 white 贴图 → `crown.rgb = 白` 乘 mask → **球顶出现白色方块**。
  修正：shader 默认改为 **0（关闭）**，由脚本在配置了 `orbCrownTex` 时才设为实际强度。
  **教训：新增贴图类属性时，必须检查"默认 white × 默认开启"会不会产生纯色斑块**
  （同类检查：GroundGlow 的 `_NoiseTex` 在无图时脚本把 `_NoiseStrength` 置 0；
  HeatDistortion 的 `_NoiseTex` 无图时把 `_Strength` 置 0，均已规避）
- ⚠️ **已有材质的参数不会被 shader 默认值覆盖**：`_StretchMax` 改默认 2.5 只影响新材质，
  现有 `L17_EmberParticleMat.mat` 里存的仍是 1.5，需用户在 Inspector 手动调
- ⚠️ **旋臂不要 `frac`**：`frac` 在接缝处会产生跳变；交给采样器的 Repeat 平铺更平滑
- 🔴 **`_TailFade` 只加 Properties 忘了加 HLSL 声明（已修）**：
  报错 `undeclared identifier '_TailFade' at L17_EmberParticle.shader(174)` →
  **整个 shader 编译失败 → 火星粒子完全不渲染**。用户报告的"粒子消失了"真凶是这个，
  不是此前推测的 Depth Texture 未生效（后者只是潜在风险）。
  **根因：加属性时没成对检查 Properties 与变量声明区。**
  修完后写了一次性脚本批量校验 5 个 shader 共 79 个属性是否都已声明，确认无其他遗漏。
