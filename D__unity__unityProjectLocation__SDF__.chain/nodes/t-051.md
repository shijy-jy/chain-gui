> 触发：CS0592；NonSerialized；编译错误

# 任务：修复模块 CS0592 (NonSerialized 误标属性)

## 现象 (Unity 实测编译错误)
- L17_FXModule.cs(50,6) / L17Mod_Ember.cs(25,6)(26,6):
  error CS0592: 'System.NonSerialized' 仅可用于字段声明

## 根因
并行会话把 [System.NonSerialized] 标在**属性**上:
- `public bool Initialized { get; protected set; }` (基类)
- `public float RingY { get; private set; }` / `public uint AliveCount { get; private set; }` (Ember)

## 修复
删除这 3 处特性 (Unity 序列化只作用于字段, 属性本就不序列化, 删除零副作用);
其余 18 处 [System.NonSerialized] 均在字段上, 合法保留 (grep 全量核对)。

## 验收标准
1. Unity 编译零错误 (CS0592 消失)
2. 行为不变 (属性语义无变化)
