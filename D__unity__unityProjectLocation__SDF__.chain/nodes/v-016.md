# 验证：t-017 粒子材质面板提示

## 验证方法
ShaderLab drawer 的 parse error 与 ShaderGUI 的绑定均以 refresh console + 编辑模式读回为证据（面板悬停观感需用户在材质 Inspector 查看）。

## 探针过程证据（3 轮定位引擎限制）
1. `[ToolTip("hello world ascii test")]`（纯 ASCII）→ `Parse error: unexpected $undefined, expecting TVAL_ID or TVAL_VARREF at line 5`
2. `[Header("光斑贴图: ...")]`（带引号中文）→ 同签名 parse error
3. `[Header(裸文本)]` → 同签名 parse error
→ 结论：带字符串参数的 drawer 整体不被 Tuanjie ShaderLab 解析器支持（Unity 官方 2019.3 起支持）；无参 `[HDR]` 现役正常。

## 最终方案验证
- refresh 编译：**0 错误**（此前 L17_EmberParticle 的 line 19 parse error 消失；warning 5 条均为 bridge 自身 NWB 日志，与本任务无关）
- 编辑模式读回：
  - `shader=SDF/L17_EmberParticle propCount=4` ✓
  - `guiType=L17EmberParticleGUI isShaderGUI=True` ✓（Editor 程序集解析命中）
  - 材质数据未动：`_MainTex=T_Fire_Ember`（用户选的星芒贴图）、`_ColorBoost=2.50`、`_Stretch=0.30`、`_StretchMax=1.50` ✓（ShaderGUI 只改显示不碰数据）

## 结论
粒子材质 4 个参数的面板提示全部就位：材质 Inspector 里悬停属性名（光斑贴图/亮度倍增/速度拉伸/拉伸上限）即显示中文说明；未来加参数只需在 GUI 脚本的 s_Order/s_Tips 登记一行。
