> 触发：元素球是正方形；径向采样出方形；圆形裁剪失效；GlowExtent UV

# 任务：修复元素球显示为正方形（应为球形）

## 需求原文
「为什么现在运行完会显示一个正方体元素球，而不是球形，是我的采样不对，我明明是按照径向采样采样的应该是一个圆盘，为什么是正方形」

## 根因（不是用户的径向采样问题）
用户已把火焰壳改为径向极坐标扰动（theta=atan2、噪声按 角度/半径 采样、r2=d+扰动），采样本身正确。问题在**上游的 UV 重映射方向反了**——引入外圈辉光画布时写的：
```hlsl
float2 uv = (i.uv - 0.5) / max(_GlowExtent, 1.0) + 0.5;   // 除法, 方向反
```
`_GlowExtent=2` 时三连锁塌缩：
1. 贴图中央 [0.25,0.75] 被拉伸铺满整个画布——T_Fire_Core 边缘的透明衰减区永远采不到，火焰失去天然圆形衰减；
2. `d = length(cuv)*2` 定义域塌缩到 [0, 0.707]（本体角点只到 0.707）——所有按 d∈[0,1] 设计的遮罩（edgeFade 0.62~0.98、haloMask 0.55~0.95、径向扰动 r2、_CircleFade 0.88）阈值全部够不到；
3. `circle = 1-smoothstep(0.88,1.02,d)` 恒 ≡1 → 方形四角完全不裁 → **正方形就是 quad 本身的边**。

## 修复（一行：除改乘）
```hlsl
float2 uv = (i.uv - 0.5) * max(_GlowExtent, 1.0) + 0.5;
```
本体区（画布中央 1/extent）映射贴图全域 [0,1]，本体尺寸与加辉光前一致，d 恢复设计域（本体边缘=1、本体角=√2）。顺带修好同样建立在 uv/cuv 上的：火焰冠 crownMask 的 uv.y 域、旋臂的极坐标域。

## 验证
- 编译 0 错误（2026-09-14 refresh）
- 运行时实测（凝聚中段，含 _CrownStrength=0.80 带冠状态）：
  - 本体角 d=1.414 → circle≈0（**四角完全裁掉**）✓
  - circle(本体边缘)=0.05、edgeFade(本体边缘)=0.20——修复前两处分别恒 1 和 1（d 域够不到阈值）✓
  - 球 visible=True、_Appear/_GlowExtent=2/_CircleFade=0.88 正常
- 圆形观感最终由用户肉眼确认（视觉验证不信任截图通道）

## 试错记录
- 🔑 **验证代码也要被验证**：本轮验证脚本自算的"本体边缘 d=0.50 (期望1.0)"是脚本算术错误（漏乘 ext），被另一条独立计算路径（dBodyCorner=√0.125×ext×2=1.414 ✓）交叉证伪——单一路径的验证输出先自查算术再下结论。
- ⚠️ **讲解≠验算**：t-017 后曾向用户讲解"本体用压缩 UV 采样"的设计——该设计本身就是错的（除法方向反），讲解时没跑数学把错误设计复述了一遍。给 GPU 专家讲 shader 原理时应该当场验算关键映射。
- 🔑 **billboard 画布放大类特效的 UV 铁律**：quad 放大 N 倍当画布时，本体层采样 UV 必须**乘** N（中央 1/N 区映射全域），径向遮罩的 d 域随之恢复 [0,1]——用除法会把贴图中央拉伸铺满 + 全部径向遮罩阈值失配。
