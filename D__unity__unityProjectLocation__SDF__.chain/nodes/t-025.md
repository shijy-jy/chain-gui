> 触发：元素球不受漩涡影响；伴随粒子环；吸收粒子数膨胀；发亮；爆裂前

# 任务：元素球 = 后出现的独立场源, 伴生粒子环, 吸收驱动, 停在爆裂前

## 用户定义的新模型
1. 元素球始终与最底下大量粒子构成的粒子环平行 (共水平面) 且在中心
2. 随受漩涡力场影响的粒子环一起平行向上; 元素球本身不受漩涡力场影响 (只伴生环)
3. 元素球是"后出现的另一个场源": 启动后牵引所有粒子到吸积盘 + 旋转吸入球心
4. 随吸收的粒子数膨胀、发亮
5. 吸收完所有粒子 → 发亮; 爆裂回正方体 = 下一轮 (当前停在爆裂之前)

## 改动 (L17_EmberVortexFX.cs)
- orbPos: 去掉"回贴编排高度"兜底 → 高度只由环平面 (GPU 加权平均) 决定;
  粒子吞尽 → 冻结最后位置 (发亮驻留点); 首次帧贴环平面
- 阶段2→3 记录 m_CoalesceStartCount = 当前存活数
- 阶段3: 增长改按吸收比例 absorbedFrac = 1 - alive/startCount (不再按时间);
  吸收完所有粒子 (或 3× 超时兜底) → 阶段4; 尺寸连续性修正 (阶段2 末 = 0.45×基准)
- 阶段4: _Boost 3→orbGlowBoost(默认6) 1.2s 发亮攀升 + 轻微胀大, 停留;
  阶段5 (爆裂重生) 由 enableBurst (默认 false) 门控
- 阶段2 重置 _Boost=3 (循环基准); 调试面板加 吸收比例

## 验收标准
1. 编译无错误
2. 阶段3 元素球尺寸/出现度与"已吸收粒子数"单调正相关 (面板 吸收: 0→1)
3. 吸收完毕 → 发亮驻留 (不进入爆裂); 观感由用户 Game 视图裁决
