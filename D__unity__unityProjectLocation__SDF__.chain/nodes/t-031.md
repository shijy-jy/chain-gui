## 二、P0-3 暖光跟随元素球（已做）

### 原理
`L17_Dissolve_3D` 原有的 `_WarmLight` 是**常量溢色**，不随球移动 → 球升起来后暖光还留在原处，
因果关系断裂。改为按"到球心距离"衰减的动态光。

### shader 改动（`Assets/shader/L17_Dissolve_3D.shader`）
1. Properties 新增三项：
   `_WarmLightCenter`(Vector) / `_WarmLightIntensity`(Range 0~3, **默认 0**) / `_WarmLightFalloff`(Float)
2. CBUFFER 同步声明
3. frag 在 `clothCol` 之后新增 5b 段：
   ```hlsl
   if (_WarmLightIntensity > 0.001)
   {
       float3 toC   = _WarmLightCenter.xyz - i.posWS;
       float  dist2 = max(dot(toC, toC), 1e-4);
       float3 L     = toC * rsqrt(dist2);
       float  ndl   = saturate(dot(normalize(i.norWS), L));
       float  atten = exp(-dist2 * _WarmLightFalloff) * (0.35 + 0.65 * ndl);
       clothCol += _WarmLight.rgb * atten * _WarmLightIntensity;
   }
   ```
   - 复用 v2f 已有的 `posWS`(TEXCOORD2) 与 `norWS`(TEXCOORD1)，无需改动顶点输出
   - **默认强度 0 → 未接脚本时表现与改动前完全一致**（向后兼容）
   - 含法线项：背对球的一面不亮，比纯距离衰减真实

### C# 改动（`Assets/SDF/Scripts/L17_EmberVortexFX.cs`）
1. 新增 `WarmCenterId / WarmIntensityId / WarmFalloffId` 三个 PropertyToID
2. 新增可调参数：`warmLightStrength`(默认 1) / `warmLightRadius`(默认 2.5)
3. 在 `orbPos` 定义**之后**写入材质块：
   ```csharp
   float warmK = (m_Phase == 0) ? 0f
               : (m_Phase == 1) ? m_Progress
               : 0.4f + 0.6f * m_OrbAppear;
   targetRenderer.GetPropertyBlock(m_Block);
   m_Block.SetVector(WarmCenterId, orbPos);
   m_Block.SetFloat(WarmIntensityId, warmK * warmLightStrength);
   m_Block.SetFloat(WarmFalloffId, 1f / Mathf.Max(warmLightRadius * warmLightRadius, 0.01f));
   targetRenderer.SetPropertyBlock(m_Block);
   ```
   强度随阶段：阶段 0 无 → 阶段 1 燃烧渐强 → 阶段 2+ 随球显形增强（阶段 4 达峰值）

## 试错记录

- 🔑 **变量作用域坑（差点写错）**：`orbPos` 定义在**第 400 行**，而脚本原有的
  `m_Block.SetFloat(...)` 在**第 365~370 行**——**不能**把暖光设置加在原有 m_Block 段里，
  否则 `orbPos` 尚未定义（编译错误）。解决：在 `vortexCenter` 之后**再开一段** Get/Set。
  （`GetPropertyBlock` 会取回已有设置，二次 Set 不会覆盖前面的 `Progress/BurnMinY` 等）
- ⚠️ **法线归一化**：`i.norWS` 经插值后非单位向量，初版漏了 `normalize`；
  同文件 228 行主光计算用的是 `normalize(i.norWS)` —— 已对齐修正
- ⚠️ **`.asset` 改编码风险**：写入前先检测原文件 BOM（三份均为无 BOM），按原编码回写，
  避免 Unity 读取异常
