# 任务：燃烧期粒子发射量提升 2~3 倍

## 需求原文
「现在的每燃烧一段正方体散落的粒子数需要翻2-3倍」

## 实现
- `spawnRate` 默认 900 → **2400**（≈2.67 倍，落在 2~3 倍区间）
- 说明：spawnRate 是"每帧发射尝试次数"，实际散落数 = 尝试 × 发射带接受率（约 0.2），两者线性关系 → 翻倍尝试即翻倍散落
- 粒子上限 32768 余量充足：12s 燃烧实际存活 ≈ 2400×12×0.2 ≈ 5760
- 单帧 emit 循环 ≈ 40 次 × 3D 贴图采样，GPU 成本可忽略

## 自验收
参数级核对：spawnRate 默认值 2400，注释同步更新；接受率逻辑未动（CSEmit 不变），线性放大关系成立。最终密度观感由用户 Game 视图裁决（嫌密/嫌稀可继续按比例调 spawnRate）。
