# 任务：螺旋吸收逻辑重排

## 用户需求
仔细整理吸收逻辑; 开放螺旋吸收强度参数; 吸收期螺旋几乎看不到要修;
吸收要"近慢远快"; 从吸收开始元素球同步膨胀, 吸收完毕膨胀到最大。

## 吸收逻辑分析 (改前, 螺旋不可见三根因)
1. 切向绕转 ×强度×(1−0.7强度) **双重门控+端部衰减** → 吸收期大部分时间只有 1~25% 强度
2. 吞没半径最大 0.93·orbRadius, 而快旋区峰值在 0.6 → 粒子刚进快旋区就被吞, 看不到绕圈
3. 缩小 4/秒 → 进吸收区 0.25s 缩没, 近心存活 < 一圈轨道时间 (0.56s)

## 修复 (compute 凝聚分支)
1. **螺旋全程满强度**: spinSpeed = Spin·r/(r²+soft²) 不再乘强度/衰减;
   混合系数下限 0.35 → 吸收一开始螺旋就有明显分量
2. **近慢远快**: 径向保持指数吸附 v=k·dist (远快近慢) + 强度二次缓入 (吸入先慢后快);
   近心吸收放缓 = 吸收区收窄 (0.9~2.1) + 缩小 1.2/s (~0.8s) + 吞没半径收小 (0.15~0.6)
   → 粒子绕球 ~1.5 圈才被吞
3. **参数收敛**: spiralKeep 移除 (端部衰减取消后无意义), 螺旋强度 = coalesceSpin (主调),
   半径形态 = spinSoft
4. 元素球同步膨胀: 既有实现已满足 (阶段3 m_OrbScale = 0.45+0.55·absorbedFrac,
   吸收开始即膨胀、完毕达最大) — 确认保留

## 数值预期
- spinSoft=0.6 峰值切向 6.67 u/s 全程生效; 径向 (r=1.5) ≈ min(3.6·强度, 9·强度)
- 近心 (r≈0.6) 绕行 0.56s/圈 × ~1.5 圈后才被吞 → 螺旋肉眼可见

## 验收标准
1. 编译无错误 (无 _SpiralKeep 残留)
2. 吸收期粒子呈明显螺旋绕入, 近心绕圈后缩小消失; 调 coalesceSpin 螺旋明显度变化
3. 观感由用户 Game 视图裁决
