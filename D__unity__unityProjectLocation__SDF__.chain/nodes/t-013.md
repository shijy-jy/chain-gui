# 任务：火星粒子阶段语义修正与渲染链修复

## 需求原文（用户对特效阶段的口语化定义）
「粒子在燃烧阶段随着燃烧的进行持续生成并下落，燃烧结束后粒子仍旧存活，此时下落到地面的火星受漩涡力场向上移动。阶段3粒子在漩涡力场作用下，持续2到3秒，阶段4 暂时按照你的建议修改」

## 一、阶段语义修正（对 t-007/t-008 的迭代）
### 旧实现的问题
- 粒子寿命只有 1.5~2.8 秒 → **燃烧阶段粒子就消失了**，与用户要求的"燃烧结束后仍旧存活"矛盾
- 无地面概念 → 火星一直下坠，无法"落地停留"
- 漩涡靠 `vortexRamp` 爬升 + `holdDuration` 停留，总时长不可控

### 新语义（严格按用户定义）
```hlsl
// 1. 燃烧期: 寿命不衰减 → 落地停留并持续发光
if (_VortexStrength > 0.001 && p.life > 0.0)
    p.life -= dt / max(_VortexLifetime, 0.01);      // 仅漩涡期衰减

// 2. 地面支撑: 落地停住 (漩涡期保留速度供力场抬升)
if (p.position.y <= _GroundY) {
    p.position.y = _GroundY;
    if (_VortexStrength < 0.001) p.velocity = float3(0,0,0);
}

// 3. 重力被上升气流抵消 (否则抬升力卷不动地面火星)
p.velocity.y -= _Gravity * dt * (1.0 - _VortexStrength * 0.9);
```
- 新增参数：`_GroundY`（地面高度）、`_VortexLifetime`（收束总时长）
- 脚本：`vortexDuration = 2.5s`（替代 ramp+hold）；漩涡力度上调（切向 3.5 / 径向 2.5 / **抬升 5.0**，须压过重力）

## 二、渲染链修复（本任务实测修复的两处断点）
1. **CopyCount 恒为 0**：`ComputeBuffer.CopyCount` 只读取 Append/Consume 缓冲的隐藏计数器，而 `_Counter[0]` 是 `InterlockedAdd` 维护的**普通数据** → instanceCount 恒 0 → 从不绘制。修复：CPU `GetData` 读回计数写入 args。
2. **材质 SetBuffer 缺失**：`new Material(particleMaterial)` 是属性副本，**StructuredBuffer 绑定不随复制传递** → shader 读全零（alive=0 → size=0）。修复：Init 中显式 `m_RenderMat.SetBuffer("_Particles", m_Particles)`。
3. **采样器声明缺失**：compute 中 `SampleLevel(sampler_NoiseTex3D,...)` 引用了被删掉的 `SamplerState` 声明 → **compute 无 `sampler_` 自动生成机制** → 整体编译失败 → `Kernel at index is invalid`。修复：恢复显式声明。

## 三、火星尺寸参数化
- 旧版尺寸**硬编码** `0.015~0.04` 世界单位 → 在 20.6 相机距离下仅约 1 像素（不可见），且无法从 Inspector 调整
- 改为 `_SparkSize` 参数（默认 0.15 ≈ 3.5px）

## GPU 安全守则自查
1. 无死循环 ✅ 2. `idx >= _Counter[0]` 边界检查 ✅ 3. 死亡回收用 InterlockedAdd 原子减 + 末位搬移（多线程竞态为 GPU 粒子标准做法，视觉不可察）✅

## 试错记录
- ❌ **"粒子看不见"的三重误判链**：Spark Size 拉大到 0.5 仍不可见 → 说明**不是尺寸问题**。逐环节排查后定位到 draw 侧两处断点（CopyCount + SetBuffer）——**compute 侧数据完全正常（存活数百），只是从未被绘制**。教训与 t-008/v-007 完全一致："数据存在 ≠ 渲染发生"。
- ⚠️ **compute 编译失败是静默的**：kernel 失效后每帧刷 `Kernel at index (N) is invalid`，但粒子数据/状态机全正常 → 易误判为逻辑问题。已在脚本 Init 加 kernel 有效性校验 + Update 守卫。
- ⚠️ **新 ComputeBuffer 未清零**：buffer 可能带垃圾值导致计数错乱，须显式 `SetData({0})`。
- 🔑 **用户的口语化阶段描述需要精确转译为物理规则**：用户说的"粒子仍旧存活"要落到"寿命衰减仅在漩涡期启用"；"受漩涡力场向上移动"要落到"重力被抵消 + 抬升力压过重力"。
