# 视觉优化详细实施方案（t-030 产物）

自验收：纯设计节点，无运行时改动。所有"预期表现"均为**预测**，须实机裁决。

本方案是 d-010（方向清单）的**可施工版**：补齐实现细节、具体参数、前置条件与预期观感。
三项关键补充：① S0 前置阻塞项（d-010 遗漏）② Additive 混合下的适配修正 ③ 资料代码纠错。

---

## S0 · 前置阻塞项（必须先做，否则 P0-1 / P1-6 必然失败）

**现状**（`Assets/Settings/URP-HighFidelity.asset`）：

```
m_RequireDepthTexture: 0     ← 软粒子需要，当前关闭
m_RequireOpaqueTexture: 0    ← 热扭曲需要，当前关闭
```

### S0-1 开启 Depth Texture
- 改 `m_RequireDepthTexture: 0 → 1`
- 用途：P0-1 软粒子
- 代价：多一次深度拷贝/预通道，中等

### S0-2 开启 Opaque Texture（P1-6 才需要，可延后到做热扭曲时再开）
- 改 `m_RequireOpaqueTexture: 0 → 1`
- 代价：**全屏 blit，开销明显**，且半透明物体不写入该纹理
- 建议：与 P1-6 同步做，不要提前开

### S0-3 三份 URP Asset 要同步
`URP-Performant` / `URP-Balanced` / `URP-HighFidelity` 三份都在 Settings 下。
Quality Settings 切换档位会让未改的那份生效 → **建议三份都改**，否则换档后特效凭空失效。

### ⚠️ 不开就写的失败形态（重要）
`SampleSceneDepth` 在纹理未启用时返回 0 → 场景深度 0 → 深度差为负 → `saturate` 归零 →
**Additive 粒子整体消失**。不报错、不报警，只表现为"特效不见了"，极易误判为 shader 写错。
排查顺序：先看 URP 开关，再看 shader。

## P0 · 立竿见影

> 执行序未按 d-010 原编号，改按**性价比**重排：P0-3 改动最小而收益最直观，建议首发。

### P0-3 暖光跟随元素球（改动最小，建议第一个做）

**现状**：`L17_Dissolve_3D` 的 `_WarmLight` 是常量色，火焰照亮布料的效果**不随球移动**——
球升起来后，暖光还留在原处，因果关系断裂。

**改动**：
1. `L17_EmberVortexFX.cs`：`_OrbCenter` **已在 compute 侧传入**，复用它再传一份给溶解材质
   ```csharp
   m_Block.SetVector(WarmLightCenterId, orbPos);   // 新增
   m_Block.SetFloat(WarmLightIntensityId, glowK);  // 随阶段 2→4 渐强
   ```
2. `L17_Dissolve_3D.shader`：新增 `_WarmLightCenter` / `_WarmLightIntensity`，
   把原本恒定的溢色改为按世界空间距离衰减：
   ```hlsl
   float  dCenter = distance(wpos, _WarmLightCenter.xyz);
   float  atten   = exp(-dCenter * dCenter * _WarmLightFalloff);
   col   += _WarmLight.rgb * atten * _WarmLightIntensity;
   ```

**参数**：`_WarmLightFalloff` 初值 0.25（球半径约 2~3 时，衰减到球外 2~3 倍半径）

**预期表现**：元素球升起、飞过立方体上方时，立方体表面的暖橙色高光**跟着球走**，
球越亮（阶段 4 `_Boost→6`）地面上/立方体上的暖光越强。
建立"球是光源"的直觉——这是从"特效贴图"升级到"发生在世界里"的关键一步。

**风险/回退**：几乎零风险。改坏了把 `_WarmLightIntensity` 置 0 即回到现状。

### P0-1 软粒子深度淡化（Additive 特化版）

**现状**：`L17_EmberParticle` / `L17_FireCore` 均为 `Blend One One` + `ZWrite Off`，
与地面/立方体相交处有**硬边纸片感**。

**改动**（两个 shader 同构）：
1. `#include ".../ShaderLibrary/DeclareDepthTexture.hlsl"`
2. `v2f` 新增 `float4 screenPos : TEXCOORD4; float viewDepth : TEXCOORD5;`
3. `vert`：`o.screenPos = ComputeScreenPos(o.posCS); o.viewDepth = o.posCS.w;`
   （透视投影下裁剪空间 `w` = 视空间 `-z`，即粒子视深度，正数）
4. `frag`：
   ```hlsl
   float2 suv    = i.screenPos.xy / i.screenPos.w;
   float  rawD   = SampleSceneDepth(suv);
   float  sceneD = LinearEyeDepth(rawD, _ZBufferParams);   // ★ 传 float4，勿只传 .x
   float  soft   = saturate((sceneD - i.viewDepth) / max(_Softness, 1e-4));
   col *= soft;                                            // ★ Additive 必须乘 rgb
   ```

**⚠️ 两个必踩的坑**（详见 t-030 资料纠错）：
- `LinearEyeDepth` 第二参传 `_ZBufferParams`（float4），不是 `.x`
- `Blend One One` 下 **alpha 不参与混合**，网上教程的 `col.a *= soft` 会**静默失效**，
  必须乘到 rgb

**参数**：`_Softness` 初值 **0.6**（0.5~2.0；越大过渡越宽、粒子整体越暗）

**预期表现**：火星飞近地面或穿过立方体时，不再出现"贴纸被切断"的硬边，
而是**柔和地淡入淡出**；元素球靠近地面时底部自然虚化，像是真的"陷进"场景里。
镜头贴地低角度观察时改善最明显。

**风险/回退**：
- 深度未开 → 粒子全消失（见 S0）
- `_Softness` 过大 → 粒子整体变暗、特效变弱 → 调小
- 回退开关：`_Softness` 设 0 时 `soft` 恒为 1（已用 `max` 保护，不会除零）

### P0-2 地面余烬光斑

**现状**：元素球/漩涡不照亮地面，落地没有"重量感"。

**改动**：
1. 新增贴地水平 quad（Additive，`ZWrite Off`，渲染队列在地面之后）
2. 片元：`exp(-d²·k)` 径向衰减 + **叠一层 `T_Noise_*` 噪声做斑驳余烬**
   （可用 t-029 下载的 CC0 噪声：`T_Noise_Turbulence_1` 或 `T_Noise_Melt_1`，UV 缓慢流动）
3. 位置 = 漩涡/球心的地面投影（复用 `_OrbCenter` 的水平分量）
4. 强度由阶段驱动：阶段 2 收束渐亮 → 阶段 4 驻留最亮 → 阶段 5 重生衰减

**参数**：半径约 3~4（略大于漩涡半径），噪声流动速度 0.1~0.2

**预期表现**：地面出现一团**会缓慢流动的暖色光晕**，边缘有明灭的余烬颗粒感。
元素球悬浮时地面有对应的亮斑 → 观众下意识认为"这个球在发光、在烧烤地面"。
比单纯加实时点光源便宜得多且更可控。

**风险/回退**：噪声选择不当会像"脏污" → 换噪声或降噪强度；与地面 Z-fighting → 抬高 0.01~0.02。

### P0-4 火星形态双通道

**现状**：`T_Fire_Ember` 只有星芒一种形态，火星群看起来"整齐划一"。

**改动**：shader 加第二张贴图 `_MainTex2`（软光斑 `L17_Glow` 或生成器产出），
按每粒 `seed` 决定形态倾向：
```hlsl
float k = step(0.5, i.seed);                       // 或按 seed 连续 lerp
half  s = lerp(sample(_MainTex).r, sample(_MainTex2).r, k);
```
更细致的做法：星芒项（`cross`）权重随 `seed` 变化，软斑项反向变化。

**预期表现**：火星群里**有的尖锐如星芒、有的柔和如光点**，且随生命周期从星芒
（新生高温）过渡到软斑（冷却），群感层次明显丰富。

**风险**：两张贴图 color space 不一致会偏色 → 两张都用同一导入设置。

---

### P0-5 Bloom 分级校准

**现状**：Bloom 参数未针对本项目 HDR 分层校准，火星/火线/元素球可能糊成一团。

**改动**：调 URP Volume → Bloom 的 `Threshold` / `Intensity` / `Scatter`。
建议先抬高 Threshold（~1.0），让只有真正 HDR 超亮的（元素球 `_Boost→6`、火线）爆开，
火星（`_ColorBoost` 2.5）保持"小而亮但不糊"。

**预期表现**：该爆的地方爆（元素球、火线），该干净的地方干净（火星是清晰小亮点），
三者亮度层级**可区分**，而不是一片过曝的橙光。

## P1 · 进阶

### P1-6 屏幕空间热浪扭曲（依赖 S0-2）

**现状**：`L17_Dissolve_3D` 的 `_RingFreq/_RingStrength` 只是**色带脉冲**，
不是真正的空气折射；元素球周围空气完全不变形。

**改动**：
1. 新增扭曲 pass（推荐：元素球/火线处的**局部 quad**，比全屏 Feature 便宜）
2. `#include ".../DeclareOpaqueTexture.hlsl"`，`ComputeScreenPos`
3. 双层噪声流动产生扰动（用 `T_Noise_Turbulence`，两层反向流动叠加）
   ```hlsl
   float2 o1 = SampleNoise(uv + t * 0.1);
   float2 o2 = SampleNoise(uv * 2 - t * 0.15);
   float2 distortion = (o1 + o2 - 1.0) * _Strength;
   float2 suv = screenUV + distortion;
   ```
4. **边缘衰减**（防 UV 越界，必做）：
   ```hlsl
   float edge = smoothstep(0, 0.1, suv.x) * smoothstep(1, 0.9, suv.x)
              * smoothstep(0, 0.1, suv.y) * smoothstep(1, 0.9, suv.y);
   distortion *= edge;
   ```
5. 强度与元素球 `_Boost` / 火线 `_EmberGlow` 联动

**参数**：`_Strength` 初值 **0.015**（0.01~0.03；再大就假）

**预期表现**：元素球、火线后方的背景（地面、立方体轮廓）出现**轻微晃动的折射**，
像夏天柏油路上方的热空气。强度要克制——能感觉到"空气在动"但不至于让画面扭曲变形。

**风险**：
- Opaque Texture **只含不透明物体**，半透明的火焰本身不会被扭曲
  → 火焰边缘与扭曲后的背景可能对不上，需靠降低强度 + 边缘衰减掩盖
- 全屏 blit 开销，移动端慎用
- 回退：`_Strength = 0`

---

### P1-7 元素球形状升级（火焰冠 + 边缘强化 + 旋臂）

**现状**：`L17_FireCore` 是**固定圆形剪影**的 billboard，`T_Fire_Band`（火流条带）尚未使用。

**改动**：
1. **火焰冠**：元素球上半部（`uv.y > 0.5`）叠加 `T_Fire_Band` 或 t-029 的
   `T_Fire_Flipbook_8x8`（UV 分格 1/8），UV 向上流动 + Perlin 扰动，
   强度随 `_Boost` 增大 → 顶部"火舌上飘"
2. **边缘强化**：billboard 无真实法线，用径向距离替代菲涅尔
   ```hlsl
   float rim = smoothstep(0.65, 0.98, d);
   col += _CoreColor.rgb * rim * _RimStrength;
   ```
3. **旋臂**（凝聚期）：`T_Fire_Band` 走极坐标螺旋 UV（角度随半径偏移），
   随 `_Coalesce` 渐显 → 粒子被"卷进来"的方向感

**预期表现**：元素球不再是"一张会动的圆形贴图"，而是**顶部有火舌向上飘、边缘一圈锐利亮环、
凝聚期能看到火焰纹路被旋转卷入**。剪影会随火焰冠自然起伏，不再是标准圆形。

**风险**：火焰冠过强会变成"头上顶个火把" → 控制在上半部且随距离衰减。

---

### P1-8 溶解边缘升级（残火余温 + 炭化位移）

**改动**：
1. **残火余温**：已燃尽区域（`progress` 之上）按"烧完后经过的时间"降温——
   暗红 → 焦褐 → `_AshColor` 灰烬，用噪声打碎避免整片同色
2. **炭化边缘位移**：火线附近顶点沿法线微位移（炭壳翘起）

**预期表现**：火线扫过后，下方不是立刻变灰，而是**留一片逐渐降温变暗的暗红余烬**，
边缘有炭壳翘起的立体感。燃烧过程的"时间厚度"明显增强。

---

### P1-9 火星拖尾增强

**改动**：
1. `v2f` 传出拉伸轴 `vax`（当前只在 vert 内部使用）
2. 沿拉伸轴做尾部衰减：`tail = 1 - abs(dot(c, vax)) * _TailFade`
3. `_StretchMax` 1.5 → 2.5

**预期表现**：火屑从"被拉长的椭圆"变成**有渐隐尾巴的流星条**，速度感显著增强。

```
S0-1 开 Depth Texture
  └─ P0-3 暖光跟随        ← 改动最小、收益最直观，先看效果
  └─ P0-1 软粒子（粒子 + 元素球）
  └─ P0-2 地面余烬光斑
  └─ P0-4 火星双形态 / P0-5 Bloom 校准

  └─ S0-2 开 Opaque Texture → P1-6 热扭曲

  └─ P1-8 / P1-9
```
