# 验收：五阶段元素球循环（对 t-015）

## 验了什么 & 怎么验的
### 1. 状态机核对（6 阶段）
| 阶段 | 触发条件 | 关键动作 |
|---|---|---|
| 0 立方体 | 启动/重生后 | progress=0, orb 隐藏, idleDuration |
| 1 燃烧 | idle 结束 | 用户前锋模型原样（progress 爬升 + 渐进漩涡 + 发射） |
| 2 收束 | progress≥1 | 全涡, collect=1, vortexDuration |
| 3 凝聚 | 收束结束 | coalesce=1, orb ElasticPop 诞生, _Appear 0→1 |
| 4 驻留 | 凝聚结束 | _Appear=1, 呼吸脉动 holdDuration |
| 5 重生 | 驻留结束 | orb 先涨后缩消散, 立方体 ElasticPop 弹回 |
| → 0 | 重生结束 | ClearParticles + scale 精确还原 + 循环 |

- 阶段转换逻辑逐一核对 ✅ 无死路 ✅ 无并发写冲突 ✅

### 2. compute 凝聚行为核对
- `_Coalesce=1` 且粒子进入 `_OrbRadius*1.8`：近心切向加速（1/r 缩放）+ 向心拉力 + 缩小(4×/s) + 增亮(→3.0) ✅
- 吞没条件：`distC < _OrbRadius*0.12` 或 `size < 0.002` ✅
- 凝聚期定时寿命衰减关闭（`_Coalesce < 0.5` 才衰减）✅
- 用户前锋模型（CSEmit）零改动 ✅

### 3. FireCore shader 核对
- billboard（相机右/上向量）✅
- 三层合成：火焰壳 UV 流动 + perlin2D 湍流扰动 + 边缘淡出 / 内核实心 / 光晕 ✅
- `_Appear`/`_Scale` 脚本驱动、呼吸脉动、HDR `_Boost` ✅
- include L17Noise.cginc（同目录）✅

### 4. 安全性核对
- orbMaterial 为 null 时优雅跳过（`if (orbMaterial != null)`），特效仍按旧三阶段运行 ✅
- 立方体 baseScale 捕获/还原 ✅
- 释放路径：orb GO/材质加入 OnDisable 清理 ✅
