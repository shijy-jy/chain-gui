# 任务：L18_Dissolve3D —— 立方体表面连续溶解

## 需求原文
「怎么处理 @Cube 他的UV使得燃烧的动画在整个正方体的表面连续，而不是每个面对应一个uv」+「直接实现，注意保留可复用资产」

## 问题根源
Unity 内置 Cube mesh 的 UV 六面各自独立映射 [0,1]，棱边两侧 UV 跳变。L17 用 `uv × _NoiseScale` 采 2D 噪声 → 噪声场以 UV 为参数，棱边处采样值断裂，溶解边界每个棱上断开。

## 方案决策（三选一，选 A）
- **A. 弃用 UV，对象空间位置采样 3D Perlin（选定）**：噪声场以 mesh 本地坐标为参数，空间连续 → 棱边两侧位置连续 → 溶解边界天然连续穿过棱边。任意 mesh 通用（球/模型均适用）。图案属于物体（移动时跟随）。
- B. UV 缝合/六面 atlas：立方体专属、工作量大，仅贴图对齐场景才必要
- C. Triplanar：3 次 2D 采样按法线混合，有方向伪影，不如 3D 噪声干净

## 可复用资产设计（用户指令"保留可复用资产"）
1. **`Assets/shader/NoiseLib.cginc`**：噪声提取为独立库——hash21/hash31（iq 风格）、grad2/grad3、quintic2/quintic3、perlin2D/perlin3D、值域常量与 C¹/C² 连续性说明。任何 shader 可 include 复用
2. **保留用户对 L17 的四段色带升级**（2026-09-12 用户手改：余烬[HDR]+辉光→炭黑→焦褐→微焦→纸本色、_BandWeights 权重、_EmberGlow）——L18 原样继承这套燃烧观感
3. L17 的 2D perlin 保留在 L17 内不动（终态资产不重构）；NoiseLib 为 L18 及后续效果的新基准

## 实现要点
- 采样域：`appdata.vertex.xyz`（mesh 本地坐标，Cube_Baked 烘焙后其对象空间仍是 ±0.5 单位域，无缩放污染）→ v2f 新增 objPos 插值器
- 噪声：`perlin3D(objPos * _NoiseScale)`，8 格点三线性，quintic fade 保持 C²
- 3D 值域 ±0.866，归一 0.5 + 0.75n（工程折中：视觉对比优先，极端值轻饱和对 clip 硬阈值不敏感）
- 色带/光照/Properties 全继承用户版 L17 四段带设计

## 验收标准
1. L18 编译无错误
2. 立方体溶解边界**连续穿过棱边**（视觉验证核心）
3. 四段色带观感与用户 L17 版一致
4. NoiseLib 可被独立 include（无管线依赖）
