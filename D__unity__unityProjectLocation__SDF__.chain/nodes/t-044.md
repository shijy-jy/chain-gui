> 触发：低环平面；y值小的平面；取消 orbLandHeight；下落目标

# 任务：落下目标 = 低环平面 GPU 读回, 取消 orbLandHeight

## 用户需求
之前读回的粒子环平面是"y 值大的平面"(被漩涡抬升的粒子抬高平均); 希望读到
"y 值小的平面"(贴地粒子构成的低平面); 若能读到就直接用, 不必开放 orbLandHeight。

## 实现
1. **compute 环平面统计加高度偏置** (新 uniform _LowPlaneK=2.5):
   `w = exp(-dxz²/2σ²) · exp(-_LowPlaneK·max(0, y-groundY))`
   → 贴地粒子权重高, 离地越高的粒子权重指数衰减 → 读回 = 低环平面
2. **脚本**:
   - 删除 orbLandHeight 字段与其全部使用 (面板同步消失)
   - 落下目标恢复 `ringY = max(低环平面读回 + 0.08, centerStart.y-0.05)`
     (+0.08 = 环半厚补偿, 下限 0.2 防半陷地)
3. 阶段2→3 快照 m_OrbLandY = m_OrbY = 低环平面 → 上升起点不变, 动线无跳变

## 数值预期
- 贴地粒子 (y≈groundY) 权重全保留; y=0.5 粒子权重 ×0.29, y=1 ×0.08
  → 低平面读回 ≈ groundY+0.05~0.15 (旋升粒子几乎不影响)
- 落地高度 ≈ 0.2~0.23 (下限主导), 与旧 orbLandHeight=0.25 观感接近

## 验收标准
1. 编译无错误 (compute 新 uniform + 脚本无 orbLandHeight 残留)
2. 球落到贴地粒子构成的低环平面 (调试面板 环平面Y 可核对)
3. 观感由用户 Game 视图裁决
