# 任务：扩充素材库（外部 CC0 资源获取 + 导入参数配置）

## 背景
t-014 已导入桌面 8 张 `T_Fire_*.jpg`（成品火焰图，分层解耦设计）。但 UV 扰动与溶解收边缺**噪声底料**，
火焰动画缺**无缝循环序列**。本任务从外部获取 CC0 资源补齐，并提供导入参数配置工具。

## 需求原文
「帮我拿到这些贴图」（用户列出三类源：URP 免费火焰包 / 噪声扰动贴图 / 无缝火焰贴图）

## 一、资源获取结果

| 资源 | 许可 | 落地位置 |
|---|---|---|
| SBS 768 张无缝噪声（512²，18 类） | CC0 | `_VFXTextureSource/noise/512/`（完整 262 张，94.6 MB） |
| → 精选 36 张（每类 2 张） | CC0 | `Assets/VFX/Noise/T_Noise_<类别>_1~2.png`（12.88 MB） |
| 无缝循环火焰 1024² × 45 帧 | CC0 | `_VFXTextureSource/fire/fluid_extras/`（46.9 MB） |

- 噪声 18 类：Perlin / SuperPerlin / Turbulence / Voronoi / Cracks / Craters / Gabor /
  Grainy / Manifold / Marble / Melt / Milky / Spokes / Streak / SuperNoise / Swirl / Techno / Vein
- 源：OpenGameArt — Screaming Brain Studios《700+ Noise Textures》(CC0)、
  zookeeper《Seamless animated fire texture》(CC0，fluid_extras 变体)
- flipbook：4096²，8×8 分格，每格 512²，实际占用 45 格

## 二、关键技术点（为什么必须配导入参数）

- **噪声图必须关 sRGB**：当线性数据采样，过 sRGB 会被伽马校正，导致溶解阈值与扰动强度偏移
- **flipbook 必须 RGBA32 无损 + 关 mipmap**：DXT 压缩会让相邻帧渗色，低 mip 会串帧
- **NPOT 必须设 None**：否则 4096² flipbook 被自动缩放后 UV 分格错位
- `_VFXTextureSource/` 用下划线前缀 → Unity 忽略导入，300+ 张原图不拖慢编辑器；
  需要换图时从该目录挑着替换即可

## 三、产物

- `Assets/SDF/Editor/VFXTextureImportSetup.cs`：菜单 `Tools → VFX 贴图导入设置`，
  批量设置 `Assets/VFX` 下全部贴图
  - 噪声（`路径含 /Noise/`）→ sRGB 关、alphaIsTransparency 关、Repeat
  - Flipbook（`文件名含 Flipbook`）→ RGBA32 无损、mipmap 关
  - 全部 → Default 类型 + Repeat + NPOT=None + maxTextureSize 4096

## 四、未能自动获取的资源（需人工，不阻塞）

## 五、用法建议（火球配方，待后续 task 落实）

或直接用 `T_Fire_Flipbook_8x8` 走 flipbook（UV 分格 1/8）

## 试错记录

- ⚠️ **PowerShell 里 `$_` 被外层 shell 吞掉**：`catch { 'ERR: ' + $_.Exception.Message }` 报
  "Unexpected token '.Exception.Message'" → 去掉 `powershell -Command` 包裹、直接执行 PowerShell 命令即可
- ⚠️ **`Get-Content` 不带 `-Encoding` 被安全策略拦截**：Windows 中文文件按 GBK/UTF8 解码易错，
  必须显式传 `-Encoding UTF8`（或用 `-AsByteStream`）
- ⚠️ **7z 解压**：本机无 7z CLI，但 PowerShell 5.1+ 自带 `tar` 可直接解 `.7z`
- 🔑 **OpenGameArt 直链获取**：页面 HTML 筛 `href` 匹配 `\.(zip|7z|rar)$` 即得下载直链，无需登录
- 🔑 **flipbook 合成**：`System.Drawing` 建 4096² 画布，45 帧按 8×8 网格 `DrawImage` 绘制，
  InterpolationMode 设 HighQualityBicubic
