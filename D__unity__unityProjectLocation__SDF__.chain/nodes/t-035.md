## 二、P1-6 屏幕空间热扭曲

### 新增 `Assets/shader/L17_HeatDistortion.shader`

billboard quad，`Blend One Zero`（用扭曲后的背景整体替换，非叠加）：
- 采样 `_CameraOpaqueTexture`（`#include "DeclareOpaqueTexture.hlsl"`）
- 两次**不同位置**采样噪声分别作为 x/y 扰动分量 → 避免同值导致固定 45° 单向偏移
- 径向淡出 `1 - smoothstep(_FadeStart, 1, d)` → 消除 quad 方形硬边
- `clamp(duv, 0.001, 0.999)` 防 UV 越界拉边
- 属性：`_NoiseTex` / `_Strength`(0.015) / `_NoiseSpeed` / `_NoiseScale` / `_Scale` / `_Intensity` / `_FadeStart`

### 两个关键设计（都踩过坑才定下来）

**① Queue = `Transparent-1`**
扭曲 quad 必须**早于**火焰（默认 Transparent = 3000）渲染。否则它会把已经画好的
火焰整个覆盖掉（因为 `Blend One Zero` 是完全替换）。改用 `Transparent-1` 后：
扭曲背景先画 → 火焰叠加其上。

**② 径向淡出 + 低强度**
Opaque Texture **只含不透明物体**，半透明的火焰自身不会被扭曲 → 火焰边缘与扭曲后的
背景天然对不上。只能靠 `_Strength` 维持在低值（0.01~0.03）+ 边缘淡出掩盖。

### `L17_EmberVortexFX.cs` 改动
1. 参数：`enableHeatDistortion` / `heatDistortionMaterial`(可留空) /
   `heatDistortionNoise` / `heatDistortionRadiusMul`(1.6) / `heatDistortionStrength`
2. 字段 `m_HeatGO` / `m_HeatMat`；Init 建 quad；OnDestroy 清理
3. Update 驱动：
   - 位置 = `orbPos`；尺寸 = 球尺寸 × `heatDistortionRadiusMul`（由 shader `_Scale` 控制，
     **GameObject 的 localScale 保持 1，否则双重缩放**）
   - 阶段 0 无 → 阶段 1 燃烧用 `orbBaseSize × mul × 0.8`（此时 `m_OrbScale` 还是 0，
     不能直接用球尺寸）→ 阶段 2+ 随 `m_OrbAppear`

## 试错记录

- ⚠️ **燃烧期尺寸不能取 `m_OrbScale`**：阶段 1 时 `m_OrbScale = 0`（球未显形），
  直接用会让 quad 退化成一点。改用 `orbBaseSize` 作基准
- ⚠️ **shader 内 `_Scale` 与 GameObject scale 冲突**：vert 用 `_Scale` 做 billboard 展开，
  若再设 `localScale = radius` 会平方缩放 → GameObject 必须保持 `Vector3.one`
- 🔴 **Opaque Texture 未开时的失败形态是"黑块"而不是"没效果"**：
  `_CameraOpaqueTexture` 取不到时为黑，`Blend One Zero` 会把该区域涂黑。
  这与软粒子"粒子消失"一样属于**不报错的静默失败**，排查时优先查 URP 开关

## 静态验收（已完成）

- shader 与脚本改动后 linter 零错误
- 三份 URP Asset 的 Depth / Opaque 均已复核为 1

## 待办：**Game 视图裁决**（未完成，故仍为 in_progress）

1. 元素球/火线后方的地面、立方体轮廓是否出现**轻微晃动的折射**
2. 扭曲是否只在球周围、边缘无方形硬边

判定失败调参：
- **出现黑块** → Opaque Texture 未生效（查 S0-2，或 Unity 未重新导入 URP Asset）
- 画面明显变形/很假 → 调小 `_Strength`（默认 0.015，安全区 0.01~0.03）
- 有方形硬边 → 调小 `_FadeStart`（默认 0.2）让淡出更早开始
- 火焰边缘与背景错位明显 → 进一步降强度，或接受该局限（Opaque Texture 的固有限制）
- 想完全关闭 → `enableHeatDistortion = false`（同时建议把 Opaque Texture 改回 0 以省开销）

裁决通过后建 v-* 节点并置 `success`。
