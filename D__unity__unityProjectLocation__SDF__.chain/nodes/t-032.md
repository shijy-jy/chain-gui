# 任务：批次 2（d-011 的 P0-1）

依赖 t-031 的 S0-1（Depth Texture 已开启）。

## 需求原文
「继续」→ 按 d-011 执行序，批次 2 = P0-1 软粒子

## 实现

两个 shader 同构改动（`Blend One One` Additive，均按 Additive 特化处理）：

1. `#include ".../ShaderLibrary/DeclareDepthTexture.hlsl"`
   （提供 `SampleSceneDepth` / `LinearEyeDepth` / `_ZBufferParams`）
2. `v2f` 新增 `float4 screenPos` + `float viewDepth`
3. `vert`：`o.screenPos = ComputeScreenPos(o.posCS); o.viewDepth = o.posCS.w;`
   （透视投影下裁剪空间 w = 视空间 -z，即粒子视深度）
4. `frag`：
   ```hlsl
   if (_Softness > 0.001)
   {
       float2 screenUV = i.screenPos.xy / i.screenPos.w;
       float  rawD     = SampleSceneDepth(screenUV);
       float  sceneD   = LinearEyeDepth(rawD, _ZBufferParams);  // 第二参传 float4, 不是 .x
       float  softFade = saturate((sceneD - i.viewDepth) / _Softness);
       col *= softFade;      // ★ Additive 必须乘 rgb
   }
   ```
5. 新增属性 `_Softness`（Range 0~2，默认 0.6，0 = 关闭）

- `L17_EmberParticle`：v2f 用 TEXCOORD4/5（原 0~3 已占用）
- `L17_FireCore`：v2f 用 TEXCOORD1/2（原仅 0）

## 试错记录

- 🔴 **`float2 suv` 重复定义（编译错误，已修）**：`L17_FireCore` 的 frag
  **已有** `float2 suv = clamp(duv + 0.5, 0.01, 0.99)`（火焰壳采样用），
  软粒子块里再声明 `float2 suv` → 重复定义，编译直接失败。改名 `screenUV`。
  linter 查不出（shader 不在 C# 编译链），靠改完逐行复查才发现。
- ⚠️ **`soft` 变量遮蔽**：`L17_EmberParticle` 的 frag 已有 `half soft`（光斑采样结果），
  块内再声明 `float soft` 虽不报错（内层遮蔽）但语义混乱 → 改名 `softFade`。
- 🔑 **教训：往已有 frag 里插入代码块前，必须先扫一遍该 frag 的全部局部变量名**，
  尤其是 `suv` / `soft` / `d` / `c` / `t` 这类短名——本项目 shader 大量使用短名。

## 静态验收（已完成）

- 两个 shader 改动后 linter 零错误（注：linter 不覆盖 HLSL，shader 正确性靠人工复查）
- 已逐行复查两个 frag，无重名、无未声明变量
- `ComputeScreenPos` / `SampleSceneDepth` / `LinearEyeDepth` 均来自 URP 标准头文件
- `_Softness` 默认 0.6，0 时走 `if` 另一侧完全不生效（可直接关闭，便于 A/B 对比）

## 待办：**Game 视图裁决**（未完成，故仍为 in_progress）

需用户在 Unity 中确认：
1. 火星飞近地面/穿过立方体时，硬边是否消失、是否柔和淡出
2. 元素球靠近地面时底部是否自然虚化
3. **镜头压低到接近地面平视**时改善最明显（硬边在此角度最刺眼）

判定失败调参：
- **粒子整体消失** → Depth Texture 未生效（查 t-031 的 S0-1；或 Unity 未重新导入 URP Asset，需手动刷新）
- 仍有硬边 → 确认软因子乘的是 rgb 而非 alpha
- 整体变暗/特效变弱 → 调小 `_Softness`（默认 0.6，可试 0.3~0.4）
- 想 A/B 对比 → 把 `_Softness` 设 0 即完全关闭

裁决通过后建 v-* 节点并置 `success`。
