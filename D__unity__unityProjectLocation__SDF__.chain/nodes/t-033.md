# 任务：批次 3（d-011 的 P0-2）

## 需求原文
「继续」→ 按 d-011 执行序，批次 3 = P0-2 地面余烬光斑

## 一、新增 shader `Assets/shader/L17_GroundGlow.shader`

水平贴地 quad，Additive：
- 径向指数衰减 `exp(-d²·_Falloff)`（中心亮 → 边缘渐隐）
- 两层不同频率、反向流动的噪声相乘 → 明灭颗粒（`_NoiseStrength` = 0 时退化为纯径向光晕）
- 属性：`_Color`(HDR) / `_Intensity`(脚本驱动) / `_NoiseTex` / `_NoiseSpeed` /
  `_NoiseStrength` / `_Falloff`

## 二、`L17_EmberVortexFX.cs` 改动

1. 参数（Inspector）：`enableGroundGlow` / `groundGlowMaterial`(可留空) /
   `groundGlowNoise`(可留空) / `groundGlowRadius`(默认 3.5) / `groundGlowStrength`(默认 1)
2. 字段：`m_GroundGO` / `m_GroundMat`
3. Init 创建 quad：
   - `PrimitiveType.Quad` 默认在 XY 平面 → `localRotation = Euler(90,0,0)` 转成水平
   - 材质：优先用拖入的 `groundGlowMaterial`；**留空则 `Shader.Find("SDF/L17_GroundGlow")` 自动创建**
     （临时材质复制后 `Destroy`，不泄漏）
   - 噪声：留空则把 `_NoiseStrength` 设 0（退化为纯光晕），不报错
   - `localScale = radius * 2`
4. Update 每帧驱动：
   - 位置 = `(orbPos.x, groundY + 0.02, orbPos.z)`（抬高 0.02 避免与地面 Z-fighting）
   - 强度分阶段：0 无 → 1 燃烧 `0.35·progress` → 2 收束 `0.35+0.35·rise`
     → 3 凝聚 `0.7+0.3·orbAppear` → 4 驻留 `1.0` → 5 重生随 `orbAppear` 消失
5. OnDestroy 清理 GO 与材质

## 设计取舍

- **不用实时点光源**：贴地 quad 零光照成本、范围/强度完全可控，视觉重量接近
- **水平位置跟随 `orbPos` 而非 `vortexCenter`**：阶段 2 两者水平分量相同，
  但 orbPos 语义更直白（球飞到哪，地面亮到哪）
- **噪声可空**：默认无噪声也能出效果，避免"用户没配图就看不见"

## 试错记录

- ⚠️ **C# 的 `[Header]` 可以用，ShaderLab 的不行**：本轮在 C# 参数区用了
  `[Header("P0-2 地面余烬光斑")]` —— 这是 **C# Inspector Attribute**，与 ShaderLab 的
  `[Header]` drawer **不是一回事**。项目已知的 Tuanjie 限制只针对 **.shader 文件内**的
  带字符串 drawer（见 PROCESS_LOG 2026-09-14T12:33 条目），C# 侧无此限制
- ⚠️ **Quad 朝向**：`CreatePrimitive(Quad)` 建在 XY 平面（法线 -Z），
  不转 90° 会竖直立着；`Cull Off` 虽能避免背面剔除导致不可见，但几何朝向仍是错的
- ⚠️ **父对象缩放传递**：quad `SetParent(transform)` 会继承父级缩放，
  阶段 5 的 `ElasticPop` 会让光斑跟着抖一下；与既有 `m_OrbGO` 行为一致，暂不特殊处理

- 材质/噪声均可留空，留空路径有明确降级行为（纯光晕 / 警告日志），不会静默失败

## 待办：**Game 视图裁决**（未完成，故仍为 in_progress）

需用户在 Unity 中确认：
1. 燃烧期起地面是否出现暖色光晕，且随火势渐强
2. 凝聚/驻留期光斑是否最亮，且**水平位置跟着球走**
3. 拖入 `T_Noise_Turbulence_1`（或 `T_Noise_Melt_1`）后是否出现明灭余烬颗粒

判定失败调参：
- 完全看不见 → 检查 `enableGroundGlow`、`groundGlowStrength` 是否为 0；
  或 Console 是否有"未找到 SDF/L17_GroundGlow shader"警告
- 与地面闪烁（Z-fighting）→ 抬高 y 偏移（当前 0.02）
- 太大/太小 → `groundGlowRadius`（默认 3.5）
- 太亮/太暗 → `groundGlowStrength` 或材质 `_Color` 的 HDR 强度

裁决通过后建 v-* 节点并置 `success`。
