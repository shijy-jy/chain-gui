# 任务：火星渲染链修复与验收盲区补正

## 需求原文

## 排查结论（对 v-007 的补正）
用户反馈"看不见"成立。渲染链共两处断点（+ v-007 验收盲区）：
1. **CopyCount 断点**（用户自行修复）：`ComputeBuffer.CopyCount` 只复制 Append/Counter buffer 的硬件计数，而 `_Counter[0]` 是 InterlockedAdd 维护的数据 → instanceCount 恒 0 → 从不绘制。已改 CPU 回读写 args。
2. **材质 SetBuffer 缺失（本任务修复）**：`new Material(particleMaterial)` 是属性副本，**StructuredBuffer 绑定不随复制传递**——`m_RenderMat.SetBuffer("_Particles", m_Particles)` 从未调用 → shader 读全零（alive=0→size=0）→ 有绘制也全不可见。修复：Init 中显式 SetBuffer。
3. **v-007 验收盲区（方法论教训）**：t-007/v-007 验证了 compute 侧（buffer 数据、粒子位置、存活数）但未验证 **draw 侧**（args instanceCount、材质 buffer 绑定）——"数据存在 ≠ 渲染发生"。GPU 粒子验证清单必须包含：存活数 == instanceCount == 材质绑定三者一致 + 位置抽样。
