> 触发：元素球辉光；发光；淡入；调节参数

# 任务：元素球外圈辉光 + 开放参数 + 淡入

## 用户需求
给元素球换上辉光效果, 开放调节参数, 同时让元素球淡入显示。

## 设计 (在 t-037 色带重构版上叠加)
1. **外圈辉光层** (L17_FireCore.shader):
   - quad 画布放大 _GlowExtent 倍 (vert: ×_Scale×max(_GlowExtent,1)),
     火焰本体用压缩 UV ((i.uv-0.5)/extent+0.5) 采样 → 本体尺寸与观感不变
   - 辉光层: exp(-dGlow²·_GlowFalloff) 径向指数衰减, 加在圆形裁剪之后
     → 不受 circle 裁剪, 覆盖整个放大画布, 边缘自然衰减到 0 无方形硬边
   - 辉光不参与软粒子淡出 (超出本体, 淡出只对本体有意义)
2. **开放参数 4 项**: _GlowColor [HDR] / _GlowIntensity (0-2, 默认0.6) /
   _GlowExtent (1-3, 默认2.0) / _GlowFalloff (0.3-3, 默认0.9)
3. **淡入**: 全层 (含辉光) × _Appear — 脚本既有编排: 收束期 SmoothStep(0.6,1)·0.35
   (2.2s 渐显) → 凝聚期 0.35+0.65·吸收比例 → 驻留 1; 辉光同步淡入淡出 ✓
4. **剔除安全**: 脚本 orb GO 包围盒 ×2.5 (含辉光画布, 防屏幕边缘误剔除)

## 验收标准
1. 编译无错误
2. 元素球周围出现柔和外圈辉光, 随 _Appear 淡入; 面板调 4 参数可见变化
3. 观感由用户 Game 视图裁决
