> 触发：亮斑位置；伴随上升；牵引凝聚；上升轨迹

# 任务：收集点改为上升轨迹（对 t-022 位置修复的进一步纠正）

## 用户纠正
「有一部分做错了，亮斑一开始出现在最底下的圆环的中间，随着圆环的上升，元素球伴随上升，同时元素球牵引凝聚周围的火星，随着上升，元素球逐渐变大，并显现这个上升和凝聚的过程」

## 设计修正
- 亮斑/元素球**起点 = 底部圆环中间**（groundY + 0.25，环平面=groundY，微抬避免球半陷地）
- 收束期(阶段2): 收集点固定在底部 → 环在底部形成/外飘/收缩, 亮斑在环中间出现
- 凝聚期(阶段3): 收集点从底部**上升到最终高度**（t² 缓入）→ 元素球伴随上升,
  同时引力牵引凝聚周围火星, 元素球越升越大 (_Appear 0.35→1)
- 驻留/重生: 停在最终高度

## 实现 (脚本 L17_EmberVortexFX.cs)
```csharp
Vector3 baseCenter = targetRenderer.bounds.center;
Vector3 centerStart = new Vector3(baseCenter.x, groundY + 0.25f, baseCenter.z);
Vector3 centerEnd   = baseCenter + vortexCenterOffset;
if (m_Phase == 2)       vortexCenter = centerStart;
else if (m_Phase == 3)  vortexCenter = Vector3.Lerp(centerStart, centerEnd, t3*t3);
else                    vortexCenter = centerEnd;
```
- 元素球 quad 位置每帧 = vortexCenter → 自动伴随上升
- compute 的升力/吸附目标 = vortexCenter → 环与球同步上升
- coalesceDuration 2.5→3.5 (上升+牵引+长大, 过程充分显现)

## 验收标准
1. 编译无错误
2. 阶段2 收集点读回 = 底部 (groundY+0.6); 阶段3 随 t² 上升到 centerEnd
3. 观感由用户 Game 视图裁决
