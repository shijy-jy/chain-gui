> 触发：元素球落下来后上升一定距离就停下；上升距离开放

# 任务：元素球动线 = 落下 → 上升 → 停下

## 用户需求
修改元素球的移动——"元素球落下来后上升一定距离就停下"，上升距离参数开放给用户。

## 设计 (在并行会话 orbRiseHeight 雏形上补齐)
- **出现高度** = 立方体中心 + vortexCenterOffset (旧收集点, 语义改为"落下起点")
- **落下 (收束期)**: 球从出现高度 SmoothStep(0.3,1) 平滑落下到粒子环平面,
  与底部环汇合 (亮斑伴随渐显, 与环的"上升收束"形成对冲)
- **上升 (凝聚期)**: 球从着地高度上升 orbRiseHeight (开放参数, SmoothStep 缓起缓停);
  漩涡中心 = 球本身 (场源) → 火星环伴随上升
- **停下 (驻留/发亮)**: 停在上升终点, 残余火星汇入, 发亮 (爆裂仍由 enableBurst 门控)
- 燃烧期: 球隐藏于出现高度, 漩涡中心行为不变 (兼容旧手感)

## 验收标准
1. 编译无错误
2. 阶段2 球从出现高度单调下降落到环平面; 阶段3 单调上升 orbRiseHeight; 阶段4 不再移动
3. 面板 orbRiseHeight 调大调小, 驻留高度随之变化; 观感由用户 Game 视图裁决

## 实施记录
- 动线块 (L17_EmberVortexFX.cs 行 374-407): 燃烧期=出现高度; 收束期 SmoothStep(0.3,1)
  落下到环平面 (ringY = 环平面读回, clamp ≥ centerStart.y-0.05); 凝聚期 SmoothStep 上升
  orbRiseHeight; 阶段4/5 m_OrbY 保持 = 停下
- 漩涡中心: 阶段2 = 底部环中间 (环在底部收束, 球落下与环汇合); 其余 = orbPos (场源,
  凝聚期环随球升, 驻留期残余火星汇入停驻的球) — 取代并行会话的 centerStart→centerEnd lerp
- 阶段2→3 记录 m_OrbLandY = m_OrbY (落下着地高度 → 上升起点, 与 t3=0 连续)
- orbRiseHeight: 默认 2.5, Range 0-10 (在并行会话雏形上改语义: 球动线而非收集点终点)
- vortexCenterOffset 语义改为"元素球出现高度 (落下起点)"; centerEnd 变量移除 (grep 确认无残留)
