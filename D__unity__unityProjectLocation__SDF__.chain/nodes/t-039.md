# 任务：全项目 shader 参数面板中文化

## 需求原文
「先给所有shader的所有参数带上面板提示，最好参数中文化，如果不能就改成面板有中文提示」

## 关键约束（决定了实现路径）

**Tuanjie 的 ShaderLab 解析器不支持任何带字符串参数的 drawer**：
`[ToolTip("中文")]` / `[Header("中文")]` 无论 ASCII/中文一律 `Parse error: unexpected $undefined`
（2026-09-14 实测；无参 drawer 如 `[HDR]` 正常）。

由此得出两条结论：
- **中文 displayName 是安全的** —— 它属 Properties 标准语法，不是 drawer。
  本项目所有 shader 的显示名本来就已经是中文，无需改。
- **悬停提示只能由 C# 侧 ShaderGUI 提供** —— 这是唯一可行路径。

## 实现

### 新建 `Assets/SDF/Editor/L17ShaderTipsGUI.cs`（全项目通用）

两级查找，避免写 263 条重复提示：
1. **`s_Common`（按属性名）** —— 溶解家族 5 个变体（`_2D` / `_AudioBeat` / `_DomainWarp` /
   `_Ignition` / `_Sparks`）共享同一套属性名，写一次全家族生效。约 60 条。
2. **`s_Override`（按 `Shader名|属性名`）** —— 处理**同名不同义**的属性，如
   `_Intensity` 在地面光斑 / 热扭曲 / 烟三者含义完全不同；`_NoiseTex`、`_Scale` 同理。
3. 未命中任何提示的属性照常绘制，**不会丢字段**。

去重后实际编写约 105 条唯一提示（原始 13 个 shader 共 263 个属性）。

## 试错记录

- ⚠️ **PowerShell 里双引号转义写错导致整条命令解析失败**：
  `"    CustomEditor \`"L17ShaderTipsGUI\`"+$nl` 少了字符串结束引号 → ParserError。
  **解法：拼接含双引号的文本时改用单引号字符串**，单引号内双引号无需转义：
  `$ins = $nl + '    CustomEditor "L17ShaderTipsGUI"' + $nl`
- ⚠️ **文件换行符不一致**：部分 shader 是 CRLF、部分是 LF。批量插入前需检测
  `$t.Contains("`r`n")` 选用对应换行符，否则会混用；写入前也检测了 BOM 并按原编码回写。
- 🔑 **批量改 shader 后必查大括号配平**：11 个文件逐个统计 `{` 与 `}` 数量，
  全部相等（配平=True），确认插入 `CustomEditor` 没破坏结构。
