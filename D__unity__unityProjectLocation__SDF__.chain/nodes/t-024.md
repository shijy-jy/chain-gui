> 触发：元素球粒子环同水平面；同步上升；开放引力；吸积盘；吸入先慢后快

# 任务：共面同步上升 + 元素球引力开放 + 吸积盘牵引

## 用户要求
1. 元素球和粒子环基本在一个水平面，伴随着粒子环同步上升
2. 开放元素球引力参数
3. 优化粒子牵引效果，类似吸积盘
4. 吸入速度也是先慢后快

## 设计
- **环平面统计 (GPU→CPU)**：CSUpdate 对存活粒子做水平高斯加权平均高度
  (定点原子加 int, y×1000 / w×4096, sigma=_AvgSigma), 新 kernel CSClearAvg 每帧清零;
  脚本读回 → 元素球高度 = 平滑后的环平面 (一帧延迟 + 指数平滑), 存活数 <64 时贴编排高度
- **中心拆分**：_VortexCenter (编排轨迹, 管升力/收缩) vs _OrbCenter (元素球实际位置, 管吸积盘)
- **吸积盘 (compute 凝聚分支)**：
  - 盘面共面: 近盘粒子 (dist<3·OrbRadius) 高度拉向球心平面, diskFlatten 开放参数
  - 向心吸入: v = k·dist 指数吸附, 上限 = orbGravity × strength (强度二次缓入 → 先慢后快)
  - 切向绕转: (CoalesceSpin/r) × (1-0.7·strength) → 角动量转移, 先绕后吸
- **开放参数**：orbGravity (元素球引力), diskFlatten (共面收紧), avgSigma (统计半径)

## 验收标准
1. 编译无错误 (compute kernel 4 个, 脚本字段齐全)
2. 阶段3 元素球 Y ≈ 环平面 Y (调试面板 环平面Y vs 球Y 对比)
3. 观感: 吸积盘 (平盘绕转 → 渐快吸入), 由用户 Game 视图裁决

## 实施记录
- compute: CSClearAvg kernel + _AvgY/_AvgW 定点原子累积 (y×1000 / w×4096, int 原子加全平台安全);
  凝聚分支改为吸积盘 (共面收紧·dt + 指数吸入上限 orbGravity×strength + 切向绕转随强度衰减)
- 脚本: orbGravity/diskFlatten/avgSigma 开放参数; m_RingY 读回 + 指数平滑 (8/s);
  orbPos = (编排XZ, 环平面Y), 存活数<64 时贴编排高度; _OrbCenter 传入 compute
- 调试面板加 环平面Y/球Y 两项

## 试错记录
- ❌ 盘面收紧初版用每帧速度冲量 (无 dt): 等效弹簧刚度 ~150/s²、阻尼≈0
  → 粒子会在球心平面垂直振荡 (~2Hz 抖动). 已改为乘 dt 的加速度 (弱弹簧, 全局阻力阻尼)
- ⚠️ 定点原子加选 int 而非 float: Metal 无原生 float 原子加, int 版全平台安全
- 🔑 关键转折: 力场中心拆分为 _VortexCenter(编排轨迹)/_OrbCenter(球实际位置),
  否则吸积盘会绕编排中心转, 球仍悬在环上方 → 不共面
