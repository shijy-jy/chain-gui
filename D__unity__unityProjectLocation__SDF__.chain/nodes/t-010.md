# 任务：溶解 shader 噪声逻辑升级

## 需求原文
「这个我用了感觉一般，有没有可能是噪声使用的逻辑不合理，能不能在这里优化」——背景：用户已试过 Render Scale 提升分辨率，观感仍一般。

## 诊断（旧噪声逻辑的三处不合理）
1. **单频单层噪声** → 火纹只有一个尺度，呈"大团块"，缺自然侵蚀的大小结构
2. **值域扰动**（`d = n - progress + warp*(warpN-0.5)`）→ 扰动加在**噪声值**而非空间：噪声梯度平缓处微小数值扰动被放大成怪异边界跳跃；且 warpN 与主噪声独立采样，撕咬细节与主图案脱节
3. **分布非线性（关键元凶）**：Perlin 输出是**钟形分布**，大部分值挤在 0.35~0.65；阈值 progress 均匀扫 0→1 时，前 30% 几乎不烧、中段突然烧完、后段无变化 → "拖进度手感憋闷"

## 升级方案
### 1. FBM 多尺度（L17Noise.cginc 新增 fbm3D）
3 层八度，各层**按自身屏幕空间频率自适应淡出**（`fwidth` 检测该层每格 <约 8px 时衰减、≤2px 压掉）→ 远处自动简化防混叠，近处细节保留；返回按实际幅值归一化

### 2. 空间域扭曲（替代值域扰动）
```hlsl
float3 flow = float3(perlin3D(np*0.5+11.3), perlin3D(np*0.5+5.7), perlin3D(np*0.5+9.1)) - 0.5;
float3 wPos = np + _EdgeWarp * progress * flow;
```
低频向量场扰动**采样坐标**，边界蜿蜒自然且与主图案咬合

### 3. 分布重塑（拉平直方图）
```hlsl
n = smoothstep(0.22, 0.78, n);   // → progress 与覆盖率近似线性
```

## 验收标准
1. 拖 _DissolveProgress 时燃烧覆盖率**基本线性**（0.3 烧 30%、0.6 烧 60%）
2. 边界呈大/中/小三个尺度的碎边（非大圆团）
3. 远距离高频层自动退场，火线保持干净
4. 蜿蜒强度随进度增强（越烧越狂野）

## 参数语义变更（重要）
- `_EdgeWarp` 从"值域扰动 (0~0.2)"变为"**空间位移 (0~0.5)**"——旧材质里的 0.04 在新语义下几乎无感，须手动改到 0.15~0.3
- `_WarpScale` 属性移除（高频细节改由 FBM 第三八度提供，不再单独采样）

## 试错记录
- ❌ **旧值域扰动方案证伪**：边界在噪声梯度平缓区出现怪异跳跃条带，且细节与主体脱节 → 改空间域扭曲
- ⚠️ **参数语义变更未同步到材质**：升级后用户材质仍存旧值 0.04，导致"改了跟没改一样" —— 教训：**shader 参数语义变更时必须同步告知用户改材质**（本轮已在回复中明确给出新值建议）
- 🔑 分辨率（Render Scale）解决不了噪声分布问题——这是本轮最关键的判断：用户 1.25 倍无感正是因为**问题在分布不在采样质量**
