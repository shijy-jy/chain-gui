# 任务：元素特效素材库导入与火元素分层方案

## 需求原文
「我想接着用这个火的贴图做一个火元素的效果贴图，分析元素特效一般都是怎么做的，找一些参考分析」
→ 「C:\Users\jcm20\Desktop\特效贴图 所有资产都在这里了」
→ 选择"先导入资产到项目"

## 一、素材库盘点（15 张，专业管线产出）
| 文件 | 内容 | VFX 定位 |
|---|---|---|
| `vfx_fire_core` | 完整火焰球体（白核+橙红湍流+丝缕火舌） | 元素球本体 |
| `vfx_fire_band` | 横向火流（龙头爆发+拖尾，6240×2656 超宽） | 火舌/喷射/漩涡臂 |
| `vfx_fire_ember` | 星芒状火花爆发（黑底亮线，加法混合用） | 爆发瞬间/粒子 |
| `vfx_fire_smoke_1/2/3` | **中性灰**烟云团 | 烟层（可染色，一图多用） |
| `vfx_fire_distort` | 扭曲数据 | 热浪折射 |
| `vfx_fire` | 综合火图 | 备选 |
| `vfx_{ice,lightning,poison,psychic,water,grass,dark_v2}` | 其他元素主图 | 未来扩展 |

**关键发现**：素材是"**分层解耦**"的专业设计——烟做灰度（可染任意元素色）、火花做加法亮线、火流做长条拖尾。每张图对应特定混合模式与动画方式。

## 二、导入执行
- 目标目录：`Assets/VFX/Fire/`（新建）
- 重命名为 `T_Fire_*.jpg` 规范命名
- 手写 .meta 预设导入参数（一次到位，免逐张 Inspector 调整）：
  - `T_Fire_Band` → **Repeat**（横向 UV 流动需要平铺）
  - `T_Fire_Distort` → **sRGB 关**（数据贴图非颜色，过 sRGB 会失真）
  - 其余 → Clamp + sRGB + mipmap
- GUID 固定写入，避免后续引用漂移

## 三、元素特效架构分析（通用骨架）
**四层堆叠 + 三段时间轴**：
```
④ 后期层   Bloom / 扭曲 / 色温偏移
③ 次要素层 碎片 / 火星 / 烟 / 余烬       ← 寿命错开产生"厚度"
② 主体层  核心球 / 爆发环 / 火舌 / 能量流
① 底层    光照染色 / 地面烙印 / 热扭曲   ← 决定"发生在世界里"还是"贴在屏幕上"
```
```
[起 15%] 蓄势 → [爆 25%] 释放 → [散 60%] 余韵
```
**火的专属语言**（与冰/雷的区别）：色温黑体辐射、运动**向上**（浮力+湍流）、节奏持续脉动、形态有机无定形。

**三套参考案例**：A 元素球（持续型）/ B 爆发型（一次性）/ C 漩涡吸收型（呼应当前系统）。

## 试错记录
- ⚠️ **桌面素材的编码/规格差异**：素材为 4096²~6240×2656 的 JPG（15 张共 29.9MB），导入时须控 maxTextureSize 与压缩格式，避免工程膨胀。
- 🔑 **"专业素材"的判据**：烟是灰度而非橙色 → 说明是分层解耦设计而非成品图，可复用于多元素——这直接决定了后续烟层实现方式（灰度 × 元素色染色）。
