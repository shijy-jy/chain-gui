# 元素球运动数据解析（快照: t-026 版本, 默认参数）

自验收：本文为纯分析产物（无执行改动），基于 L17_EmberVortexFX.cs 行 374-407
动线块 + L17_EmberVortex.compute 力场分支逐行推导演算。

## 核心结论
1. 元素球是**运动学物体**: 每帧直接写 transform.position (行 472), 无受力/无积分;
   速度/加速度 = 缓动曲线的解析导数, 完全确定可预演
2. 力 (重力/升力/吸附/绕转) 只作用于**粒子**, 元素球只提供场心位置
3. 动线 = 落下(SmoothStep 窗口) → 上升(SmoothStep) → 停, 三段端点一阶导均为 0 (无跳变)

## 起点定义
- birthPos = 立方体包围盒中心 + vortexCenterOffset (世界单位, 每帧重算)
- 默认: 立方体中心 (≈4.25, 缩放8.5落地) + (0,2.2,0) → 出现高度 ≈ 6.45
- 落下目标 ringY = max(GPU环平面加权平均Y, groundY+0.20), 即底部火星环实际所在平面
- 上升起点 m_OrbLandY = 阶段2→3 时刻的 m_OrbY 快照 (≈ringY≈0.2~0.25)
- 上升终点 = m_OrbLandY + orbRiseHeight(2.5) ≈ 2.7; X/Z 全程 = 立方体中心, 无水平运动

## 分段运动学 (默认参数数值)
| 阶段 | 位移函数 | 峰值速度 | 峰值加速度 |
|---|---|---|---|
| 0/1 燃烧 | y=6.45 常量 (隐藏) | 0 | 0 |
| 2 落下 | Lerp(6.45→0.2, SmoothStep(0.3,1,t2)), 5.5s | −2.44 u/s @3.58s | ∓2.53 u/s² (起/止) |
| 3 上升 | L + 2.5·SmoothStep(t3), 3.5s | +1.07 u/s @1.75s | ±1.22 u/s² (起/止) |
| 4/5 驻留 | y≈2.7 常量 | 0 | 0 |

- 落下比上升快 ~2.3×; 可见落下段 3.8u/2.2s (出现度 t2>0.6 才可见)
- 阶段3 粒子提前吞尽 → 球中途急停 (速度不连续, 已知观察点)

## 场力 (粒子侧, 决定环如何伴随球)
- 收束期: 重力−0.98 (漩涡抵消90%), 轴向升力 2.5·t2², 径向 1.5·(t2²−0.3(1−t2)), 切向 3.5·t2², 阻力 0.25
- 凝聚期: 升力 2.5 (指向上升中的球), 盘面收紧 2.5·s·w·dt (弱弹簧), 吸入 v=min(2.4s·d, 9s) 速度直写,
  绕转 (8/r)·(1−0.7s)·s 帧冲量, 吞没半径 1.5·(0.12+0.5s)
- 环跟随性: 升力终端速度 10 u/s ≫ 球峰值 1.07 u/s → 环滞后 ≈0.1~0.3 世界单位
