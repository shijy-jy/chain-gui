## 实现内容
### 1. 六种噪声类型（统一支持 FBM 叠加 + 无缝平铺 + 分布重塑）
白噪声 / 值噪声 / 柏林噪声 Perlin / Worley 细胞 F1 / Worley 边缘 F2-F1 / 正弦波叠加

### 2. 双输出维度
- **2D 贴图**：128/256/512/1024 → PNG（自动配 Repeat + Trilinear + sRGB 关 + mipmap）
- **3D 体积贴图**：32³/64³/128³ → Texture3D .asset（自带 mip 链 = 体积噪声也有预滤波抗锯齿）

### 3. GPU 计算（L17_NoiseGen.compute）
`CSNoise2D` / `CSNoise3D` 两个 kernel，与 CPU 版同算法同结果；compute 缺失时自动退回 CPU 路径（带进度条）

### 4. 附加按钮
"生成光斑贴图" —— 128² 径向渐变软光点（L17_Glow.png），供粒子渲染使用

## 关键算法要点
- quintic fade $w(t)=6t^5-15t^4+10t^3$ 与 shader 内 perlin 同款，保证程序化/贴图两模式观感一致
- 无缝平铺：频率取整数 + 格点取模（Worley 特征点同样取模）
- 分布重塑：`smoothstep(0.22, 0.78)` 拉平钟形直方图 → 溶解进度线性
- 3D Perlin 值域 ±0.866，归一系数 0.5774；2D 值域 ±0.7071，系数 0.7071

## GPU 安全守则自查
1. 无死循环 ✅ 2. kernel 内边界检查（id >= _Size 提前 return）✅ 3. 无越界（3D 索引 (z*size+y)*size+x 严格在 [0, size³)）✅ 4. Dispatch 线程组数按尺寸计算，无 TDR 风险（最大 128³/8×8×4）✅

## 试错记录
- ❌ **Texture3D.SetPixels 数组长度错误**：3D 模式初版用 `AsyncGPUReadback` 回读 3D RenderTexture —— **AsyncGPUReadback 对 3D RT 只回读单层切片**（数据长度 = 尺寸²），而 Texture3D 需要尺寸³ → `ArgumentException: size of data to be filled was larger than...`。修复：3D 路径改走 **ComputeBuffer + GetData**（结构化缓冲回读无切片歧义，且更快）。2D 路径无此问题（本就是一层）。
- ⚠️ **采样器声明不能省**：优化时曾删掉 compute 里显式 `SamplerState`，但 `SampleLevel(sampler_NoiseTex3D, ...)` 仍引用它 —— **compute shader 没有顶点/片元 shader 的 `sampler_` 自动生成机制**，导致整体编译失败 → 所有 kernel 失效 → 运行时 `Kernel at index (0) is invalid`。恢复显式声明即修复。
- 🔑 **Windows PowerShell 写 .meta 的编码坑**：`Set-Content -Encoding UTF8` 在 PS 5.1 会写 BOM，Unity 解析 YAML frontmatter 可能异常；改用 `-Encoding UTF8 -NoNewline` 并注意 Unity 生成的标准格式。
