# 任务：元素球径向扰动 + 半透明渲染

## 需求原文
「优化元素球渲染逻辑，使用噪声贴图按照径向uv采样（噪声贴图中心位置为 0，正方形贴图边长的
二分之一是 1）元素球贴图，同时采样uv给上时间变化流动采样，半透明渲染」

## 一、径向极坐标扰动

以贴图中心为原点、边半长为 1 的极坐标系：

```hlsl
float theta = atan2(cuv.y, cuv.x);
float ang01 = theta / 6.28318 + 0.5;              // 角度 → 0~1
// 噪声贴图按 u=角度 / v=半径 采样
float2 nuv = float2(ang01 + flow * _RadialSpin, d + flow * _RadialFlow);
float n = SAMPLE_TEXTURE2D(_DistortTex, sampler_DistortTex, nuv).r;
// 径向推拉: 半径被噪声值偏移
float r2 = saturate(d + (n - 0.5) * _Distort * 2.0);
float2 duv = float2(cos(theta), sin(theta)) * (r2 * 0.5);
```

- `d` 复用现有半径（`length(cuv)*2`）；`r2*0.5` 转回 cuv 空间（d=1 对应半长）
- 贴图路径与程序化 perlin2D 回退两条分支都改成了径向推拉
- 新属性：`_RadialFlow`(径向流动 0.3) / `_RadialSpin`(径向旋转 0)

## 二、时间变化流动

- `_RadialFlow`：扰动波纹沿半径向外/向内流动（`nuv.y += flow * _RadialFlow`）
- `_RadialSpin`：整体绕中心旋转（`nuv.x += flow * _RadialSpin`）

## 三、半透明渲染

`Blend One One`（Additive）→ `Blend SrcAlpha OneMinusSrcAlpha`。

理由：Additive 火球在亮背景上会"消失"（叠加到白 = 白），Alpha Blend 则任何背景都有实体感。

**连锁改动（Additive→Alpha 的必改项）**：
1. **alpha 计算**：`a = saturate(heat + halo)` → `saturate(heat*1.2 + halo*0.5)`（主体更实）
2. **软粒子**：`col *= softFade` → `a *= softFade`（Alpha 混合下乘 alpha，与 Additive 乘 rgb 相反）
3. **外圈辉光**：加 `a = max(a, glow * _GlowIntensity * 0.5 * _Appear)`（否则辉光区 alpha=0 不可见）

## 五、二次修复：半透明下方形边框暴露（用户反馈）

**现象**：改半透明后，Game 视图火球外围有一圈**半透明方形**（Additive 时代没有）。

**两个根因**（都是 Alpha Blend 暴露出来的，径向采样本身没有问题）：

| 根因 | 数值 | 为什么 Additive 时看不见 |
|---|---|---|
| ① 外圈辉光衰减太慢 | `exp(-dGlow²·0.9)` 在 quad 边中点(dGlow=1)仍有 **0.41**，且它加在圆形裁剪**之后**不受裁剪 | Additive 只是往背景叠 0.4 亮度，不明显；Alpha Blend 下它是 **alpha≈0.12 的半透明方块** |
| ② 圆形裁剪失效 | 加辉光放大后，本体空间 `d` 最大只有 **~0.7**，永远达不到阈值 `_CircleFade=0.88` → 裁剪形同虚设 | 同上，Additive 时方块只是"不太亮" |

**修复**：
1. 辉光加径向遮罩：`glow *= 1 - smoothstep(0.60, 0.98, dGlow)` → quad 边缘强制归零
2. 圆形裁剪坐标从本体空间 `d` 改为 **quad 空间 `dGlow`**（火球边缘 ≈0.6 / 边中点 1.0 /
   四角 1.414 → 0.88 起淡出不伤本体、四角全裁）；`dGlow` 声明提前到裁剪段，辉光段复用

**经验（写入 MEMORY）**：**换混合模式后，所有"只往颜色上叠加"的层都要重新审视**——
Additive 下"亮度不够高所以看不见"的东西，Alpha Blend 下会变成"alpha>0 的可见方块"。

校验：linter 零错误、大括号 19/19 配平、dGlow 单次声明、裁剪段位于辉光段之前（声明顺序正确）。
