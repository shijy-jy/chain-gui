> 触发：凝聚看不到；特效素材看不到；离屏；收集点

# 任务：修复收集点高空离屏（凝聚过程与特效素材不可见根因）

## 用户反馈
「另外现在几乎看不到凝聚的过程以及特效素材的使用」

## 根因
`vortexCenter = targetRenderer.transform.TransformPoint(vortexCenterOffset)` —— TransformPoint 会把 offset 乘上立方体的 transform 缩放。立方体缩放 8.5，offset.y=2.2 → 收集点在**世界 ~18.7 单位高空**（立方体中心 ~4.25 + 18.7 ≈ 23）。后果链：
1. 收束期粒子被抬升 20+ 单位 → 飞出画面 → "看不到收缩上抬"
2. 凝聚/元素球发生在画面外 → "看不到凝聚过程"
3. T_Fire_Core 元素球全程 isVisible=False（t-016 已标记，本轮修复）→ "看不到特效素材"

## 修复
- 收集点改为**世界单位偏移**：`targetRenderer.bounds.center + vortexCenterOffset`
- 语义变更：offset 不再受立方体缩放影响——用户已序列化的 2.2 现在表示"立方体中心上方 2.2 世界单位"（≈ 6.45 世界高度，画面内）
- 粒子材质 T_Fire_Ember 已确认生效（.mat guid 核对 ✓）——此前同样因粒子飞到画面外而不可见

## 自验收
参数级核对：vortexCenter 计算式 = bounds.center + offset（世界单位）；字段注释同步；T_Fire_Ember guid 与 .mat 一致。观感由用户 Game 视图确认（凝聚全程应在画面内）。
