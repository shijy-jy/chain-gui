### 3. 前置条件核查（★ 本次关键发现）
`Assets/Settings/URP-HighFidelity.asset`：
```
m_RequireDepthTexture: 0
m_RequireOpaqueTexture: 0
```
**两者均为关闭**。含义：
- 软粒子（P0-1）依赖 `_CameraDepthTexture` → 当前**不可用**
- 屏幕空间热扭曲（P1-6）依赖 `_CameraOpaqueTexture` → 当前**不可用**

若不先开启就写 shader，`SampleSceneDepth` 取到 0 → 深度差为负 → `saturate` 归零 →
**Additive 粒子整体消失**（表现为特效凭空不见，易误判为 shader 写错）。
此为 d-010 遗漏的**阻塞项**，d-011 已列为 S0 前置步骤。

## 三、资料纠错（重要，勿照抄）

资料 9 的示例代码有**两处错误**，直接抄会导致效果全黑或消失：

| 资料写法 | 问题 | 正确写法 |
|---|---|---|
| `LinearEyeDepth(rawDepth, _ZBufferParams.x)` | 第二参应为 `float4` 完整参数，只传 `.x` 结果错误 | `LinearEyeDepth(rawDepth, _ZBufferParams)` |
| `ComputeScreenPos(i.vertex / i.vertex.w)` | 已除过 w 再传给 ComputeScreenPos → 二次除 w，UV 错误 | `ComputeScreenPos(i.posCS)`（传裁剪空间坐标），或 `GetNormalizedScreenSpaceUV(i.posCS)` |

另：资料 9 把软因子乘在 `col.a`，**仅适用于 Alpha Blend**。
本项目粒子/元素球是 `Blend One One`（Additive），alpha 不参与混合，
**软因子必须乘到 rgb**，否则毫无效果。

## 试错记录

- ⚠️ **`.asset` 文件用 search_content 搜不到 `m_RequireDepthTexture`**：
  Settings 目录下正则匹配 depth/opaque 返回 0 条（疑似被忽略规则或二进制判定影响）。
  解法：改用 `[System.IO.File]::ReadAllText` + `[regex]::Matches` 直接读取才命中——
  **配置类 .asset 核查不能只依赖文件搜索工具，必要时直读原文**
- 🔑 **Additive 粒子做软粒子的陷阱**：`Blend One One` 下 alpha 无意义，
  网上的软粒子教程默认 Alpha Blend，照抄 `col.a *= factor` 会静默失效（不报错、无效果）
- 🔑 **深度纹理未开时的失败形态**：不是报错，而是"粒子整体消失"——排查时优先查 URP 开关
