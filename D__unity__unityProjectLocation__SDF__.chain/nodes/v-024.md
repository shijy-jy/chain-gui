# 验证报告：t-032 螺旋吸入明显化

## 静态核对（读回源码确认）
1. **compute 合成目标速度**（凝聚分支）: target = dirO·radialSpeed + tangent·spinSpeed,
   一次 lerp → 切向不再被径向覆盖 ✓
2. **切向剖面** r/(r²+_SpinSoft²): 中心 r→0 时 spinSpeed→0 (无 1/r 爆炸),
   峰值在 soft 半径, 外区衰减 ✓; tangent normalize 输入 r≥1e-4 无零向量 ✓
3. **端部保留** lerp(1, _SpiralKeep, strength) 取代硬编码 (1-0.7s),
   strength=1 时切向 = 峰值×spiralKeep → 最后阶段螺旋保留 ✓
4. **盘面收紧后移**到目标合成之后, 不再被径向 lerp 冲掉 ✓
5. **脚本字段/传值**: spinSoft/spiralKeep 声明 + SetFloat 与 compute uniform
   _SpinSoft/_SpiralKeep 对应 ✓; coalesceSpin tooltip 同步更新 ✓
6. **与并行会话 t-031 (P0-3 暖光跟随) 无冲突**: 其新增 warmLightStrength/Radius
   字段独立, 无同名/同 uniform ✓
7. 强度门控 (strength>0.001) 不变, 收束期无影响 ✓

## 结论
- 静态层面根因修复到位: 螺旋在凝聚期全程成立、端部按 spiralKeep 保留、参数三开
- **运行时画面裁决待并行会话执行**（编译 + Game 视图: 阶段3/4 螺旋明显度,
  重点观察 spiralKeep=1 时最后吸收阶段）

## 已知风险（观察点）
- 峰值切向 6.67 u/s 若过强会压过径向吸入使粒子迟迟进不了吞没半径 →
  调小 coalesceSpin 或调大 orbGravity 即可
- spiralKeep 大时驻留期残余粒子持续绕转, 吸收变慢 — 属预期 (螺旋感), 可接受
