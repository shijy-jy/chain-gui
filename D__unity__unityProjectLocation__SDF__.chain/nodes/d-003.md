# 系统架构（架构轨概念树根）

自验收：架构梳理节点，无执行产物。本子树是图谱的**架构轨**（按系统分层组织的概念节点，
代码骨架挂在此轨）；与**过程轨**（t-*/v-* 时间线）双轨并存，正文互引、不重挂 parent。

## 分层
```
编排层  d-008 生命周期编排与元素球动线 (L17_EmberVortexFX.cs)
   ↓ 每帧参数
模拟层  d-005 GPU 粒子模拟管线 (L17_EmberVortex.compute: 发射/漩涡/吸积盘/回收/环平面统计)
   ↓ StructuredBuffer
渲染层  d-004 溶解着色器子系统 (L17_Dissolve_3D.shader + 2D 变体)
        d-006 火星粒子渲染 (L17_EmberParticle.shader)
        d-007 元素球渲染 (L17_FireCore.shader)
   ↑ 资产生成
工具层  d-009 噪声贴图生成器 (L17_NoiseTextureGenerator.cs)
```

## 关键约定
- 溶解与粒子发射的同步 = 同一张 3D 噪声贴图 + 同参数 (_NoiseScale/_FrontStart/_FrontJitter)
- 元素球 = 运动学场源: 脚本写位置, compute 以其为中心 (漩涡/吸积盘), shader 画其形
- 过程轨任务 → 架构轨模块映射: 溶解 t-001~t-013 → d-004; 粒子/漩涡/元素球 t-014~t-027 → d-005~d-008; 噪声工具 t-014~t-015 → d-009
