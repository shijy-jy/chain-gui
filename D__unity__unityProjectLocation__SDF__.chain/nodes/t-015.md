# 任务：立方体燃烧→漩涡→凝聚元素球 五阶段循环

## 需求原文
「初始燃烧的还是原来的正方体，最后是凝聚成元素球」+ 确认「按你的建议来」

## 用户确认的决策
- 燃烧体保持**正方体**（现有溶解逻辑不动：燃烧前锋模型 + 火焰/色带/灰烬全套）
- 元素球凝聚在**收集点**（立方体上方 +2.2m，沿用 vortexCenterOffset）
- 元素球驻留 ~3s 后**收缩消散** → 立方体**弹性弹回**重生 + 短暂**冲击闪光**
- **自动循环**

## 参考做法（检索所得，守则 9）
- RealtimeVFX《Realistic Fireball Projectiles》：火球 = 内核实心球 + 火焰壳(UV流动扰动) + 光晕 三层结构
- Applibot《Unity CustomShader 炎の球体》：火焰 UV 向上流动 + 噪波扰动 + 边缘淡出 + 呼吸脉动
- sf-studio 黑洞 shader / MeshEditor 涡流扭曲：黑洞吸收三步 = 卷入螺旋 → 接近中心角动量守恒加速 → 吞没前缩小增亮

## 实现内容
### 1. compute（L17_EmberVortex.compute）— 在用户前锋模型基础上加凝聚
- 新增参数：`_Coalesce` / `_OrbRadius` / `_CoalesceSpin` / `_CoalescePull`
- 吸收区新行为：`_Coalesce=1` 时粒子**不立即熄灭**，而是
  - 近心快旋：`tangential * _CoalesceSpin / r`（角动量守恒感）
  - 向心强拉 + 快速缩小（`size *= 1 - dt*4`）+ 增亮（`brightness → 3.0`）
  - 彻底缩小时熄灭（被球吞没）
- 凝聚阶段关闭定时寿命衰减（粒子寿命由"融入球"决定）

### 2. 元素球 shader（L17_FireCore.shader 新建）
- billboard + 三层火焰：火焰壳(T_Fire_Core + UV 流动 + perlin2D 湍流扰动 + 边缘淡出) / 内核实心(径向高亮) / 外圈光晕(指数衰减)
- `_Appear` / `_Scale` 由脚本驱动；`_PulseAmp`/`_PulseFreq` 呼吸；HDR `_Boost` → Bloom

### 3. 状态机（L17_EmberVortexFX.cs）— 3 阶段 → 6 阶段
```
[0 立方体] idleDuration 停留 (新增)
[1 燃烧]   用户原有: 前锋燃烧 + 漩涡随进度 + 发射
[2 收束]   用户原有: 全涡吸收 vortexDuration
[3 凝聚]   粒子融入 + 元素球 ElasticPop 诞生 (新增)
[4 驻留]   呼吸脉动 holdDuration (新增)
[5 重生]   球收缩爆发(先涨后缩) + 立方体 ElasticPop 弹回 (新增)
```
- 元素球 quad 运行时创建（orbMaterial 为 null 时优雅跳过）
- ElasticPop：阻尼振荡过冲（`(1-e^-8t) * (1 + 0.25e^-6t·sin(14t))`）
- 立方体 baseScale 在 Init 捕获，重生后精确还原

## GPU 安全守则自查
1. 无死循环 ✅ 2. `idx >= _Counter[0]` 边界检查 ✅ 3. 凝聚期吸收半径判断在积分后、无除零（r+0.06）✅ 4. 粒子死亡回收沿用原子计数+末位搬移 ✅

## 试错记录
- ⚠️ **用户已在会话间大改脚本**（前锋模型 `_FrontStart/_FrontJitter/_BurnMinY/_BurnHeight` + 燃烧期渐进漩涡 + `_CollectPhase`）：动工前必须读现状，把凝聚环节**接在用户设计之后**而非覆盖——本任务全部改动都基于读到的用户版本，CSEmit 与前锋逻辑零改动。
- 🔑 凝聚期的寿命策略：收束期有 `_VortexLifetime` 定时衰减，但凝聚期必须**关闭定时衰减**（否则粒子在半路被计时器杀死，看不到"融入球"），寿命完全交给吸收半径判断——这是"凝聚感"成立的关键。
