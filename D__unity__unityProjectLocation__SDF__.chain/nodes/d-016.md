# 节拍包络系统落地设计（d-015 的实施）

自验收：设计节点；实施与验收见 t-053/v-036。

## 设计
1. **每相位包络曲线**: Director 新增 `AnimationCurve[6] phaseEnvelopes`
   (横轴=相位进度 0..1, 纵轴=强度倍率). 空曲线 Init 补恒 1 → **零行为变化**,
   用户拖曲线雕刻节奏
2. **规则**: 包络只乘各模块**亮度/强度**输出, 不乘位置/尺寸 (构图不被包络破坏)
3. **命中顿帧 hit-stop**: `hitStopOnPhase` + `hitStopFrames` (默认 -1/4).
   进入指定相位时冻结 N 帧: dt=0 → 相位推进/粒子 compute/发射/模块动画全停
   (真实时间照流, shader _Time 脉动不停 — 火还在闪, 观感更活)
4. **统一相位切换入口** EnterPhase(p): 触发顿帧 + 置相位 + 清相位计时,
   六处转换点全部改走入口

## 改动清单
- FXContext: +envelope
- Director: 节奏组 3 字段 / Init 补曲线 / dt 顿帧 / EnterPhase / 包络采样 / ctx.envelope
- 5 模块: 输出 × weight × c.envelope (各 1 行)

## 节奏模板 (用户拖曲线的参考)
蓄力=前低后抬 / 释放=EaseOut 尖峰 / 命中=Elastic 过冲 / 余波=长尾衰减
