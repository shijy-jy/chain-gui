# 现世地理疆域（十三州框架）

现世地理以**州 → 郡/国 → 县**三级行政区划为准，标准时点为裂土纪；「国」为封王之地，行政等同郡。

## 三级行政区划

| 级 | 名称 |
|---|---|
| 一级 | 州（十三州 + 后期新州） |
| 二级 | 郡 / 国 |
| 三级 | 县（邑 / 城） |

## 裂土纪势力格局

| 小说势力 | 范围 | 说明 |
|---|---|---|
| 北廷 | 畿州·衍州·稷州·望州·齐州·玄州·屏州·寒州 | 挟神京以令诸侯的中原雄主政权（律令新法一脉） |
| 神庭旧贵白氏 | 畿州·神京·九章台 | 前朝神庭正统，名存实亡；九章分鼎后崩解 |
| 蜀藩 | 丰州（+汉州） | 西川藩镇，凡人觉醒者暗流聚集 |
| 江东 | 升州·岭州·海州 + 云梦州南 | 冠冕南迁后神庭旧贵的大本营 |
| 赤黎魔族 | 北疆（核心：赤黎原） | 北疆魔族——州郡政属北廷、民多魔族，政权与族域错位是北疆动乱的底色 |
| 南线弃壤 | 岭州·云梦州·升州南境海岸外 | 弃壤雾海侵蚀的最前线 |

## 三界延伸

- **虚境**：同构镜像——虚境亦有十三州格局，细节错位（错位清单待补）。
- **弃壤**：现世南疆（岭州 / 云梦州 / 升州南境）海岸外即雾海——弃壤膨胀的最前线；弃壤只进不出，堕神与诸凶永远向南线边界缓慢移动。
