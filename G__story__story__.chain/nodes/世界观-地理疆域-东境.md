# 东境（途州 · 齐州）

> 裂土纪东方：途州四战之地、诸雄拉锯；齐州为黄幡之乱重灾区。

## 途州

治所**鼓城**，旧治**邳城**。

| 郡国 | 治所 / 要邑 | 备注 |
|---|---|---|
| 鼓城国 | 鼓城 | 双关：战鼓四起 |
| 下邳国 | 邳城 · 睢陵 | 某猛将覆灭之地 |
| 东溟国 | 郯县 | 双关：海→溟 |
| 琅琊国 | 开阳 | 琅琊世族（冠冕南迁后显于新亭的旧贵之首） |
| 广陵郡 | 广陵 · 江都 | 双关：广陵散=绝唱，呼应雾海绝唱 |
| 东莞郡 | 东莞 | |

## 齐州

治所**淄城**。临海之山有**天玄宗**——现任宗主玄澈，太上长老云罗（金玉之师）；七年一度宗门大会，内门大比。

| 乐安国 | 临济 | |
| 北海国 | 剧城 | 某名士守城 |
| 东莱郡 | 黄县 | |
| 平原郡 | 平原 | 某枭雄早年任相之地 |

## 与年表事件咬合

- **黄幡之乱**：途州、齐州为重灾区——弃壤灾民揭竿、黄幡为号，两次危机皆来自弃壤的伏笔之一
- **黑风峡之变后**：东境成为南北粮运与漕运的替代通道
