# 天地之灵（九神之下）

## 现世 · 天律诸灵

**古神**：天律运转的副产品，律令运行之余韵汇于山川河海自生灵识，约数十尊（详表与眷属归附待补）。已知十三尊：

| 古神 | 司职 | 形态 |
|---|---|---|
| 风母 | 司风 | 无形，草木倾伏处便是其身 |
| 雨伯 | 司雨 | 老叟形，身侧永随雷云 |
| 渊主 | 司深海 | 沉于海底不可见，潮汐为其呼吸 |
| 山君 | 司群山 | 万丈石人，坐则成峰 |
| 日驭 | 司日轮行轨 | 赤衣御者，驾六螭拉日 |
| 月妪 | 司月相盈亏 | 白发老妇，手中弯月盈缺随拨 |
| 地脉灵 | 司大地脉息 | 无定形，地脉交汇处为其窍 |
| 霜女 | 司寒暑交替 | 素衣少女，吐息成霜 |
| 雷君 | 司雷 | 击鼓即雷 |
| 露姬 | 司露 | 晨行草尖，履痕成露 |
| 雪翁 | 司雪 | 白须老人，呵气成雪 |
| 雾使 | 司雾 | 行走无声，行处生雾 |
| 星官 | 司星轨 | 夜布星图 |

**神兽**：天地灵气聚于飞禽走兽而生，有灵识法力但无司职。四象各镇一方：苍龙（栖东境途州齐州外海，每百年浮出视为大兆）、玄龟（行于北疆渊海之间，负碑而行，碑文无人能识，据说为天律之注脚）、朱雀（栖丰州南中群山之火山，五百年自焚重生）、白虎（独行西荒寒州，杀伐过盛时出山镇压兵戈）。神兽坠入弃壤后法力化为执念反噬现世，形成恶性循环。

## 虚境 · 映律诸灵

- **倒影古神**：虚境无独立古神，皆为现世古神在映照中的倒影，与本体大致相同但有细微错位（如风母无形，其影有形为薄纱）。
- **映兽**：虚境独有，映律自身所孕。形态为两种以上事物的映照叠合（如鹿与水的映照——身如鹿，通体透明如流水）。映兽会映照来者之心——心怀善意则温顺，心怀恶意则恐怖。

## 弃壤 · 无律之灵

- **堕神**：诛厄、帝挚、祁拉。在无律之境神躯异化——帝挚每一刻都在变，唯声音不变：低沉持续的呜咽，是弃壤万千残躯最原始的悲鸣。堕神与诸凶永远向着现世与虚境缓慢移动。
- **凶兽**：追随堕神的神兽堕入弃壤后异化而成。**九婴**：极端执念凝成的人形，以恨意为钉，钉住一小片无律使其暂时「稳定」——稳定的根基是苦难；**相柳**：九首蛇身，贪水的执念，所过之处江河倒流；**猰貐**：被弃之兽，食人的执念；**巴蛇**：吞象的执念，腹中自成一方天地。
