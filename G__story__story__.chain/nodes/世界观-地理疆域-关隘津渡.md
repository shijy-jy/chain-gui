# 关隘津渡（著名小地名）

> 不属于州郡县治的高频小地名：关隘、渡口、要塞、古战场。对应战事以四纪年表为准。

| 名称 | 所在 | 双关 / 典故 | 对应战事 |
|---|---|---|---|
| 冠渡 | 衍州 | 冠冕之渡——一渡定冠冕归属 | 冠渡之战（北廷定鼎中原） |
| 虎踞关 | 畿州 | 虎踞龙盘，险固之极 | 裂土纪初群雄会战之地 |
| 缄谷关 | 畿州·函谷郡 | 函=缄（封）——封关锁谷 | 神庭纪诸侯叩关 |
| 冲津关 | 畿州·兆畿 | 要冲渡口 | 西线要冲会战 |
| 锋阁 | 丰州·梓潼 | 剑=锋——天险如锋 | 蜀藩北出受阻之地 |
| 蒹葭关 | 丰州·梓潼 | 诗经·蒹葭 | 某双雄夜战 |
| 旸平关 | 丰州·汉中 | 旸=初日——汉中初阳 | 汉中争夺 |
| 阴平道 | 丰州·阴平 | 阴=幽暗——亡蜀暗路 | 某奇袭 |
| 麦城 | 云梦州·郢郡 | 麦/没=末路 | 某名将败亡之地 |
| 华胥道 | 云梦州·郢郡 | 华胥梦国——与梦境映射互文 | 赤崖之役败退要道 |
| 赤崖 | 云梦州·江夏 | 壁=崖——业火赤崖 | 赤崖之役（三分雏形） |
| 逍遥津 | 升州·淮南 | 庄子·逍遥游 | 某猛将震津 |
| 阶亭 | 寒州 | 街/阶=等级——神眷等级制之失 | 某言过其实之将失守 |
| 五杖原 | 岐州·扶风 | 丈=杖——权杖坠落 | 蜀藩名相陨落处 |

## 补充

- 「国」与「郡」同级：鼓城国、北海国等只是封王，行政体系与郡一致。
- 锋阁、蒹葭关、旸平关、阶亭、五杖原属「蜀藩北出、北廷西御」诸役。
