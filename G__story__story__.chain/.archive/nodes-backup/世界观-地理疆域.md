# 现世地理疆域（十三州框架 · 方案 v1）

> 状态：方案 v1，待主人拍板细化
> 母本：汉末三国十三州（州 → 郡/国 → 县三级 + 著名关隘津渡）
> 原则：**借格局不照抄**——沿用三级制与十三州骨架，地名全部化用重命名，附「小说名 ↔ 三国原名」对照；与既有地标（神京 / 九章台 / 赤黎原 / 黑风峡 / 雾海）无缝咬合。
> 标准时点：**裂土纪**（现世纷争、群雄割据的小说主体时代）；三国后期新拆的州（雍/平/梁/广）另列。

## 三级行政区划

| 级 | 三国 | 小说 |
|---|---|---|
| 一级 | 州 | 州（十三州 + 后期新州） |
| 二级 | 郡 / 国 | 郡 / 国（国=封王，行政等同郡） |
| 三级 | 县 | 县（邑 / 城） |

## 命名规则（三档策略）

1. **州名全部重命名**，每个带「回古味 + 双关」：冀州→**望州**（冀=望）、荆州→**云梦州**（云梦泽 + 梦境映射）、并州→**屏州**（屏障/屏藩）……
2. **郡国名**：三国原名本身即汉末古名、已回古味，多数保留；少数关键郡双关改名：巨鹿→**逐鹿郡**（逐鹿中原）、右北平→**北平郡**、敦煌→**煌沙郡**……
3. **县邑与关隘**：高频、涉主线的双关改名：邺→**业城**（业力）、街亭→**阶亭**（神眷等级制）、函谷关→**缄谷关**（函=缄）；其余保留古名，全部可在对照表中查回。
4. 保留的古名统一视为**世界内古名**，与虚构名（神京 / 九章台）并存——古名本身即「回古味」，改名只针对会抢戏、会与现实撞车的高频名。
