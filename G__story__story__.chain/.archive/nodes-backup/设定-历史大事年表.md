# 历史大事年表（四纪史框架）

> 分类：设定 · 归属：遗忘异录世界观
> 状态：方案 v4（痕迹隔离 + 事件命名全面小说化），待主人拍板细化
> 定位：借现实历史母题，不照抄朝代史实；事件是"发生"，不是"真相"
> 变更沿革：v1 精选 12 事 → v2 扩容四纪年表 31 事 → v3 痕迹隔离 → v4 事件命名小说化（不再对参考名谐音换字，命名取自小说自身概念）

## 核心理念

- **借格局不照抄**：只借现实历史的叙事母题（神战/更替/变法/篡权/起义/边患/南渡/绝唱），不搬朝代名与史实
- **事件是发生，不是真相**：每个事件背后有神庭版、魔族版、民间版等多版本，真相留白
- **年表服务群像**：大事是势力洗牌的支点，服务"高瞻远瞩"多视角群像写法（各方闭门算账、信息差互撞）
- **母题纪属自由调配**：现实母题按叙事需要分配入四纪，不按真实年代排序
- **痕迹隔离**：现实人名、事件名只存在于母题库；年表、地理、正文一律只用小说名

## 四纪框架

1. **太初纪**：天地初开，神魔立约前的混沌时代
2. **神庭纪**：神庭建立，秩序神系统治的黄金时代（末段以神堕之变收束）
3. **流放纪**：神堕六步之后，神魔流放、法则失控的动荡时代
4. **裂土纪**：现世纷争，人族群雄逐鹿、势力割据的时代（小说主体时代）

### 裂土纪主线弧（结构阅读）

- 变法 → 逐鼎 → 裂土之始 → 冠渡 → 赤崖 → 焰陵 → 畿门 → 南服 → 双辉 → 赤黎 → 黑风峡 → 渊盟 → 九章分鼎 → 神京倾覆 → 北廷南奔 → 郾城大捷 → 雾海绝唱
- 与主线呼应：渊盟之脆弱 → 神京倾覆（魔族南侵背后是堕神诛厄与弃壤的召唤——两次危机皆来自弃壤的第二阶段）；雾海绝唱之后，旧秩序终结，主线进入「新秩序重建」

- **叙事价值**：这个事件对势力洗牌、人物弧光的用处

- **地理咬合**：与地理疆域十三州方案的对应（见 [[世界观-地理疆域]]）

### 新事件留白示例（核心 12 事见速查）

- **神魔立约**：神庭版「代天易主、顺应天律」；民间版「成王败寇的第一次僭越」
- **天党之役**：官方版「大捷定边」；弃壤版「怨瘴沉壤之始」——神庭从未承认的战争成本
- **神京焚乱**：旧贵版「权臣无道」；民间版「旧宫焚毁之夜，九章台第一次失语」
- **畿门之变**：北廷版「奉律除奸」；民间版「又一次挟神京以令诸侯」
- **郾城大捷**：北廷版「中兴在望」；魔族版「渊盟之后的又一次背盟」

### 速查：核心十二事要点

1. **承序之战**：两股先天之力的继承之争，奠定神庭"承序"正统叙事；民间疑其另有隐情
2. **诛厄之战**：游神诛厄堕魔（=魔神）之战，锁死"魔神"定性；真相多版本
3. **律令新法**：裂土纪某雄主以铁律变法，代价是"以律束神"触碰神庭禁忌
4. **神堕之变**：秩序神座下神使（原夙氏族长，读心）暗算诛厄窃神力、意图造"心灵完美世界"，神堕六步的开端；承担原罪分量
5. **黄幡之乱**：弃壤灾民揭竿，黄幡为号；两次危机皆来自弃壤的伏笔之一
6. **赤黎之役**：北疆魔族（聚居赤黎原）与中原王朝的攻守拉锯
7. **冠冕南迁**：神庭旧贵南渡，衣冠与礼法随迁，南线弃壤成为新前线
8. **黑风峡之变**：北疆粮道黑风峡被断，中枢由盛转衰的节点
9. **渊盟**：人族与北疆魔族以"渊"为界立盟，盟约脆弱、各怀算计
10. **九章分鼎**：九章台白氏本宗权威崩解，畿州分裂为多家
11. **神京倾覆**：旧都神京陷落，神庭正统叙事彻底破碎
12. **雾海绝唱**：南疆弃壤前线雾海的最后一战，旧秩序最后的绝唱

## 命名规则（事件）

- 事件名取自小说自身概念：神魔立约（神庭肇建）/ 律令定一（律令独尊）/ 藩眷之乱（眷族）/ 天党之役（战场地名）/ 裂土之始（纪名）/ 畿门之变（畿州城门）/ 双辉之世（术法+科技并盛）/ 北廷南奔（北廷残部）
- 不对现实事件名谐音换字；仅战场类事件以小说地理命名（冠渡之战、赤崖之役、焰陵之役、郾城大捷），与赤黎之役、黑风峡之变同一规则
- 回古味 + 双关：渊盟 / 诛厄之战 / 神堕之变 / 承序之战 / 神京焚乱 / 畿门之变
- 与地理疆域方案统一视觉语言
