# 抗锯齿的采样层级：MSAA / SSAA 各自增加了什么采样

## 一、问题定义与坐标系

抗锯齿的本质是**以一个以上的采样点估计单个输出像素的颜色**，用以抑制采样率不足导致的走样：几何边缘的阶梯、高光闪烁、纹理摩尔纹。

各方案的差异可归结为一个问题——**它增加的是哪一层的采样**。为此需先将"采样"分解为三个彼此独立的维度：

| 维度 | 定义 | MSAA | SSAA | 后处理型（FXAA / SMAA） | 时域型（TAA） |
|---|---|---|---|---|---|
| **覆盖采样** | 每个输出像素内用于判定图元覆盖的采样点数 | ×N | ×N（由超采样隐含） | 不增加 | 每帧 1，跨帧累积 |
| **着色采样** | 每个输出像素执行片元着色器的次数 | **1（默认）** | N | 0（在已成像图上操作） | 1/帧 |
| **纹理采样密度** | 对贴图的采样次数，与输出像素的物理密度相关 | 不变 | 随渲染目标分辨率升高而升高 | 不变 | 随抖动与累积升高 |

结论：**MSAA 只增加覆盖采样；SSAA 同时增加三者；后处理型不增加任何采样，而是在已完成的图像上做边缘检测与模糊；时域型在时间维度上累积样本。**

用词必须区分两个层级：**屏幕像素 / 渲染目标（RT）像素**是抗锯齿作用的层，**贴图（Texture）像素**只是被采样的数据源。MSAA 的亚像素位于前者内部，不在贴图中。

## 二、MSAA 的机制（逐步骤）

1. **光栅化**：对像素内 N 个采样点做覆盖判定，生成覆盖掩码。采样图案由厂商固定（常见 4× rotated grid），开发者只能选择样本数，不能自定义采样位置。
2. **深度与模板**：**逐采样**存储与测试——这是边缘处不出现错误遮挡判定的前提。
3. **着色**：片元着色器**每像素执行一次**（默认在像素中心求值；可通过 `centroid` / `sample` 插值修饰符改变取值位置与执行粒度）。
4. **写回**：本次着色结果写入该像素中**所有被覆盖的采样点**。
5. **Resolve**：对像素内 N 个采样点的颜色求平均，输出单采样图像。分块架构（TBDR）可在片上内存完成 resolve，故移动端 MSAA 相对便宜。

### 边界场景示例：石头与水面交界

设某像素位于石头三角形与水面边界上，开启 4× MSAA 后该像素含 4 个采样点，其中 2 个被石头覆盖：

- 石头在该像素**着色一次**，得到颜色 $C_s$，该颜色写入**被覆盖的 2 个采样点**；
- 未被覆盖的 2 个采样点保存的是**该采样位置上实际可见的背面表面**（水面，或更远处的背景）**经过其自身着色后的颜色** $C_b$——水面同样参与了逐采样流程；
- resolve 后该像素颜色为

$$C_{\text{pixel}} = \frac{2\,C_s + 2\,C_b}{4}$$

即**按覆盖率加权混合**，边缘由此呈现连续过渡，而非二值跳变。

**此处有两个常见误解需要澄清**：

- 像素内各采样点保存的是**该采样位置上实际可见表面的颜色**，而不是"前景取像素中心的颜色、其余一律填背景色"。MSAA 并不做"中心采样 + 背景填充"的拼接。
- 因此 MSAA 改善的是**边缘的覆盖率精度**（几何走样），并不改善**着色内容本身的精度**（纹理细节、高频光照变化）。前一句是"边缘更平滑"，后一句是"画面质量全面提升"——两者不可混同。

## 三、SSAA 的机制

- 以 N 倍线性分辨率渲染：每个超采样点**完整执行一次着色**（含 N 次纹理采样与 N 次光照计算）；
- 随后降采样（盒式或高斯）得到目标分辨率输出；
- 因此 SSAA **同时提升覆盖、着色、纹理三类采样**，对几何边缘、细节走样与纹理摩尔纹均有效；
- 代价：着色成本约 ×N（像素数 ×N）、带宽约 ×N（颜色/深度缓冲及 resolve 传输）、显存占用 ×N；
- 引擎中的等价物：Render Scale > 1 / 超采样开关。

## 四、MSAA 为何不抑制纹理与着色走样

因果链：片元着色器每像素执行一次 → 纹理仅在该点被采样一次 → 像素内部的高频变化未被采到 → 摩尔纹与高光闪烁照旧。

MSAA 增加的采样点只参与**覆盖判定**与**逐采样深度测试**，不参与着色计算。

因此可以给出一条统一的解释：**"MSAA 开销低"与"MSAA 作用范围窄"出自同一设计**——省下的 N−1 次着色，同时也正是 N−1 次纹理采样与光照计算。

纹理走样的根因是采样率不足以及 mip/LOD 选择不当，应通过 mipmap + 各向异性过滤（源头手段）或提高采样密度（SSAA / TAA）解决。

## 五、使 MSAA 退化或失效的条件

| 条件 | 后果 |
|---|---|
| 使用 `sample` 插值修饰符或强制**逐采样着色** | 着色退化为每采样一次，成本模型回到 SSAA，而收益仍仅限边缘 |
| 与**解析式抗锯齿**（`fwidth` 类边缘软化）叠加 | 与覆盖率平均叠加，可能造成边缘过度模糊 |
| **延迟渲染** | G-Buffer 需逐采样存储全部属性（属性数 × 采样数），显存与带宽成倍放大；延迟管线通常改用 TAA 或后处理 AA |
| 与 **TAA** 同时启用 | URP 下两者互斥（实测记录见「溶解与噪声遮罩」） |
| **移动端（TBDR）** | resolve 可在片上内存完成，故相对便宜；但样本缓冲受 tile 内存预算约束，超预算将退化为多次 pass，代价显著上升 |

## 六、工程手段与术语口径

- **表述规范（一）**：区分"屏幕 / RT 像素"与"贴图像素"。描述 SSAA 对贴图的影响时应使用**"采样密度升高"**，而非"贴图精度提高"——贴图的分辨率与内容均未改变。
- **表述规范（二）**：区分**覆盖率（coverage）走样**与**着色（shading）走样**。MSAA 仅解决前者；"开了 MSAA 就没有锯齿了"是错误陈述——高光闪烁、纹理摩尔纹、透明边缘依然存在。
- **`alpha to coverage`（A2C）**：将 alpha 转化为覆盖率，借用 MSAA 的采样点生成软边。其本质是以几何抗锯齿的机制近似半透明软边，代价是仍参与深度写入，且边缘质量受样本数限制。
- **方案选择**：SSAA 用于离线或高配下的画质优先；MSAA 适合几何边缘密集、着色较轻的场景；TAA / FSR / DLSS 属时域重建，代价是拖影与细节变软；FXAA / SMAA 成本最低，但以模糊换取边缘平滑，不重建覆盖率。
