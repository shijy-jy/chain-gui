# 项目讲述稿（六项目 2 分钟版 + 钩子）

**用法**：这是**成品稿**，可脱稿练；结构说明见「口述讲稿模板」。每份稿子都遵循同一结构：**背景（带数字）→ 我做的事 + 边界 → 最难的点 → 怎么解决 + 代价 → 结果与不足**，结尾留一个**钩子**（把主动权递给面试官的句子）。
**每个数字都能在「项目深挖」对应节点或 `artifacts/` 侦察报告里查到证据。**

---

## 1. TA_show（当前主力，讲得最细）

> 我在做一个**雨夜氛围的实时场景**，Unity URP，自研 18 个脚本、10 个 shader；画面由五层构成：大气散射天空、全屏雾、能量网格地面、40 根接地光柱、雨和湿地倒影——技术部分是我自己实现的，没有参考现成工程。
> 最难的是**看起来像美术问题、实际是渲染管线问题**的一类 bug。比如倒影会随视角错位旋转，我最后定位到镜像相机是用 `LookRotation` 拼出来的：**镜像让坐标系手性翻转**，三角形环绕方向反了，剔除就错了；改成严格反射矩阵加 `GL.invertCulling`。同一处还叠着两个问题——镜像渲染时贴地网格线被画进了反射 RT，二次采样后出现"错位假网格"和地平线硬分界带。**三类 bug 叠加，只修一个都不够。**
> 性能上雾的后处理原本每像素跑两次全步数行星积分，我直接删掉改成烘焙 cubemap 加仰角驱动的解析雾；网格是 41 万顶点的程序化网格，用顶点退化加片元早退，窗口内砍掉约 36%。
> 不足是我**没做帧时间测量**，性能只能讲手段不能讲收益——这是我下一步要补的。

**钩子**：「这个项目里有一处我用了三天才定位的 bug，根因是坐标系手性——要我展开吗？」

## 2. SDF（系列 shader 特效）

> 这是一个 **URP 的系列 shader 特效工程**，主线是火焰溶解：溶解家族（3D 主用加 5 个 2D 变体）、**65536 容量的 GPU 火星漩涡粒子**、元素球、以及 CAS 锐化/热扭曲/地面光斑/烟这几个后处理件；共 35 个 shader 文件、17 个相关 C# 脚本，我用一份 104 节点的工程图谱记录了整个过程。
> 【待你核对：这个地方**部分实现由并行会话完成**，讲之前要标清哪些是你亲手写的。】
> 最能说明问题的是一个**数值 bug**：粒子环平面统计的平均高度暴涨到 12700 以上。我用**量级估算**定位——1000 个粒子、平均高度约 3，正确量级应该是 6000 左右，对不上就说明公式错了：加权平均的**分子漏乘了权重**（分母算了）。修法是 `InterlockedAdd` 补上权重，一行，之后做了溢出核验。同类经验还有：`float` 原子加在 Metal 上不可用，所以加权统计必须用**定点整数**。
> 不足是当时用静态核对做验收，后来发现**截图不能作为 GPU 粒子系统的判据**，改成了运行时结构化采样——这个教训我记在工程图谱里了。

**钩子**：「那次的教训是验收方法本身有盲区，我后来把验收改成了运行时采样——要不要讲这个盲区是怎么暴露的？」

## 3. water（FFT 海面）

> 这是一个 **URP 的实时海面渲染工程**：Tessendorf/FFT 统计波谱海面加物理大气散射天空。要说清边界：工程里 181 个脚本中**自研只有 FFTVerify 和 Atmosphere 两块**，其余是第三方资产；FFT 管线我也参考了开源实现，**自己做的是数值验证工具链、4 层频谱参数、LOD 脚本和大气链路的迭代**。
> 实现上是固定 1024²、6 个 kernel；**4 层频谱，每层 2 组 JONSWAP，共 8 个涌浪源**；位移、法线、Jacobian 全部在**频域解析求导**而不是有限差分；泡沫用 Jacobian 折叠检测加跨帧衰减累积。
> 最难的一类是**静默错误**：比如大气里 m⁻¹ 和 km⁻¹ 漏乘，画面"看着还行"，**没有任何报错**。我的应对是先做数值可观测性——用 `CopyTexture` 加 `ReadPixels` 把频谱、位移、Jacobian 画出来，能看见数值再谈调参。循环动画不闭合的问题则是把角频率量化到 2π/200 秒，让每个波的周期都是 200 秒的整数分之一。
> 不足是**没有性能数据**，另外海-气桥的 shader 写了但没接进渲染链。

**钩子**：「我是先用数值验证工具链确认频谱对不对，再开始调观感的——这个方法后来在别的项目一直用。」

## 4. windtest（体积云 + 大气）

> 这个工程**名字叫 windtest，但内容跟风没关系**——它是 URP 的**体积云加大气散射**技术 Demo，11 个渐进式学习模块。我要说清边界：**云管线是按一个开源项目逐模块复刻的**（原工程完整放在 `参考文件/` 里做对照），**自研的是大气散射、以及对参考实现四类缺陷的定位修正**。
> 那四类缺陷很典型：光线平行于包围盒轴时出现 **NaN**（$1/0$ 再乘 0）；用"每步密度累加"导致云**快速饱和、没有厚度感**，改成光学深度积分加指数；用曲线贴图查表做光照衰减，改成 Beer × powder 解析式；还有一处 **RenderTexture 泄漏**——用 `.Release()` 归还 `GetTemporary` 拿到的 RT。每一处我都有与参考实现的 diff 对照。
> 最有价值的一步是把两个模块**接起来**：云的环境光不再用固定色，而是采样大气生成的天空 cubemap，于是日落时云自动联动。
> 不足是**云与大气的最终合成还没完成**，最后一张截图云还是黑白密度形式。

**钩子**：「把云和大气接起来这一步，是我自己加的——它让日落时的云自动变色。」

## 5. render_unified_oss（四后端渲染器）

> 这是我自己写的 **OpenGL + CUDA 渲染器**，C++17，**零渲染第三方依赖**，65 个源文件约 1.6 万行。所谓"unified"指**四个后端共享同一个场景与同一套接口**：光栅 CPU/GPU、路径追踪 CPU/GPU，按键切换。渲染上实现了 GGX 微表面、Kulla-Conty 能量补偿、Heitz VNDF 采样、玻璃 BTDF、MIS/NEE、**ReSTIR DI 与 GI**、SVGF 降噪，以及可选 OptiX AI 降噪。
> 我最看重的是三件"把话说死"的事：一是**可执行的回归判定链**——`eval/` 是个零依赖的评判核心，20 张基线图，一个三态脚本做冒烟、比对、更新基线，而且**光栅要求位级一致、路径追踪只要求统计级 PSNR ≥ 50 dB**，口径分开写清；二是**数学正确性用独立方法仲裁**——单次散射 GGX 的白炉能量只剩 0.335，补偿后到 0.9962（±1%），VNDF 把方差从 0.747 降到 0.136；三是**为一个崩溃做了逆向定位**，把"加载模型导致崩溃"证伪成"关窗时的 ODR 违例"（栈 Cookie 被写穿）。
> 不足有两处要说明：**没有做性能量化**（全仓库只有 README 里一句帧时间声明），另外 `docx/` 里那几份文档是**外部 AI 生成的评审输入**，不是我写的。

**钩子**：「我给自己定的规矩是'先写什么叫做对了，再动手'——那套判定链就是这么来的。」

## 6. Engram（知识图谱工具）

> Engram 是我**独立开发**的一个桌面工具：**Rust 四个 crate（core / mcp / gui / cli）+ Svelte 5 + Tauri 2**，配一个 MCP stdio 服务，让开发者和 AI 共用同一份工程记忆。设计上最关键的一条是：**纯文本 `.chain/nodes/*.md` 是唯一事实源，索引、统计、审计、代码骨架全部是可重建可删除的派生物**；前端和 MCP 两条入口都只调用同一个写路径。
> 工程上我做了：**tree-sitter 代码骨架**（公开接口、签名、调用边、Mermaid 图，带 stale 检测）、MCP 工具契约从 9 个演进到 13 个（写路径串行队列加乐观锁）、CLI 三个子命令加**退出码契约**、NSIS 静默安装流水线。前端卡顿我定位到"全图节点每帧写宽高"，改成位置缓存加 30fps 节流。
> 踩过的坑也很实在：**PowerShell 写出的 BOM 会让索引静默跳过节点**（后来在前言解析里显式剥 BOM）；**PowerShell 5.1 调 MCP 必须按 UTF-8 字节直写 stdin**，否则中文查询会被写坏而且传输静默死亡；还有安全边界 `is_safe_id` 只允许 ASCII，于是这个库约定成"**ASCII id + 中文 title**"。
> 不足是**缺少规模化使用数据**来支撑"检索效果好"，只能讲机制。

**钩子**：「我给它定的宪法是'事实源与派生物必须分离'——这条约束直接决定了后面所有设计。」

## 通用零件（每段都能用）

- **边界声明句**："这里我要说清边界——X 是我做的，Y 是参考/复刻的。"（详见「自研边界与证据强度」）
- **代价句**："这个方案换来的是 X，付出的是 Y。"（没有代价句的方案听起来就像没做过）
- **口径句**："36% 是窗口内、同参数前后对比，不是全场景帧率。"
- **不足句**：主动说未完成/未量化的部分——这是**可信度的来源**，不是减分项。
- **钩子句**：结尾把主动权递回去，让面试官问你准备最充分的那块。
