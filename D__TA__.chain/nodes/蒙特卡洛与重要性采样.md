# 蒙特卡洛与重要性采样

## 要解决什么

渲染里的积分（渲染方程、体积散射、软阴影）几乎都算不出解析解，只能用随机采样估计：

$$\hat I = \frac{1}{N}\sum_{i=1}^{N}\frac{f(x_i)}{p(x_i)},\qquad E[\hat I]=\int f(x)\,dx$$

**无偏条件**：只要 $f(x)\neq 0$ 的地方都满足 $p(x)>0$，估计就是无偏的——这条比公式本身更重要，**bug 十有八九出在"某个区域 pdf 为 0 而 f 不为 0"**。

## 方差决定观感（噪声）

$$\mathrm{Var}[\hat I]=\frac{1}{N}\left(\int\frac{f^2}{p}\,dx - I^2\right)$$

三个直接结论：
- 标准差按 $1/\sqrt{N}$ 下降 → **采样数翻倍只能降约 30% 噪声**，加倍采样不是好策略，降方差才是。
- $p \propto f$ 时方差最小 → 这就是重要性采样的全部动机。
- $p$ 比 $f$ "宽" 太多（欠采样）→ 偶发大权值 → **椒盐噪声**；$p$ 太"窄"（漏采样）→ **有偏**（能量丢失）。

## 无偏性与 MSE：所有取舍的总账

**无偏性**（管"方向对不对"）：$\mathbb{E}[F_N]=I$ 对任意 $N$ **精确**成立。三条性质：
1. 是精确性质，不是"尽量接近"；
2. **与 pdf 好坏无关**——只要 $f\neq0$ 处 $p>0$，任何 pdf 都无偏；
3. **可线性组合**：多个无偏估计的加权和（权和为 1）仍无偏——帧平均与 MIS 都靠这条。

**收敛性**（管"离得近不近、逼近快不快"）：独立同分布下由强大数定律保证 $F_N\xrightarrow{\text{a.s.}}I$；收敛速度由方差给出 $\sigma_N=\sigma_1/\sqrt N$。

**两者由一条公式连接**——本库最该记住的公式之一：

$$\mathrm{MSE}(F_N)=\mathbb{E}\big[(F_N-I)^2\big]=\underbrace{\operatorname{Var}(F_N)}_{\text{方差}}+\underbrace{\big(\mathbb{E}[F_N]-I\big)^2}_{\text{偏差}^2}$$

四种组合，四种工程含义（"概念辩证卡②"的骨架）：

| 情形 | 含义 |
|---|---|
| 无偏 | 偏差项为零 → MSE 只剩方差，**样本越多越接近**（这就是"趋于无穷收敛到无噪画面"的依据） |
| **无偏 ≠ 收敛快** | 方差可能巨大（小光源下某策略方差是 MIS 的 $6.9\times10^6$ 倍）——**无偏保住方向，方差决定速度** |
| **有偏 ≠ 不收敛** | 偏差随 $N\to0$（一致性）时仍有偏方法收敛；偏差不消失则 MSE 有下界，**再多样本也到不了真值** |
| 完美采样 | $p\propto f$ 时 $\operatorname{Var}=0$，$N=1$ 即收敛——无偏与零方差在此合流 |

**同一笔交易出现在两个轴上**：俄罗斯轮盘在**路径长度轴**上用"有偏风险"换"有限成本"（期望上无偏）；ReSTIR 的 M-cap 在**样本历史轴**上做同样的事（有偏但一致）。→ 详见「方案 · ReSTIR 时空复用」。

## MIS（多重重要性采样）

当有多个采样策略都能采到同一积分（如 NEE 光源采样 + BSDF 采样）时，用权重合成而不是二选一：

$$w_i(x)=\frac{p_i(x)}{\sum_j p_j(x)}\quad(\text{balance heuristic}),\qquad \hat I=\sum_i \sum_{x\in S_i} w_i(x)\frac{f(x)}{p_i(x)}$$

平衡启发式的直观：**每个策略只对自己擅长的区域负责**——掠射角/大面积光源由光源采样负责，光滑高光由 BSDF 采样负责。

## 在你项目里的落点（都是真实的数值证据）

- **`render_unified_oss` 白炉测试 0.335 → 0.9962（±1%）**：单次散射 GGX 丢能量是物理必然，用 Kulla-Conty LUT 补偿；**VNDF 采样把方差从 0.747 降到 0.136（5.5×）**——同一积分、同一 N，只换了 pdf，这就是"降方差优于加采样"的实证。
- **pdf 选错会导致"采样更多反而更噪"**：PT CPU 128 SPP 比低 SPP 更噪，根因是 F0=0.04 的墙面上镜面/漫反射 **50/50 分样本**；改成 $p_{\text{spec}}=\mathrm{clamp}(F_{\text{avg}}(F_0),0.02,0.98)$ 后正常（`t-011`）。
- **ReSTIR 的"有效样本数"**：ReSTIR 用历史样本复用提升 $N$，但 M-cap 硬截断会**把样本质量均衡化**——所以 N=32 与 N=1 看不出差别（`d-010`/`d-011`）。
- **反例（确定性方法）**：`water` 的 FFT 海面不用蒙特卡洛——统计波谱把"无数随机波"求和变成**频域确定性计算**，噪声问题被彻底消除。**面试里能说清"什么时候不该用蒙特卡洛"比只会用更加分。**

## 可能被追问的三层

1. **原理层**：为什么 $1/\sqrt{N}$？（中心极限定理）无偏但高方差 vs 有偏但低方差，各自什么时候可接受？ReSTIR 的偏差从哪来（M-cap 与相关性）？
2. **实现层**：balance 与 power heuristic（$\alpha=2$）差别与代价？怎么写一个 pdf 正确的 GGX 采样？为什么 pdf 要做除法而不是"乘个权重"？
3. **边界层**：NEE + MIS 还漏了哪些光路（焦散、多光源互相可见）？如果 pdf 与 f 都难算，还能用什么（路径引导 / 重采样）？
