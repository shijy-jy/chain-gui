# 方案 · GPU 粒子系统（模拟 + 渲染）

**为什么上 GPU**：几万粒子的位置积分、力场与邻域统计在 CPU 上要遍历+回传，GPU 侧一次 dispatch 就是全部。本项目容量 **65536** 粒，粒子结构 **48 B**（位置/速度/寿命/种子等紧凑排布）——**结构体大小直接决定带宽**，是粒子上限的第一约束。

## 一、模拟侧：三段 compute

| 阶段 | 干什么 | 关键点 |
|---|---|---|
| `CSEmit` | 在正方体 6 面上按 3D 噪声采样、用窄带筛选发射火线 | 发射位置与几何同源（避免"看起来不像从这个物体出来的"） |
| `CSUpdate` | 重力/阻力 → **漩涡力场**（切向+径向+轴向，收束期用 $\text{ramp}^2$ 编排）→ **吸积盘**（盘面共面收紧 + 指数吸入 + $1/r$ 绕转 + 吞没） | 力场是**分层叠加**的：先整体运动，再局部场，再阶段编排 |
| `CSClear` / `CSClearAvg` | 清场 + 环平面加权统计清零（双缓冲交替） | 统计与模拟分离，便于单独验证 |

**O(1) 回收（swap-remove）**：删除粒子时不移动数组，把**末位粒子搬到被删位置**、计数减一。GPU 上没有"列表删除"，这是标准手法。

## 二、三类原子操作的坑（这块最能体现"吃过亏"）

1. **计数器用 `InterlockedAdd` 普通缓冲，而不是 Append/Consume**：本系统里 `CopyCount` 去读 Append 计数器**无效**——计数语义不对，最后改成显式原子加。
2. **`float` 原子加在 Metal 上不可用** → 加权统计必须用**定点整数**：把 $y$ 乘 1000、$w$ 乘 4096 再原子加整数，最后还原。**"全平台安全"是设计约束，不是优化选项。**
3. **环平面统计的正确性**：存活粒子按**水平距离高斯加权**求平均高度。这里出过一个经典 bug——**分子漏乘权重**（分母算了、分子没算），结果平均值暴涨到 **12700+**；定位靠**量级估算**：1000 粒、$y\approx3$ 应得 ≈6147，对不上就说明公式错（`t-046`，一行修复 + 溢出核验）。

## 三、渲染侧：实例化广告牌

`DrawMeshInstancedIndirect` + **`SV_VertexID` 六索引 quad 角点表**——**没有顶点缓冲**，每实例的 4 个角点在顶点着色器里按索引查表生成，再从相机右/上向量展开成面向相机的四边形：

- **速度拉伸**：把速度投影到屏幕平面，沿该方向拉长 quad → 高速粒子变成流线，而不是圆点。
- **双层辉光**：核心用高次幂（约 8 次）的紧凑亮斑 + 光晕用低次幂（约 2.5 次）做大范围衰减 + 十字星芒；**两次幂的组合比单次更能表现"有核有晕"**。
- **生命期色温**：白热 → 橙 → 暗红，让粒子自带"冷却"叙事。

**两个必踩的绑定坑**：
- **数据源是 compute 的 `_Particles` StructuredBuffer**，材质被复制后**必须显式 `SetBuffer` 重新绑定**，否则渲染读到空缓冲（症状：粒子全在原点或直接不可见）。
- **3D 噪声采样需要显式 `SamplerState`**（不能依赖隐式采样器）。

## 四、软粒子：Additive 下的一个反直觉点

软粒子用深度差淡化边缘，避免粒子与几何相交出现硬边。**但在 Additive 混合下，`softFade` 必须乘到 `rgb` 上，不能乘 `alpha`**——因为 Additive 的 alpha 根本不参与混合，乘 alpha 等于没做（画面依旧硬边）。
→ 通用教训：**写 shader 前先想清"这个混合模式里哪些通道真正起作用"**。（`t-032`）

## 五、可能被追问的三层

1. **原理层**：为什么粒子系统要"结构体数组 + 索引回收"而不是对象？`InterlockedAdd` 与 Append 计数器的语义差别？为什么 float 原子加在部分平台缺失（硬件是否支持 float atomics）？
2. **实现层**：`SV_VertexID` 查表生成的 quad 与实例化 Mesh 的差别与开销？速度拉伸在速度接近 0 时怎么避免退化（长度下限/退化方向）？双层辉光的两个幂次与 Bloom 阈值怎么配合？软粒子的深度差怎么拿到（深度纹理 or 场景深度拷贝）？
3. **边界层**：粒子数上限由什么决定（带宽 / 填充率 / 原子竞争）？大面积 Additive 粒子的**填充率**问题怎么量化与缓解？半透明排序与 TBDR 的取舍？什么时候该回到 CPU 粒子（少量、需要大量游戏逻辑交互）？

## 六、手写/白板题（自测）

1. 写出"末位搬移"回收一个粒子的原子操作序列，并说明为什么它比"整体前移"便宜。
2. 写出加权平均的分子分母，并解释漏乘权重时结果会偏大还是偏小、为什么量级估算能抓到它。
3. 写出广告牌在顶点着色器里展开成相机朝向面的两行代码（用相机 right/up）。
