# 渲染效果（面经：效果类）

**这个分组管什么**

面经里归为「效果类」——「光遇的体积云怎么实现」「极光怎么做的」「用了哪些后处理」。这一类的特点是：追问全在你自己的实现细节上。

本组收的是「能被问到具体实现」的成品效果，每个节点都带代价与失效边界。

## 本组节点

- **体积渲染基础** —— Beer-Lambert、ray-AABB、powder 近似
- **实时大气散射链路** —— LUT → 多散射迭代，water / windtest / TA_show 三处落地对照
- **FFT统计波谱海面** —— 频域求导、Jacobian、折叠检测
- **平面反射的正确性** —— 镜像矩阵、手性翻转导致剔除出错
- **溶解与噪声遮罩** —— 噪声 + 阈值 + fwidth 分析式边缘
- **后处理链顺序** —— 六阶段链与顺序错的两个症状
- **抗锯齿的采样层级** —— MSAA / SSAA / FXAA / TAA 各自多采了哪一层；「屏幕像素 vs 贴图」的用词分界
