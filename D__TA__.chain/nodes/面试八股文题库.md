# 面试八股文题库（六册 · 高频问答速答版）

## 这是什么

2026-09-22 新建的一套**面试八股文**——标准化问答、可背诵的速答手册，共六册，存于 `artifacts/面试八股文题库/`。

**与库内其它东西的分工**（别混用）：

- **知识节点**（「渲染与着色器」「图形数学基础」等）讲**原理与我自己项目的证据**，自包含、可深挖，是本库的原料；
- **本套题库**给**面试现场能直接说出口的标准答案**——每题四栏：`答（背这段）` / `细节·公式` / `追问会问什么` / `坑`，并逐册映射回知识节点；
- **「白板题汇总」**是限时自测清单（40 题，黑板的写法）；本套题库是它的答案侧与扩容（共 92 题，含口述与追问）。

一句话：**白板题汇总负责"考我"，本套题库负责"给我答案"，知识节点负责"我的证据"。**

## 为什么要自建（外部调研结论）

2026-09-22 做了三轮独立网络调研（约 24 组查询、80+ 条查询语句，覆盖中文面经、图形学/渲染题库、引擎与工具链、移动端、英文资源）。结论：

1. **中文 TA 领域不存在体系化八股文**——前端那种大而全、持续维护的文档在 TA 侧没有，只有零散单篇、个人博客大纲、面经帖；
2. **GitHub 上没有中文 TA 面试仓库**（只找到 Unity **客户端**向仓库、韩文仓库、美术向 TA 的**工程文件**）；
3. **三个方向完全空白**：渲染管线改造（自定义 SRP / RenderFeature / RDG / 断批排查）、TA 工具链与 DCC、特效与动画管线；
4. **GAMES202（真正拉开差距的部分：阴影、PBR、实时光追、降噪）的中文笔记远少于 GAMES101**。

所以本套题库的定位是 **骨架自建 + 外部资源回填**，而不是"找一份网上的抄下来"。

## 怎么用（接到 P4 阶段）

1. **先自测不要先背**：用「白板题汇总」限时过一遍，标记答不出的题；
2. 答不出的题 → 到对应分册**先自己讲一遍再看答案**；「追问会问什么」是第二遍要过的内容；
3. 每读完一册回到知识节点补**自己的项目实例**——八股给标准答案，你的项目给差异化；
4. 面试里被问到本套题库没覆盖的题，**当场记下来、24 小时内建节点**（P5 复盘闭环）。

## 边界声明（诚实划界）

- 外部链接**均来自搜索实际返回、未打开页面正文核实**，因此内容判断属推断、链接可能失效；使用前需自行点开确认；
- 本套题库的答案是**通用标准答案**，**不含个人项目证据**；真正的差异化仍在「项目深挖」六个节点与「自研边界与证据强度」；
- 04 册所有性能数字都给了机型/分辨率/构建类型等口径前提，**脱离条件引用就是错**；
- 05 册刻意不写不确定的 bpy / Unity API 名，遇到具体接口一律"以项目锁定的版本为准"。
