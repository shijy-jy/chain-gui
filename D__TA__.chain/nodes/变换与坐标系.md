# 变换与坐标系（含法线为什么用逆转置）

## 空间链（渲染管线的骨架）

$$\text{模型} \xrightarrow{M} \text{世界} \xrightarrow{V} \text{观察} \xrightarrow{P} \text{裁剪} \xrightarrow{\div w} \text{NDC} \xrightarrow{\text{viewport}} \text{屏幕}$$

**每个坑都出在"某一步用了错的矩阵或错的约定"**上：
- 模型→世界用 $M$；法线必须用**逆转置** $(M^{-1})^{T}$（下面详述）；
- 观察空间的正负方向（Unity 是右手观察空间 + 左手世界）决定相机前向是 $-z$ 还是 $+z$；
- 裁剪空间到 NDC 的 $w$ 除法会让"投影后线性插值"失真——所以透视正确的插值要带上 $1/w$；
- **反向 Z**（`UNITY_REVERSED_Z`）把近平面映射到 1、远平面映射到 0，配合浮点分布显著提升深度精度。写反的症状很典型：**天空像素的深度判断出错**（`TA_show` 的雾 pass 就踩过，见「平面反射的正确性」与「数值精度与静默错误」）。

## 法线为什么用逆转置（面试必答，要会推）

法线 $n$ 的定义是**与切平面垂直**。若用 $M$ 变换切线 $t$（$t' = Mt$），要保持"变换后的法线仍垂直于变换后的切线"，即要求

$$(M^{-1})^{T}n \cdot Mt = n^{T}M^{-1}Mt = n\cdot t = 0$$

所以法线要用 $(M^{-1})^{T}$（逆转置）。**什么时候可以偷懒用 $M$**：当 $M$ 是**正交矩阵**（只含旋转、均匀缩放）时 $(M^{-1})^T = M$。一旦有**非均匀缩放**（压扁的物体）就必须用逆转置，否则法线会歪——这是"压扁的模型光照不对"的标准根因。
**相邻事实**：**镜像矩阵**（平面反射用的那个）是"不正交"的典型——所以镜像相机下法线也必须走逆转置。

## 切空间与 TBN

切线空间法线贴图需要一个基 $(T, B, N)$：
- $N$ = 顶点法线，$T$ = 切线（UV 的 $u$ 方向），$B = N \times T$（**注意手性与 Unity 的 `tangent.w` 符号**，用来处理 UV 镜像）；
- 在 y-up 左手约定下，$T_2 = V_h \times T_1$ 这类写法会让法线分量变负——`render_unified_oss` 的 VNDF 移植就栽在这里，改成 $T_2 = T_1 \times V_h$ 才对（`t-010`）。**跨坐标系移植代码时，叉乘顺序必须重新验证。**

## 左右手坐标系：一个真实的 3D 案例

**MMD 是左手坐标系**。实测证据（`jianmo` 工作区的 `node-25`）：VMD 里「頭」绕 **+X** 旋转 20°，在这个模型上表现为**绕世界 X 的 −20°**，也就是**抬头**。→ **`+X` 是抬头、`−X` 才是低头**，方向标反会白追一整轮。
验证方式很朴素但有效：低头 20° 时眉毛质心位移实测 $(0,-0.0626,-0.0679)$（前倾 + 下移），与手算的绕世界 X 转 −20° 完全吻合。

**换算提醒**：左手系与右手系之间的转换不是"某个轴取反"这么简单——通常是**一对手性矩阵**（沿某轴镜像 + 保持旋转语义），且**位置、旋转、缩放、法线各自的处理不同**。

## 这个节点的实际用途（交叉引用）

- 「平面反射的正确性」——为什么镜像矩阵下法线要逆转置；
- 「数值精度与静默错误」——反向 Z 与深度精度；
- 「URP RenderFeature 的插入点与依赖」——自写全屏 Vert 的 UV 翻转（`UNITY_UV_STARTS_AT_TOP` / `_ProjectionParams.x` 是"屏幕坐标约定"的一部分）；
- 「光照模型与微表面 BRDF」——VNDF 采样的坐标系约定；
- 「动画与骨骼管线」——MMD 左手系与骨骼静止朝向约定。

## 可能被追问的三层

1. **原理层**：为什么法线不能用 $M$（用切平面垂直性推导）？为什么透视插值要做 $1/w$ 校正？反向 Z 为什么提升精度（浮点在 0 附近密、1 附近疏，而反向 Z 让近处落在密区）？
2. **实现层**：`tangent.w` 的符号语义？怎么在 shader 里判断"当前是否在渲染镜像/翻转的相机"？世界→观察矩阵在 Unity 里怎么取（`UNITY_MATRIX_V`）与它的手性？
3. **边界层**：大世界坐标下漂浮原点（floating origin）会改变哪些既有假设？从 Unity 移植到 UE 时哪些约定会变（左手/右手、Z-up/Y-up、行/列主序、NDC 深度范围）？

## 手写/白板题（自测）

1. 推导"法线用逆转置"，并给出"可以退化为 $M$"的充分条件。
2. 写出模型→世界→观察→裁剪的矩阵链，并说明哪一步做了透视除法。
3. 给定一个左手系的世界方向与一个右手系的相机，写出把前者转到相机空间的思路（含手性处理）。
