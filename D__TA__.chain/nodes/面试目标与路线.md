# 面试目标与路线（综合 TA / 3–6 个月）

## 目标画像（2026-09-21 确认）

- **岗位方向**：**综合 TA**——渲染向（shader / 效果 / 管线）与工具向（编辑器扩展 / 批处理 / DCC 桥接 / 流程自动化）**两条线并重**，现场按 JD 应变。
- **时间线**：**3–6 个月**，稳步打磨，不赶工——允许"先做深再铺广"。
- **产出形式**（4 类，全部要）：
  1. **知识节点**（图谱里的原料，基础）
  2. **口述讲稿**（自我介绍 1/3 分钟版 + 每项目 2 分钟版）
  3. **模拟追问**（三层追问练习，答不上来的直接建节点）
  4. **技术手写/白板题**（公式与推导能手写）

## 路线（阶段 → 验收标准）

| 阶段 | 内容 | 验收标准 | 状态 |
|---|---|---|---|
| **P0 项目深挖** | 6 个项目各一个节点：定位 / 我负责什么 / 难题→办法 / 证据 / 追问三层 | 每个节点都能让 AI（或朋友）追问三层而不露怯 | **6/6 节点已建**，待补证据（见下） |
| **P1 补证据 + 划边界** | 补齐「自研边界与证据强度」里列的缺口：git、性能数据、归属确认 | 「强」级证据覆盖每个项目的核心主张 | 进行中（最优先） |
| **P2 基础知识** | 优先「渲染与着色器」+「图形数学基础」，其次「引擎与管线」「DCC 与工具链」 | 每个 hub 下"必须能答出来"的最小清单全部成节点，且每个数学节点带一个最小可算例子 | **进行中**：渲染 3 + 数学 2 + 引擎 2 + 实现办法 3；各 hub 的"待建"清单见对应节点 |
| **P3 口述讲稿** | 自我介绍 1/3 分钟、6 个项目 2 分钟版、被追问时的深挖版 | 脱稿复述，每句主张都能指到证据 | 未开始 |
| **P4 模拟追问 + 白板题** | 三层追问压力测试；手写渲染方程 / MIS 权重 / 法线变换 / Gerstner / 透视投影等 | 白板题一次写对；追问不出现"这个我没想过" | 未开始 |
| **P5 复盘闭环** | 每次面试后把答不上来的问题**立刻建节点** | 每场面试后 24 小时内产出节点 | 持续 |

## P2 的基础知识优先级（先按这个排，等 JD 再调）

1. **渲染与着色器**：光照模型（Lambert/Phong/微表面）、管线阶段与坐标空间、后处理与色彩空间、体积与大气、水面、粒子与溶解类效果、调试与验证手段。
2. **图形数学基础**：变换与法线变换、蒙特卡洛与重要性采样、MIS 权重、色彩与光度学、浮点与半精度。
3. **引擎与管线**：URP 的 RenderFeature/RenderPass 插入点与代价、资源与构建、平台差异与降级、帧预算拆解。
4. **DCC 与工具链**：Blender 脚本、批处理与校验、导入导出约定、DCC↔MCP/AI 桥接。

## 待你提供的输入（缺了会走偏）

- **目标公司 / JD 关键词**（哪怕是"某厂 TA 岗 JD 原文"）——我按 JD 反向映射图谱，避免练了不考的。
- **要不要准备 UE**（当前 6 个项目全是 Unity + 1 个 OpenGL/C++，UE 相关会成短板）。
- **移动端经验**：现有素材里几乎没有移动端项目，若 JD 要求得单独补。
- **作品集形式**：视频演示 / 可跑构建 / WebGL / 图文页——决定我要不要帮你整理产出物料清单。
