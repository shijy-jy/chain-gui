# 渲染与着色器

**管什么**：从"要一个画面效果"到"在 GPU 上跑起来"的知识——光照与材质模型（BRDF/PBR 及其取舍）、各类效果的实现路线、渲染方程的近似手段、以及怎么用确定性证据验证渲染结果。

**边界**：模型/贴图等资产怎么生产 → 「DCC 与工具链」；引擎怎么加载资源、管线怎么搭 → 「引擎与管线」；底层的概率与积分理论 → 「图形数学基础」。但**某个效果自己的完整推导属于本 hub 下的那个效果节点**，不要上提成通用理论。

## 子分组

（面经里的题目分类：管线类 / Shader 类 / PBR 类 / 效果类 / 特效类 / 性能类 / 工具链类 / 协作类。以下是中间层分组，每个分组节点里还有跨 hub 关联。）

### 光照与PBR

- **光照模型与微表面 BRDF**（`光照模型与微表面BRDF`）——Cook-Torrance / GGX / 能量守恒与 Kulla-Conty 补偿 / VNDF 采样；含"什么时候**不**该用 PBR"
- **方案 · ReSTIR 时空复用（含无偏性的"成对结构"）**（`ReSTIR时空复用`）——RIS 定理与"成对结构"、M-cap 偏差的精确来源与 `dynCap = N×F` 改造、空间复用为何 Jacobian=1、GI 重连与 GRIS、无偏性总账表

### 渲染效果

- **体积渲染：光线步进与光学深度**（`体积渲染基础`）——Beer-Lambert、ray-box 求交的 NaN 陷阱、光学深度积分 vs 累加饱和、powder
- **方案 · 实时大气散射链路（LUT → 多散射迭代）**（`实时大气散射链路`）——water / windtest / TA_show 三处落地对照，本 hub 最有分量的一条线
- **方案 · FFT 统计波谱海面**（`FFT统计波谱海面`）——Gerstner → FFT 的递进链、JONSWAP/共轭打包/Stockham/频域解析求导/Jacobian 泡沫、循环与平铺的处理
- **平面反射：镜像相机的正确构造**（`平面反射的正确性`）——手性翻转 / 剔除 / 二次采样三类叠加 bug
- **方案 · 溶解特效与噪声遮罩**（`溶解与噪声遮罩`）——噪声空间三选一、fwidth 分析式 AA、八度自适应淡出、与 Bloom 阈值的相互作用
- **后处理链顺序：顺序即语义**（`后处理链顺序`）——六阶段推荐链、顺序错的典型症状表、四个项目的链位置落点、保证顺序不出错的工程手段

### 特效与粒子

- **方案 · GPU 粒子系统（模拟 + 渲染）**（`GPU粒子系统`）——三段 compute、swap-remove 回收、三类原子操作坑（Append 计数/float 原子加成定点/加权平均漏权重）、实例化广告牌与速度拉伸、Additive 软粒子的通道陷阱
- **方案 · 特效节奏：节拍结构、缓动曲线与顿帧**（`节拍与特效节奏`）——攻击特效的五段节拍比例、每段的曲线形状、顿帧/预期/过冲三技巧、黑板包络与统一入口的工程落地（含"零行为变化默认值"）
