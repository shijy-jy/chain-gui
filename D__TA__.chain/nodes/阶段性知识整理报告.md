## 六、技术要点摘要

**渲染与着色器**
1. 微表面 BRDF 的能量守恒需 Kulla-Conty 补偿；单次散射 GGX 白炉能量实测仅 0.335，补偿后达 0.9962（±1%）；VNDF 采样将方差由 0.747 降至 0.136。
2. 实时大气散射采用"透射率 LUT（256×128）→ 多散射 LUT 不动点迭代（32×32、2 轮）→ 天空 cubemap"三阶结构，同一实现已在三个工程各落地一次。
3. FFT 统计波谱海面：固定 1024²、6 kernel、4 层频谱（8 个 JONSWAP 涌浪源）；位移、斜率、Jacobian 均采用频域解析求导；泡沫由 Jacobian 折叠检测加跨帧衰减累积生成。
4. GPU 粒子系统：三段 compute（发射/更新/清场统计）、末位搬移式回收、原子操作需回避浮点累加（Metal 不支持）而改用定点整数。
5. 后处理链为有序语义链：Bloom 必须位于色调映射之前（能量域），锐化位于其后（感知域）；顺序错误会产生可识别的症状。

**图形数学基础**
1. 渲染方程为 Fredholm 第二类积分方程，其 Neumann 级数项对应光路弹跳次数；直接光与间接光为互补分解。
2. 无偏性与收敛性由 MSE = Var + Bias² 统一；无偏保证方向，方差决定速度；有偏但一致（M-cap、俄罗斯轮盘）是同一笔偏差与方差的交易。
3. 法线须以逆转置矩阵变换；面积缩放因子为 Jacobian 行列式；三者统一于同一 Jacobian 的不同侧面。
4. 四类静默错误（位宽截断、逻辑漏项、量纲不一致、浮点非结合性）均无报错，须以量级估算与数值验证拦截。

**引擎与管线**
1. 渲染管线分两层理解：GPU 图形管线（应用/几何/光栅化/像素四阶段，可编程点为顶点与片元着色器）与引擎渲染管线（pass 组织方式）。
2. 裁剪在齐次空间完成，视锥由 6 个线性半空间界定；过早执行透视除法将导致相机后方顶点失效。
3. early-Z 有前提（不写深度、不 discard、不改深度状态），条件被破坏则退回 late-Z；TBDR 架构下还会破坏 HSR。
4. 模块化重构应以"变化原因"为切分依据，接口契约需规定单向数据流；重构后的验收必须包含运行时抽样，静态核对存在盲区。

**DCC 与工具链**
1. Blender 的 RNA 包装对象不具身份稳定性，对象比较必须使用名称或指针，四类 `is` 比较失效案例已归档。
2. 材质槽默认为数据链接，替换网格数据将静默丢失材质；工具须显式报告空槽并给出原因。
3. 骨骼重定向的关键前提是骨骼静止朝向符合目标约定；IK 可达性（伸展比）是"动作看起来不对"最灵敏的指标。

**实现办法（四条方法论）**
1. 确定性验证优先：判据先于实现，口径须与后端浮点性质匹配，验证不得与被验证同源，视觉模型仅用于定性。
2. 把重复劳动脚本化：一次性批处理、编辑器扩展、流水线三种形态；生成器必须确定性。
3. 先量化再优化：量化现象 → 量级估算定位 → 单变量改动并用同一口径复验。
4. 程序化生成代替手工资产：几何、表面、统计、采样四个层次；代价是可控性、确定性与成本转移。
