# 引擎与管线

**管什么**：Unity（含团结 / Tuanjie）、Unreal 等引擎的渲染管线结构、资源与构建流程、性能预算与平台差异、工程模块划分。

**边界**：逐行 shader 实现 → 「渲染与着色器」；资产与脚本的生产 → 「DCC 与工具链」；与引擎无关的通用排错 → 「工程实践」。

## 子分组

（面经里的题目分类：管线类 / Shader 类 / PBR 类 / 效果类 / 特效类 / 性能类 / 工具链类 / 协作类。以下是中间层分组，每个分组节点里还有跨 hub 关联。）

### 渲染管线

- **基础渲染管线：阶段、坐标空间与现代变体**（`基础渲染管线`）——GPU 图形管线四阶段与可编程点、坐标空间链与透视校正、现代变体表（前向/延迟/Forward+/TBDR/GPU-driven/光追）、以及"一个物体没被画出来"的分阶段排查清单
- **渲染管线基础问答（正式作答稿）**（`渲染管线问答正式作答稿`）——三道题十一个子问的**标准化书面作答**（裁剪与透视除法、early-Z/late-Z、G-Buffer 与 MSAA、draw call 开销、顶点着色器能力、discard 机制、TBDR、光追前景），附术语对照表与"作答要点速记"
- **URP RenderFeature 的插入点与依赖**（`URP-RenderFeature插入点与依赖`）——renderPassEvent 语义表、`ConfigureInput(Depth)` 的隐藏耦合、全屏 Blit 的 UV/手性问题、`GetTemporary`/`ReleaseTemporary` 生命周期

### 性能优化

- **性能测量口径：怎么测、测什么、怎么复现**（`性能测量口径`）——四层测量工具与各自的坑、报告口径模板与四条硬规矩、"测量代码自己也会错"的两个真实事故、以及针对六个项目的可执行补测计划
- **LOD 与剔除：从顶点退化到视锥裁剪**（`LOD与剔除手段`）——顶点退化、`discard` 与 early-Z/TBDR 的冲突、整三角形视锥裁剪、16 位索引静默截断
- **TBDR 与移动端渲染（tile 内存 / HSR / 约束清单）**（`TBDR与移动端渲染`）——分块架构与 IMR 的对比、HSR 为什么让 early-Z 近乎免费、移动端六条约束（discard / 写深度 / 切 RT / blend / MRT / 读回）、以及"TBDR ≠ 桌面延迟渲染"这个陷阱题

### 引擎与工程协作

- **工程结构与协作：模块化重构（Director + 模块）**（`工程结构与协作`）——施工级重构文档的目录、接口契约与单向数据流、Unity 序列化迁移坑、静态验收的盲区、可分步回退的 checklist
