## 4. 关键难题 → 实现办法

1. **NaN**：光线平行于包围盒轴时 `1/0=inf`、`0×inf=NaN` → 平行轴检测 `isPar`，把 t 区间置 `±1e30` 剔除；参考版无此处理 — `Module04_RayBoxDistance/RayBoxDistance.hlsl:20-29`
2. **云无厚度感**：参考实现 `cloudDensity += stepCloudDensity` 快速饱和（`参考文件/VolumetricClouds/CloudMarching.shader:224`）→ 改为光学深度积分 `cloudOD += ρ·ds`、`density=1-exp(-OD·σ)` — `Module05_CloudDensity/CloudMarching.shader:234-236`
3. **光照量纲错误 + 曲线查表开销**：参考用 `_LightAttenuationCurve` 贴图（`参考…CloudMarching.shader:243`）→ 改为 `od=Σρ·ds` + 早退阈值 + HZD `Beer×powder` 解析式 — `CloudMarching.shader:238-261`
4. **RT 泄漏**：参考用 `tempRT0.Release()` 归还 `GetTemporary` 得到的 RT（`参考…BilateralBlur.cs:48-58`）→ 改 `RenderTexture.ReleaseTemporary` — `Module09_BilateralBlur/BilateralBlur.cs:49-58`
5. **日落后面仍亮**：CPU 太阳衰减缺地面遮蔽 → `sunDir.y<=0` 直接返回 0，与 GPU 天空一致 — `Atmosphere/Scripts/AtmosphereController.cs:386-387`
6. **云暗部与天空脱节**：云环境光用固定色 → 生成天空 cubemap（Tex2DArray 6 面 + mip），CloudRendering 采样 `_SkyCubemap`，日落自动联动 — `Module07_CloudRendering/CloudRendering.shader:97-119,154-160`

## 5. `参考文件/` 内容

GitHub 项目 **MagicStones23/Unity-Volumetric-Clouds** 的原始完整工程，分 4 组：`VolumetricClouds/`（7 个 shader + 7 个 cs + 4MB×2 三维噪声 .asset + 2D/蓝噪声 PNG + 3 个 .mat）、`Scenes/`（URP 管线资产 + SampleScene）、`Skybox/`（Skybox.shader/mat）、`Library/`（`RayBoxDistance.hlsl`、`FrameRate.cs`、`Library_ViewProjectionMatrix.cs`）。README 明确说明用于**逐模块对照**，故 `Assets/` 内容多为其拆分复刻版。
