## 1. 项目定位

**雨夜实时氛围场景的技术演示（TA 作品集性质）**，非小游戏/非工具。依据 `Docs/SceneOverview.md:9-21`（"一个雨夜实时氛围场景…画面构成五层"）；`CODELY.md:10-12` 记录的场景调参/材质坑；构建场景仅 `SampleScene`（`ProjectSettings/EditorBuildSettings.asset`），无玩法/UI/关卡。

## 2. 技术栈与规模

- 引擎：团结引擎 **Unity 2022.3.62f1c1**（`ProjectSettings/ProjectVersion.txt`）
- 管线：**URP 14.0.12**（`Packages/manifest.json`），活动资产 `URP-HighFidelity`（`ProjectSettings/GraphicsSettings.asset:44`）；HDR 开、Opaque Texture 开、**Depth Texture 关**；RendererFeature = AtmosphereSky / SSAO / AtmosphereFog（`Assets/Settings/URP-HighFidelity-Renderer.asset:13,29,64`）

## 4. 关键难题 → 实现办法

1. **横向网格线整组消失**：>65535 顶点时 16 位索引被引擎静默截断 → 显式 `IndexFormat.UInt32`。证据 `Scripts/InteractiveGridLines.cs:97-99`（场景 extent=80 ⇒ 412,804 顶点，`SampleScene.unity:1165`）
2. **倒影随视角错位旋转**：`LookRotation(镜像fwd,镜像up)` 手性翻转 → 改严格反射矩阵 `V_main×Scale(1,-1,1)` + `GL.invertCulling`。证据 `WetPlanarReflection.cs:96-116`
3. **反射 RT 被二次采样成"错位假网格 + 地平线硬分界带"** → 镜像渲染期间临时禁用贴地网格线。证据 `WetPlanarReflection.cs:25-31,108-119`
4. **雾在地面画出"钉在屏幕上的横带" + 天空像素误判**：`min(uv.y,0.58)` 夹取 + 反向 Z 写反 → 删夹取、改 `UNITY_REVERSED_Z` 分支。证据 `AtmosphereFog.shader:78-90,115-120`
5. **每像素两次全步数行星积分纯性能白花** → 移除 ray-march，改"烘焙 cubemap 承担天空美感 + 仰角驱动解析雾"，雾色逐像素采样反射 RT 保持天地缝合。证据 `AtmosphereFog.shader:95-99,126-128`
6. **LUT 只在 `Start()` 生成** → 参数 hash 脏检查 + cubemap 100 ms 节流。证据 `AtmosphereController.cs:132,229,466-504,986`
7. **雾依赖 SSAO 才拿到深度（隐藏耦合）** → 显式 `ConfigureInput(ScriptableRenderPassInput.Depth)`。证据 `AtmosphereFogRendererFeature.cs:74`
8. 其他：shader 加属性后需显式 compile 才生效；光柱 5 张贴图被脚本运行时覆盖（`CODELY.md:12,15`）

## 6. 面试可用素材（技术含量）

1. **实时大气散射 LUT 链**：透射率 256×128 → 多散射 32×32 迭代 → 天空 cubemap 128²×6 面 ray-march，含参数 hash 脏检查与节流 —— **强**（`AtmosphereLib.hlsl:87-400`、4×`.compute`、`AtmosphereController.cs:567-974`）
2. **41 万顶点程序化网格的 GPU 形变 + 双保险 LOD**：顶点退化 `positionCS=(2,2,2,1)` + 片元早退，实测砍掉窗口内约 36% —— **强**（`InteractiveGridLines.shader:155-157,312-313`）
3. **平面反射的正确性修复**：从近似到严格镜像矩阵，解决手性/剔除/二次采样三类叠加 bug —— **强**（`WetPlanarReflection.cs:96-119`）
4. **CPU 只推参数、GPU 算几何**的 6 组全局数组协议（8/40/48 槽手工对齐），40 根光柱共用单个 38,280 顶点 Mesh，世界位置由顶点着色器反算 —— **强**（`SkyPillars.shader:6,253,384-418`；`SampleScene.unity:163`）
5. **性能架构取舍与量化**：主动删掉雾 pass 的行星积分、给反射 RT 提供 512/1024/2048 与隔帧选项 —— **强**（`AtmosphereFog.shader:95-99`；`WetPlanarReflection.cs:20-23`）
