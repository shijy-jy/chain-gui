# 面试八股文题库 · 00 · 索引与外部资源

**这份文件是什么**：一套 TA（Technical Artist）面试八股文的**总入口**。包含三部分——① 本套题库怎么用；② 网上现成资源的清单（分主题、带推荐理由与避坑）；③ 本套题库的分册与本知识库节点的对应关系。

**为什么需要自己造一套**：见本文第四节。结论先说——**中文 TA 领域不存在体系化的八股文**（前端那种大而全、持续维护的文档在 TA 侧没有），GitHub 上也没有中文 TA 面试仓库。所以本套题库的定位是「**骨架自建 + 外部资源回填**」。

---

## 一、本套题库怎么用

| 分册 | 覆盖 | 对应你知识库里的 hub |
|---|---|---|
| `01-渲染管线与光栅化` | 管线阶段、坐标变换、光栅化、深度、剔除、抗锯齿、渲染路径、后处理链 | 渲染与着色器 / 引擎与管线 |
| `02-光照与PBR` | 渲染方程、BRDF、微表面、工作流、IBL、采样、色彩与输出 | 渲染与着色器 / 图形数学基础 |
| `03-图形数学与采样` | 齐次坐标、矩阵链、法线变换、四元数、蒙特卡洛、MIS、浮点、色彩数学 | 图形数学基础 |
| `04-引擎与性能优化` | URP/SRP、渲染路径、合批与变体、移动端 TBDR、性能测量、帧预算 | 引擎与管线 / 实现办法 |
| `05-TA工程实践与DCC工具链` | 岗位协作、资产规范、bpy 脚本化、导出管线、资产校验、工程化验证 | DCC 与工具链 / 实现办法 / 工程实践 |

**推荐顺序**（按你的 P2/P3 路线）：

1. **先自测，不要先背**。拿 `白板题汇总` 的 40 题限时过一遍，标记答不出的题；
2. 答不出的题 → 到本套题库找到对应分册的题目 → **先自己讲一遍再看答案**；
3. 答案里的「追问会问什么」是**第二遍**要过的内容——面试官不会只问一层；
4. 「坑」那一栏是你已经犯过或可能犯的错，**过一遍能省一场面试**；
5. 每读完一册，回到知识库对应节点补自己的项目实例——**八股给的是标准答案，你的项目经验才是差异化的部分**。

## 四、资源空白点（这些查不到现成资料，只能自己造）

这一节是本次调研**最有价值的发现**，直接决定了本套题库为什么要自建：

1. **中文 TA 领域没有体系化八股文。** 前端有成熟的大而全、持续维护的「高频八股文总结」；TA 侧只有零散单篇、个人博客大纲、面经帖。**不存在公认标准的中文 TA 八股。**
2. **GitHub 上几乎没有中文 TA 面试仓库。** 三轮调研只找到 Unity **客户端**向仓库、韩文仓库、美术向 TA 的**工程文件**。这一栏是空的。
3. **「渲染管线改造」专项题库完全空白。** 没有任何一份"自定义 SRP / URP RenderFeature / HDRP 定制 / RDG / 断批排查"的面试题库——**这是 TA 工程侧含金量最高、资料最缺的一块**。本套 04 册的第二节就是补它。
4. **TA 特有工程题（资产规范、自动化脚本、DCC↔引擎协作、性能预算制定）几乎空白。** 只找到"素材"而非"八股"。**工具链方向是整个市场供给最薄的地方**，也是你（有 Blender 工具链实战）最容易做出差异化的方向。
5. **工具链/DCC 方向**：Houdini(HDK/VEX)、Substance、PCG 只有 1 篇莉莉丝 PCG 面经。
6. **特效 / VFX 方向完全空白**：Niagara / VFX Graph、粒子预算、Shader 特效，**一条都没搜到**。
7. **动画与骨骼管线完全空白**：骨骼 LOD、蒙皮预算、动捕清理、Retarget 无现成八股。**这块你有实战（jianmo 的 IK/重定向），可以做成作品集里的强项。**
8. **TBDR 中文题库空白**：搜到的全是原理资料（Stanford / Apple / Arm），没有中文面试向整理。
9. **GAMES202（实时渲染高级）的中文笔记远少于 101**：只找到一份。而**面试里真正拉开差距的恰是 202 的内容**（阴影、PBR、实时光追、降噪）。
10. **英文 TA 侧缺一份结构化题库**：Tech-Artists.Org 是论坛问答（口语化、不成体系），Glassdoor 需登录且样本量小，**没有**类似 system-design-primer 那种英文 TA 结构化题库。
11. **未核实项（不要当作事实）**：`Shader面试题100道` 的 41-60 / 81-100 两段未检索到；RTR4 系列笔记的总篇数与完整性未确认；所有 GitHub 仓库的 star 数与最后更新时间未核实；所有 URL **均未打开页面正文**。
