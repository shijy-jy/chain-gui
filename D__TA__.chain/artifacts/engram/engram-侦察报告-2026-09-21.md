## 1. Engram 是什么

- 定义：开发者与 AI 共用的工程记忆图谱；Tauri 2 桌面应用 + MCP stdio 服务，把 `.chain/nodes/*.md` 纯文本渲染成交互式图谱，"人看图、AI 读文件"，共享同一份事实源（framework）。
- 架构：Svelte 5 →invoke→ engram-gui；外部 AI →stdio→ engram-mcp；两者都只调 `engram_core::ops` 唯一写路径（framework / arch-constitution）。
- 设计取舍：节点 md 是唯一事实源，索引/统计/审计/骨架均为可重建可删的派生物，绝不写回 YAML（arch-constitution 宪法 2）；rel 仅 contains/solves/alternative（model-profile）；模式是配置不是分支（model-profile）；检索增强失效必须降级关键词并显式声明 degraded（宪法 6）；GUI 只许加性改动（宪法 5）；架构条款变更必须走 ADR（engineering）。
- 演进：2.8.0 workspace 化 + core 下沉；2.10.0 补齐错误码 + 幂等迁移（arch-constitution）；MCP 契约 v1(9 工具)→v4(13 工具)（mcp-contract）；记忆层 L2 六件套 embed/index/stats/retrieval/consolidate/audit（memory-l2）。
- 数据格式：见第 3 节。

## 3. 技术要点清单

- **frontmatter**：id/title/body/created/updated/revision；type(5 值 goal/design/task/verification/note)；status(6 值含 none)；parent + rel + rel_desc（contains 实线/solves 虚线/alternative 点线）；tags/evidence；v2.10+ 生命周期扩展 archived+archived_reason、derived（检索 ×0.85）、frozen+freeze_reason（冲突冻结）、folded、code_map、content_hash，均 serde skip-if-false 零破坏存量（model-profile）。
- **双模式 profile**：`.chain/.mode` 标签决定；analysis=strict（严格单根树/无环/无悬空、拒 note/none、指南 v14）vs dev=友好（多根/孤立/环均可、含 note/none）（model-profile；AI_GUIDE.md）。
- **检索**：recall 阶梯 = 向量（余弦 top-k，两档阈值 0.35/0.2）→ 冷启动（创建时间+图谱度数）→ 关键词降级（degraded:true）；derived ×0.85；归档默认过滤、include_archived 找回；ACT-R `S=ln(Σ(now−t)^(−d))`，d=0.5，负值 clamp 0（memory-l2）。本库实证：audit.jsonl 1 条 recall，mode=vector、degraded=false、score 0.575→0.505、threshold 0.35。
- **骨架挂载 code_map**：tree-sitter 提取公开接口 + 签名 + 文件:行:列 + 调用边 + Mermaid 图 → 落 `.chain/code_map/<id>.md`；节点 frontmatter 只存源码路径；stale 标记兜底；v6 起允许绝对路径跨盘挂载；语言矩阵 rust/csharp/cpp(+hlsl/glsl/cuda) 与 unity 自动检测（AI_GUIDE §7）。本库 9 个节点挂了骨架，全部 `stale: false`，最大 106KB。
- **MCP 工具面（契约 v4，13 个）**：读 get_overview/search/read_node/expand/read_path/get_guide；语义 recall；写 create_node/update_node/link_nodes/archive_node/unlink_nodes/consolidate（写入全部经 write_lock 串行队列）（mcp-contract）。稳定错误码 CONFLICT: / DUPLICATE_TITLE: / SCHEMA_TOO_NEW: / MIGRATE_FAILED: / VERIFY_FAILED: / INVALID_REL: / WORKSPACE_MODE_MISMATCH: / CONSOLIDATE_EMPTY:（scanner-ops）。
- **CLI 子命令**：`migrate --workspace`（五相 detect→backup→transform→verify→write，失败回滚）、`reindex --workspace`、`sync-code-map --workspace [--lang] [--node]`、`--version`（四版本矩阵 + git 短哈希）；退出码 0 成功 / 2 dry-run 将变更 / 3 校验失败 / 4 SCHEMA_TOO_NEW / 5 非工作区 / 1 其他（gui-cli、schema-migrate）。schema 为 `.chain/.schema` major.minor，缺失=隐式 1.0，当前 1.1。
