## 3. 渲染方案

**FFT 统计波谱（Tessendorf）单线，非 Gerstner、非混合**。固定 1024²，6 kernel（`FFTOcean_Complete.compute:8-13`）；4 层频谱 Tile 0.04/0.06/0.12/0.18、贡献 0.8/0.8/0.6/0.4，每层 2 组 JONSWAP ＝ 8 涌浪源（`FFT_SpectrumVerify.cs:91-124`）；位移/斜率/Jacobian 全频域解析求导（compute:337-363）。

- 泡沫：Jacobian 折叠 ＋ `.a` 跨帧衰减累积（compute:352-363）＋ 岸边深度交叉。
- SSS：k1 波峰 / k2 视角 / k3 阴影补光 / k4 SH 四件套（`FFTOcean_Render.shader:388-405`）。
- 反射：URP `GlossyEnvironmentReflection` ＋ Schlick（shader:375-399）；**无屏幕空间折射**（折射仅在水下后处理 `UnderwaterEffect.shader:78`，Snell 48.6° 窗）。
- LOD/网格：单张 200m 平面（`waterMeshRes=10`）＋ 距离自适应曲面细分 ＋ 视锥整三角形剔除（`FFTOcean_Render.cs:37-44`、shader:90-226）。Gerstner 只在工程根 `_Backup_WaterSplit/`（不在 Assets、不参与编译）。

## 4. 难题 → 办法

**递进链 A（FFT）**：问题 → **方案 · Gerstner 波求和** → **局限 · O(N波×N顶点) 与谱采样失真** → **方案 · FFT 统计波谱法（solves）** → **局限 · FFT 边界**（不模拟破碎、200s 精确循环、平铺重复、无波物耦合、风场全局）。

**递进链 B（大气）**：问题 → **方案 · 单次散射体积积分** → **局限 · 嵌套步进 32×64≈2000 次/像素** → **方案 · 透射率 LUT（solves，256×128）** → **局限 · 缺多次散射（地平线/日落失真）** → **方案 · 多次散射 LUT 不动点迭代（solves，32×32、2 轮）** → **局限 · 各向同性源＋未计地面**（Hillaire 2020 候选未采用）。

- 循环动画 → ω 量化到 2π/200s（`RepeatTime=200`，`FFT_SpectrumVerify.cs:44`）。
- 平铺重复 → 4 层不同 Tile 错开（**缓解未根除**）。
- 白冠无形状 → Jacobian 几何近似，泡沫只衰减不漂移。
- 逐像素天空反射太贵 → 128³ Cubemap 按需更新（太阳 >0.5° 或高度 >0.2km）。
- 雾 pass 左右镜像 → 改用 core `Blit.hlsl` 的 `Vert`；`RWTexture2D` 不能 `SampleLevel` → 只读孪生纹理；**m⁻¹ ↔ km⁻¹ 漏乘无报错**（`nodes\大气模块工程踩坑.md`）。
