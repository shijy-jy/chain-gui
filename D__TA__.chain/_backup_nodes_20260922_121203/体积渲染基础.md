# 体积渲染：光线步进与光学深度

## 物理模型

介质中沿光线的辐射传输（只用吸收+发射的最简形式，够解释云和雾）：

$$L(x)=\int_{0}^{d} T(t)\,\sigma_a(t)\,L_{\text{in}}(t)\,dt,\qquad T(t)=\exp\!\left(-\int_0^t \sigma_a(s)\,ds\right)$$

- **透射率** $T$ 就是 Beer-Lambert 定律；$\tau=\int\sigma\,ds$ 叫**光学深度**（optical depth）。
- 数值实现时，把 $\tau$ 累加出来再取指数：$\rho_{\text{out}} = 1-\exp(-\tau\cdot\sigma)$。

**这一步和"把每步密度直接加到颜色上"有本质区别**：后者（$\rho \mathrel{+}= \sigma\,ds$）会**快速饱和**，云看起来是一层平板、没有体积感——这是参考实现里的真实缺陷，改成光学深度积分后边缘才出现自然的透光渐变。

## 射线与包围盒求交（slab 方法）与那个经典 NaN

对 AABB 求交得到步进区间：

$$t_1=\frac{\mathbf{b}_{\min}-\mathbf{o}}{\mathbf{d}},\quad t_2=\frac{\mathbf{b}_{\max}-\mathbf{o}}{\mathbf{d}},\quad t_{\text{enter}}=\max(\min(t_1,t_2)),\ t_{\text{exit}}=\min(\max(t_1,t_2))$$

**坑**：当光线平行于某个轴时 $\mathbf{d}$ 的分量为 0 → 除法得 $\pm\infty$ → 再做 `min/max` 乘法就出现 $0\times\infty=\text{NaN}$，整个像素变黑或变白。修法是**先判平行轴**（`isPar`），把该轴区间置成 $\pm 10^{30}$ 之类的极值直接排除。参考实现没有这个处理，等于把 NaN 留给了用户。

## 步进里的工程决策

| 决策 | 做法 | 代价 / 备注 |
|---|---|---|
| 步长 | 均匀步进 / 距离自适应 / 蓝噪声抖动 | 固定步长在斜视时出现层状带状（banding） |
| 早退 | 透射率低于阈值（如 $T<0.01$）就 break | 省一半以上步数，视觉几乎无差 |
| 光照 | 每步再向光源步进（嵌套 → 成本平方级） | 32×64 嵌套 ≈ **2000 次/像素**，这就是要上 LUT 的原因 |
| 光照近似 | Beer × powder（HZD）、Henyey-Greenstein 相函数 | 换掉逐光源步进，量级级别的省 |
| 噪声 | 蓝噪声 + 时间抖动 + TAA/双边模糊 | 抖动必须配时域滤波，否则帧间闪烁 |

**powder 效应**：$1-\exp(-2\tau)$ 让云在**背光边缘**变亮——这是云"松软"观感的关键项，纯 Beer 定律做不出来。

## 可能被追问的三层

1. **原理层**：Beer-Lambert 的适用前提（无散射/单次散射？）？为什么光学深度能累加而颜色不能？相函数 $g$ 的物理含义（前向散射 vs 各向同性）？
2. **实现层**：slab 求交的 NaN 具体在哪一步产生、为什么用 $10^{30}$ 而不是 `FLT_MAX`？抖动与 TAA 怎么配合（Halton/蓝噪声 + 重投影）？双边模糊为什么要用深度做权重？云的自阴影怎么做而不爆成本？
3. **边界层**：这套屏幕空间步进在什么情况下崩（相机进云、远景云过细、大 FOV）？体积云 vs 体积雾 vs 距离场的取舍？移动端先砍哪一步？
