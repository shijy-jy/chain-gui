# 数值精度与静默错误（从溢出到量纲）

## 为什么单独立一条：**静默错误最贵**

渲染里的 bug 分两类：**报错的**（编译失败、断言失败——便宜）和**不报错的**（画面"看着还行"但是错的——贵，因为它会被带进后续所有调参）。这一类有一个共同特征：**结果错得"合理"**。

我项目里撞到的四种，正好覆盖四类根因：

| 类型 | 真实事故 | 为什么静默 | 拦截手段 |
|---|---|---|---|
| **位宽/溢出截断** | 41 万顶点的网格横向线整组消失：索引是 **16 位**，超过 65535 被引擎静默截断（`TA_show`） | 引擎不报错，只是三角形不见 | 检查清单：**顶点数 vs 索引位宽**（超限必须显式 `IndexFormat.UInt32`） |
| **逻辑漏项导致数值暴涨** | GPU 粒子 `orbCurrentY` 涨到 **12700+**：加权平均**分子漏乘权重**（分母算了） | 数值是"大得不合理"而不是崩溃 | **量级估算**：1000 粒、$y\approx3$ 应得 ≈6147，对不上就说明机制找错了（`SDF` `t-046`） |
| **单位/量纲不一致** | 大气散射里 $\mathrm{m^{-1}}$ 与 $\mathrm{km^{-1}}$ 漏乘 | 画面只是"稍微不对"，没有报错 | 全链路单位检查；**任何常数都写单位注释**；用数值验证抓 |
| **浮点非结合性** | 路径追踪 CPU 端到端**无法位级复现**（`max_abs_diff` ≈15–17，~0.4% 像素集边缘） | 不是 bug，是浮点特性；把"统计一致"当成"通过"会掩盖真问题 | **分口径验收**：光栅要求位级一致，路径追踪只能要求统计级（`PSNR ≥ 50 dB`） |

还有两个相邻的坑：**NaN 传播**（ray-box 求交里平行轴导致 $0\times\infty$，见「体积渲染基础」）和**硬钳制抹平能量**（`packColor` 把 HDR 高光压成白斑，见「色彩与光度学基础」）。它们都不是精度问题本身，但**都属于"数值处理不当且不报错"**。

## 精度本身：什么时候会咬人

- **半精度（FP16）**：10 位尾数、5 位指数——能表示的范围够宽但**有效数字少**。典型症状：远处几何抖动/z-fighting、噪声图案在低对比处长出条带、大世界坐标下位置精度崩溃。
- **世界坐标精度**：坐标值越大，绝对精度越差（float 只有 ~7 位十进制有效数字）。解决方案是 **相对坐标/分块原点**（camera-relative rendering / floating origin）——本次对话的工作区里就有 LOD origin 相关脚本（`apply_lod_origin_v5_min.py`）。
- **深度精度**：反向 Z（`UNITY_REVERSED_Z`）显著提升远平面精度；写反了会出现"雾/深度判断在天空像素上出错"这类症状（`TA_show` 的雾 pass 就踩过）。
- **导数与 `fwidth`**：在分支/不连续函数上求导会得到错误值——这是"分析式 AA 在物体边缘失效"的常见原因。

## 拦截静默错误的三条工程习惯

1. **写下单位与量级**：常数带单位（`1e-3f // m^-1`）、参数写典型范围。**量级估算比读代码快**（12700 那个 bug 就是算出来的）。
2. **把"看不见"变成"看得见"**：工具要主动汇报异常值（例：`scene_info` 原来用 `if s.material` 过滤，把空材质槽也吃掉了，与"没有槽"无法区分——**过滤条件把异常值抹掉是失明的常见根因**）。
3. **给数值留断言与夹取**：$p$ 为 0、除零、负值开根、光照累计溢出——在 debug 构建里断言，在 release 里夹取并计数（计数不显示也要能查）。

## 可能被追问的三层

1. **原理层**：float 与 half 的位分配与各自的有效数字？为什么大坐标精度会崩（相对误差 vs 绝对误差）？反向 Z 为什么能提升精度（浮点分布 vs 双曲分布的匹配）？
2. **实现层**：什么时候必须用 `IndexFormat.UInt32`（以及它对内存/带宽的影响）？怎么写一个"位级可复现"的浮点渲染（禁用 FMA、固定求值顺序、统一精度）？`isnan` / `isfinite` 的开销？
3. **边界层**：跨平台的浮点一致性为什么几乎做不到（编译器收缩、FMA、驱动）？验收标准该怎么定才既有意义又能通过？大世界方案（floating origin）的其它代价？

## 手写/白板题（自测）

1. 写出 float16 / float32 的符号位、指数位、尾数位分配，并各举一个"够用/不够用"的渲染场景。
2. 给定"1000 个粒子、平均高度应为 3"，估算加权平均的正确量级，并说明如何用这个数判断分子漏乘权重。
3. 列出"深度测试/雾在天空像素上出错"的可能原因，并指出反向 Z 是最可能的那一个时怎么验证。
