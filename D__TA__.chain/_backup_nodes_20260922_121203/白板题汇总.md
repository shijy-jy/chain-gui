# 白板题汇总（限时自测清单）

**用法**：每题 **3 分钟、纸笔或白板、出声讲**。答不出来的立刻在对应节点下补内容，或新建节点——这就是 P4 的产出。

**评分三档**（自评，别自欺）：
- **及格**：能写出公式/代码，符号无错；
- **良好**：能说出**代价与取舍**（为什么不用另一个方案）；
- **优秀**：能说出**边界条件**（什么情况下这个方案会失效）。

## 训练协议

1. **3 分钟/题**，超时即算不会——不会的当场记下来；
2. **出声讲**（面试是口述，不是默写）；录音复听找断片处；
3. 每周把 40 题过一遍，**只练上轮答不出的**；
4. 答不出的题：先回查对应节点 → 还不够就**新建节点**（这是本库增长最快的来源）；
5. 白板题与「项目讲述稿」交叉练：**讲稿里的每个技术主张，都要能落到一道白板题上**。
