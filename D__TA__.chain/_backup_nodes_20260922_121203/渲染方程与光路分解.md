# 渲染方程与光路分解（LTE / 直接与间接）

**来源**：我在 `G:\learning` 工作区里对蒙特卡洛渲染基础的整理（含 20 张"概念辩证卡"，见「概念辩证卡学习法」）。

## 一、方程本身

$$L_o(x,\omega_o) = L_e(x,\omega_o) + \int_{H^2} f_r(x,\omega_i\to\omega_o)\, L_i(x,\omega_i)\, \cos\theta_i\, \mathrm{d}\omega_i,\qquad \cos\theta_i=\max(\langle n(x),\omega_i\rangle,0)$$

- $L_e$：自发光，**已知输入**；
- $f_r$：BRDF（朗伯面 $f_r=\rho/\pi$）；
- $L_i$：入射辐射亮度——**它本身又是别的点的 $L_o$**，这就是方程的迭代本质，也是"算不出来"的根源。

## 二、直接 vs 间接（最能体现理解的一步）

把入射项按"光从哪来"拆开 $L_i = L_i^{dir} + L_i^{ind}$：

$$T(x,\omega_o) = \underbrace{\int_{H^2} f_r\,L_e(y(x,\omega_i))\,V(x,y)\,\cos\theta_i\,\mathrm{d}\omega_i}_{\text{直接：光第一次接触表面就进相机}} + \underbrace{\int_{H^2} f_r\,L_i^{ind}\,\cos\theta_i\,\mathrm{d}\omega_i}_{\text{间接：光至少弹过一次}}$$

**两者的工程含义完全不同**（这也是我学习路线里把它们分成两个里程碑的原因）：
- **直接光**：点对点，可用 NEE 直接连线光源 → **方差相对可控**；决定画面亮度与阴影，是 ReSTIR **DI** 的攻坚对象。
- **间接光**：链式递归、路径更长 → **方差天然更高**；带来色溢与柔光，是 **GI** 的攻坚对象。
- **它们是互补分解**：多算一份就双重计数——这正是 NEE + BSDF 采样必须用 MIS 组合、而不能简单相加的原因（见「蒙特卡洛与重要性采样」）。

## 三、路径形式与四类光路

定义传输算子 $(\mathcal TL)(x,\omega_o)=\int f_r L\cos\theta\,\mathrm d\omega$，则 $L=L_e+\mathcal TL$，展开成 Neumann 级数：

$$L = L_e + \mathcal TL_e + \mathcal T^2L_e + \mathcal T^3L_e+\cdots$$

第 $k$ 项 = **恰好 $k$ 次弹跳**的光。用 Heckbert 路径记号（L=光源，E=眼睛，D=漫反射，S=镜面）：

| 记号 | 画面上的表现 | 分类 |
|---|---|---|
| $LDE$ | 普通漫反射受光 | 直接漫反射 |
| $LSE$ | 镜中灯影 | 直接镜面 |
| $L(D\mid S)D^+E$ | 色溢、柔光、镜中镜 | 间接 |

**这套记号的价值**：把"某个效果属于哪一类光路"说清楚，就知道它该用哪种采样策略——**面试里能这么回答比背公式有用得多**。

## 四、朗伯面的工作形式

$$L_o(x,\omega_o)=L_e(x,\omega_o)+\frac{\rho}{\pi}\int_{H^2}L_i(x,\omega_i)\cos\theta_i\,\mathrm{d}\omega_i$$

墙、地板这类漫反射面都用这个形式，是后续所有推导（路径追踪、ReSTIR 的 $\hat p$ 构造）的起点。

## 五、可能被追问的三层

1. **原理层**：为什么渲染方程是 Fredholm 第二类积分方程？Neumann 级数收敛的条件（$\|\mathcal T\|<1$，即反射率 < 1）？为什么"无限次弹跳"在物理上必须考虑而在实现上可以截断（俄罗斯轮盘）？
2. **实现层**：直接光为什么多用 NEE（而不是等 BSDF 采样碰巧打到光源）？间接光的路径长度怎么终止（RR 的无偏性论证）？为什么 $L_i$ 用辐射亮度（沿光线不变）而不是辐照度？
3. **边界层**：参与介质（体积）的传输方程与表面 LTE 的关系（多了 in-scattering 项）？非均匀介质/各向异性散射怎么处理？实时渲染里哪些项被近似掉了（这是"实时"与"离线"的分界）？
