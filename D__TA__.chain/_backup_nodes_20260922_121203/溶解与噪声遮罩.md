# 方案 · 溶解特效与噪声遮罩

## 本质

溶解 = 用一张**噪声/遮罩场** $n(\mathbf{p})$ 与一个随时间上升的**阈值** $t$ 比较，低于阈值的像素被裁掉：

$$n(\mathbf{p}) < t \;\Rightarrow\; \text{discard}$$

所以溶解的**全部质量**在四件事上：噪声长什么样、噪声定义在**哪个空间**、边缘怎么处理、视觉层次怎么叠。

## 关键决策：噪声定义在哪个空间

这是我在项目里做过的三选一（`SDF` 的 `t-002`），三个方案各有代价：

| 空间 | 效果 | 代价 |
|---|---|---|
| **UV 空间** | 能对齐贴图、可控 | 立方体六个面各自独立 → **跨棱处图案断裂**（用过一次就弃了） |
| **对象空间 3D**（选它） | 任意拓扑都连续、跨棱不断裂；物体移动时图案跟着走 | 图案随物体移动；**无法与贴图/美术指定位置对齐** |
| 世界空间 3D | 物体移动时图案"留在原地"（像穿过雾） | 角色移动时溶解位置漂移，不可控 |

**为什么选对象空间 3D Perlin**：溶解是"物体自身的解体"，图案跟随物体是**符合直觉的**；而跨棱断裂是硬伤（近看立刻露馅）。三维噪声还有一个隐性好处：**不需要 UV**——对程序化生成/导入资产质量不齐的工程更鲁棒。

## 边缘处理：从"锯齿"到"分析式 AA"

阈值比较出来的是**硬边**，直接 discard 会有台阶状锯齿与移动时的 shimmer（时间上的噪声闪烁）。四层体系：

1. **分析式抗锯齿**：用屏幕空间导数估计边缘宽度，$\text{edge} = \mathrm{smoothstep}(t - w, t + w, n)$，其中 $w \propto \mathrm{fwidth}(n)\times 1.5$——**fwidth 给了"噪声在屏幕上变化多快"**，于是边缘宽度自动随距离/角度适配，不用手调。
2. **八度自适应淡出**：远处把 fbm 的高频八度逐个淡出（对应 mipmap 的思路）——否则高频噪声在远处产生 moiré 与闪烁。
3. **边缘发光/色带**：把"接近阈值"的窄带映射成热色带并提亮（HDR），模拟被烧穿的高温边缘。这是**风格化**处理，不是物理解算。
4. **后处理配合**：边缘的 HDR 亮度与 Bloom 阈值互相影响——四层叠加起来峰值 ≈9.3 而 Bloom 阈值是 1.0 时，画面直接**全白过曝**；修法是分层归因（贴图定形 / 色带定色 / **HDR 只提最热处**）而不是整体压曝光。

> **面试要点**：四层体系必须**一起调**，任何一层单独拉满都会破坏观感；而且 TAA 与 MSAA 在 URP 里互斥，选抗锯齿方案时要连带考虑后处理链（`t-011` 顺手**证伪**了"后处理导致 MSAA 失效"的错误前提）。

## 性能与工程注意

- **噪声成本**：Perlin/fbm 的八度数直接决定 ALU 成本；溶解通常是全屏或大面积物体，值得按距离裁剪八度。
- **`discard` 的账**：discard 破坏 early-Z / TBDR 的 HSR（详见「LOD 与剔除手段」）。溶解类效果无法避免 discard，但**可以把边缘那圈之外的区域在顶点阶段退化**，或改用 alpha-test 更便宜的通路。
- **半精度**：移动端 half 下的噪声与阈值比较容易出现**边缘抖动**，阈值与噪声值需要做偏置处理。
- **可控性**：美术要的是"从下往上烧、边缘窄一点、颜色偏青"这类**语义参数**——把它们映射成噪声方向权重、阈值曲线、色带偏移，而不是让美术直接改噪声尺度。

## 同一套思路的其它用法

同一个"噪声阈值 + 边缘带"结构还能做：**火焰/能量体的形态**（噪声扰动 SDF 或 alpha）、**破损/锈蚀**、**材质过渡**（两张贴图按噪声混合）、**能量护盾的扫描线**。元素球那条线里我用的是另一种路线：贴图定形 / 色带定色 / HDR 提亮（`t-037`）——**同样是风格化控制，但用贴图而不是程序化噪声**，取舍点是"要可控还是要鲁棒"。

## 可能被追问的三层

1. **原理层**：Perlin 与 Simplex / Worley 的区别与适用？（Gradient noise vs cell noise）fbm 为什么用 $1/f$ 的振幅衰减？为什么 3D 噪声在对象空间连续？
2. **实现层**：`fwidth` 在什么情况下会失效（不连续的函数、被优化掉的导数、顶点插值边界）？怎么用 smoothstep 做边缘带而仍然 alpha-to-coverage？八度淡出用什么权重曲线？
3. **边界层**：溶解需要真正的几何消失（顶点消失）而不是 alpha 裁掉，怎么做？discard 之外的替代方案（写深度 + 提前剔除）？如何让溶解支持"指定方向/指定起点"（如从伤口开始）？
