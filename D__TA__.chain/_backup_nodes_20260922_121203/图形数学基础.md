# 图形数学基础

**管什么**：会被反复引用的通用理论——线性代数与变换、几何与微分、概率与蒙特卡洛积分、色彩与光度学单位。

**边界**：只服务于某一个效果的推导 → 放那个效果节点里，不要上提到这里；本 hub 的准入标准是"换个效果照样用得上"。

## 已有子节点

- **蒙特卡洛与重要性采样**（`蒙特卡洛与重要性采样`）——估计式 / 无偏性三条性质 / **MSE = Var + Bias²** 的总账 / 方差与 $1/\sqrt{N}$ / MIS 权重；含项目里的真实数值（白炉 0.335→0.9962、VNDF 方差 5.5×、pdf 选错导致更噪）
- **渲染方程与光路分解**（`渲染方程与光路分解`）——LTE 各项含义、直接/间接的互补分解、Neumann 级数与 Heckbert 光路记号、朗伯面工作形式
- **色彩与光度学：线性空间、HDR 与色调映射**（`色彩与光度学基础`）——辐照度 vs 辐射亮度、sRGB 与线性空间、tone map 与自动曝光、量纲一致性（$\mathrm{m^{-1}}$↔$\mathrm{km^{-1}}$ 静默错误）
- **数值精度与静默错误**（`数值精度与静默错误`）——位宽截断 / 逻辑漏项 / 单位不一致 / 浮点非结合性四类静默错误，以及量级估算、`fwidth`、反向 Z、半精度与大世界精度

- **变换与坐标系**（`变换与坐标系`）——空间链、法线为什么用逆转置（含推导与"可退化为 $M$"的条件）、切空间 TBN 的手性、左右手系（MMD 左手系实测）、反向 Z 与深度精度

- **Jacobian 与微分几何：折叠、面积与采样换算**（`Jacobian与微分几何`）——$\det J$ 的几何意义、位移折叠检测（泡沫）、$p_A=p_\omega\cos\theta/r^2$ 的 pdf 换算、与"法线逆转置"的统一解释（余子式矩阵）
