# 面试当天清单与复盘闭环

## 一、反问清单（问什么 = 暴露你在意什么）

**好的反问会暴露你的专业关注点**；"加班多吗""福利怎样"这类问题不专业也浪费机会。按五类准备，每次挑 2~3 个：

| 类别 | 可问的问题 | 你想获取的信息 |
|---|---|---|
| **管线与技术栈** | 现在主要用什么引擎版本与渲染管线？效果主要是美术在引擎里搭还是 TA 提供工具/模板？ | 你的技术积累能不能直接用上 |
| **岗位日常** | 这个岗位典型的一周里，做效果 / 写工具 / 支持美术大致各占多少？ | 岗位是"渲染向"还是"工具向"（决定你进去后的定位） |
| **工具与流程** | 内部有没有自研的 DCC 工具或自动化流程？资产从 DCC 到引擎有哪些校验环节？ | 有没有你擅长的"把重复劳动脚本化"的空间 |
| **成长与评估** | 团队怎么评估 TA 的产出（效果质量 / 性能 / 协作效率）？有没有技术分享或规范沉淀的机制？ | 是不是一个能积累方法论的团队 |
| **项目现状** | 项目处在什么阶段（原型 / 量产 / 优化）？当前最大的技术难点是什么？ | 你进去第一个月会面对什么 |

**加分做法**：把某个反问与自己的经历挂上——"我在工程里用图谱记录踩坑，你们有没有类似的知识沉淀方式？"

## 二、面试当天检查表

- [ ] **作品集**：可跑构建 + **视频备份**（防现场设备出问题）+ 每个项目一页图示（含前后对比）
- [ ] **讲稿**：1 分钟与 3 分钟自我介绍**出声**各念一遍；六个项目 2 分钟版**各过一遍**（见「项目讲述稿」）
- [ ] **白板题**：只扫上一轮答不出来的那几道（见「白板题汇总」）
- [ ] **边界声明**：过一遍「自研边界与证据强度」——**这是最容易临时说错的部分**（哪些是自研、哪些是复刻/参考/协作）
- [ ] **数字口径**：把要讲的数字连口径一起复习（"36% 是窗口内、同参数对比，不是全场景帧率"）
- [ ] **材料**：笔记本充电、投屏转接头、纸笔（白板题要能画）

## 三、复盘闭环（P5：本库增长最快的来源）

**时限：面试结束后 24 小时内**（再晚记忆就模糊了）。五步：

1. **凭记忆把被问到的每个问题写下来**（含**追问链**：他为什么追问、追到第几层）；
2. **逐题标记**：答得好 / 答得含糊 / 答不上来；
3. **答不上来的 → 在本库建节点**：标题就用问题本身，正文开头写 `> 触发：面试问过；<关键词>`，内容按"原理层 / 实现层 / 边界层"三段补；
4. **讲稿被追问卡住的地方** → 回「项目讲述稿」补深挖层（把衔接句与证据补上）；
5. **新题目** → 追加进「白板题汇总」。

**复盘记录模板**：

| # | 被问的问题 | 追问链 | 自评 | 处理 |
|---|---|---|---|---|
| 1 | 大气散射多散射为什么两轮就够 | → 不动点迭代收敛条件 → 各向同性假设 | 含糊 | 已在 `<节点id>` 补 |
| 2 | ReSTIR 的偏差来源 | → M-cap → 相关性 | 答不上 | 已建节点 `<问题标题>` |

**为什么这套有效**：面试问题在同类岗位之间**重复率极高**（渲染管线、数学、项目细节、协作方式就那几类）；每场只补最痛的 3~5 个，三场之后覆盖度就相当高了。

## 四、如果只剩 48 小时（冲刺版）

只做三件事，**不要新学任何东西**：
1. **讲稿脱稿**（六个项目 2 分钟版 + 自我介绍）；
2. **白板题高频 10 题**（挑最常被问的：微表面 BRDF、白炉、Beer-Lambert、法线逆转置、蒙特卡洛与 MIS、RenderFeature 顺序、16 位索引、顶点退化）；
3. **自研边界复盘**（避免把复刻/协作说成独立完成——这是最不可挽回的错误）。

## 五、证据

- 路线与阶段：`面试目标与路线`（P4 模拟追问、P5 复盘闭环）
- 讲稿：`项目讲述稿`、`口述讲稿模板`
- 题目库：`白板题汇总`（40 题 + 回查节点）
- 边界口径：`自研边界与证据强度`
