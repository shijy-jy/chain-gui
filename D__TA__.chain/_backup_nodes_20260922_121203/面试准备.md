# 面试准备

**管什么**：把图谱里的知识变成"能说出口的东西"。知识节点是原料，本 hub 是成品。

**边界**：知识本身 → 各主题 hub；项目细节 → 「项目深挖」。这里只放**面向面试的表达形式**。

## 已有子节点

- **口述讲稿模板（自我介绍 + 项目讲述）**（`口述讲稿模板`）——三线自我介绍骨架、项目五段式、TA_show 完整示例稿、追问衔接句与练习方法
- **项目讲述稿（六项目 2 分钟版 + 钩子）**（`项目讲述稿`）——六个项目的成品稿，每段含边界声明、代价句、不足句与"钩子"句
- **白板题汇总（限时自测清单）**（`白板题汇总`）——40 道手写/口述题按四个大类 + 开放题分组，每题标回查节点，含三档评分标准与训练协议
- **概念辩证卡学习法（20 张卡 + TA 扩展）**（`概念辩证卡学习法`）——我自建的概念对卡片体系（M0 ①–⑨ / M1 ⑩–⑭ / ReSTIR ⑮–⑳）+ 我补的 8 张 TA 工程侧卡片；含新卡的准入标准与训练用法
- **面试当天清单与复盘闭环**（`面试当天清单与复盘闭环`）——五类反问清单、当天检查表、24 小时复盘五步法与记录模板、只剩 48 小时的冲刺版
- **模拟追问记录（P4 练习台账）**（`模拟追问记录`）——逐次练习的逐题评估、错点清单、缺的知识点、下次要练什么；**每条的错点都必须落到节点正文**（2026-09-22 第 1 次：主题「基础渲染管线」）
- **自研边界与证据强度**（`自研边界与证据强度`）——六项目的自研/参考边界清单、证据强度三级、三条硬规则
- **面试目标与路线（综合 TA / 3–6 个月）**（`面试目标与路线`）——目标画像、P0–P5 阶段与验收标准、基础知识优先级

## 待建

- **真实面试复盘**：拿到面试后按「面试当天清单与复盘闭环」的五步法写回（P5）；练习阶段的记录继续追加到 `模拟追问记录`

## 写作约定

- 每份讲稿都要能**脱稿复述**；写长了就是没写清。
- 讲稿里每个技术主张都要能指到「项目深挖」里的证据；指不到的，要么补证据，要么删掉。
