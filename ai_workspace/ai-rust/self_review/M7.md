## 校验规则实现细节

### 字段级（validate_fields）
- id 格式：正则 `^[a-z]+-\d{3}$`（手写实现，无 regex 依赖）
- id 文件名一致：filename 去掉 .md 后与 id 比较
- type 枚举：goal / design / task / verification
- status 枚举：pending / in_progress / success / failed / blocked
- title 非空：trim 后长度 > 0
- created/updated RFC3339：手写校验（YYYY-MM-DDTHH:MM:SS+HH:MM 或 Z），含值域检查
- revision 正整数：as_u64 > 0
- tags 数组：Sequence / Null / 缺失都合法，其他类型报错
- updated >= created：手写 days_from_civil 算法转 epoch 比较

### 结构级（validate_structure）
- id 全局唯一：HashSet 检测
- parent 引用存在：ids.contains(parent_id)
- 环检测：DFS following parent links + 去重报告
- root 唯一：parent 为 null 的节点有且仅有一个
- parent 类型约束（warning）：goal 不应有 parent；非 goal 应有 parent

### walker 集成
- 从 `parse_node_file` 改为 `parse`（Mapping 级别），容错：解析失败进 errors 而非 bail
- 字段级校验在 Mapping 上做（能精确报字段错误）
- 反序列化失败的节点也跳过而非崩溃
- 结构级校验在所有节点收集后做
