# 概念辩证卡索引（20 张速查：M0 ①–⑨ · M1 ⑩–⑭ · ReSTIR ⑮–⑳）

各卡片全文在其所在节点（📌 标记处），本页只列一句话结论。

| 卡片 | 概念对 | 所在节点 | 一句话结论 |
|---|---|---|---|
| ① | 直接光照 ↔ 间接光照 | [渲染方程LTE](渲染方程LTE.md) | 互补分解；分别对应 M2/M3 的攻坚对象 |
| ② | **无偏性 ↔ 收敛性** | [无偏性与收敛性](无偏性与收敛性.md) | 无偏保方向，方差定速度；MSE=Var+Bias² 是总账 |
| ③ | 无偏性 ↔ pdf 匹配度 | [方案 · 重要性采样](重要性采样.md) | 对不对与好不好，作用在 MSE 的不同项，互不干扰 |
| ④ | 策略 A ↔ 策略 B | [直接光照的两个采样策略](直接光照的两个采样策略.md) | 正—反—合；MIS 是合题 |
| ⑤ | 约束 ↔ 自由 | [方案 · 多重重要性采样MIS](多重重要性采样MIS.md) | 无偏是底线约束，权重选择是约束内的方差优化 |
| ⑥ | 样本数 ↔ 弹射数 ↔ pdf 质量 | [方案 · 路径追踪](路径追踪组装.md) | 管噪点 / 管能量 / 管效率，三轴正交 |
| ⑦ | 离线 ↔ 实时 | [方案 · 帧间累积](离线与实时的收敛.md) | 同一估计量，单帧内求和 vs 时间轴上求和 |
| ⑧ | **方差 ↔ 偏差** | [方案 · 帧间累积](离线与实时的收敛.md) | 实时渲染的交易账本；ReSTIR 用有偏换方差（M2/M3 预告） |
| ⑨ | **光线弹射 ↔ 俄罗斯轮盘 ↔ 无偏性** | [方案 · 俄罗斯轮盘](俄罗斯轮盘.md) | 正—反—合：无限弹射不可算，硬截断有偏，RR 把偏差搬运成方差换回无偏+有限成本 |
| ⑩ | **能求值 ↔ 能采样** | [方案 · SIR重采样](方案 · SIR重采样.md) | 点查询 vs 全局操作；RIS 只借用"求值" |
| ⑪ | **CDF 反解 ↔ 打分重采样** | [直接光照的两个采样策略](直接光照的两个采样策略.md) | 三轴对齐；RIS 顶替那个反不出来的 CDF |
| ⑫ | **概率选中 ↔ 硬过滤** | [方案 · SIR重采样](方案 · SIR重采样.md) | 无偏↔有偏的分水岭；成对结构 |
| ⑬ | **均值收敛 ↔ EMA** | [离线与实时的收敛](离线与实时的收敛.md) | 时间复用是帧间累积的泛化，非 EMA |
| ⑭ | **MIS ↔ RIS（组合器 ↔ 采样器）** | [方案 · SIR重采样](方案 · SIR重采样.md) | MIS 管策略集内组合，RIS 管策略集外采样；同场景分层嵌套互嵌 |
| ⑮ | 全局采样 ↔ 点查询+抽签 | [方案 · ReSTIR时空复用](方案 · ReSTIR时空复用.md) | M1 三轴对齐的 ReSTIR 落点 |
| ⑯ | 时间复用 ↔ 空间复用 | [方案 · ReSTIR时空复用](方案 · ReSTIR时空复用.md) | 时间管攒、空间管铺，互补覆盖 |
| ⑰ | 复用收益 ↔ 错配代价 | [方案 · ReSTIR时空复用](方案 · ReSTIR时空复用.md) | 有效性门是平衡点 |
| ⑱ | **无偏 ↔ 有偏但一致** | [方案 · ReSTIR时空复用](方案 · ReSTIR时空复用.md) | M-cap 与 RR 同构（成对结构断裂） |
| ⑲ | **DI ↔ GI（同域 ↔ 异域）** | [方案 · ReSTIR时空复用](方案 · ReSTIR时空复用.md) | DI 同域重加权 Jacobian=1，GI 重连，GRIS 统一两者 |
| ⑳ | 质量 ↔ 性能 | [方案 · ReSTIR时空复用](方案 · ReSTIR时空复用.md) | 旋钮三方权衡，无全局最优 |

## 卡片之间的关系（闭环图）

```
②无偏↔收敛 ──→ ③无偏↔pdf ──→ ④A↔B(正反合) ──→ ⑤约束↔自由
     │                                        │
     └── ⑥三轴(样本/弹射/pdf) ←── ⑨RR(正反合) ←── ⑦离线↔实时

ReSTIR 篇：⑮⑪的落点 ──→ ⑯时空复用 ──→ ⑰收益↔错配 ──→ ⑱M-cap(⑫的兑现) ──→ ⑲DI↔GI ──→ ⑳旋钮
```
