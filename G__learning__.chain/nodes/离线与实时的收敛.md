# 方案 · 帧间累积（离线与实时的收敛）

## 解决了什么 / 没解决什么（递进链）

- **解决**：[局限 · 每像素样本需求大](局限 · 每像素样本需求大.md)——把样本摊到时间轴：每帧 1 SPP 跨帧平均（等权平均/EMA），静止画面渐进收敛。
- **未解决（引出下一环）**：等权平均无遗忘，相机一动历史全废；EMA 有余晖；且"帧数换样本"速率远不够 → [局限 · 相机移动破功且样本仍不足](局限 · 相机移动破功且样本仍不足.md)

同一个无偏估计量，在两种时间安排下的收敛方式。

## 等权平均（渐进累积）

$$A_n = \frac{1}{n}\sum_{i=1}^{n} X_i, \qquad A_n = \frac{(n-1)\,A_{n-1} + X_n}{n}, \qquad \operatorname{Var}[A_n] = \frac{\sigma^2}{n}$$

> 代码对照：`ptAccumulateKernel` 的 `(old*(spp-1) + cur) / spp` 就是递推式，spp = n。

**要点：与所有历史帧等权平均，不是只与上一帧平均**。等权平均没有遗忘 → 相机一动历史全部作废 → 必须清零重来（`onCameraChanged`）。

## 指数滑动平均 EMA

$$A_n = \alpha\,X_n + (1-\alpha)\,A_{n-1} = \alpha\sum_{k=0}^{\infty}(1-\alpha)^k\,X_{n-k}, \qquad \operatorname{Var} = \frac{\alpha}{2-\alpha}\,\sigma^2$$

历史权重几何衰减（第 $k$ 帧前的样本权重 $(1-\alpha)^k$），能跟上运动，但稳态方差**永远不为零**——实时画面总有"历史残影噪声"。

**等效样本数 ESS**（EMA 稳态方差换算成等价 spp）：

$$\mathrm{ESS} = \frac{\sigma^2}{\operatorname{Var}_{EMA}} = \frac{2-\alpha}{\alpha},\qquad \alpha=0.1\to19\ \text{spp},\quad \alpha=0.05\to39\ \text{spp}$$

**通用混合模型**（下面所有方法的共同骨架）：

$$S_t = \text{Lerp}(H_{t-1}, C_t, \alpha) = (1-\alpha)\,H_{t-1} + \alpha\,C_t$$

$C_t$ 当前帧噪声结果、$H_{t-1}$ 重投影后的历史、$\alpha$ 混合系数——**所有方法的区别就是如何动态或静态地算 $\alpha$**。

### 置信度混合（历史验证，硬切换 α）

先验证历史：比较当前帧与重投影历史的深度/法线/物体 ID；不可信（被遮挡、跨几何边缘）→ $\alpha=1.0$ 完全抛弃历史；可信 → 标准系数（如 $\alpha=0.1$）。消除动态鬼影的代价：边缘处历史常被抛弃 → 样本骤降 → **边缘噪点比平坦区多**。

### 方差引导混合（SVGF 核心思想）

按当前帧局部邻域亮度方差动态取 $\alpha$：方差小（平坦区）→ 极小 $\alpha$（如 0.02）大量拉历史，丝绸般平滑；方差大（高频/边缘）→ 大 $\alpha$ 保留细节。与蓝噪声 + ReSTIR 配合效果极佳。

### 帧间累积方法对比

| 方法 | $\alpha$ 取值 | 核心特征 | 适用场景 |
|---|---|---|---|
| 帧平均 | $\alpha=1/t$ | 完美收敛、无响应能力 | 离线渐进出图 |
| 标准 EMA | $\alpha$ 固定（如 0.1） | 响应与稳定的折中 | 基础 TAA、简单实时降噪 |
| 置信度混合 | $\alpha\in\{0.1,\ 1.0\}$ | 验证历史、边缘防鬼影 | 现代 TAA、ReSTIR 时间复用门限 |
| 方差引导 | $\alpha$ 随局部方差变 | 平坦区极平滑、边缘保细节 | SVGF、DLSS-RR 基础思想 |

## 与蓄水池的配合关系（值层 ↔ 样本层，2026-09-02 归档）

两者同宗：都是**用时间换样本**（辩证卡⑦ 的实时答案），但作用于**两个不同的层次**：

| | 帧间累积（值层） | 蓄水池时间复用（样本层） |
|---|---|---|
| 混合对象 | 着色后的**像素值**（历史被压成"一个数"） | **样本本身** $\{y, W, M\}$（证据统计） |
| 历史能否重做 | ❌ 历史的数是死的 | ✅ 可在当前像素**重新评估**（target-ratio / 重连 / 补可见性） |
| 遗忘旋钮 | $\alpha$（历史值遗忘）→ 稳态方差 | M-cap（历史样本遗忘）→ 有偏但一致 |
| 历史验证 | 置信度混合的深度/法线门 | 时间复用的重投影 + 深度/法线有效性门 |

**泛化关系**（Bitterli 2020 的精神）：时间复用是帧间累积的**泛化**——累积只能"把历史的答案混进来"，复用能"把历史的问题重做一遍"。三组同构旋钮：α ↔ M-cap（都防历史无限累积）；深度/法线验证 ↔ 有效性门（同一个"历史可信吗"，值层与样本层的镜像）；方差引导的 α ↔ 蓄水池按权重概率选中（都按"证据质量"倾斜）。

**实际管线中的串联**：ReSTIR 四步产出 1 SPP 着色结果 → 仍带噪 → 送 EMA/置信度混合/SVGF 做输出平滑。**蓄水池管"采样质量"，累积管"输出平滑"，两层各司其职**（原项目模式 4 即 ReSTIR 着色 → temporal reproject α=0.1 → SVGF a-trous 的真实串联）。

> **📌 概念辩证卡⑬：均值收敛 ↔ EMA（RIS 的收敛轴）**
> - **均值收敛**：N 个独立 RIS 估计等权平均，方差 $1/N$，无遗忘（相机移动清零重来）。RIS 的收敛就是它。
> - **EMA**：指数滑动平均，历史权重几何衰减 $(1-\alpha)^k$，稳态方差 $\frac{\alpha}{2-\alpha}\sigma^2$ 永不为零；优点能跟运动。
> - **辩证关系**：ReSTIR 的跨帧机制是**时间复用（reservoir 合并）**——论文定位为"temporal accumulation 的泛化"：继承"跨帧累积样本"的职能，载体是合并而非指数平均。**时间复用 ≠ EMA**；它是把均值收敛"赊样本"的思路升级成"借样本本身"。
> - **学习者的判定**：⚠️ "EMA 收敛"——实为均值收敛（见 [学习轨迹与判定卡](学习轨迹与判定卡.md) RIS 第一轮判定）。

## 离线和实时的完整对照

| | 离线渲染 | 实时渲染 |
|---|---|---|
| 样本来源 | 每像素 N 个样本，一次成图 | 每帧每像素 1 SPP |
| 收敛方式 | $A_N$ 跑到方差目标/时间预算 | 跨帧等权平均或 EMA |
| 相机移动 | 无此问题 | 等权平均必须清零重来；EMA 可跟随但有余晖 |
| 上限 | 预算（时间/内存） | 硬预算：16.7ms/帧（60fps） |

> **📌 概念辩证卡⑦：离线 ↔ 实时（同一个无偏估计，两条时间轴）**
> - **离线**：把 $N$ 个样本堆在**一帧内**——"空间换时间"：内存/算力买收敛，无所谓耗时。
> - **实时**：把 $N$ 个样本摊在**连续帧上**——"时间换空间"：每一帧预算极紧（16.7ms），用"帧间积累"赊样本。
> - **辩证关系**：两者的**估计量完全相同**（同一个 $F_N$），只是"求和发生在哪"不同——离线在单帧内求和，实时在时间轴上求和。这决定了实时的三条命门：相机移动必须重置（等权平均无遗忘）、历史误差会残留（EMA）、以及——**用空间复用（M2）与时间复用（M2/M3）把"赊来的样本"再借给邻居像素**，这正是 ReSTIR 的入口。

> **📌 概念辩证卡⑧：方差 ↔ 偏差（总账本，通往 ReSTIR 的门）**
> - **方差**：样本随机性带来的抖动，$\propto 1/N$，可被"更多样本/更好的 pdf/跨像素复用"压制。
> - **偏差**：系统性误差（截断、近似），与 $N$ 无关，只能靠"更准的模型/更大的 $d$"消除。
> - **辩证关系（MSE 分解的总账）**：$\mathrm{MSE} = \operatorname{Var} + \mathrm{Bias}^2$。实时渲染的困境：样本不够 → 方差爆表；**ReSTIR 的选择（M2/M3 预告）**：用**有偏**（M 钳制、近似复用）去换**方差**——MSE 总账上这是一笔"主动引入小偏差、大幅砍掉方差"的交易。**先把无偏/方差/偏差三条轴焊死，M1 的 reservoir、M2 的 M-cap 才看得懂它们在交易什么。**
