# 符号表与公式速查卡

## 符号表

| 符号 | 含义 | 符号 | 含义 |
|---|---|---|---|
| $L_o(x,\omega_o)$ | 出射辐射率 | $p(\cdot)$ | 概率密度函数 pdf |
| $L_i(x,\omega_i)$ | 入射辐射率 | $N$ | 样本数 |
| $L_e$ | 自发光辐射率 | $c_i$ | 策略 i 的样本分配比例 |
| $f_r$ | BRDF | $w_i$ | MIS 权重函数 |
| $\rho$ | 朗伯 albedo | $\beta$ | 路径吞吐 |
| $\theta,\ \theta'$ | 表面/光源入射角 | $V$ | 可见性 0/1 |
| $A$ | 光源面积 | $r$ | 着色点到光源距离 |
| $\mathrm{d}\omega$ | 立体角元 | $N_L$ | 光源数量 |
| $I$ | 目标积分真值 | $q$ | 俄罗斯轮盘存活率 |
| $\operatorname{Var}$ | 方差 | $\mathrm{MSE}$ | 均方误差 = 方差 + 偏差² |
| $\mathbb{E}$ | 期望 | $\hat p$ | MIS 混合分布 $\sum c_i p_i$ |

## 10 条关键公式（验收默写清单）

1. LTE：$L_o = L_e + \displaystyle\int_{H^2} f_r\,L_i\cos\theta_i\,\mathrm{d}\omega_i$
2. MC 无偏：$\mathbb{E}\left[\dfrac{f(X)}{p(X)}\right] = \displaystyle\int_\Omega f = I$
3. MC 方差：$\operatorname{Var}[F_N] = \dfrac{1}{N}\left(\displaystyle\int\dfrac{f^2}{p} - I^2\right)$
4. **MSE 分解：$\mathrm{MSE} = \operatorname{Var} + \mathrm{Bias}^2$**（辩证卡②⑧的总账）
5. 最优 pdf：$p \propto |f|$（C-S 取等）
6. 余弦采样：$p_A = \cos\theta/\pi$（Malley 投影）
7. 光源采样：$p_B = \dfrac{r^2}{A\cos\theta'}\cdot\dfrac{1}{N_L}$
8. MIS 无偏条件：$\sum_i w_i = 1$；balance：$w_i = \dfrac{c_i p_i}{\hat p}$；power：$w_i \propto (c_i p_i)^\beta$
9. 等权平均：$A_n = \dfrac{(n-1)A_{n-1} + X_n}{n}$，$\operatorname{Var} = \sigma^2/n$
10. 俄罗斯轮盘：$\mathbb{E}[F^{RR}] = q\cdot\dfrac{F}{q} + (1-q)\cdot 0 = F$；期望弹射数 $\mathbb{E}[L] = \dfrac{1}{1-q}$
