# 方案 · 路径追踪

## 解决了什么 / 没解决什么（递进链）

- **解决**：[问题：如何求解完整渲染方程](问题：如何求解完整渲染方程.md)——递归展开 LTE（Neumann 级数），NEE+BSDF 采样+MIS 逐跳估计，无偏地包含全部弹跳阶。
- **未解决（引出下一环，两条）**：
  1. 级数无穷项无法有限算完 → [局限 · 无限弹跳不可计算](局限 · 无限弹跳不可计算.md)
  2. 每像素样本需求大，实时预算不够 → [局限 · 每像素样本需求大](局限 · 每像素样本需求大.md)

把 NEE、BSDF 采样、MIS 组装成递归求解 LTE 的完整循环。

## 吞吐 β 与路径贡献

一条路径 $x_0\to x_1\to\cdots\to x_k$（$x_k$ 是光源）的贡献：

$$L_{path} = L_e(x_k)\cdot\prod_{j=1}^{k}\frac{f_r(x_j)\,\cos\theta_j}{p_j} = L_e(x_k)\cdot\beta_k, \qquad \beta_k := \prod_{j=1}^{k}\frac{f_r(x_j)\,\cos\theta_j}{p_j}$$

$\beta$ 就是代码里的 `beta`：每跳乘一次"BRDF·cosθ 除以采样 pdf"，朗伯+余弦采样时恰好化简为 $\rho$（$f_r\cos\theta/p = (\rho/\pi)\cos\theta/(\cos\theta/\pi) = \rho$）。

## 四类路径在代码里的对应

| 路径类 | 代码机制 |
|---|---|
| 直接漫反射 $LDE$ | 主命中点 NEE（策略 B 贡献公式） |
| 直接镜面反射 $LSE$ | 金属/玻璃确定性反射/折射方向命中发光面（撞灯分支，weight=1） |
| 间接漫反射 | 余弦采样延路径 → 下一跳 NEE |
| 间接镜面反射 | 漫反射→镜面→…→灯，同样由递归撞灯分支给出 |

**关键修正：镜面顶点没有 NEE**——代码里 `isMetal`/`isGlass` 分支直接跳过 NEE，它们的"直接光"来自确定性方向撞灯。

## 完整循环 = 递归展开 LTE

```
发射面命中  →  L += weight · β · Le          （Le 项，weight 是撞灯 MIS）
漫反射顶点  →  NEE（策略 B 贡献）+ 余弦采样延路径（递归项）
镜面顶点    →  确定性反射/折射（无 NEE），β 乘菲涅尔
```

> **📌 概念辩证卡⑥：样本数 ↔ 弹射数 ↔ pdf 质量（三轴）**
> - **样本数 $N$**（管**噪点**）：$\operatorname{Var}\propto 1/N$——光线少 → 噪点大且散。
> - **弹射数 $d$**（管**能量**）：maxDepth 截断丢第 $k+1$ 阶光 → **偏差**，画面偏暗、缺色溢——与噪点无关。
> - **pdf 质量**（管**效率**）：同噪点水平省多少样本：$N_p = N_u\cdot\dfrac{\operatorname{Var}_p}{\operatorname{Var}_{uniform}}$——匹配 pdf 只省**光线**，不省**弹射**。
> - **辩证关系**：三者作用在 MSE 分解的不同项（弹射→偏差项，样本与 pdf→方差项），**正交、各管一件事**。口诀：**样本数管噪点，弹射数管能量，pdf 质量管效率。**
> - **深度与噪声的间接联系（诚实补充）**：有 RR 时路径长度随机化，把截断偏差转化为一小部分额外方差——但主导项仍然分离。RR 的完整辩证分析见[俄罗斯轮盘](俄罗斯轮盘.md)。
