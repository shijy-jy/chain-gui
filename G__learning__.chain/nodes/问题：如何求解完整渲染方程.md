# 问题：如何求解完整渲染方程

## 问题的来源（为什么会出现这个问题）

本问题**由 [渲染方程LTE](渲染方程LTE.md) 的迭代本质引出**：$L_i$ 本身又等于别的点的 $L_o$，方程的解展开成 Neumann 级数 $L = L_e + \mathcal{T}L_e + \mathcal{T}^2L_e + \cdots$——**无穷多项，每项对应一次额外的弹跳**。想要"完整"的解，就必须同时回答"无穷级数如何有限计算"与"每像素多少样本才够"两个子问题。出现场景：从直接光照迈向全局光照的那一刻。

## 问题的表述

渲染方程包含**无限阶的间接光**（Neumann 级数无穷多项）：

$$L_o = L_e + \mathcal{T}L_e + \mathcal{T}^2 L_e + \mathcal{T}^3 L_e + \cdots$$

每一项对应一次额外的弹跳。要求"完整"的解，就必须同时回答两个子问题：

1. **深度问题**：无穷级数如何有限计算？（引出：无限弹跳不可计算 → 俄罗斯轮盘）
2. **精度问题**：每像素多少样本才够收敛？实时渲染的帧预算只有 16.7ms（引出：每像素样本需求大 → 帧间累积 → ReSTIR）

## 为什么必须解决

直接光照只是方程的第一阶；色溢、柔光、反射质感全靠高阶项。只算直接光的画面又黑又硬。
