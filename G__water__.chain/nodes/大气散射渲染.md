# 大气散射渲染

基于物理的大气散射渲染主题中心（hub）。汇总从 `D:\unity\unityProjectLocation\water` 工程（`Assets/Atmosphere/`）研读得到的全部知识点。代码注释引用设计文档 **AKG4e3《实时大气散射渲染实战》v2.0**（工程外文档，本库不收录内容）。

## 工程实现组成

| 层 | 文件 | 职责 |
|---|---|---|
| 数学核心 | `Shaders/AtmosphereLib.hlsl` | 散射/透射/相位函数/单次散射积分（计算与渲染共用） |
| 透射率 LUT | `Shaders/TransmittanceLUT.compute` | 256×128 透射率预计算（Bruneton 2008） |
| 多散射 LUT | `Shaders/MultiScatterLUTGen.compute` | 32×32 多次散射不动点迭代（Bruneton 2017 各向同性简化） |
| 天空 Cubemap | `Shaders/SkyCubemapGen.compute` | 水面反射用天空环境图（按需更新） |
| 天空盒 | `Shaders/AtmosphereSkybox.shader` | 全屏三角形 + 单次散射 + 太阳盘 |
| 雾效 | `Shaders/AtmosphereFog.shader` | 全屏后处理：透射率衰减 + 散射光 |
| 海洋桥 | `Shaders/OceanAtmosphereBridge.hlsl` | 海洋渲染接入大气的 4 个函数（可宏降级） |
| 控制 | `Scripts/AtmosphereController.cs` | 参数同步、LUT/Cubemap 生成、太阳光衰减 |
| 参数 | `Scripts/AtmosphereConfig.cs` | ScriptableObject 参数真相源（系数 m⁻¹、长度 km） |
| 管线 | `Scripts/AtmosphereSkyRendererFeature.cs`、`AtmosphereFogRendererFeature.cs` | URP 天空/雾渲染特性 |

## 子节点（递进链）

- 问题：实时渲染物理大气散射
- 方案 · 单次散射体积积分 → 局限 · 嵌套光线步进的性能瓶颈
- 方案 · 透射率 LUT 预计算（solves）→ 局限 · 单次散射缺失多次散射能量
- 方案 · 多次散射 LUT 不动点迭代（solves）→ 局限 · 各向同性近似与未计地面
- 配套：天空渲染与太阳盘 / 天空 Cubemap 按需生成 / 大气雾与海洋-大气桥 / 大气模块工程踩坑
- 细节：瑞利散射与米氏散射 / 透射率 LUT 的参数化映射

## 主要参考书目

- Bruneton, E. & Neyret, F. *Precomputed Atmospheric Scattering*. EGSR 2008.（透射率 LUT）
- Bruneton, E. *Precomputed Atmospheric Scattering: improved implementation*, 2017.（多次散射不动点迭代）
- Hillaire, S. *A Scalable and Production Ready Sky and Atmosphere Rendering Technique for Video Games*. EGSR 2020.（多次散射 LUT 的工业级形态，本工程候选出路）
