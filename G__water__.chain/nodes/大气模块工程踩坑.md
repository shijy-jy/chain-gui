# 大气模块工程踩坑

从工程代码注释与结构反推的真实踩坑记录（雾效 Shader 头注释明确记录了修复根因）。

## 1. Blit 镜像 bug（雾效 pass 左右颠倒）

- **现象**：手动全屏三角形顶点 + 未用核心包 `Blit.hlsl` 的 `Vert` → fog pass 以**镜像方式**重写相机颜色，场景与天空左右不一致；RendererFeature 开=错、关=对。
- **根因**：相机目标 ↔ 临时 RT 之间的翻转校正缺失——`Blit.hlsl` 的 `Vert` 内会应用 `_BlitScaleBias`。
- **修复**：改用 `Packages/com.unity.render-pipelines.core/Runtime/Utilities/Blit.hlsl` 提供的 `Vert/Varyings`（工程注释原文保留此记录）。

## 2. RWTexture2D 不能采样（多散射迭代）

`RWTexture2D` 不支持 `SampleLevel`，而多散射迭代 kernel 要读上一轮 LUT。解法：**只读孪生声明** `Texture2D<float4> _MultiScatterLUTPrevRead` + `SamplerState`，C# 端把同一 RT 同时绑到可写与只读两个槽。

## 3. 单位换算：m⁻¹ ↔ km⁻¹

配置是 m⁻¹、长度 km；Shader 内系数 **×1000** 成 km⁻¹，世界坐标经 `WorldToAtmosphere` 米→千米。任何一处漏乘/漏除都是"天空颜色完全不对"级别的错误，且无编译报错。

## 4. LUT 必须设全局纹理

LUT 经 `Shader.SetGlobalTexture` 设置后，天空盒/雾/Cubemap/海洋桥的全局变量 `_Atm_TransmittanceLUT` 才可见；只设到材质上会静默失效。

## 5. Cubemap 不要每帧生成

128³×6 + 16 步散射的生成开销不低，太阳每帧微动就重算是浪费 → 角度/高度阈值按需更新（见 天空 Cubemap 按需生成）。

## 6. 资产材质不要 DestroyImmediate

`ReleaseMaterials` 只清静态引用不销毁材质——材质可能是磁盘 `.mat` 资产（`AtmosphereSkybox.mat`/`AtmosphereFog.mat`），销毁会毁掉资产本身；光源颜色被调制过也要还原（`_originalColorCaptured` 记录原色）。
