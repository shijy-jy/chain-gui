# 大气雾与海洋-大气桥

天空之外，大气系统还通过**雾效后处理**、**海洋桥**、**太阳光衰减**三条线影响场景。

## 1. 大气雾（`AtmosphereFog.shader` + RendererFeature）

全屏后处理（`AfterRenderingOpaques`），每个不透明像素：

1. 采样场景深度 → 天空像素（depth≥1）**跳过**（天空盒自己算了散射）；
2. 深度 + `UNITY_MATRIX_I_VP` 重建世界位置，算相机到片元距离 $d$；
3. 最终色 = $\text{scene}\times T_{cam}(d) + L_{inscatter}(d)$：
   - $T_{cam}(d)$：`TransmittanceToDistance`（部分路径透射率近似）；
   - $L_{inscatter}(d)$：`SingleScatteringToPoint`（积分只到片元距离）；
4. Blitter 双 blit（相机色 → temp → 相机色）。

→ 物体随距离**变淡并染上天空色**，与天空盒同一物理模型，海面远景自然融入大气。

## 2. 海洋-大气桥（`OceanAtmosphereBridge.hlsl`）

给海洋 Shader 用的 4 个函数（设计原则"**只增不改**"+ `OCEAN_ATMOSPHERE_DISABLED` 宏完全降级为旧行为）：

| 函数 | 作用 |
|---|---|
| `OceanAtmTransmittance(pos, sunDir)` | 海面点 → 太阳的大气透射率（调制阳光） |
| `OceanAtmFog(cam, pos)` | 海面雾效散射光 |
| `OceanAtmSkyReflection(reflectDir)` | 反射方向的天空散射色（镜面反射） |
| `OceanAtmSunSpecular(pos, sunDir)` | 太阳高光的大气衰减 |

## 3. 太阳光衰减（CPU 侧）

`ComputeSunTransmittanceCPU`：在海平面沿太阳方向 ray march 64 步（与 Shader 公式**逐字一致**），得 RGB 透射率：

- 设置全局 `_Atm_SunTransmittance`（自定义 Shader 可用）；
- **直接调制 Directional Light 颜色**（记录原色、销毁时还原）→ URP 标准材质也自动获得大气衰减（日落时场景光照变红变暗）。
