# 资产链实现（obj_loader / cornell_materials / model_library）

## obj_loader.cpp（rapidobj 包装）

**装载流程**（loadObjScene）：
1. 路径 `u8path` 转宽路径打开（中文文件名/GBK 环境坑 t-003）；**MTL 搜索路径必须转绝对父目录**——rapidobj `FindBestPath` 对相对路径做 basepath/path 拼接会拼双份（t-002 实测）
2. `ParseFile(SearchPath(父目录, Load::Optional))` → `Triangulate`（多边形三角化）
3. 材质转换 `convertMaterial`：
   - `Kd → baseColor`；`newmtl` 名透传（UTF-8 可中文；无名 → "材质N"）
   - **Pr/Pm 显式时优先**（PBR 粗糙/金属度，t-026 基准场景用）；否则 `Ns → roughness = √(2/(s+2))^{1/2} = (2/(s+2))^{1/4}`（Beckmann→GGX 等价，t-009 替换拍脑袋映射）
   - `Ke → emission + isEmissive`（任一分量 >0）
4. **每文件兜底材质**（fileMatCount==0 时补"默认灰 <文件名>"）——多文件装载的不变量：每文件 ≥1 材质、局部索引合法（t-007 D3）
5. 面材质索引：rapidobj 对无 usemtl 面给 −1，负值/超范围**钳到本文件兜底**（杜绝 0xFFFFFFFF 越界）
6. 顶点去重：`makeKey(p,n,u) = p<<42 | n<<21 | u`（21 bit 各字段，0x1FFFFF = 无该属性哨兵）hash 到 vertexMap
7. 负索引 `resolveIndex`：OBJ 相对索引（−1=最后一个）解析，越界一律钳 0（"宁可少画错画"）
8. `computeVertexNormalsIfMissing`：无顶点法线时面积加权面法线累积归一，零长兜底 (0,1,0)

## cornell_materials.cpp（内置场景规则）

- 材质工厂：makeDiffuse（roughness 0.9）/ makeLight（emission=color×intensity）/ **makeMetal = 铁导体**（η=2.91, k=3.09 三通道等值 + roughness 0.9，t-028 观感定案）/ makeGlass（ior 1.5, roughness 0）
- `assignCornellBoxMaterials`：墙体按**面法线分类**（classifyWall：|n.y|>0.7 地板/天花板、|n.z|>0.7 后墙、n.x 符号左右墙）+ 网格名匹配（cornell/wall/box→墙体、metal/glass→球）；材质 5+2 追加 + 中文名
- `addCornellCeilingLight`：y=7.99 处 1.5×1.5 quad，法线 (0,−1,0)，emission 15（"顶灯"）
- `buildEmissiveLights`：逐三角形收集 isEmissive → emissiveTriangles/emissiveMeshIndices（NEE 光源表，与各后端 emissiveTriIndex 顺序一致——PT CPU 有 mismatch 校验警告）

## model_library.cpp（装配）

- `scanModelFolder("models")`：内置 Cornell 恒第一；顶层 `*.obj`；跳过 `cornell_*`；**宽文件名 → UTF-8**（WideCharToMultiByte）；按名排序
- `buildModelScene`：loadObjScenes（内置 3 文件合并）→ 内置条目 assignCornellBoxMaterials → **无 isEmissive 材质时补顶灯**（用户模型 PT 非黑屏保证；t-026 起自带 Ke 的基准场景跳过补灯，全权控制照明）→ buildEmissiveLights

## 三条材质数据源（d-003 定案）

OBJ/MTL → 内置 Cornell 规则 → 兜底灰；热更新不经过本链（Application::applyMaterialEdit 直接改 Scene 权威副本 + updateMaterial 分发）
