## 二、跨模块不变量（改代码前必读）

1. **像素打包**：全工程统一 `(0xFF<<24)|(r<<16)|(g<<8)|b`，内存序 = BGRA little-endian，配 `GL_BGRA`（display.cu 注释自证）；RasterCPU 背景 `0xFF333333`，RasterGPU 初始灰 0.2
2. **确定性**：PT CPU 每像素每 pass `PCG32::setState(x+y*W+0x12345678, pass+1)`；PT GPU 蓝噪声 `sampleBlueNoise(x, y, frameIndex)` + 各复用核独立 PCG32 种子（不同盐值：0xB17E5EED/0xC0FFEE/…）
3. **渲染分辨率固定 1280×720**（无 resize，跨机器基线可比的前提）
4. **显示链分后端**：mode 3 = 0.40 曝光 + 软拐点 `v(1+v⁴)^(-1/4)` + sRGB（t-029）；mode 4 = 0.60 曝光 + clamp + γ2.2（packColorToRGBA8Kernel）；光栅 = linearToSRGB 直接（无曝光）
5. **etaScale 语义**（t-009 修正）：透射穿越界面累计 `Π(η_t/η_i)²` 并**乘入最终 L**；旧版只用于俄罗斯轮盘是 bug
6. **NaN 防线**：半向量退化 `|wi+wo|²<1e-12` 判失败；traceRay 路径中与出口双重 isfinite 兜底；BVH 非有限 diag 跳轴
7. **设备头约定**：float3 无内建运算符 → device_math.cuh / bsdf_device.h 全逐分量；设备缓冲一律 void*（float3 是 CUDA 类型不进宿主头，t-012 约定）
8. **无头诊断必须落盘**：GUI 子系统 printf 不可见（ptcpu_stats.log / visioncli_latest.txt 惯例）
9. **SHADOW_EPS = 1e-4**：交点沿法线（或透射方向）偏移后发阴影/次级射线

## 三、模式四一帧旅程（与 d-015 §五 对应到内核名）

```
ptGpuKernel (G-buffer: 2-sample AA 主命中, matFlags 0/1/2/3/4)
→ restirGiCandidateKernel (4 样本池 + RR 0.5 到 x2) → restirGiTemporalReuseKernel
→ restirGiSpatialReuseKernel → restirCandidateKernel (DI 1 样本) → restirTemporalReuseKernel
→ restirSpatialReuseKernel → restirGiShadeKernel (WRITE 间接) → restirShadeKernel (ADD 直接)
→ [accumMode? ptAccumulateKernel + pack 早退]
→ [enable_restir_] restir_simplified 时/空 → [enable_temporal_] temporalReprojectKernel
→ [enable_spatial_] buildVarianceKernel + atrousKernel ×N → [enable_optix_] OptiX 半分辨链
→ packColorToRGBA8Kernel → Display::uploadFromGPU → 历史乒乓交换 ×6 组
```

## 四、代码内已标注的已知偏差（真实注释，非猜测）

- ReSTIR 合并无 Talbot MIS 权重（wSum/M 是可见条件均值的有偏估计，注释自测 +20% 偏差）；历史权重不按当前目标重评估；diGReject 巨权拒绝是启发式（d-010/d-011）
- 空间复用不重追可见性（成本换软阴影泄漏，注释自述）；DI shade 同样跳过可见性（~0.9ms/帧）
- GI 漫反射 x1 落在灯上被丢弃（DI 的职责）；发射面主命中直接 Le
- 时域 moment 用同 α 累积（TheVaffel 用 moment_a，文档化简化）
