# BSDF 实现（src/shading/bsdf.cpp；bsdf_device.h 逐式镜像）

> 数学推导见 d-006/d-018；本节点记录**代码级**细节——权重怎么换算、分支概率怎么选。

## 公共工具

- `halfVector(wi,wo)`：`|wi+wo|² < 1e-12` 判退化（灯光与视线几乎反向时 0/0=NaN 防线）
- `Basis`：以法线为 y 的局部正交基；`|n.z| ≥ 0.999` 时 s=(1,0,0) 特例（叉积退化保护）
- `cosineSampleHemisphere`：`φ=2πu1, r=√u2`，y=√(1−u2)
- `schlickF0(m)` = `mix(0.04, baseColor, metallic)`；`diffuseSplitProb` = `clamp(kcFavg(lum(f0)), 0.02, 0.98)`

## evalPbr（NEE 求值，返回 {f, pdf}）

| 材质 | f | pdf |
|---|---|---|
| 金属 | `F(复菲涅尔)·CT反射 + KC补偿(逐通道)` | `vndfReflectionPdf` |
| 玻璃 | `F(介质)·CT反射 + KC补偿`；F 用 `dielectricFresnelFull(hdotwo, ηI, ηO)`（η 按 wo 所在介质定） | `F·vndfReflectionPdf`（策略=以概率 F 反射） |
| 漫反射 | `(1−F)·ρ/π + F·CT + KC补偿` | `(1−ps)·(ndoti/π) + ps·vndfReflectionPdf`（与采样概率一致，t-011） |

- 玻璃 NEE 只做反射瓣（透射不采样，BSDF 采样已无偏覆盖——d-006 §8）

## samplePbr（BSDF 采样，返回 {wi, weight, pdf, transmitted, etaScale}）

**金属**：VNDF 采样 h → `reflectHalfLocal` → `wiL.y≤0` 即弃（射入表面下方）→
`weight = F·G2/G1(ωo) + kcComp·kc`，其中 `kc = ndoti·4·ndoto/(G1o·D)`（补偿项 f_ms·μi/p 随主瓣 pdf 计入，Frostbite 式）

**玻璃**：
- 内部视线（ndotwo<0）**翻基**到视线侧（nEff=−n），VNDF/权重公式在翻转基下不变
- `u3 < F` 走反射（F≥1 即 TIR 必反射）：`weight = G2/G1o + kcComp·kc`（补偿项经 F 归一：`kc = wiL.y·4·ndoto/(F·G1o·D)`）
- 否则透射：`refractHalfLocal`（失败防御丢弃）→ `weight = G2/G1o`（η 与 F 与选择概率全部精确对消）→ `pdf = (1−F)·vndfTransmissionPdf` → `transmitted=true, etaScale=(ηo/ηI)²`
- 透射侧 `absIdoth = −dot(wiL,hL)` 取绝对值、`ndoti = −wiL.y`（i 在另一侧）

**漫反射（能量比例分裂，t-011）**：
- `u3 < ps` 余弦分支：`weight = (1−F(ndoto))·ρ/(1−ps)`，`pdf = (1−ps)·(ndoti/π)`（漫反射被出射角菲涅尔调制）
- 否则 GGX 分支：`weight = (F·G2/G1o + kcComp·kc)/ps`，`pdf = ps·vndfReflectionPdf`
- ps = F_avg(F0) 能量代理：F0=0.04 墙面镜面瓣样本 50%→~8.6%，有效漫反射样本翻倍

## 镜像纪律

- bsdf_device.h 与 bsdf.cpp **逐式同源**（同公式、同分支、同 clamp），防 CPU/GPU 公式漂移（t-009）
- 设备端全逐分量运算（float3 无运算符的 nvcc 环境坑）；`MF_HD` 宏让 microfacet.h 一份源码 MSVC/nvcc 双编译
- NPR 槽位：evalBsdf/sampleBsdf switch 到 NPR 时回退 PBR + 一次性日志（plumbing 已通，UI 未暴露）

## 数值防线清单（代码内）

半向量退化 / Basis 叉积特例 / wiL.y≤0 弃采样 / refractHalfLocal 失败弃 / 分母 max(…,1e-8) / pdf≤0 弃路径（调用方）/ isfinite 出口（traceRay）
