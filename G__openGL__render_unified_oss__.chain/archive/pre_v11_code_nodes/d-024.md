# 模式 1/2 实现：CPU/GPU 光栅化

## RasterCPU（raster_cpu_backend.cpp，216 行）

**流程**：`renderFrame` → 清屏 `0xFF333333` + 深度 1.0 → 逐 mesh 逐三角形：MVP 变换（w≤0 剔除）→ NDC→屏幕（y 翻转）→ `rasterizeTriangleSSAA` → `display_->uploadFromCPU`。

**光栅核**（rasterizeTriangleSSAA）：
- 包围盒裁剪到屏幕；**4x SSAA**：子样本偏移 `{0.25, 0.75}²`，逐子样本 barycentric 判定
- `barycentric()`：边向量点积法（d00/d01/d11/d20/d21），denom<1e-12 拒绝；`u,v,w ≥ -1e-5` 容差
- 逐子样本 z 比较（`sampleBestZ` 单调收紧）→ 命中才插值法线/世界坐标/视角方向
- 顶点色参与：`albedo = baseColor * 插值顶点色`
- 着色 = `shadeCornell`（t-009 后为 Cook-Torrance 求值：主方向光 + ambient + 面光源循环 ×0.05 hack）
- 命中子样本颜色平均后 `packColor`（linearToSRGB + clamp ×255）

**其它**：dumpFrame = RGBA8 帧 → PPM（评判链）；captureFrame → BMP；updateMaterial 只改场景副本。

## RasterGPU（raster_gpu_backend.cu，263 行）

**upload**（宿主侧 .cpp）：Scene → `VertexPod(44B)/TrianglePod(16B)` 逐字段转换 + 顶点偏移合并多 mesh；材质数组**直接 cudaMemcpy 宿主 Material**（布局与 .cu 内定义的设备 Material 结构一致，双方 static_assert 64B）；emissive 三角形经 `emissiveMeshIndices` 重映射顶点索引后单独上传。

**内核**（rasterGpuKernel，**每像素一线程，遍历全部三角形——无 BVH**）：
- 16×16 block；NDC→屏幕；逐三角形 MVP + barycentric（整数像素中心，无 SSAA）
- 命中且 z 更近 → 插值 normal/worldPos/viewDir；材质越界钳 materials[0]
- `mat.isEmissive` → 直接 `color = mat.emission`
- 否则 `toPod`（设备 Material → PtMaterialPod）→ `dsh::evalBsdfDevice`（与 PT 同源 CT/GGX 求值）：ambient + 主光 `f·I·ndotl` + 逐面光源 `f·Le·ndotl/max(d²,0.1)·0.05`
- `packColor`（sRGB 转换后 `(uint32)(v*255)`，无 +0.5 四舍五入——与 CPU 端 +0.5 的细微差异，不影响位级判定口径因为基线同机同驱动）

**材质热更新**：`cudaMemcpy(d_materials_+index, &mat, 64B)` 单材质重传，不重建几何/光源。

## 两后端对照（同源着色，差异在采样与数据结构）

| | RasterCPU | RasterGPU |
|---|---|---|
| 覆盖采样 | 4x SSAA（0.25/0.75 偏移） | 1 sample/像素 |
| 几何访问 | 场景副本直读 | POD 上传 + 全三角形线性扫描 |
| 背景色 | 0xFF333333 | 初始灰 0.2（被三角形覆盖） |
| 面光源 | shadeCornell 循环 | 内核内循环（同 0.05 系数） |
| 确定性 | 位级（dump PPM 对比基准） | 位级（同机同驱动） |

## 历史锚点

t-009 把两后端从 Blinn-Phong 升级为与 PT 同源 CT 求值（金属带色复菲涅尔、玻璃 F0(η)、漫反射 (1−F)ρ/π+f_s）；光栅无透射/无环境反射/0.05 系数为如实保留的近似（d-006 §8）。
