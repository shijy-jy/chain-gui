# 显示层 + 应用装配实现

## Display（display.cpp/.cu，CUDA-GL interop）

- **双 PBO 乒乓**：`cudaGraphicsGLRegisterBuffer(WriteDiscard)` 注册两个 PBO；GPU 后端 map→D2D memcpy→unmap 写入当前 write PBO（uploadFromGPU），CPU 后端 `glTexSubImage2D` 直接刷纹理（uploadFromCPU，cpuUploaded_ 标记跳过 PBO 上传）
- **present()**：display PBO 异步 DMA → 纹理（`glTexSubImage2D(…, nullptr)` 从 PBO 读）→ 固定管线全屏 quad（GL_REPLACE）→ HUD 位图字体叠加（wglUseFontBitmapsA，Consolas 16px，半透明黑底面板）
- **swapBuffers 分离**（t-029）：quad 上屏后、ImGui 绘制后再 SwapBuffers——图像 → ImGui UI → 交换的次序由 app 控制
- `renderFrame/fillSolid` 是 Stage 1 遗留（时间渐变/纯色填充内核），空场景用 fillSolid 黑屏

## Application 状态机（application.cpp）

- **createBackend**：new 后端 → 5 个开关 plumbing（shadingModel/accum/svgf×2/autoExposure）→ initialize(1280×720) → loadScene → setCamera；失败即 dispose
- **双后端常驻**：previewBackend_（光栅）+ renderBackend_（PT）同时存活；`switchPreviewMode/switchRenderMode` = 建新 → 切活跃指针 → 别名安全 dispose 旧（`old != next && old != 另一个常驻者`）；onStartRender/onStopRender 只切活跃指针**不重建**（调参保留，t-028）
- **switchModel**：暂存调参 → buildModelScene → frameCameraToScene（AABB 包围球，dist=radius/tan(22.5°)·1.15）→ 三指针别名安全 dispose → 双后端重建 → 恢复预览/渲染状态 → 调参回灌（夹取 tuneRange）
- **applyMaterialEdit**：场景权威副本 + 三指针别名安全分发 updateMaterial（backend_/preview/render 两两不重复）
- **run 循环**：PeekMessage 泵（连续渲染无需消息）→ autotest 状态机（1s 后 arm；arm 时先 --model 切场景 → setRenderMode → dump 时强制 accum → --curve/--passes 下发后端）→ **--passes 独占终止**（否则与 10s 墙钟竞态，t-022）→ dump 落盘后再 PostQuitMessage → autotestQuit_ 当轮跳过渲染 → needsRender 门控渲染 → updateViewport + present + renderImGui + swapBuffers

## 无头 CLI 协议（main.cpp + run 循环）

| 参数 | 语义 |
|---|---|
| `--autotest [mode 1-4] [secs] [accum]` | 1s 后激活模式跑 N 秒优雅退出 |
| `--passes N` | 固定帧数终止（CPU pass=独立样本，GPU frame=复用帧） |
| `--dump <dir>` | 终止前 dumpFrame（PT→PFM 线性 / Raster→PPM）+ captureFrame BMP |
| `--curve <ref.pfm>` | PT CPU 每 pass PSNR/rel_err 落 CSV |
| `--model <name>` | arm 时按显示名（或 +".obj"）切基准场景 |
| `--visioncli <bmp> [prompt]` | 无头视觉判图（结果落盘 visioncli_latest.txt） |
| `--comparecli <test.pfm> [ref.pfm]` | 无头参考对比（指标+误差图+三联图报告） |

- lpCmdLine 子串解析，值取到下一 ` --`；路径 ASCII（ANSI 字节）
- **陈旧产物守卫**：main/app 各记 sizeof(Application)，启动比对不一致弹框（depfile 失效环境的 ODR 防线，t-005）
