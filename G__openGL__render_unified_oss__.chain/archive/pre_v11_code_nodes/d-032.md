# 补漏内化（第二批精读，覆盖 d-024~d-031 未逐行核对的剩余实现）

> 审计任务 t-034 发现第一批内化有 7 处只到接口/注释级；本节点补全逐行核对结果。

## 一、设备端核心设施（path_trace_gpu_backend.cu 1-668）

- **sampleBlueNoise**：`Murmur3 fmix32(frameIndex+0x9E3779B9)` 生成 6-bit 帧偏移，64×64 瓦片循环——替换旧线性偏移序列（(73,137) mod 64 的对角线流动伪影 + 帧间方差升高，BL-20260814-04b）
- **`__constant__ RtTunables c_tune`** + `setRtTunables`（cudaMemcpyToSymbol，每帧）；设备 **PCG32**（pt_rng.h 直移植）；**Frame** 局部基（与 CPU Basis 同构）
- **复菲涅尔**：ComplexF + cxAdd/Sub/Mul/Div/Sqrt + `conductorFresnel3`（逐通道复数；注释自曝 r_perp 曾误用 cos_t.re，后修正为复数乘）；`dielectricFresnel`（TIR 返回 1）
- **设备 BVH 三函数**（显式栈 32、dirIsNeg 近子先、与宿主同构）：
  - `bvhIntersect`：tMin=0、tMax=1e30，收敛最近命中
  - `bvhOccluded`：**先直接测全部发射面三角形**（多数阴影射线指向顶灯 2 三角形，命中即短路；数学等价——灯是场景一部分，BL-20260814-02）
  - `bvhOccludedGlassTransparent`：阴影射线**跳过 isGlass 面**（t-018：否则玻璃透射 NEE Vis=0 全黑）
- `sampleAreaLight/areaLightPdf`：蓝噪声 u,v 三角形采样；`pdf = dist²/(|cos|·area·N)`
- **`traceRay`**：完整迭代 PT（与 CPU traceRay 逐行镜像：MIS/NEE/RR/BSDF/etaScale/NaN 双防线），带 `primaryHitIn` 主命中复用与 `skipPrimaryNEE`——**ReSTIR 管线下无调用者（死代码，t-009 回溯核实）**

## 二、DI 候选与空间复用尾部（797-876、1153-1171）

- `restirCandidateKernel`：仅 matFlags==1（漫反射主命中）；**diSamples 循环**（默认 4，上限 32）；每样本独立 G-reject；RIS 目标 `pHat = ρlum·ndotl·LeLum·G·Vis`，`pSrc = 1/(N·area)`；加权随机选择（sel<wgt 换样本）
- `restirSpatialReuseKernel` 尾部：每邻居在**中心像素**重评估（无 Vis 射线）→ wJ → 合并单样本 +1 计数 + 加权随机

## 三、GI 候选内核完整流程（1427-1809）

- kSpp 样本池（PCG32 盐 0x6A7B8C9D，seq=p+1）
- **x0 出射方向分支**：
  - 金属：镜面反射（确定性 pdf=1）+ **硬编码铝 η=(1.39,0.97,0.59)、k=(7.62,6.5,5.39) 复菲涅尔染色 `beta0 = bc0·F`**（BL-20260816-06；t-014 回退后的旧逻辑）
  - 玻璃：F 分叉（**固定 IOR 1.5**）+ 透射走**穿球循环**（≤3 段、0.01 偏移防自交、TIR 处理）→ 球后场景点作 x1（t-018）
  - 漫反射：余弦半球，pdfX1 = cos/π
- x1 追踪：sky@x1（flags=2）；**x1 在灯上：漫反射丢弃（DI 的职责，防双重计数 +10~24% 权重注入）；镜面存 Le 进 alb1（flags=1 镜面灯反射）**
- **RR：P=0.75 NEE@x1（1-bounce）/ P=0.25 弹 x2→NEE@x2（2-bounce）**（BL-20260814-24 把 0.5 调到 0.75：0.5 实测间接平坦区噪声 5.3；⚠️ .cu 顶部与 pt_gpu_scene_layout.h 注释仍写 P=0.5——注释漂移）
- x2 在灯上：丢弃（与 1-bounce 重复；旧 MIS 抑制 ~5e-4，t-013j +10~16%）
- **pSrc 重组**：`pdfX1 × RR概率(flags0:0.75 / flags3,4:0.25×pdfX2) × 1/(N·area)`；flags=1 确定性（无 RR 无灯采样）
- **每个候选都计入 M（含无效/零权重）**——排除会偏置 wSum/M 向"可见条件均值"（实测地板 1-bounce +20%）
- RIS 用**加权随机**（max-pick 偏向重尾 pdf → 擦边弹射变永久 firefly）
- `resv.pad = (金属|玻璃) ? 1 : 0`——specular 标记，shade/temporal 读 beta0 的依据

## 四、GI 时域/空间复用（1820-2148）

- **时序**：重投影 + 深度/法线门 + **重连可见性**（x0_cur→x1_prev 与 x1→x2 两段阴影射线；**发射面列表传 nullptr——灯在这里按几何遮挡**）+ 当前像素重评估 fprev + pSrc 重组（与候选同式）+ 动态 M-cap + 按 `wHist/(r.wSum+wHist)` 概率选择 prev 样本
- **空间**：k=4 + 门控 + **朝前面检查（无重连射线——实测 36ms 超预算）** + **2020 式全储层合并**（nr.wSum/nr.M 整体并入；样本按 `nr.wSum/(r.wSum+nr.wSum)` ≈30-50% 选择）——旧单样本合并仅 ~12% 复制率、像素不共享样本、静态模式残留（间接区 4.79）；t-013m 的中心重加权是错误对象（+8~12% 能量）
- 漫反射类 flags=1（pad!=1）在空间复用侧丢弃

## 五、OptiX 链预处理核 + OptiX 包装实现

- `halfTonemapKernel`：2×2 box 下采样 + Reinhard `x/(1+x)`（×exposure 逐通道）；`halfAlbedoKernel`：2×2 box；`halfNormalFlowKernel`：平均世界法线→相机空间 + flow（prev→current，半分辨像素）；`inverseTonemapKernel`：`x/(1−x)/exposure`（0.98 钳制防除零）；`logLumReduceKernel`：256 线程共享归约 + 每块 atomicAdd
- `optix_denoiser.cpp`（OPTIX_ENABLED 分支）：**loadNvoptix**——nvoptix.dll 在驱动店（DriverStore\FileRepository\nv*）显式 LoadLibrary；TEMPORAL_UPSCALE2X + albedo/normal 引导；**必须 withOverlap scratch（实测模型要 603MB，withoutOverlap 258MB 不够）**；内部引导层双缓冲（输出分辨率）+ prevOutput 持久化；invoke 后 cudaMemcpyAsync 持久化 + 内部层指针交换；`temporalModeUsePreviousLayers = !newSequence`；无 SDK 编译为 stub
- 自动曝光：`target=0.18/avgLum` 夹 [0.05,20] → ratio 夹 [0.5,2] → EMA 0.95/0.05

## 七、eval 核心实现（frame_dump.cpp / compare.py / selftest.py）

- **frame_dump.cpp**：writePFM 行翻转（spec 自底向上）+ `PF\nW H\n-1.0\n`（小端）；writePPM P6；writeBMP BI_RGB 自底向上 BGR 4 字节对齐、72DPI、54 字节头；**readPFM/readPPM：fread 2 字节魔法号后必须 fgets 吃掉首行余行再读尺寸行**（t-031 坑）；readPPM 支持 255/65535
- **compare.py**：魔数分发读 PFM/P6/BM；指标 max_abs_diff / PSNR（峰值=max(ref)，--psnr-peak 可钉死）/ mean_rel_err；--heatmap 对数刻度 `t=log10(1+rel·1000)/log10(1001)` 蓝→白；--sidebyside 三联（Reinhard + 参考峰值归一 0.8）；--blocks N×N 分块矩阵；**纯 stdlib zlib 手写 PNG chunk**；单行机器可解析 verdict + 退出码
- **selftest.py**：10 项自检（合成图对 + subprocess 调 compare.py 证明判定逻辑）
