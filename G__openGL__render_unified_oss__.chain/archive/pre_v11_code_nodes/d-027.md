# BVH / ThreadPool / PCG32 / device_math 实现

## BVH 构建（bvh.cpp）

- **12 桶 SAH**：每轴三角形重心分 12 桶 → 扫左右桶累积计算 cost = N_left·A_left + N_right·A_right → 三轴取最小；无有效分割即停
- **防坑（t-003 实证后加固）**：非有限 diag 跳轴（NaN 转 size_t 在 MSVC 上是未定义行为）；**深度上限 31**（遍历栈 32 项，内部分支每层压 1 项，留 2 项余量——深树曾致 /GS 栈 Cookie 崩溃）
- **分区**：头尾指针 + 桶号重算（在分割轴上的桶 < minSplitIndex 归左）
- **内存**：`deque<BuildNode>` nodePool（尾部插入不失效指针）+ 池化 allocNode
- **展平**：递归 flatten → 连续 `nodes_` 数组；内部节点 triangleCount=0（child1 先写、child1OrTriIndex 后补），叶节点存三角形区间起点；叶内三角形在 triangles_ 中连续

## BVH 遍历（intersect / occluded）

- 显式栈 `std::array<int,32>` + pushNode 越界守卫（触发即中止遍历，防御性）
- slab 测试（预计算 invDir + dirIsNeg）→ **近子先**遍历（dirIsNeg 分支选 child1 近）；内部节点紧凑布局：child0 = currentNode+1
- 叶内 `mollerTrumbore`（EPS=1e-6，u/v/t 全条件）逐个测试；intersect 收敛 tMax 取最近，occluded 命中即返回 true
- HitResult：t/point/normal（顶点法线插值归一）/bary/materialIndex/emissiveTriIndex

## ThreadPool（thread_pool.cpp）

- 共享任务队列 + `nextTaskIdx_` 原子分发 + `pendingCount_` 计数；**主线程也参与消费**（parallelForTiles 内直接循环取任务），wait() 忙等 yield
- tile 大小：`tileW = ceil(W/√tc)`（方形切分，扫描线按 tile 串行）

## PCG32（pt_rng.h）

- `setState(init_state, init_seq)`：标准 PCG 序列；`uniform() = next()·0x1p-32`
- 用途：PT CPU 每像素每 pass 确定性种子；PT GPU 各复用核的样本选择（不同盐值 + frameIndex·黄金比混合，帧间去相关）

## device_math.cuh（共享设备头）

- float3 运算符（CUDA 无内建）+ dot/cross/length/normalize/fminf3/fmaxf3
- `mulMatVec`：列主序 4×4 × float4（主光线生成）
- `packColor`：linear→sRGB→`(0xFF<<24)|RGBA8`（与光栅/宿主同构）
- 铁律：跨 .cu 共享数学只 include 本头（避免 ODR），不要 include 别的 .cu

## 与上层的关系

BVH 同时服务 PT CPU（宿主结构直用）与 PT GPU（BvhNodePod/FlatTriPod 上传镜像，pod_guards.h 锁布局）；RasterCPU 无 BVH（逐三角形光栅），RasterGPU 同样全量扫描。
