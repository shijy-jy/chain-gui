# 降噪内核实现（src/denoising/*.cu，全部 16×16 block）

## temporal_reproject.cu（SVGF 时域，默认开）

- **重投影**：`prevUV = inv(prev)·curr × NDC(x+0.5,y+0.5)` → **像素中心映射 `floor(prevU·W)`**（旧 ×(W−1) 是 off-by-one，每帧混入左邻样本——BL-20260814-01 修复）
- **三钳制**（任一失败 → 直接输出当前帧并重置 moment）：① 视口外；② 深度 `|hD−cD| > 0.1·max(cD,1e-3)`；③ 法线 `(1−ndot) > 0.1`，**bothMiss（双零法线）必须通过**（旧点积拒绝背景像素永远，~9.5% 像素从不累积——对照 Schied 2017 向量距离语义）
- **SVGF 颜色钳制**（Schied 2017 §4.2）：历史颜色钳到当前帧 3×3 邻域 `μ±γσ`（γ=1.0，逐通道）——压 ghost/firefly 而不模糊（box 不是空间滤波）
- **混合**：`out = α·cur + (1−α)·hClamped`（α=tune_.alpha 默认 0.1）；moment 同 α 累积 noisy 输入的 lum²（与 TheVaffel 的 moment_a 不同，文档化简化）
- 调试通道：dbgCounters[4]（视口/深度/法线/接受）+ dbgPixel[8]（像素 (900,300) 全量中间量）

## svgf_atrous.cu（方差引导空间，默认开）

- `buildVarianceKernel`：`var = max(moment − lum², 1e-4)` → (color, variance) float4
- `atrousKernel`：5×5 taps × stepSize(1,2,4,8)；核 {1, 2/3, 1/6}；中心权 centerW
  - **颜色权重 = 论文公式** `exp(−|Δlum|/(colorPhi·√var))`——TheVaffel 参考实现算了 phi_color 但从未使用（port bug，已修）
  - **硬拒绝**：normal dot<0.9 / depth 相对差>10% / **emissive 边界门**（matFlags==4 两侧互斥——灯面与天花板共法线共深度，颜色权会让 2.5 radiance 光环漏进天花板辉光，t-021；全量 flag 门测出反馈伪影，只守 emissive 边界）
  - 方差传播 `totalVar = Σw²·var/(Σw)²`；ping-pong float4，最后一遍写 finalColor
  - TheVaffel 的 pow(dot,0.01) 边缘项移植后实测 4x 梯度坍缩（墙缝糊）→ 弃用（注释自述）
- 调参：colorPhi/varFloor/centerW/atrousPasses（Denoise 组）；空间链要求 temporal 开（moment 生产者）

## restir_simplified.cu（早期实验，默认关）

- 空间：中心权 2 + 3 个**固定偏移**邻居（{-2,0},{2,0},{0,2}——帧变蓝噪声偏移会边缘闪烁，故固定），深度/法线门
- 时域：重投影 1 + 4 邻域，加权平均（**非 max-pick**——max-pick 传播 firefly/低频斑块），当前帧权重 4/9（旧 1/6 导致 ~2s 时域滞后 ghost，BL-20260814-06）

## spatial_filter.cu（最简基线）

5×5 高斯（σ=1.0）共享内存 tiling：TILE 16 + 2 halo → 20×20 装载，`__syncthreads` 后 `#pragma unroll` 卷积

## optix_denoiser.cpp（TEMPORAL_UPSCALE2X，默认关；无 SDK = stub）

- 半分辨输入（tonemap 后的 LDR color + albedo + camera-space normal + flow）→ OptiX 去噪 + 2x 上采样 → inverse tonemap
- **自动曝光**（t-021 可关）：`Σlog2(lum)` 归约 → `target = 0.18/avgLum` 夹 [0.05,20] → ratio 夹 [0.5,2] → EMA 0.95/0.05；OFF = 固定 tune_.exposure
- 实测劣于 t-010 链（noise 2.76/4.02 vs 1.47/2.62）→ 开关保留供 A/B（BL-20260814-18）

## 接线约束（宿主 renderFrame）

restir_simplified 跑在 temporal **之前**（temporal EMA 累积更干净样本；跑后面会把邻居历史混进 EMA，帧间噪声 15.3→19.0 实测）；temporal 输出成为下帧历史（EMA 链完整性）；相机移动清历史走 firstFrame 路径
