## 渲染主循环

- `renderFrame`：每帧**一个 pass**（一个独立样本/像素）；`renderOnePass` → ThreadPool `parallelForTiles`（tile 大小 = W/√tc）
- `renderScanline`：每像素 `PCG32::setState(x+y·W+0x12345678, pass+1)` → 像素抖动 NDC → `invViewProj × clip` → 方向 → `traceRay`
- **帧平均**：`accumBuffer += sample; display = accum/(pass+1)` —— 方差 ∝ 1/N，静止收敛到零噪声（与 mode 4 的 EMA 噪声地板对照，d-007）
- `totalPasses_` 默认 128（`setPassBudget` 可改，512 参考图用）

## traceRay 主循环（深度 ≤ maxDepth_=8）

```
BVH intersect (SHADOW_EPS, +∞)
 ├─ miss → L += beta·sky(0.02,0.02,0.04)·etaScale, break
 ├─ emissive → MIS 加权 (hadBsdfBounce 时 powerHeuristic(lastBsdfPdf, areaLightPdf)) → break
 ├─ depth≥2: 俄罗斯轮盘 q = min(0.9, max(beta·etaScale)); 存活 beta/=q
 ├─ NEE: sampleAreaLight (均匀选灯 + 三角形面积采样)
 │     → occluded 阴影检查 → evalBsdf → powerHeuristic(lightPdf, ev.pdf)
 │     → L += beta·f·Le·ndotl·w/lightPdf·etaScale
 └─ BSDF 采样 sampleBsdf → beta *= weight; transmitted 时 etaScale *= s.etaScale
      射线原点 = 命中点 + 法线(或 wi)·SHADOW_EPS; 记录 lastBsdfPdf
```

- **NEE 数学**：选灯 pdf = 1/count；灯上点 pdf = 1/area；立体角 pdf = `dist²/(|cosLight|·area·count)`（Jacobian）
- **MIS**：power heuristic `pdfJ²/(pdfJ²+pdfK²)`，两个策略（BSDF 采样 vs 光源采样）听 pdf 大的一方
- **NaN 双防线**：循环内每步 isfinite(beta/L) 否则整条路径置 0；出口再兜底（t-009）
- 玻璃 NEE 只做反射瓣（eval 返回 F·spec+comp 与 F·pdf；透射靠 BSDF 采样，d-006 §8）

## 显示链与判定链

- `packColor`：0.40 曝光 → **软拐点 tone map** `v' = v·(1+v⁴)^(-1/4)`（两次 sqrt 实现）→ sRGB → RGBA8（t-029；中灰区与旧硬钳制误差 <1%，0.40 标定不破坏）
- `dumpFrame`：accum 均值（**tone map 之前**的线性 HDR）→ PFM；`--curve` 每 pass 对参考 PFM 算 PSNR（峰值=max(ref)）/rel_err 追加 CSV
- 相机变化判定：`memcmp(viewProj, lastViewProj_)` 才 resetAccumulation（每帧 setCamera 不再误清累积，BL-20260816-02）
- 完成时打印平均亮度（回归检查）+ 每 pass 落盘 `ptcpu_stats.log`（GUI 无控制台）

## 历史锚点

t-009 重写 BSDF 三支（GGX 粗糙金属/粗糙透射/能量比例漫反射）+ etaScale 修正；t-011 maxDepth 5→8 + 能量比例分支分裂（墙面镜面瓣样本占比 50%→~8.6%，有效漫反射样本翻倍）；t-022 实测端到端不可位级复现（~0.4% 边缘像素，根因另立调查项）→ 判定口径 PSNR≥50dB。
