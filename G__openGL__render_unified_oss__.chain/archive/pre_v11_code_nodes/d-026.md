## DI 数学（注释自证）

- 目标函数 `pHat = ρlum·ndotl·LeLum·G`，`G = (ndotl·cosLight)/dist²`（true-contribution，无 MIS balance）
- 候选/复用侧 `G > diGReject` 即拒绝（[t-019] 贴灯奇异点守卫——代码注释占用 t-019，图谱无此节点）
- shade 权重 = `(wSum/M)/pHat`；直接光 = `(albedo/π)·ndotl·Le·G·weight`（漫反射目标）
- **可见性不重追**（DI shade 与空间复用）：候选与时域复用已验 V，跨阴影边缘的软泄漏交给降噪链（文档化简化，~0.9ms/帧）

## 时序复用合并（t-020/d-011 动态 M-cap 落地版）

```
重投影 → 门控: 深度 |hD−cD| ≤ 0.1·max(cD,1e-3)
             法线 bothMiss 通过 / (1−ndot) ≤ 0.1
             可见性 bvhOccluded 当前像素
合并:  dynCap = N·F (N=本帧候选数, F=frameWindow)
       mPrev = min(prev.M, dynCap); wPrev = prev.wSum·mPrev/prev.M   ← 只压缩历史
       wSumNew = r.wSum + wPrev; M_new = r.M + mPrev
       样本按权重 wPrev/(r.wSum+wPrev) 选择 (PCG32 盐 0xB17E5EED)
```

## GI 储层语义（RestirGiReservoir 112B，flags 0-4）

`0=NEE@x1, 1=镜面灯反射, 2=sky@x1, 3=NEE@x2(2-bounce), 4=sky@x2`；储层存 x1/x2 位置法线 albedo + beta0（specular 路径 pad==1 存 BRDF 加权吞吐，shade 时直接读，diffuse 时重建 `(bc0/π)·ndotl01`）；x1→x2 传输 `beta12 = alb1·ndotl12/π`；`giMisWeight`：光源策略 pdfL 与 BSDF 策略 pdfB 的 power heuristic（指数 misBeta 可调）→ 压掉 1/dist² 权重尾；阴影用 `bvhOccludedGlassTransparent`（跳过玻璃，与 CPU 对齐 t-018）

## 宿主编排（renderFrame，QPC 计时）

调参上传 `setRtTunables`（__constant__，每帧）→ 内核链（见 d-023 §三）→ HUD 8 帧回读 → accum 分支早退 → 降噪链（restir_simplified/temporal/atrous/OptiX 逐级 enable 门控，d-031）→ pack → uploadFromGPU → **6 组历史乒乓交换**（radiance/normal/depth/moment + DI/GI 储层；时域 EMA 链完整性靠"blended 输出成为下帧历史"，BL-20260814-01）→ 性能遥测（每 60 帧 [PerfSec] ptKernel vs temporal+pack）

## 关键实现选择与已知偏差

- 单 kernel 合并 SPP（BL-20260814-02：4 launch → 1 launch，数学位级不变）；maxDepth 固定 8
- 无 Talbot MIS 合并权重；历史权重不按当前目标重评估（重评估只当有效性门）；M-cap 线性 rescale；diGReject 启发式——全部注释自述，d-010/d-011 已入账，修复路线 = 储层补原始 pdf 字段
- t-014（GI 候选新 BSDF）已按用户指示整体回退：现 GI 金属=理想镜面+硬编码铝、玻璃=光滑 Snell（t-009 回溯核实：.cu 内新 BSDF traceRay 无调用者）
- `enable_restir_`/`enable_optix_` 默认关；开关链默认 temporal+spatial 开
