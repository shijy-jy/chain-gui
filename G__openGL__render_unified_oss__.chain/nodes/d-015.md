# 代码框架总览：三层同心圆模块地图与契约体系

render_unified_oss 的架构概念总索引。代码以骨架形式（code_map）挂在各层概念节点 d-016~d-022 上；本节点承载跨层规则、不变量与契约清单。骨架派生文件：`.chain/code_map/d-015.md`（stale 时先刷新再读）。

## 一、三层同心圆与依赖铁律

```
┌─ 装配层  app/        生命周期 + 双后端状态机 + UI + 诊断 + 视觉调试
├─ 能力层  shading/    BSDF 抽象 + 微表面数学（每模型一文件）
│          denoising/  SVGF 时/空降噪（只被 PT GPU 调用）
│          backends/   四后端 + BVH + POD 契约防线
│          assets/     场景契约 + OBJ/MTL + 模型库
│          raster/     CUDA-GL 显示层（只被 app 装配）
└─ 核心层  core/       math/camera/timer（稳定）
```

铁律：`core ← assets ← shading/backends ← denoising ← app`，raster 只被 app 装配；只允许上层 include 下层（2026-09-02 实测无反向 include）。

## 三、跨模块不变量（改代码前必读）

1. 像素打包统一 `(0xFF<<24)|(r<<16)|(g<<8)|b` = BGRA 小端，配 GL_BGRA
2. 确定性：PT CPU `PCG32::setState(像素, pass)`；PT GPU 蓝噪声 Murmur3 帧偏移 + 各核独立盐值
3. 渲染分辨率固定 1280×720（跨机器基线可比的前提）
4. 显示链分后端：mode 3 = 0.40 曝光 + 软拐点 `v(1+v⁴)^(-1/4)` + sRGB；mode 4 = 0.60 曝光 + clamp + γ2.2；光栅 = 直出 sRGB
5. etaScale = 累计 `Π(η_t/η_i)²` 并乘入最终 L（t-009 修正，旧版漏乘是 bug）
6. NaN 防线：半向量退化拒绝 + traceRay 出入口双 isfinite
7. SHADOW_EPS=1e-4；设备头 float3 全逐分量；设备缓冲一律 void*

## 四、模式四内核级一帧旅程

`ptGpuKernel`（G-buffer 2-sample AA）→ `restirGiCandidateKernel`（kSpp 池，RR 0.75/0.25 到 x2）→ GI 时/空复用 → `restirCandidateKernel`（DI）→ DI 时/空复用 → `restirGiShadeKernel`（WRITE 间接）→ `restirShadeKernel`（ADD 直接）→ [accum 帧平均早退] → [开关链：restir_simplified → temporalReproject → atrous×N → OptiX] → packColorToRGBA8 → Display → 6 组历史乒乓交换
