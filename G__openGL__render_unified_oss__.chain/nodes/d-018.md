# shading 层：BSDF 抽象与微表面数学

着色模型概念，每 BRDF/模型一文件：

- **抽象接口（bsdf.h / bsdf_device.h 镜像）**：`BsdfQuery/Eval/Sample` + `evalBsdf/sampleBsdf`——追踪/光栅循环**只认接口不认具体模型**；`ShadingModel{PBR, NPR}` 切换只改枚举值（NPR 槽位预留，未实现前回退 PBR）
- **微表面数学单一事实源（microfacet.h，MF_HD 宏 MSVC/nvcc 双编译）**：GGX D、Smith G1/G（高度相关）、Schlick/复菲涅尔/电介质菲涅尔、Cook-Torrance 反射、Walter 粗糙 BTDF（差平方分母）、VNDF 采样（Heitz 2018，y-up `T2=T1×Vh`）、Kulla-Conty 多次散射补偿（ggx_energy_lut.h 离线 LUT）
- **光栅端**（lambert_blinn）：与 PT 同源的 Cook-Torrance 求值 + sRGB↔线性双向转换

理论推导见 d-004/d-006；实施与权重细节见 t-009/t-010/t-011 与归档 `.chain/archive/pre_v11_code_nodes/d-028.md`。
