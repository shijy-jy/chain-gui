# 材质面板背后的完整数学物理（与本工程实际代码逐行对应）

## 0. 一句话总览

渲染器算的最终量是**辐射亮度 Radiance** $L$（单位 W/(m²·sr)，"每平方米每球面度多少能量"）。
屏幕像素 = 对这个量的蒙特卡洛估计。材质面板改的每件事，最终都在改下面这个
**渲染方程**（Kajiya 1986）里的项：

$$L_o(x,\omega_o) = L_e(x,\omega_o) + \int_{H^2} f_r(x,\omega_i,\omega_o)\, L_i(x,\omega_i)\,(n\cdot\omega_i)\, d\omega_i$$

- $L_e$ ← 面板的 **emission / isEmissive**
- $f_r$（BRDF）← 面板的 **baseColor / metallic / roughness / ior / 玻璃金属开关**
- $L_i$ ← 场景里的光源（含其他面光源的 emission）与间接光
- 路径追踪（PathTraceCPU/GPU）= 用蒙特卡洛递归估计这个积分；光栅（RasterCPU/GPU）= 只算"一次反弹+一个主光"的经验近似

## 1. BRDF 的物理定义与约束

$$f_r(\omega_i,\omega_o) = \frac{dL_o(\omega_o)}{dE_i(\omega_i)} = \frac{dL_o(\omega_o)}{L_i(\omega_i)\cos\theta_i\,d\omega_i}$$

三个物理约束（PBR 正确性的来源）：
1. **互易性** $f_r(\omega_i,\omega_o)=f_r(\omega_o,\omega_i)$
2. **能量守恒** $\int_{H^2} f_r \cos\theta\, d\omega \le 1$（反射不可能超过入射）
3. **归一化**：Lambert 常数 $\rho$ 需要除 $\pi$ 才守恒——
   $\int_{H^2}\frac{\rho}{\pi}\cos\theta\,d\omega = \frac{\rho}{\pi}\cdot\pi = \rho \le 1$。
   代码里 `Lambertian BRDF = albedo / PI` 的 $\pi$ 就是这里来的。

## 2. 面板参数 → 物理量的完整映射

| 面板控件 | Material 字段 | 物理含义 | 改的是哪个公式 |
|---|---|---|---|
| 基础色（色板, sRGB→线性） | baseColor | 反射率 ρ（光谱三通道近似） | Lambert ρ/π、玻璃/金属染色 |
| 粗糙度滑条 | roughness | 微表面粗糙度 | **光栅**: Blinn 指数 (1-r)·256；**PT: 当前未参与（理想镜面），见 §7 差距** |
| 金属度滑条/金属开关 | metallic / isMetal | 导体 vs 电介质分支 | 选 §3.3 复菲涅尔还是 §3.4 电介质 |
| 玻璃开关 | isGlass | 透射介质 | Snell 折射 + 透射分支 + TIR |
| 折射率 | ior | 电介质折射率 η | Snell + 电介质 Fresnel |
| 自发光色板 | emission | 出射辐射 L_e | 渲染方程 L_e 项 |
| 预设按钮 | 多字段 | 铝的 n,k 常数 / η=1.5 | 见 §3.3 |

**为什么面板必须 sRGB→线性**：PBR 的一切积分发生在**辐射（线性）空间**，gamma 编码只是显示端压缩。
面板给美术看 sRGB（直觉），存储/计算用线性（物理）。代码 `srgbToLinear`：
$x \le 0.04045 \Rightarrow x/12.92$，否则 $((x+0.055)/1.055)^{2.4}$。

## 3. 各公式逐条（与 src 代码一一对应）

### 3.1 Lambert 漫反射（PT 端，物理式）

$$f_r = \frac{\rho}{\pi},\qquad p(\omega)=\frac{\cos\theta}{\pi}\text{（余弦加权采样）}$$

代码技巧（`traceRay` 406-417 行）：采样后
$\beta \mathrel{*}= \rho$，因为 $\frac{f_r\cos\theta}{p} = \frac{(\rho/\pi)\cos\theta}{\cos\theta/\pi} = \rho$，
cos 与 π 精确相消——所以 `beta *= mat.baseColor` 直接就是无偏权重。

### 3.2 光栅端 Lambert+Blinn（经验式，非物理）

```
diffuse  = ρ · I · max(N·L, 0)
shininess= max(2, (1-roughness)·256)
specular = I · max(N·H, 0)^shininess     ← Blinn-Phong: H=(L+V)/|L+V|
ambient  = ρ · ambientColor              ← 常数环境近似
面光源近似 = Le · max(N·L,0) / max(d²,0.1) · 0.05   ← 0.05 是几何修正系数
```

Blinn-Phong 是**经验公式**：指数只是"高光尖锐度"，不守恒、无 Fresnel——所以光栅预览里金属/玻璃不真实。

### 3.3 导体菲涅尔（金属，精确物理式）

金属的折射率是**复数** $\tilde\eta = n + i\kappa$（n=折射、κ=吸收），且随波长变化——
这就是金属有颜色的物理根源（铝 n≈1.39 κ≈7.62，三通道各一组）。

代码 `conductorFresnel`（91-104 行）逐通道复数运算：

$$\sin^2\theta_t = \frac{\sin^2\theta_i}{\tilde\eta^2},\quad \cos\theta_t = \sqrt{1-\sin^2\theta_t}$$

$$r_\parallel = \frac{\tilde\eta\cos\theta_i - \cos\theta_t}{\tilde\eta\cos\theta_i + \cos\theta_t},\quad
  r_\perp = \frac{\cos\theta_i - \tilde\eta\cos\theta_t}{\cos\theta_i + \tilde\eta\cos\theta_t},
  \quad F = \frac{|r_\parallel|^2 + |r_\perp|^2}{2}$$

金属表面 F 恒接近 1（全反射+吸收）→ 金属没有漫反射项，直接 `beta *= F` 继续反射——代码 346-355 行。

### 3.4 电介质 Fresnel + Snell 折射（玻璃，精确物理式）

代码 `dielectricFresnel`（107-115 行）+ 折射分支（356-386 行）：

$$F = \frac12\left[\left(\frac{\cos\theta_i-\eta\cos\theta_t}{\cos\theta_i+\eta\cos\theta_t}\right)^2 +
       \left(\frac{\eta\cos\theta_i-\cos\theta_t}{\eta\cos\theta_i+\cos\theta_t}\right)^2\right]$$

- **全内反射 TIR**：$\sin^2\theta_i \ge 1 \Rightarrow F=1$（代码 110 行直接返回 1）
- 概率 F 走反射、1-F 走折射（俄罗斯轮盘按物理概率分叉，370 行）
- 折射方向按 Snell 定律：$\omega_i = (-\omega_x/\eta,\; -\cos\theta_t,\; -\omega_z/\eta)$
- **etaScale**：radiance 穿越介质界面按 η² 缩放（381 行 `etaScale *= η²`），因为立体角被折射压缩

### 3.5 蒙特卡洛采样与估计量（PT 的无偏性来源）

**NEE 直接光源采样**（390-404 行）：采样面光源上一点，
面积 PDF → 立体角 PDF 的 Jacobian（sampleAreaLight 258 行）：

$$p(\omega) = \frac{d^2}{|\cos\theta_L|\cdot A}\cdot\frac{1}{N_{lights}},\qquad
  L \mathrel{+}= \beta\cdot\frac{\rho}{\pi}\cdot L_e\cdot(n\cdot l)\cdot\frac{w}{p(\omega)}$$

**MIS 权重**（power heuristic，63-65 行）：BSDF 采样与光源采样两个策略按

$$w = \frac{p_J^2}{p_J^2 + p_K^2}$$

加权——哪边 pdf 大听哪边，避免"小光源用 BSDF 采样撞大运"的方差爆炸。

**俄罗斯轮盘**（337-344 行）：$q = \min(0.9, \max(\beta\cdot\eta^2))$，
概率 q 继续、1-q 终止，继续时 $\beta \mathrel{/}= q$ —— 统计无偏地截断无穷路径（maxDepth=5）。

**β（throughput）**：沿路径累积的乘积权重；最终 $L += \beta \cdot L_e$ 的每一段都在做
$\prod \frac{f_r\cos\theta}{p}$ 的蒙特卡洛估计——这就是渲染方程的离散化。

## 4. 四后端的物理精度对照

| | RasterCPU/GPU | PathTraceCPU/GPU |
|---|---|---|
| 漫反射 | Lambert（经验系数） | Lambert ρ/π（物理） |
| 金属 | 无（白色高光） | 复折射率 Fresnel（物理，带色） |
| 玻璃 | 无 | Snell+电介质 Fresnel+TIR（物理） |
| 光源 | 常数主光 + 0.05 面光近似 | NEE+MIS 面积采样（物理） |
| 全局光 | 常数 ambient | 递归积分（间接光、天空兜底 0.02/0.02/0.04） |


## 7. 已知简化与下一物理升级（衔接 d-003 路线图）

1. **PT 端 roughness 未启用**（金属/玻璃是理想镜面）。物理正解是微表面 Cook-Torrance：
   GGX 法线分布 $D=\frac{\alpha^2}{\pi((n\cdot h)^2(\alpha^2-1)+1)^2}$、Smith 几何项、Schlick F——
   这是"把粗糙度滑条变成物理"的下一步
2. metallic 未做 0-1 插值（Disney 允许混合金属/介质）
3. 玻璃无体积吸收（Beer-Lambert）与色散
4. 面光源 0.05 系数是光栅端的几何 hack
