# 设计：models/ 文件夹模型库

## 目标

用户往项目内固定文件夹丢 `.obj` 文件，程序启动扫描并列出，可在面板里切换渲染。

## 核心决策

1. **文件夹 = 项目根目录的 `models/`**（与 CMakeLists.txt 同级）。
   - 运行期以工作目录相对路径扫描：VS 里工作目录=项目根；双击 exe 时 = exe 目录（post-build 已拷贝 models/ 过去，见 CMakeLists）。
   - 只扫 `models/` 顶层 `*.obj`，不递归。
2. **扫描与装配独立成模块** `assets/model_library`：
   - `scanModelFolder()` 枚举条目（内置 Cornell 排第一；`cornell_*` 文件不再单独列出，避免与内置条目重复）。
   - `buildModelScene()` 按条目装配 Scene：内置 Cornell = 三文件 + 墙体材质 + 顶灯；用户模型 = 单文件 + MTL 颜色（若有）+ 默认灰材质兜底 + 复用 Cornell 顶灯（保证路径追踪非黑屏）。
3. **运行期切换**：面板新增 Model 分区（下拉列表）；切换时重建 scene + 重建双后端（预览/渲染），暂存并回灌调参值，相机按新场景 AABB 自动取景。
4. **OBJ 加载器升级**：`loadObjScene` 改从 obj 同目录搜索 .mtl（Cornell 无 .mtl，行为不变；用户带材质的模型能读到颜色）。
5. **不做**：纹理贴图、递归子目录、模型变换导入（v1 边界）。

## 验收口径

- 往 `models/` 放一个带 .mtl 的 .obj，重启后在面板 Model 列表可见、可切换、路径追踪出图非黑
- 内置 Cornell 条目行为与现状一致（含墙体红绿材质与顶灯）
- CLI 构建不变（新增一个 .cpp 进 CMake 源列表）
