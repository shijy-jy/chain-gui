# backends 层：渲染后端接口与 POD 契约防线

每积分器/光栅化器一个后端类的概念：

- **IRenderBackend 接口**（render_backend.h）：纯虚 = name/initialize/renderFrame/getOutput/shutdown；**其余全虚函数默认实现兜底**——新后端（BDPT/MLT/光子映射）零成本接入，application 只加枚举 + UI 一项（ARCHITECTURE.md §3 新后端机制）
- **四后端**：RasterCPU（重心坐标 + z-buffer + 4x SSAA）/ RasterGPU（每像素一线程）/ PathTraceCPU（BVH+MIS+NEE，128 pass 帧平均，ground truth）/ PathTraceGPU（ReSTIR DI+GI+SVGF，实时）
- **契约防线**：宿主结构 ↔ 设备 POD 逐字段转换单点（各后端 loadScene）+ `pod_guards.h` sizeof/offsetof 编译期对照——契约变更编译即点名（§4.2 同步清单）
- **共享设施**：SAH BVH（深度上限 31 与遍历栈守卫，t-003 教训）、ThreadPool、PCG32、设备数学

ReSTIR 分析见 d-007/d-010/d-011；内核细节见归档 `.chain/archive/pre_v11_code_nodes/d-026.md`。
