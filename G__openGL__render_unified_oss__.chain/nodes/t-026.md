> 触发：基准场景；procedural OBJ；16 基线

# 要做什么

1. `tools/gen_bench_scenes.py`（纯 Python3 标准库、完全确定性、可复现）：生成
   `models/bench_{material,lights,dark,depth}.obj/.mtl`：
   - material: 材质阶梯（粗糙度行 Pr=0.05..0.85 + 金属行 Pm=0.2..1.0，UV 球+地板）
   - lights: 四块不同色温/尺寸/朝向的 Ke 发光面板（顶灯自动跳过）
   - dark: 单块暗面板（Ke=1.2，高方差低 SPP 压力）+ 高墙
   - depth: 走廊 + 5 层纵深遮挡盒（交错材质）
2. loader 扩展（obj_loader.cpp）：MTL `Pr`/`Pm`（PBR 粗糙度/金属度，显式设置时优先于
   Ns 映射）+ `Ke`（自发光 → isEmissive）。无 Pr/Pm/Ke 的旧模型行为零回归。
3. model_library.cpp：场景已有 isEmissive 材质时**跳过补顶灯**（多光源/暗场景
   需全权控制照明）。
4. `--model <name>` autotest 参数：arm 时按显示名切模型（重建场景+自动取景）再启模式。
5. 基线：4 场景 × 4 模式 = 16 张基线入库 + bench_meta.json。

# 验收

- 16/16 场景模式跑通（exit 0 + dump 落盘）✓
- 亮度层级 sanity：bench_dark lum 0.034 << bench_lights 0.137（暗场景压力成立）✓
- 材质阶梯：Pr/Pm 生效（bench_material 与旧 cornell 材质面板兼容）✓
- 生成器确定性：同参数重跑字节一致（设计保证，纯闭式循环无随机）
