# core 层：数学别名、轨道相机与计时设施（稳定层）

依赖树最底层：不 include 任何其它层，全工程依赖它。三个设施：

- **math.h**：GLM 别名（Vec2/3/4、Mat4）——头文件库，无 .cpp
- **camera**：OrbitCamera 轨道相机——LMB 旋转 / MMB 平移 / RMB+滚轮 dolly，Shift 3x / Alt 0.1x 灵敏度；球坐标（yaw/pitch/radius）反算 eye，输出 view/projection 矩阵
- **timer**：QPCTimer（QueryPerformanceCounter 计时）+ debugPrintf（OutputDebugStringA）/consolePrintf 双写日志——GUI 子系统无控制台，诊断必须落盘（PROCESS_LOG 级环境坑）

接口与调用关系见骨架；交互/矩阵语义见 d-001（初版架构）与 d-025（PT CPU 消费方式）。
