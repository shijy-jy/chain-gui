> 触发：ReSTIR 候选数敏感度；N32 与 N1

# 问题

每帧 32 个候选样本的蓄水池与每帧 1 个的蓄水池，最终画面差别不大——重采样是否不是最好/完整的版本？

# 结论

**三层原因叠加，主因是 M-cap 饱和**；且实现确非完整版（缺 Talbot MIS 合并权重等，见下）。

## 原因 1（主因）：M-cap 是均衡器

merge 数学（`restir*TemporalReuseKernel`, .cu 1042-1067 / 2011-2041）：
`M_new = min(M_cur + M_prev, mcap)`，超限时 `wSum *= mcap/(M_cur+M_prev)`。

- N=1/帧：每帧 +1，稳态 M≈30 → 蓄水池 = 最近 30 帧的移动平均 ≈ **30 个有效样本**
- N=32/帧：每帧 +32，M=62 → 截断到 30，且 wSum 每帧 ×30/62≈0.484 —— 历史权重每帧被腰斩 → 蓄水池基本只剩当前帧 32 个样本 + 压缩历史 ≈ **30-45 个有效样本**

→ 两者稳态有效样本数都在 30 上下，方差自然接近。**N 要起作用必须同时放大 mcap**（N=32 配 mcap≥128 才拉开差距）。

## 原因 2：空间复用稀释

k=4 邻居全量蓄水池合并（`.cu` 2049-2149）：每像素最终样本来自 ~5 个邻域像素的历史，邻域冗余进一步抹平单像素 N 的差异。

## 原因 3：SVGF 兜底

时域重投影 + à-trous 3 遍吸收残余方差；裸测 ReSTIR 差异需关 enable_temporal_/spatial（或对照 accumMode 帧平均参考，d-007/t-012 工具现成）。

## 实现缺什么（"不是最好/完整"确认为真）

1. **缺 Talbot 2019 MIS 合并权重**：完整版时间/空间复用按有效样本数 m_i 加权（w_i = p̂(x_i)/(p_src·m_i)，样本选择 ∝ m_i·w_i），当前是朴素 wSum 求和 + 线性 rescale——wSum/M 是"可见条件均值"的有偏估计，**自家注释（.cu 1771 附近）曾实测 +20% 偏差**
2. **历史权重未按当前目标重评估**：重评估只当"有效性门"，merge 用历史累积权重（.cu 1035-1040 注释自述）；相机/光照变化时偏差大
3. **M-cap 用线性 rescale 近似无偏**，完整版是 min(M_prev, cap) 截断 + MIS
4. **diGReject 巨权拒绝**是启发式守卫（非标准 ReSTIR），压掉巨权样本也压掉部分有效贡献
5. 更完整的目标 = GRIS（ReSTIR PT + shift mapping + Jacobian），即 docx P5 / t-014（已回退）的方向

# 验证路径（实验设计）

- 关 SVGF（或对照 accumMode 帧平均），固定相机：
  - N=1 + mcap=30（基线）vs N=32 + mcap=30（预期≈基线，验证饱和理论）
  - N=32 + mcap=120（预期显著变好，验证 N 与 mcap 的耦合）
- 修复路线：merge 升级 Talbot MIS（t-014 阶段二/三范畴，需储层存原始 pdf，节点正文已记录）
