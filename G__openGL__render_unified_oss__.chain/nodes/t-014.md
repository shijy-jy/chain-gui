# P5 第一步（最小修复）：GI 候选路径的金属/玻璃换新 BSDF

## 背景（用户文档 P5 + t-009 回溯核实）

模式四显示路径 = ReSTIR GI/DI shade（无条件运行），其中金属=理想镜面且 GI 候选
**硬编码铝 η/k**、玻璃=光滑 Snell（IOR 固定 1.5）——粗糙度/金属度滑条在模式四不生效。

## 本阶段范围（分阶段最小修复，规避双重计数/权重回归雷区）

1. 新增 `d_matIndex_` G-buffer（每像素主命中材质索引，uint32）——GI 候选读真实材质。
2. **GI 候选的金属/玻璃分支** → `dsh::sampleBsdfDevice`：
   - 金属：VNDF 粗糙反射 + 真实导体 η/k + Kulla-Conty 补偿（beta0 = s.weight, pdfX1 = s.pdf）
   - 玻璃：F 分叉 + 粗糙折射 + 透射穿球循环（IOR 读材质 ior 替换固定 1.5）
   - 漫反射分支**保持原余弦采样不动**（本阶段零风险）；specular 标记 pad==1 沿用 →
     GI shade/时序重用的存储 beta0 机制天然兼容（已核实无硬编码重评估）。
3. **DI 直接光（restirShade 的硬编码铝、DI 候选的 Lambert 目标）留到阶段二**——单独改。

## 验收标准

1. 全量重建 + 四模式 autotest exit 0 + accum 模式无头回归 exit 0。
2. 单元测试全绿（数学层不变）。
3. 视觉验收（用户）：模式四金属球高光随 roughness 变模糊、玻璃球透射随 roughness 磨砂、
   金属球颜色随材质面板 η/k/金属度真实变化（不再锁铝）。

## 进度与结论

### 实际做了什么

1. **d_matIndex_ G-buffer**（uint32/像素，主命中材质索引）：ptGpuKernel 写入、host 分配/释放、launch 签名贯通。
2. **GI 候选的金属/玻璃分支 → `dsh::sampleBsdfDevice`**：
   - 金属：VNDF 粗糙反射 + 真实导体 η/k + Kulla-Conty 补偿（beta0 = s.weight = f·cos/pdf，pdfX1 = s.pdf）——**硬编码铝常数删除**；
   - 玻璃：F 分叉 + 粗糙折射 + 透射穿球循环（IOR 读 `gm.ior`，替换固定 1.5）；
   - 漫反射分支保持原余弦采样（阶段一范围）。
3. specular 标记 pad==1 机制沿用 → **GI shade 与时序重用读存储 beta0，与新采样权重天然兼容**（shade==candidate 目标精确一致）。

### 已知近似（如实声明，阶段二处理）

- 时序重用的镜面重评估复用存储 beta0（E[f·cos/pdf]=∫f·cos 半球积分期望），在相机小幅移动下是有界近似——与旧确定性方案的近似哲学一致；精确化需在储层加存原始 pdf 字段（阶段二与 DI 一起）。
- **DI 直接光仍是旧逻辑**（restirShade 硬编码铝、DI 候选 Lambert 目标）——阶段二。

### 验证

- 全量重建通过（32/32）；四模式 autotest exit 0；**mode 4 + accum 无头回归 exit 0**（新 GI 候选路径被真实执行）；单元/模型测试全绿；无 crash 日志。
- 视觉验收（用户）：模式四金属球高光随 roughness 模糊、颜色随材质面板 η/k/金属度变化；玻璃球透射随 roughness 磨砂。
