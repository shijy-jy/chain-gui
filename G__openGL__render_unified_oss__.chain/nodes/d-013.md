# 问题

用户报告：PT CPU 模式中左侧金属球"像玻璃球"，PT GPU 模式正常。

# 诊断手段（新工具链）

本地视觉引擎：llama.cpp b9637（CUDA 13.3）+ Qwen2.5-VL-3B 官方权重（unsloth Q4_K_M
GGUF + mmproj-F16，hf-mirror 拉取），`http://127.0.0.1:8080`，REST 直连判图。
harness 的 modlens 视觉桥与 llama-server 的 OpenAI 端点不兼容（结构化 JSON 契约无法
强制）→ 走 REST 直连。工程内 `out/pfmview.py` 导出裁剪 PNG 供判图。

# 视觉判定（4/4）与数值佐证

| 裁剪 | 视觉判定 | 数值 |
|---|---|---|
| CPU 金属球 | 不透明反光，但**"看起来像玻璃"**（绿/红/黑/白色块 + 右上高光） | 球内最大 RGB 和 153（51× 白斑） |
| CPU 玻璃球 | 透明折射 ✓ | 最大 167 |
| GPU 金属球 | **"金属"**（均匀灰、顶部高光） | 最大 5.6，平均 (0.27,0.14,0.13) |
| GPU 玻璃球 | 透明 ✓ | 最大 41 |

# 结论

**CPU 是物理正确的镜面金属**：roughness 0.05 近镜面把红墙/绿墙/黑地板/顶灯的反射
清晰映出（彩色色块 = "玻璃感"的来源）+ 顶灯反光白斑（物理上就该这么亮）。
**GPU 的"正常"是 ReSTIR 镜面反射欠采样的副产品**：镜面方向几乎采不到光 → 均匀灰暗 →
反而"看起来像金属"。

# 决策（用户拍板 2026-09-03）

方向 **B**：CPU 向 GPU 观感靠拢。执行记录见 t-028：三次视觉仲裁迭代后采用
**铁导体 + roughness 0.9**（暗灰哑光，最接近 GPU 灰度；视觉模型 3B 对彩色渐变
球一律判玻璃，只能初筛不能终裁）。**t-028 发现真正的观感元凶 = CPU 显示链
packColor 硬钳制**：镜面反射顶灯 (≈15×0.97) ×0.40 曝光后 >>1 → 纯白斑 = 玻璃感；
材质参数无法消除，建议 t-029 显示链软拐点 tone map。
