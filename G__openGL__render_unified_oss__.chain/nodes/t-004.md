> 触发：UI 中文字形乱码

# 要做什么

面板 Model 模型 分区的新增文字（模型/选择/重新扫描/工程根目录…）显示乱码。

根因：ImGui 中文字形按白名单加载（`initImGui` 里 `rb.AddText("渲染控制启动停止回预览模式中光栅路径追踪参数统计")`），
t-002 新增的标签没同步进白名单 → 缺字形 → 乱码。用户中文文件名同理（任意汉字都可能是缺的）。

# 实际做了什么

1. 白名单追加 Model 分区新增汉字："模型选择重新扫描工程根目录丢进去后点"
2. 追加 `rb.AddRanges(io.Fonts->GetGlyphRangesChineseSimplifiedCommon())`（~2500 常用简体字），任意中文文件名不再挑字；图集 1024x2048，成本可接受
3. 图集构建后关键字形 sanity check（模/型/选/择/扫/描/重/新），缺字会在控制台日志暴露

# 验证结果

- 独立 harness（vendored imgui + msyh.ttc 同配置建图集）：**22/22 字形全命中、0 缺失**（新标签全字 + 常用集任意字 龙/猫）
- 完整构建通过；`--autotest 4 8` 冒烟：渲染 8 秒后优雅退出，exit 0，无崩溃日志

## 试错记录

- ⚠️ harness 首轮链接失败：imgui.cpp 的调试函数（ShowMetricsWindow 等）引用 imgui_widgets/imgui_tables，harness 需四件套一起编（imgui + draw + tables + widgets）
- 🔑 教训重申：ImGui 白名单方案很脆（代码里注释就写着"新增中文标签必须同步"），常用简体字集一次挂上后基本免维护
