> 触发：compare.py 对比裁判

# 要做什么

d-012 最小闭环第二环：参考图对比裁判。全部逻辑在 eval/（可移植），render_unified 不粘。

1. `eval/compare.py`（纯 Python3 标准库）：读 PFM（线性 HDR，支持大小端 scale）与
   二进制 PPM；输出三项指标 `max_abs_diff` / `psnr_db`（RGB 联合 MSE，**峰值默认 =
   max(reference)**，可 --psnr-peak 钉死）/ `mean_rel_err`（|a−b|/(|b|+1e-3)）；
   阈值命令行可覆盖、省略即跳过；尺寸不匹配直接 FAIL；单行机器可解析输出 + 退出码
   0/1；--json 可选。
2. `eval/selftest.py`：合成图对六项自检（identical PASS / 手改一像素 FAIL / 尺寸
   不匹配 FAIL / 零图 PSNR FAIL / PPM identical PASS / 无阈值 PASS）。

# 验收

- `python eval/selftest.py` 6/6 全绿 ✓
- t-022 双跑验证即用本工具判定：Raster max_abs_diff=0 PASS；PT CPU 双跑 PSNR
  57.7~72.6dB（作为阈值修正依据，见 t-022 发现）

# 备注

  PT 双后端 psnr≥50dB。regress.ps1 按模式显式传参，不依赖默认。
