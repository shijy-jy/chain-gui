> 触发：参考累积模式；帧平均替代 EMA

# d-007 §4 落地：模式四"参考累积模式"开关

## 背景

用户确认模式四观感差距根源 = EMA(α=0.1) 噪声地板（等效 ~19 SPP），RESTRI 的帧平均静止收敛到零噪声。给模式四加开关：ON = 帧平均（绕过时序+a-trous），OFF = 现有 EMA 实时链路。PT CPU 已是帧平均，无需改动。

## 要做什么

1. `.cu` 新增 `ptAccumulateKernel`（acc=(acc·(N−1)+cur)/N，与 RESTRI 同式）+ `launchPtAccumulate` 包装。
2. 主机侧：`d_accum_` float3 全分辨率缓冲（initialize 分配 / freeFrameBuffers 释放）；`accumMode_`/`accumSpp_` 状态。
3. `renderFrame`：ReSTIR shade 之后分支——accumMode ON 时累积 + 打包累积缓冲 + 直接返回（绕过时序/a-trous/OptiX）；OFF 走原链路。
4. 重置语义：进入 accum 模式清累积并计数归零；相机移动/材质热更新/着色模型切换时同步清累积；退出 accum 模式清时序历史（防陈旧 ghost）。
5. `IRenderBackend::setAccumMode(bool)` 虚接口 + `Application::accumMode_` + createBackend 下发 + Render Control 区复选框（带 tooltip：帧平均 vs EMA 的差异）。

## 验收标准

1. 全量重建 + 四模式 autotest exit 0（accum OFF 默认，行为不变）。
2. 单元测试/模型测试全绿。
3. 视觉验收（用户）：accum ON 静止 60 帧后画面显著干净（无 EMA 噪声地板），相机动后重置为 1SPP 再收敛；OFF 与原实时行为一致。

## 进度与结论

### 实际做了什么

1. `.cu` 新增 `ptAccumulateKernel`（acc=(acc·(N−1)+cur)/N，RESTRI 同式）+ `launchPtAccumulate`。
2. 主机侧：`d_accum_`（void*，float3 全分辨率；float3 是 CUDA 类型不可进宿主头——首次构建踩坑后改为 void*）；`accumMode_`/`accumSpp_` 状态。
3. `renderFrame`：ReSTIR shade 之后分支——accumMode ON 时帧平均累积 + 打包累积缓冲 + 直接返回（绕过时序 EMA/a-trous/OptiX）；OFF 走原链路零改动。
4. 重置语义：进入 ON 清累积重开；退出 ON 清时序历史（防陈旧 ghost）；相机移动/材质热更新/着色模型切换同步清累积。
5. `IRenderBackend::setAccumMode(bool)` 虚接口 + `Application::accumMode_` + createBackend 下发 + Render Control 区复选框（tooltip 说明帧平均 vs EMA 差异）。
6. 无头回归：`--autotest 4 N accum` 参数（main.cpp 解析 "accum"）。

### 验证

- 全量重建通过；四模式 autotest exit 0（默认 EMA 行为不变）；**mode 4 + accum 无头回归 exit 0**；单元测试/模型测试全绿；无 crash 日志。
- 视觉验收（用户）：ON 静止 60 帧显著干净（无 EMA 噪声地板）；相机动后重置为 1SPP 再收敛；OFF 与原实时行为一致。

### 试错记录

- ⚠️ `float3*` 成员进宿主头 → C2143/C4430（float3 是 CUDA 类型，宿主头不包含 cuda_runtime）→ 设备缓冲一律 void*，这是本项目既有约定。
