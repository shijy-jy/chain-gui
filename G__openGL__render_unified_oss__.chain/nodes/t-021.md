# 要做什么（用户批准的 P0+P1 范围）

为 d-010/d-011 的 A/B 验证铺路的参数开放批次（不含测量链，另议）：

1. **P0-1 重编用户日常 Release exe**：t-020 只编了 verify-nodebug；`out/build/x64-Release`（Ninja Release）重编后 SVGF 双开关与 frameWindow 滑条才出现在用户日常 exe。
2. **P0-2 diSamples 上限 8→32**：DI 侧 N=32 实验需要（kTuneParams 一行）。
3. **P1-1 自动曝光开关**：IRenderBackend::setAutoExposure + PT GPU 实现（ON = OptiX 链 EMA 自适应, OFF = 固定 exposure 滑条值, A/B 同基线）；渲染卡 Checkbox；createBackend plumbing。注：普通 pack 路径始终用滑条值（天然固定），自适应仅存在于 OptiX 超分链（enable_optix_ 默认 OFF）。
4. **P1-2 ReSTIR HUD**：统计核（ΣL, ΣL², ΣM_di, ΣM_gi，Rec.709 亮度，测量点 = ReSTIR 着色后降噪链前，SVGF 开关同点可比）→ 每 8 帧回读 → 渲染卡显示 DI/GI 蓄水池 M 均值与亮度均值/方差；IRenderBackend::getRestirStats 虚接口（默认 false 不支持）。

# 变更记录

- `include/backends/render_backend.h`：+setAutoExposure(bool)（默认 no-op）、+getRestirStats(...)（默认 false）
- `include/backends/path_trace_gpu_backend.h`：+两个 override 声明；+autoExposure_/d_statsSum_/stats 缓存成员（POD，不依赖 CUDA 向量类型）
- `src/backends/path_trace_gpu_backend.cpp`：diSamples 1~8→1~32；extern decl launchRestirStats；d_statsSum_ 分配/释放；renderFrame 在 DI shade 后、accum 早退前每 8 帧回读统计（DI 最终 = d_reservoirOut_，GI 最终 = d_prevGiReservoir_，均为交换前本帧值）；OptiX 分支曝光自适应套 autoExposure_ 门；setAutoExposure/getRestirStats 实现
- `src/backends/path_trace_gpu_backend.cu`：restirStatsKernel（块内 256 线程归约 + 每块 4 次 atomicAdd）+ extern "C" launchRestirStats
- `include/app/application.h` + `src/app/application.cpp`：autoExposure_ 成员 + createBackend plumbing
- `src/app/application_ui.cpp`：渲染卡新增 自动曝光 Checkbox + ReSTIR HUD 两行（仅 backend_ 支持时显示，双语 tooltip 说明测量点/含义/用法）
