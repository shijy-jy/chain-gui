# 完整版材质模型落地（d-006 的执行单元）

## 要做什么

1. **共享数学模块** `include/shading/microfacet.h`（MF_HD 宏，MSVC/nvcc 双编）：GGX D、Smith G1/G（高度相关）、Schlick F、GGX 半向量采样、反射 PDF、Cook-Torrance 反射求值、Walter BTDF、绕半向量折射、完整电介质菲涅尔、α=roughness²。
2. **BSDF 抽象接口** `include/shading/bsdf.h`（CPU）+ `include/shading/bsdf_device.h`（设备镜像）：`ShadingModel{PBR, NPR}`、`BsdfQuery/BsdfEval/BsdfSample`、`evalBsdf/sampleBsdf`。PBR 实现 `src/shading/pbr_bsdf.cpp`；NPR 槽位预留（未实现前回退 PBR + 日志，不暴露 UI）。
3. **Plumbing**：`Application::shadingModel_` + `IRenderBackend::setShadingModel()` 虚接口 + 四后端存储。
4. **PT CPU**：traceRay 重写——三类材质走接口；金属=GGX 粗糙导体（复菲涅尔）；玻璃=GGX 反射 + Walter 粗糙折射（F 按 h·ωo、概率 F 分叉、权重 G(h·o)/((n·o)(n·h)) 与 G|i·h|/((n·o)(n·h))）；漫反射=Lambert+GGX 镜面瓣（F0=mix(0.04,ρ,metallic)，50/50 分裂）；三类都加 NEE（玻璃只做反射 NEE）；**etaScale 修正**：(η_t/η_i)² 累积并乘入最终贡献（现代码只用于 RR，是 bug）。
5. **PT GPU**：主路径 kernel 镜像同一套（bsdf_device.h + microfacet.h）。ReSTIR 关闭路径（1493+ 与 773 段）保持旧逻辑并注释"重开前需镜像"。
6. **光栅 CPU/GPU**：Blinn-Phong 换 Cook-Torrance 求值（金属带色复菲涅尔、玻璃 F0(η) 无漫反射、漫反射 (1−F)ρ/π + f_s）。
7. **MTL 映射修正**：roughness = (2/(s+2))^{1/4}（Beckmann→GGX 等价，替换 1−s/1000）。
8. **UI tooltip** 更新（roughness=GGX α²、metallic=F0 插值、玻璃=粗糙透射）。
9. **测试** `build/verify-models/microfacet_test.cpp`：NDF 归一、G/F∈[0,1]、互易、能量≤1、采样归一；全量重建 + model_test + 四模式 autotest。

### 试错记录（数学推导的三次证伪）

- ❌ 折射公式第一版符号错误（ωi=−ηωo+(ηc−√s)h）→ 广义 Snell 检验证伪 → 修正为 ωi=ηωo−(ηc+√s)h。
- ❌ BTDF/透射 pdf 分母误用和 (ηiA+ηoB)² → 推导复核（PBRT 的 sqrtDenom 结构 + Snell 微分）应为**差平方** (ηiA−ηoB)²，且透射权重与反射同形 G(h·ωo)/((n·ωo)(n·h))（η 因子精确对消）→ 已修，白炉测试证实。
- ❌ 测试自身的两个错假设：∫D dω=1（GGX 归一的是投影积分 ∫D(n·h)dω=1，无投影积分随 α 增长到 ~2）→ 改为投影归一 + 双估计量一致性；0.1f<=0.1 浮点比较陷阱 → a<0.2f。
