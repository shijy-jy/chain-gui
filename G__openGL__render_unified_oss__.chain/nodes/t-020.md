> 触发：SVGF 面板化；动态 M-cap

# 要做什么

1. **SVGF 开关开放到面板**（d-010/d-011 实验前置）：
   - IRenderBackend 加 `setSvgfTemporal(bool)` / `setSvgfSpatial(bool)`（默认空实现，t-012 setAccumMode 同款模式）
   - PathTraceGPU 实现（映射 enable_temporal_ / enable_spatial_）
   - Render Control 区两个 Checkbox；switchModel 重建后端后回灌三个开关状态
2. **动态 M-cap（d-011 Tier 1）**：
   - `RtTunables.mcap` 升级为 `frameWindow`（语义 = 历史帧窗口 F，默认 30，范围 1~240）
   - 两处 temporal reuse merge 换公式：`dynCap=N*F; mPrev=min(prev.M,dynCap); wPrev=prev.wSum*mPrev/prev.M`（只压缩历史不稀释新样本）；样本选择 ∝ 压缩后权重
   - kTuneParams 条目改名 frameWindow（Sampling 组）

# 变更记录

- `include/backends/render_backend.h`：IRenderBackend 增加 `setSvgfTemporal/setSvgfSpatial` 虚函数（默认 no-op）
- `include/backends/path_trace_gpu_backend.h`：override 声明；删除已死常量 `kRestirMCap_`
- `src/backends/path_trace_gpu_backend.cpp`：setSvgf* 实现（映射 enable_temporal_/enable_spatial_）；kTuneParams `mcap` → `frameWindow`（Sampling 组，1~240 步进 1，默认 30）；tuneValue/tuneSetValue case 9 改写；launch 传 `tune_.frameWindow`
- `include/backends/pt_gpu_scene_layout.h`：RtTunables `mcap` → `frameWindow`（默认 30）
- `src/backends/path_trace_gpu_backend.cu`：restirTemporalReuseKernel 与 restirGiTemporalReuseKernel 合并公式换 Tier-1 动态 M-cap；GI 核保留单样本权 wPrev 作为有效性门（重连+朝向+可见性），压缩历史权重命名 wHist 避免重定义
- `include/app/application.h` + `src/app/application.cpp`：`svgfTemporal_/svgfSpatial_` 成员（默认 true）；createBackend 重建后回灌开关
- `src/app/application_ui.cpp`：渲染卡内新增"SVGF 时域滤波 / SVGF 空间滤波"两个 Checkbox（双语 tooltip 说明实验用途）；frameWindow 由 tuneGroup 通用滑条自动呈现
