# denoising 层：SVGF 降噪管线

实时降噪概念，每算法一文件，只被 PT GPU 管线调用（无反向 include）：

- **时域**（temporal_reproject）：inv(prev)·curr 重投影 + 三钳制（视口/深度/法线 bothMiss）+ **SVGF 颜色钳制**（历史颜色钳到当前帧 3×3 邻域 μ±σ）+ EMA α + moment 同 α 累积
- **空间**（svgf_atrous）：moment → 方差 → 5×5 à-trous ×N（step 1/2/4/8），颜色权重 = 论文公式 exp(−|Δlum|/(colorPhi·√var)) + 硬门（法线 0.9/深度 10%/发光面边界门），方差传播 Σw²·var/(Σw)²
- **辅助/实验**：restir_simplified（早期时/空滤波，默认关）、5×5 高斯基线、OptiX TEMPORAL_UPSCALE2X 链（默认关，实测劣于本链）、蓝噪声 64×64 数据

设计取舍（EMA 噪声地板 vs 帧平均）见 d-007；内核实现细节见归档 `.chain/archive/pre_v11_code_nodes/d-031.md`。
