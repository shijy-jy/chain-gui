# 设计定案：四模式统一架构

（据 README 与代码现状建档，作为后续开发/维护任务的父节点。）

## 核心决策

1. **单一场景多后端**：Cornell box（`models/`）由四套后端共享，按键 1–4 切换后端
2. **四套后端**：
   - RasterCPU：重心坐标 + z-buffer + 4x SSAA + Lambert/Blinn
   - RasterGPU：CUDA 光栅化，每像素一线程
   - PathTraceCPU：BVH + MIS + NEE，128 遍渐进式（ground truth）
   - PathTraceGPU：ReSTIR DI + ReSTIR GI + SVGF 去噪（实时展示）
3. **显示层独立**：`src/raster` 负责 CUDA–OpenGL interop + PBO 双缓冲，与后端解耦
4. **去噪独立成层**：SVGF（时域重投影 + à-trous），接口在 `include/` 声明
5. **运行时可调**：Win32 + OpenGL 壳 + 调优面板（当前 11 个实时参数）

## 目录结构（as-built）

- `include/` — 接口、设备 POD 布局、去噪接口
- `src/app` — Win32 + OpenGL 壳、消息循环、调优面板
- `src/backends` — 四后端 + BVH + PCG32 + 线程池
- `src/denoising` — ReSTIR 辅助 + SVGF
- `src/raster` — 显示层（CUDA–OpenGL interop、PBO ping-pong）
- `src/assets` — OBJ 加载 + Cornell 材质
- `models/` — Cornell box 网格（教学测试场景）

## 验收口径

- Release 产物：`build/bin/Release/render_unified.exe` + `glew32.dll` + `models/`（自动拷贝）
- 四模式均可运行、可切换；模式 3 作 ground truth，模式 4 达实时帧率
- 构建命令：`cmake -S . -B build && cmake --build build --config Release`
