# 工程基建：构建、评判链与基准场景

渲染分层之外的周边设施概念：

- **构建（CMakeLists.txt）**：C++17 + CUDA 17，四架构 75/80/86/89；GLEW vendored；OptiX SDK 自动探测（缺省 = stub）；**OBJECT_DEPENDS 全头兜底**（中文 MSVC depfile 失效的环境坑对策，t-006/t-007）；Release 调试符号 + RENDER_GIT_HASH 注入；post-build 拷贝 dll + models/
- **可插拔评判链（eval/，d-012 定案）**：零依赖核心（C++17 frame_dump PFM/PPM/BMP 读写 + Python3 标准库 compare.py/selftest.py + 3 步接入契约）——换工程不换裁判；工程内只留四后端 dumpFrame 胶水；口径：Raster 位级一致、PT PSNR≥50dB
- **基准与参考（benchmarks/）**：cornell + 4 基准场景 × 4 模式 = 20 张基线 + meta.json；512-pass 参考图 + 收敛曲线
- **工具（tools/）**：regress.ps1（冒烟 + -Compare/-UpdateBaseline 判定链）、gen_bench_scenes.py（确定性场景生成）、generate_blue_noise.py（FFT 频谱整形）
