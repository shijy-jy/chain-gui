# 关键结论（诚实记录）

- 视觉模型（qwen2.5vl 3B）对"光滑球体+彩色渐变"一律倾向判玻璃——对 GPU 的
  均匀灰球判金属。模型可用作初筛，**不能作最终仲裁**。
- **方向 B 的物理极限**：任何物理金属反射顶灯（emission 15）都产生 >>1 的线性值，
  CPU 显示链 packColor ×0.40 后硬钳制 → 纯白斑 = "玻璃感"的直接来源；
  GPU 无白斑恰因镜面欠采样。材质参数无法消除白斑。
- 采用 v4（铁+0.9）：暗灰哑光 + 边缘光压暗，物理上最接近 GPU 灰度，白斑亮度
  从 51× 降到 17×（已扩散）。
- **真正的观感修复 = 显示链**：mode 3 packColor 的硬钳制 (clamp) 换成软拐点
  tone map（如 filmic/Reinhard），镜面高光不再白斑化 → 建议列为 t-029。
- GPU 侧金属"灰"实为 ReSTIR 镜面反射欠采样（d-013），方向 A（修 GPU 镜面 NEE）
  另议。
