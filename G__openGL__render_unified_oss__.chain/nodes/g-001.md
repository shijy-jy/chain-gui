> 触发：四模式教学渲染器；零第三方依赖

# 最终目标

把 render_unified 做成一个可构建、可运行、可复现的教学级渲染器：
一个 Cornell box 场景，四套渲染模式共享，C++17 + CUDA 从零实现。

## 刚性约束（不可突破）

- **零第三方渲染依赖**：光栅化 / 路径追踪 / 去噪全部自研，GLEW 仅用于 OpenGL 扩展加载
- **四模式共用同一场景与资产**：Cornell box 网格与材质定义（`models/`）由所有后端共享
- **平台基线**：Windows 10/11 x64 + NVIDIA GPU（sm_75 / sm_80 / sm_86 / sm_89），CMake ≥ 3.24
- **许可合规**：MIT；第三方组件一律在 `THIRD_PARTY.md` 登记

## 弹性空间

- 各模式的调优参数与性能指标可迭代（调优面板当前暴露 11 个参数）
- 单模块内部实现可自由重构，前提是不改变对外行为与接口

## 边界

- 不引入现成渲染引擎/库替代自研管线
- 不破坏"零第三方渲染依赖"这一教学与 OSS 卖点

## 当前状态（据 README 与代码现状建档）

- 四模式均已落地：RasterCPU / RasterGPU / PathTraceCPU / PathTraceGPU
- PathTraceGPU = ReSTIR DI + ReSTIR GI + SVGF，目标 ~95 ms/frame @ 1280x720（RTX 4060 Laptop）
- 模式 3（PathTraceCPU）为渐进式 ground truth，模式 4（PathTraceGPU）为实时展示
- 当前工作区 `render_unified_oss` 即开源版工程根目录

后续 design/task/verification 节点挂在 g-001 下；d-001 记录四模式统一架构的定案设计。
