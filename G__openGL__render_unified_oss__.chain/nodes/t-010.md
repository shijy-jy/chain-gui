> 触发：Kulla-Conty 能量补偿；VNDF 采样

# P1+P2：Kulla-Conty 能量补偿 + VNDF 采样（用户文档 P1/P2，同一工单）

## 要做什么（按用户文档推荐路径）

1. **离线预计算**：`build/verify-models/precompute_kc.cpp` 用现有 microfacet.h 函数对单散射白炉做蒙特卡洛积分，生成 `include/shading/ggx_energy_lut.h`（E(μ,α) 32×32 LUT + E_avg(α) 32 表，自洽于渲染器本身的 G2 权重）。
2. **microfacet.h**：
   - `sampleGGXVndf`（Heitz 2018 Listing 1，y-up 适配，含视线下半球翻转）替换采样路径；
   - `vndfReflectionPdf` = G1(ωo)·D(h)/(4(ωo·n))（与旧 pdf 不同：权重换 G2/G1 形式）；
   - Kulla-Conty：`ggxE/ggxEAvg` LUT 查询（双线性）、`kcFavg`（Schlick 解析 F_avg=F0+(1−F0)/21）、`kcFms`、`kcCompensation(μi,μo,α,F0)` = F_ms(1−E(μi))(1−E(μo))/(π(1−E_avg))。
3. **bsdf.cpp / bsdf_device.h**：
   - 采样：VNDF 替换 D(n·h) 采样；反射权重 = F·G2/G1(ωo)（F 分叉时 = G2/G1）；透射权重同形 G2/G1(ωo)；pdf 换 VNDF pdf；
   - **补偿波瓣计入权重**（Frostbite 式）：weight += f_ms·μi·4·(ωo·n)/(G1(ωo)·D(h))——让采样路径真实携带补偿能量（仅评估加会丢路径能量）；
   - eval（NEE）：fs = F·spec + f_ms，pdf 换 VNDF pdf 保证 MIS 一致；金属 F0=复菲涅尔法向值，漫反射 F0=mix(0.04,ρ,m)，玻璃反射用介质 F0。
4. **测试升级**（microfacet_test）：
   - 白炉验收从 "energy ≤ 1" 升级为 "全 α energy ≈ 1 ± 2%"（含补偿权重）；
   - VNDF pdf 归一 ∫D_v dω=1；VNDF 高粗糙度方差对比断言（α=0.8，新旧各 1e5，方差显著下降）；
   - 互易性保持（Kulla-Conty 满足，Turquin 不满足——选 A 的理由）。
5. 全量重建 + 四模式 autotest + PT CPU 亮度回归。

## 进度与结论

### 实际做了什么

1. **LUT 离线生成**：`build/verify-models/precompute_kc.cpp` 用渲染器同源的 VNDF 采样 + G2/G1 权重对单散射白炉做蒙特卡洛积分，生成 `include/shading/ggx_energy_lut.h`（E(μ,α) 32×32 + E_avg(α) 32 表，MF_TABLE 宏双编译）。
2. **microfacet.h**：`sampleGGXVndf`（Heitz 2018 Listing 1 y-up 适配）、`vndfReflectionPdf`=G1(ωo)D/(4(ωo·n))、`vndfTransmissionPdf`、Kulla-Conty 全套（`ggxE/ggxEAvg` 双线性查询、`kcFavg`=F0+(1−F0)/21 解析、`kcFms`、`kcCompensation`）。
3. **bsdf.cpp / bsdf_device.h**：采样全换 VNDF；权重换 G2/G1(ωo) 形式（反射/透射同形）；**补偿波瓣随主瓣 pdf 计入采样权重**（f_ms·μi/p，Frostbite 式，保证路径真实携带补偿能量）；eval（NEE）加 f_ms 且 MIS pdf 同步换 VNDF；玻璃内部视线翻基处理。
4. **测试升级**：microfacet_test **44 断言全绿**——KC 补偿白炉全 α 0.9962–1.0030（±1%，优于文档 ±2% 目标）、VNDF 方差 0.136 vs 旧 0.747（5.5×）、VNDF/NDF 均值一致、补偿互易、玻璃白炉 0.977。
5. 全量重建 + 四模式 autotest exit 0 + PT CPU 亮度 1.66（补偿后粗糙墙面能量恢复，比 1.62 更亮为预期方向）。

### 试错记录（两次证伪，一次工具自误）

- ❌ VNDF y-up 适配叉积符号错：Heitz 原文 (z-up) `T2 = Vh × T1` 的法线分量 T2.z=+√lensq 恒正；y-up 同写法得 T2.y=−√lensq（右手定则取向相反）→ 采样出的 h 大量背向视线。修正为 `T2 = T1 × Vh`。**关键教训：跨坐标系的公式移植要先验证对称轴分量符号**。三方仲裁（NDF 采样 / VNDF 采样 / 修正后的 Simpson 求积）收敛到 0.05% 内确认修复。
- ❌ 初版 LUT 用坏采样器生成 → 数值自洽但物理错误（KC 白炉自洽无法暴露共享偏差）→ 修复采样器后必须重新生成 LUT。教训：**预计算表和采样器同源时，自洽测试测不出共享偏差，需要独立方法交叉验证**（本任务用 NDF 采样器 + Simpson 求积双仲裁）。
- ⚠️ 调试工具自身两处 bug：①"均匀采样"实为余弦采样配均匀归一化（4/3 偏差）；② Simpson 参数化 wi=(μcosφ,μ,μsinφ) 模长 √2μ 非单位向量。教训：仲裁工具也要被仲裁。
