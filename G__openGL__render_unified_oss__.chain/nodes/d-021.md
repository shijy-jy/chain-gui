# raster 与 app 层：CUDA-GL 显示与双后端装配

最上层的显示与装配概念：

- **Display（raster/）**：双 PBO 乒乓 + CUDA-GL interop；CPU 后端走 glTexSubImage2D、GPU 后端走 map→D2D memcpy→unmap；present = PBO 异步 DMA → 全屏四边形 + HUD；swapBuffers 分离给 ImGui
- **Application（app/）**：**双后端常驻状态机**——预览（光栅）与渲染（PT）同时存活，Start/Stop 只切活跃指针不重建（调参保留）；switchModel = 重建场景+双后端+调参回灌+自动取景；材质编辑 = 场景权威副本 + 三指针别名安全分发
- **UI**：菜单栏 + 卡片式面板（渲染/场景/材质/参数/调试）+ kUiZhTexts 字形白名单单一事实源 + 暗色主题 + DPI 缩放；调参暂存松手才写入
- **无头面**：`--autotest/--passes/--dump/--curve/--model/--visioncli/--comparecli` 协议 + 陈旧产物守卫（sizeof(Application) 双 TU 比对）+ crash_diag 符号化栈日志 + vision_judge 本地视觉引擎客户端

实现细节见归档 `.chain/archive/pre_v11_code_nodes/d-030.md` 与 t-030/t-031。
