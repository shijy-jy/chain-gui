> 触发：参考真值；512-pass 收敛曲线

# 要做什么

1. PT CPU 高 SPP 参考图：`--autotest 3 --passes 512 --dump benchmarks/reference` →
   `cornell_ptcpu_ref.pfm`（无偏帧平均，512 pass）+ reference_meta.json。
2. `--curve <ref.pfm>`：IRenderBackend::setConvergenceTarget（PT CPU 实现）——
   每 pass 结束对参考算 PSNR/rel_err（线性域、峰值=max(ref)、与 eval/compare.py
   同口径）追加 CSV（参考同目录 curve.csv）。
3. 配套：IRenderBackend::setPassBudget（totalPasses_ 默认 128 会截断 512 参考图）；
   autotest quit 后当轮跳过渲染（否则 dump/CSV 后多渲一帧 → pass 计数 +1）。

# 验收

- 参考图 512 pass 落盘 ✓（ptcpu_stats.log 终行 pass=512）
- curve.csv 64 行数据（header + 64，与 --passes 64 严格一致）✓
- 收敛单调合理：PSNR 31.9dB(1p) → 52.9dB(65p)? 实测 1..64:
  PSNR 31.88 → 52.74dB 单调上升趋平，rel_err 0.57 → 0.085 ✓（log 坐标近似线性 = 无偏收敛）
- 修复过程：--passes N 实测 N+1 pass（quit 后当轮仍渲染）→ autotestQuit_ 提前 continue；
  512 参考被 totalPasses_=128 截断 → setPassBudget
