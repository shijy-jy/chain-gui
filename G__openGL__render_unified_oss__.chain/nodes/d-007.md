# 模式四 vs RESTRI 学习版：为什么"简化版"观感更好

> 用户问题：`G:\deepseek\RESTRI`（从本工程模式四脚手架出的单模式学习渲染器，Step 1 纯渐进 PT）
> 观感上各方面优于模式四。本文逐项对比两份源码后给出结论与改进清单。

## 1. 关系定位

RESTRI = 模式四 t-005 时代内核的干净拷贝（README 自述 scaffolded from mode 4）+ 三个新 kernel：
`ptRadianceKernel`（1 SPP/帧）→ `ptAccumulateKernel`（**精确帧平均**）→ `packColorToRGBA8Kernel`。
无任何降噪栈；它的链目标（g-001）是学 ReSTIR DI/GI，Step 1 是"ground truth 基线"。

## 2. 逐项对比（源码级核对）

| 维度 | RESTRI Step 1 | 模式四 (当前源码) | 差异影响 |
|---|---|---|---|
| 采样 | 蓝噪声 64×64 + Murmur3 帧偏移 | 同源完全相同 | 无 |
| 相机抖动 | 蓝噪声 NDC 抖动 | 同 | 无 |
| BVH/求交/遮挡 | 显式栈 + 发射面快速路径 | 同 | 无 |
| 玻璃阴影射线 | `bvhOccludedGlassTransparent` 跳过玻璃 | `bvhOccluded` [t-018] 同样跳过玻璃 | 无（已对齐） |
| NEE+MIS | 面积采样 + power heuristic，**漫反射专属** | 三类材质都做（t-009）+ 同 MIS | 模式四更强 |
| 材质 | 旧版：金属=理想镜面复菲涅尔、玻璃=光滑 Snell、漫反射=Lambert；etaScale 只进 RR 不进 L | 新版（t-009/t-010）：GGX/VNDF 粗糙金属与粗糙透射 + Kulla-Conty 补偿 + etaScale 修正 | 模式四物理正确性领先；观感上金属/玻璃近镜面时相似 |
| **累积策略** | **精确帧平均 acc=(acc·(N−1)+cur)/N，N 无上限 → 静态收敛到零噪声** | 时序重投影 EMA α=0.1（历史权重 90%）→ **噪声地板 ≈ 1/α·… ≈ 19 spp 等效，永不收敛** | **观感差距的最大来源** |
| 空间降噪 | 无 | a-trous 3 遍（colorPhi=1.0/varFloor=1.0/centerW=2.0） | 模式四高光/阴影边缘被平滑，静态画面有低频残留噪声 |
| 时域伪影 | 无 | EMA+SVGF 颜色钳制：相机静止后残留 ghost/滞后；相机移动时清历史 → 突然回到 1SPP 噪声 | 模式四观感"跳变+糊" |
| 分辨率 | 全分辨率 | 全分辨率（半分辨率缓冲仅 OptiX 关闭路径） | 无 |
| 色调映射 | exposure 0.60 → clamp → γ2.2 | 同（0.60 标定同源） | 无 |
| maxDepth | 面板可调 | 固定 8 | 小 |
| 调参面板 | exposure/maxDepth/accum 三件 | 11 项 tune + 材质面板 | 模式四丰富 |

## 3. 结论：为什么简化版观感更好

1. **累积策略是决定性差异**：RESTRI 的帧平均方差 ∝ 1/N；模式四 EMA(α=0.1) 的方差有
   α/(2−α)≈5.3% 的**噪声地板**（等效 ~19 spp），静态多久都残留噪声。
2. **模式四的降噪栈是为"相机移动中的实时 1SPP"设计的**（时序+SVGF 钳制+a-trous），
   副作用是：静态残留低频噪声、a-trous 糊掉高光与接触阴影、移动后清历史导致噪声跳变。
   RESTRI 没有任何这类副作用——观感"干净、锐利、诚实"。
3. 其余管线（蓝噪声、NEE+MIS、色调、玻璃阴影）两份**同源等价**，不是差距来源。
4. 模式四的物理材质（t-009/t-010）已领先 RESTRI（GGX 粗糙金属/粗糙透射/KC 补偿/
   etaScale 修正）；RESTRI 仍是旧平滑镜面+光滑折射。若用户 VS 构建未重建，看到的还是旧材质。

## 4. 模式四改进清单（按性价比）

1. **加"参考累积模式"**（强烈建议，成本低）：移植 RESTRI 的 `ptAccumulateKernel` 思路——
   面板加 accum 开关，ON 时显示 `(N−1)/N 平均`（相机/材质变化时重置 N），绕过时序+a-trous；
   OFF 保持现有实时降噪路径。两种模式并存，互不干扰。
2. 时序参数可调：α 从 0.1 调 0.05~0.2 区间暴露到面板（现有 11 参数里已有 alpha，确认其生效范围）。
3. a-trous 加"关闭"开关，便于 A/B 对比定位糊的来源。
4. 相机移动时不清空历史、改走"快速重收敛"（α 临时加大）——现有实现移动即清，观感跳变。
5. 验收：静态 60 帧后，accum 模式应与 RESTRI 同级（干净无残留噪声），且保留模式四的物理材质优势。

## 5. 边界声明

- RESTRI 的 etaScale 同样只进俄罗斯轮盘不进 L（与 t-009 前的模式四相同简化）；
  其玻璃无粗糙透射/无 KC 补偿——这些是它作为"学习基线"的定位，不是它的优点。
- 本对比不改变双方代码，RESTRI 目录只读。
