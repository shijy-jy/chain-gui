## 1. 微表面理论与 Cook-Torrance 的推导

### 1.1 微表面假设

宏观表面 = 无数微小镜面的集合。微平面法线 $m$ 的分布用**法线分布函数（NDF）** $D(m)$ 描述（单位：1/sr）：
$$\int_{H^2} D(m)\,(n\cdot m)\,d\omega_m = 1$$
即投影到宏观面积上的微面面积之和 = 宏观面积。**GGX / Trowbridge-Reitz NDF**（由"可见法线分布"推导，Walter 2007 §5.2 指出 GGX 形状来自 Trowbridge-Reitz 1965 的微面斜率分布）：
$$D(m)=\frac{\alpha^2}{\pi\left((n\cdot m)^2(\alpha^2-1)+1\right)^2},\qquad \alpha=\text{roughness}^2$$
$\alpha=\text{roughness}^2$ 是 Disney/UE4 的感知线性重映射（粗糙度滑条在感知空间均匀）。

### 1.2 从微面求和到 Cook-Torrance

对反射，只有法线 $m=h$（**半向量** $h=\operatorname{norm}(\omega_i+\omega_o)$）的微面把 $\omega_i$ 反射到 $\omega_o$。由 $D$、**遮蔽-阴影函数** $G$（见 §1.3）与菲涅尔 $F$，镜面 BRDF 为（Cook-Torrance 1982）：
$$f_s(\omega_i,\omega_o)=\frac{D(h)\,G(\omega_i,\omega_o)\,F(\omega_i\cdot h)}{4\,(n\cdot\omega_i)\,(n\cdot\omega_o)}$$
分母 $4(n\cdot i)(n\cdot o)$ 来自"反射方向立体角 → 半向量立体角"的 Jacobian：$d\omega_h/d\omega_o = 1/(4(h\cdot\omega_o))$，以及微面投影因子。完整推导链：
1. 微面出射通量 $d\Phi = L_i\,D\,G\,F\,(m\cdot\omega_i)\,d\omega_i\,dA\,d\omega_m$（只算朝向 $m=h$ 的微面）；
2. $d\omega_m = d\omega_o/(4(m\cdot\omega_o))$（反射的立体角变换）；
3. $f_s = dL_o/dE_i$，代入并整理得上式。

### 1.3 Smith 遮蔽函数（Heitz 2014 的物理推导）

$G$ 描述微面互相遮挡。Smith 1967 假设微面高度与法线独立，把问题化为沿视线的一维高度场：
- 遮蔽（masking）沿 $\omega_o$：比例 $G_1(\omega_o)=\frac{1}{1+\Lambda(\omega_o)}$，
- 联合遮蔽-阴影（高度相关，Heitz 推荐的物理形式）：
$$G(\omega_i,\omega_o)=\frac{1}{1+\Lambda(\omega_i)+\Lambda(\omega_o)},\qquad
\Lambda(v)=\frac{-1+\sqrt{1+\alpha^2\tan^2\theta_v}}{2}$$
$\Lambda$ 是"可见高度分布"的指数尾（高度差超过 $\Delta h$ 的概率积分），对 GGX 的斜率分布可闭式解出上式。
（可分离形式 $G=G_1(i)G_1(o)$ 与高度相关形式的对比如 Heitz 2014 Fig.4；本工程用**高度相关**形式。）

### 1.4 菲涅尔

**电介质（从麦克斯韦边界条件）**，入射角 $\theta_i$、折射角 $\theta_t$（Snell：$\eta_i\sin\theta_i=\eta_o\sin\theta_t$）：
$$r_\parallel=\frac{\eta_o\cos\theta_i-\eta_i\cos\theta_t}{\eta_o\cos\theta_i+\eta_i\cos\theta_t},\quad
r_\perp=\frac{\eta_i\cos\theta_i-\eta_o\cos\theta_t}{\eta_i\cos\theta_i+\eta_o\cos\theta_t},\quad
F=\frac{r_\parallel^2+r_\perp^2}{2}$$
$\sin^2\theta_i>1$ 时全内反射 $F=1$。
**Schlick 近似**（反射率单调、可快速求值）：$F=F_0+(1-F_0)(1-\cos\theta)^5$，法向反射率 $F_0=\left(\frac{\eta_i-\eta_o}{\eta_i+\eta_o}\right)^2$；对电介质 $F_0\approx0.04$（η≈1.5）。金属工作流（glTF/Disney）：$F_0=\operatorname{mix}(0.04,\ \rho,\ \text{metallic})$。
**导体（复折射率 $\tilde\eta=n+i\kappa$）**：把 $\eta$ 换成复数，$F=\tfrac12(|r_\parallel|^2+|r_\perp|^2)$——金属的颜色来自 $n,\kappa$ 随波长变化（代码逐通道复数运算，d-004 §3.3 已有，保留）。

### 1.5 粗糙透射 BTDF（Walter et al. 2007）

透射时微面法线 $m=h_t$ 满足广义 Snell（对 $h_t$ 而非几何法线）：
$$\eta_i\,|\omega_i\times h_t|=\eta_o\,|\omega_o\times h_t|$$
BTDF（Walter 2007 式 21，含立体角 Jacobian $\eta_o^2$ 项）：
$$f_t(\omega_i,\omega_o)=\frac{|i\cdot h|\,|o\cdot h|}{|i\cdot n|\,|o\cdot n|}\cdot\frac{\eta_o^2\,(1-F)\,D(h)\,G(i,o)}{\left(\eta_i(i\cdot h)+\eta_o(o\cdot h)\right)^2}$$
$\eta_o^2$ 是折射对立体角的压缩（能量经 $\eta^2$ 因子守恒——这正是 d-004 §3.4 的 etaScale 的物理来源）。
折射方向（Walter 式 14，绕 $h$ 折射）：
$$\omega_i=-\eta\,\omega_o+\left(\eta(\omega_o\cdot h)-\sqrt{1-\eta^2(1-(\omega_o\cdot h)^2)}\right)h,\qquad \eta=\frac{\eta_i}{\eta_o}$$

## 2. 采样与权重（重要性采样 + 概率选择，无偏性推导）

### 2.1 GGX 半向量采样

按 $D(h)(n\cdot h)$ 采样 $h$（Walter 2007 附录；VNDF 采样 Heitz 2018 是更低方差的进阶，暂不引入）：
$$\phi=2\pi\xi_1,\qquad \cos\theta_h=\sqrt{\frac{1-\xi_2}{1+(\alpha^2-1)\xi_2}},\qquad p(h)=D(h)(n\cdot h)$$
反射方向 $\omega_i=2(h\cdot\omega_o)h-\omega_o$，其立体角 PDF：
$$p(\omega_i)=p(h)\left|\frac{d\omega_h}{d\omega_i}\right|=\frac{D(h)(n\cdot h)}{4(h\cdot\omega_o)}$$

### 2.2 权重推导（bsdf·cos / pdf 的精确结果）

反射（以概率 $F$ 选择反射分支时）：
$$\frac{f_s\,(n\cdot i)}{F\,p(\omega_i)}=\frac{D\,G\,F/(4(n\cdot o))}{F\,D(n\cdot h)/(4(h\cdot o))}=\frac{G\,(h\cdot\omega_o)}{(n\cdot\omega_o)(n\cdot h)}$$
透射（以概率 $1-F$ 选择透射分支时）：
$$\frac{f_t\,|i\cdot n|}{(1-F)\,p(\omega_i)}=\frac{G\,|i\cdot h|}{(n\cdot\omega_o)\,(n\cdot h)}$$
$F$ 恰好消去——这是"按物理概率分叉"的方差红利（d-004 §3.4 的俄罗斯轮盘思路的一般化）。
漫反射+镜面瓣 50/50 分裂（概率 0.5，两分支都加）：漫反射权重 $2\rho(1-F(\theta_o))$，镜面权重 $2GF(h\cdot o)/((n\cdot o)(n\cdot h))$。

### 2.3 NEE + MIS

对光源采样的方向 $\omega_i$，用解析 PDF 求 MIS（power heuristic，d-004 §3.5 已有框架）：
- 反射类：$p(\omega_i)=D(n\cdot h)/(4(h\cdot\omega_o))$（金属、漫反射 0.5 混合、玻璃反射乘 F）
- 漫反射类总 PDF = $0.5\,(n\cdot i)/\pi + 0.5\,D(n\cdot h)/(4(h\cdot o))$
- 玻璃透射的 NEE 暂不采样（BSDF 采样已无偏覆盖，仅方差略高）——如实记录。

## 6. 着色模型抽象：预留 PBR/NPR 切换接口（衔接 d-003 路线 C）

用户明确未来要学 NPR（toon），要求现在预留 PBR/NPR 切换接口。设计：

- `include/shading/bsdf.h` 定义 `enum class ShadingModel { PBR, NPR }` 与三个纯接口结构：
  - `BsdfQuery{ model, Material, n, wo }`（求值上下文）
  - `BsdfEval{ f, pdf }`（NEE 求值：给定 wi 返回 f(wi,wo) 与 pdf，供 MIS）
  - `BsdfSample{ wi, weight, pdf, specular, transmitted, etaScaleFactor }`（采样：返回新方向与无偏权重）
- **追踪循环/光栅循环只认接口，不认具体模型**。PBR（Cook-Torrance/GGX，本文 §1-§2）是第一个实现 `pbr_bsdf.cpp`；NPR toon 将来作为第二个实现挂进同一个 switch，UI 加一个 PBR/NPR 单选即可。
- 切换 plumbing 现在打通：`Application::shadingModel_` → `IRenderBackend::setShadingModel()`（虚接口，四后端）→ CPU 查询上下文 / GPU 设备常量。默认 PBR；NPR 槽位在实现前返回 PBR 并打日志（不暴露 UI，避免假功能——路线 C 落地时再加 UI）。
- 接口对 NPR 的表达力：toon 的"朝向主光离散色阶"在 NEE 路径天然可做（eval 按 wi 与主光夹角分阶）；BSDF 采样可偏向光源方向（权重随策略 pdf 变化，无偏性由实现者负责）。MIS 的 power heuristic 对非物理模型同样适用（只是 pdf 语义变为"该策略的采样密度"）。
- GPU 侧镜像 `include/shading/bsdf_device.h`（`__device__` 内联，同 enum 语义），PT GPU 与光栅 GPU 走同一份 `microfacet.h` 标量数学，避免公式漂移。

## 8. 剩余近似（如实记录，防止"完整版"变谎言）

1. **GGX 单次散射在高粗糙度下能量损失**（Smith G 只算一次散射；真实表面多次散射）。补偿 = Kulla-Conty 2017；本版先不做，d-006 记录，单元测试用"能量 ≤ 1"断言守住不超能量。
2. 半向量采样用 $D(h)(n\cdot h)$ 而非 VNDF（Heitz 2018）——无偏但粗糙表面方差更大。
3. 玻璃无体积吸收（Beer-Lambert）与色散；baseColor 染色保持 v1 近似。
4. 光栅端玻璃无透射（预览近似）、面光源 0.05 几何系数（光栅 hack）不变。
5. ReSTIR 关闭路径（enable_restir_=false 默认）里的镜面次生路径保持旧理想镜面逻辑，重开 ReSTIR 前需镜像新 BSDF（见 t-009 备注）。

2. PT CPU/GPU 与光栅四后端编译通过，四模式 autotest exit 0 无 NaN。
