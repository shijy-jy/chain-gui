# PT CPU（模式 3）质量排查与修复（用户反馈：128 SPP 未达预期效果）

## 排查结论（三个真实问题）

1. **漫反射 50/50 分裂浪费样本**（t-009 引入，d-006 §2.2 的原设计）：墙面 F0=0.04，GGX 镜面瓣只携带 ~4% 能量却分走 50% 样本 → 128 SPP 的漫反射有效样本 ≈ 64 SPP，比旧版纯 Lambert 更噪。修法：按能量比例分支——`p_spec = clamp(F_avg(F0), 0.02, 0.98)`（F_avg = F0+(1−F0)/21，Schlick 平均菲涅尔），低 F0 材质镜面瓣只拿 ~8% 样本；权重与 MIS pdf 同步换算（`weight/p_s`、`pdf = p_s·p_spec + (1−p_s)·p_diffuse`）。
2. **maxDepth_=5 + RR@2 截断偏差**：间接光（角落、阴影区）系统性偏暗，且不可由样本数修复。修法：maxDepth_ 5 → 8（与 PT GPU 一致）。
3. 模式三墙面为 sRGB 解码标定色（0.722 vs GPU 0.85），系 BL-20260816-04 有意的参考图对齐，非 bug——在结论中向用户说明。

## 改动面

- `src/shading/bsdf.cpp` + `include/shading/bsdf_device.h`：漫反射分支 `p_spec` 概率分裂（CPU/GPU 镜像同式，`kcFavg` 复用）。
- `include/backends/path_trace_cpu_backend.h`：maxDepth_ 5 → 8。
- 测试：microfacet_test 全绿（漫反射白炉用均匀求积不受影响）；PT CPU 完成时亮度上升为预期（更多间接光）；四模式 autotest 回归。

## 验收标准

1. 单元测试与 model_test 全绿。
2. 四模式 autotest exit 0；PT CPU 亮度合理（预计 1.66 → ~1.7+，间接光恢复）。
3. 视觉验收（用户）：128 SPP 墙面噪声应显著低于修复前（有效样本翻倍），角落变亮。

## 进度与结论

### 实际做了什么

1. **能量比例分支分裂**（bsdf.cpp + bsdf_device.h 镜像同式）：漫反射类分支概率从 50/50 改为
   `p_s = clamp(F_avg(F0), 0.02, 0.98)`（F_avg = F0+(1−F0)/21，Schlick 平均菲涅尔）。
   权重与 pdf 同步换算：余弦分支 `(1−F)ρ/(1−p_s)`、镜面分支 `(…)/p_s`、
   MIS pdf = `(1−p_s)·μi/π + p_s·vndfPdf`。F0=0.04 墙面镜面瓣样本占比 50% → ~8.6%，
   有效漫反射样本 ≈ 翻倍。
2. **maxDepth 5 → 8**（path_trace_cpu_backend.h，与 PT GPU 一致）：修复间接光截断偏差。

### 验证

- 全量重建通过；microfacet_test 44 断言全绿；model_test 全绿。
- 四模式 autotest exit 0；PT CPU 平均亮度 1.647 稳定（无 NaN/过曝恶化）。
- 视觉验收（用户）：128 SPP 墙面噪声应显著下降（有效样本翻倍），角落变亮。

### 用户问题的直接答案（帧间累积策略）

- **模式 3（PT CPU）= 精确帧平均（Box Average）**：`accum += cur; display = accum/N`，
  方差 ∝ 1/N，静止收敛到零噪声——**最优策略，不是问题所在**。
- **模式 4（PT GPU）= EMA（α=0.1）**：`out = α·cur + (1−α)·hist`，方差有噪声地板
  α/(2−α) ≈ 5.3%（等效 ~19 SPP）——这才是"累积策略拖后腿"的模式（见 d-007，
  RESTRI 用帧平均所以观感更好）。若用户想在模式四也获得帧平均质量，d-007 §4 的
  "参考累积模式"开关是下一项工作。
